跨 境 支 付 ・ 金 融 基 礎 設 施

SWIFT知識圖譜

俄烏戰爭之後，「把某國踢出 SWIFT」成了新聞常用語，也讓很多人以為 SWIFT 是一套由美國掌控的國際清算系統。這兩件事其實都不太對——SWIFT 是一家設在比利時、由全球會員銀行共同持有的合作社，而且它根本不搬錢，只負責傳話。這份圖譜要梳理的，就是報文、清算、結算三件事怎麼分工，錢究竟是怎麼跨境移動的，以及「斷開 SWIFT」到底切斷了什麼、又切不斷什麼。

閱讀提示
本頁刻意把「報文」與「清算」分開講，因為這是最常見的誤解來源。文中的機構數、報文量等數據為近年概略規模，各家統計口徑略有出入；制裁相關內容以公開的歐盟法規與 SWIFT 官方聲明為準，僅描述機制，不評價任何一方的立場。

SWIFT 到底是什麼——傳話的，不是搬錢的

一筆跨境匯款要走三層，SWIFT 只負責最上面那一層

一個簡單的類比SWIFT 之於跨境匯款，比較像掛號信與郵政系統之於一紙支票——它保證那張指令安全、格式正確、送到對的收件人手上，但支票能不能兌現、錢從哪個帳戶扣，完全是另一回事。
規模的意義在於網路效應目前約有 200 多個國家與地區、逾一萬一千家金融機構接在這張網上，日均報文量以千萬則計。它的價值不在技術多先進，而在「大家都在上面」——這也是替代系統最難跨越的門檻。
它是合作社，不是公司SWIFT 由會員金融機構共同持有，採合作社形式運作，理論上不以營利為目的；董事會席次依各國報文使用量分配，使用量大的國家席次較多。

一筆跨境匯款怎麼走——代理行與往來帳戶

兩家素不相識的銀行，靠一條「誰在誰那裡開戶」的鏈條把錢接上

MT103 與 MT202 的差別MT103 是「客戶匯款」，最終受益人是個人或企業；MT202 是「銀行間資金調撥」，兩端都是金融機構。一筆零售匯款背後，常常同時跑著這兩種報文。
正在換一套語言：ISO 20022沿用數十年的 MT 格式正逐步汰換為結構化的 ISO 20022（MX）訊息，可攜帶更豐富的付款資訊，有助於制裁篩查與自動對帳。遷移採共存期分階段進行，是近年跨境支付最大的基礎工程。
BIC 就是俗稱的 SWIFT Code八碼或十一碼，依序是銀行代碼、國別、地區與分行。它是這張網路上的地址，讓報文知道該送到哪個機構。

誰能決定切斷誰——治理結構與制裁機制

SWIFT 自己並不想當裁判，但它註冊在比利時，就得守歐盟的法律

「金融核武」這個說法要打折斷線確實痛，但它不像核武那樣一擊致命。被切斷的機構仍可透過未受制裁的第三方銀行、其他報文管道或替代系統迂迴，代價是更慢、更貴、更難稽核——是持續放血，不是瞬間死亡。
用得愈多，反彈愈大每一次動用，都在提醒其他國家「這條管道可能被拿來當武器」，因而加速替代系統的投資。這是制裁工具的內在矛盾：威懾力來自不常用，而每次使用都會削弱下一次的威懾力。
SWIFT 自己的立場一向被動官方多次聲明自己是中立的公用事業，斷線是遵守法律義務而非自主決策。這既是事實，也是它在地緣政治夾縫中保護自身正當性的必要姿態。

替代系統的競賽——為什麼取代不了

技術上複製一套報文網路並不難，難的是讓全世界都接上去

核心概念

KEY CONCEPTS
報文網路Messaging Network

SWIFT 的本質。傳送格式標準化、經加密與驗證的付款指令，確保收送雙方對「誰付誰多少錢」有一致且可稽核的紀錄，但本身不涉及資金移動。

代理行關係Correspondent Banking

兩家沒有直接帳戶關係的銀行，透過雙方都有往來的第三家銀行完成資金移轉。這是跨境支付的實際骨架，也是手續費與延遲的主要來源。

Nostro / Vostro 帳戶

同一個往來帳戶的兩種視角：從開戶方看是 nostro（我們存在你那裡的），從受託方看是 vostro（你們存在我這裡的）。兩邊各記一本帳，靠報文核對。

BICBank Identifier Code

俗稱 SWIFT Code，八碼或十一碼，依序標示銀行、國別、地區與分行，是這張網路上的收件地址。

常見報文類型

MESSAGE TYPES
MT103客戶匯款

最終受益人是個人或企業的單筆匯款指令，載明金額、幣別、收付雙方與費用分攤方式，是一般人跨境匯款時背後跑的報文。

MT202銀行間調撥

兩端都是金融機構的資金移轉，常用於支應代理行往來帳戶的部位。一筆零售匯款背後往往同時觸發 MT103 與 MT202。

MT940 / MT950帳戶報表

對帳用的日終或期間報表，讓持有 nostro 帳戶的銀行核對餘額與交易明細是否與對方記載一致。

ISO 20022（MX）新一代標準

結構化的 XML 報文格式，可攜帶遠比 MT 豐富的付款資訊，有利自動化對帳與制裁篩查。跨境支付正以共存期方式分階段遷移。

相關清算與替代系統

CLEARING & ALTERNATIVES
Fedwire / CHIPS美國

美元的兩大清算管道：Fedwire 為聯準會經營的即時全額結算系統，CHIPS 為民營的淨額清算系統。美國對美元交易的影響力主要來自這一層。

TARGET2歐元區

歐洲央行體系經營的歐元即時全額結算系統，歐元區跨國支付的最終結算都在此完成。

CIPS中國・2015

人民幣跨境支付系統，屬清算層而非報文層。雖具備自有報文能力，實務上大量交易仍是「SWIFT 傳訊息、CIPS 清人民幣」。

SPFS俄羅斯・2014 後

克里米亞事件後為防範斷線而建立的報文系統。境內運作正常，但境外參與者有限，第三國機構多因擔心次級制裁而保持距離。

關鍵事件

TIMELINE
創立1973

15 國 239 家銀行共同成立，目的是取代當時容易出錯、格式不一的 Telex 電報，建立一套標準化的銀行間報文語言。

首次用於制裁2012

歐盟制裁架構下切斷伊朗多家銀行，是 SWIFT 史上第一次因政治決定而排除特定國家的機構，也自此讓它進入地緣政治的視野。

俄羅斯部分斷線2022

俄烏戰爭後歐盟分批排除多家俄國銀行，但刻意保留部分涉及能源結算者，顯示制裁設計必須同時考慮發動方自身的經濟依賴。

ISO 20022 遷移2023 起

跨境支付報文開始由 MT 格式轉向 ISO 20022，採共存期分階段推進，是這套基礎設施數十年來最大規模的一次改版。

我們是一家中立的全球合作社，依據所在地法律運作。 SWIFT 在歷次制裁爭議中反覆重申的立場。這句話同時說明了它的兩種身分——技術上它確實只是傳話者、對報文內容不作判斷；但它註冊在比利時，也就無可避免地隨著歐盟的政治決定而行動。所謂中立，指的是不主動選邊，而非能夠置身事外。
機構數、報文量等為近年概略規模，各家統計口徑與時點略有差異；制裁範圍與名單隨法規調整而變動，本頁僅說明機制與結構，不構成對任何一方立場的評價，也不作為實務操作依據。
