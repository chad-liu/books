古印度・梵我與解脫

《奧義書》學習藍圖

《奧義書》（Upaniṣad）是理解古印度思想、印度教、佛教乃至整個印度哲學史的關鍵。如果把前面「古印度雅利安文化」接下來，《奧義書》正好處在「吠陀祭祀文化 → 《奧義書》哲學 → 沙門運動 → 佛教」這個轉折點上。

一、先用一句話掌握《奧義書》

《奧義書》把古印度思想的重心，從「如何正確祭祀神明」逐漸轉向「我是誰？宇宙的根本是什麼？為何會輪迴？如何得到解脫？」

因此，它是印度哲學從祭祀宗教 → 形上學、心性論、解脫論的重要轉折。

二、《奧義書》是什麼？

「Upaniṣad」通常音譯奧義書，也有人譯為近侍、密教、奧秘教義。它不是一本書，而是一大批古印度哲學性文獻的總稱。

傳統上有大量《奧義書》，其中比較重要的早期《奧義書》包括：

  • 《廣林奧義書》（Bṛhadāraṇyaka Upaniṣad）
  • 《歌者奧義書》（Chāndogya Upaniṣad）
  • 《他氏奧義書》／《愛多雷耶奧義書》（Aitareya Upaniṣad）
  • 《伽陀奧義書》（Kaṭha Upaniṣad）
  • 《自在奧義書》（Īśa Upaniṣad）
  • 《由誰奧義書》（Kena Upaniṣad）
  • 《剃髮奧義書》（Muṇḍaka）
  • 《疑問奧義書》（Praśna）
  • 《曼都迦奧義書》（Māṇḍūkya）

原稿的清單把《由誰奧義書》（Kena）列了兩次，並且分別以「他氏」與「愛多雷耶」兩個譯名列出同一部 Aitareya Upaniṣad。本頁各保留一筆並把兩個譯名並列，未增加也未刪去任何一部經。

其中：《廣林奧義書》與《歌者奧義書》尤其重要。

四、《奧義書》究竟在問什麼？

如果把它濃縮成五個大問題：① 我是誰？（Ātman）② 世界的根本是什麼？（Brahman）③ 為什麼人會一直生死流轉？（Saṃsāra）④ 為什麼會輪迴？（Karma）⑤ 如何停止輪迴？（Mokṣa）。因此：

這五個概念就是理解《奧義書》的核心。

五、第一核心：「梵」Brahman

中文通常譯梵。它不是一個普通的神，這點非常重要。

早期吠陀文化中有很多神——因陀羅、阿耆尼、蘇摩、伐樓那、蘇利耶——但是《奧義書》開始追問：這些神背後有沒有一個更根本的實在？於是逐漸發展出 Brahman，可以粗略理解為宇宙的根本實在、最高原理、終極真實。

但不同《奧義書》對它的描述並不完全一致。所以不要簡單把「梵」理解成「一位創造世界的神」，它更接近印度哲學中的終極實在／宇宙根本原理。

六、第二核心：「我」Ātman

中文作我、我體、自我、真我。《奧義書》開始追問：我現在看到的這個「我」，到底是不是我的真正本質？例如：

那麼問題就是：哪一個才是真正的我？《奧義書》的某些重要思想認為：真正的 Ātman 並不是短暫變化的身體、感覺或思想。

七、最重要的思想：「梵我一如」

這是後來印度哲學最著名的思想之一：Ātman ≈ Brahman，即個體最深層的真我，與宇宙最高實在具有根本一致性。

後來常用一句非常著名的表述：Tat Tvam Asi，中文通常譯「汝即彼」——也就是：你，就是那個終極實在。這句話在印度哲學史上非常重要。

九、但是：不能把所有《奧義書》都簡化成「梵我一如」

這是學習時很重要的注意事項。《奧義書》並不是一套完全統一的哲學系統。不同文本有不同說法：有的強調梵、有的強調我、有的談宇宙生成、有的談禪定、有的談死亡、有的談業與輪迴，有的甚至採取否定式描述。

十、「否定法」：Neti Neti

《廣林奧義書》中有一個非常重要的思想 Neti Neti，通常譯「非此，非此」。

意思不是「什麼都不存在」，而是：不能用任何有限、具體的概念完全界定終極實在。

十二、第四核心：輪迴 Saṃsāra

如果人死亡後還會再生——生 → 死 → 生 → 死 → ……這就是 Saṃsāra，中文作輪迴、生死流轉。

於是《奧義書》出現一個非常重要的問題：如果輪迴無止境，那麼真正的幸福是不是不可能靠世俗生活得到？因此解脫開始成為最終目標。

十四、《奧義書》與佛教最重要的共同點

佛陀時代的印度思想世界，已經存在：業、輪迴、解脫、禪定、出家、苦、生死、修行。

因此佛教並不是突然創造這些問題。佛教真正特殊之處在於：它重新定義了「我是誰」以及「如何解脫」。

十六、佛教其實對《奧義書》的問題做了「重新設計」

例如《奧義書》問「真正的我在哪裡？」，佛教回答：先觀察五蘊。

然後逐一觀察：它們是不是永恆？不是。能不能完全自主？不能。能不能說「這就是永恆的我」？不能。於是：五蘊無常 → 五蘊苦 → 五蘊無我。這就是佛教的重大思想轉向。

十八、《奧義書》與「禪修」

《奧義書》並不只是哲學討論，它也涉及冥想、禪定、呼吸、感官控制、心的集中、自我觀察。例如《伽陀奧義書》著名地使用「戰車譬喻」，可以理解為：

如果感官失控，馬就會亂跑；如果理智控制良好，戰車就朝正確方向前進。這種「控制心與感官」的思想，對後來印度瑜伽傳統影響很大。

十九、《奧義書》與「瑜伽」

這也可以與前面學過的《瑜伽師地論》形成一個非常有意思的比較。《奧義書》比較重視認識真我、終極實在、禪定與解脫；佛教瑜伽／《瑜伽師地論》則進一步發展心識分析 → 禪定 → 止觀 → 智慧 → 菩薩道 → 解脫。

所以：印度的「瑜伽」並不是佛教獨有。佛教吸收了古印度禪修文化中的一些方法，但重新放入無我、緣起、四聖諦的框架中。

二十、《奧義書》→ 佛教，可以怎麼理解？

最好的方式不是「佛教直接從《奧義書》發展出來」，而是：佛教與《奧義書》共同處於古印度宗教與思想轉型的環境中，彼此面對許多相同問題，但提出不同答案。

二十一、《奧義書》對後世印度思想的影響

影響非常深遠。後來印度哲學的重要傳統幾乎都必須面對：梵是什麼？我到底是什麼？世界是真實還是假象？如何解脫？

例如吠檀多 Vedānta尤其重視《奧義書》，後來形成不二論、有神論吠檀多、二元論吠檀多等。其中最著名的是商羯羅 Śaṅkara，強調梵是真實，個體我與梵具有根本一致性。

二十四、最值得記住的「思想轉折」

整個古印度思想史可以用一條線記憶：

神 → 祭祀 → 秩序 → 梵 → 我 → 業 → 輪迴 → 解脫 → 無我 → 緣起 → 空

但是要注意，這不是一條「舊思想被新思想完全取代」的直線。更準確地說，是：不同思想傳統同時發展、互相辯論、互相吸收與重新詮釋。
