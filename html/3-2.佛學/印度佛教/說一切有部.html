Sarvāstivāda

說一切有部

「三世諸法皆有」的阿毘達磨思想體系。把前面的佛學思想史接起來——佛陀 →《阿含經》→ 部派佛教 → 說一切有部 → 阿毘達磨 →《大毘婆沙論》→《俱舍論》→ 中觀／唯識——說一切有部是理解印度佛教「阿毘達磨化」最重要的一個節點。

它最大的特色
過去、現在、未來的一切法，皆以某種方式「存在」。這就是「三世實有」／Sarvam asti（說一切有）。
但「三世實有」絕對不能簡單理解成「過去、現在、未來的一切東西，都像桌子一樣真實存在」。它是一個非常精細的法體、時間、因果與認識論問題。
關於本頁
原稿以文字樹狀圖呈現各層架構，本頁改繪為 SVG，共二十三張，圖塊與 SVG 一一對應，節點、層級與箭頭方向依原稿，未增補也未省略。
原稿在判斷上相當克制——三世的法不是以完全相同的方式存在、「法體恆有，三世遷流」是後人的概括而非有部論師一致的表述、有部並不主張永恆的我、不要把阿賴耶識放進有部、《俱舍論》不是單純的有部教科書、中觀不是憑空出現——這些保留都以淡色區塊完整保留，不予簡化。

一、什麼是「說一切有部」？

梵文 Sarvāstivāda，可拆成：

  • sarva = 一切
  • asti = 存在
  • vāda = 學說

所以字面上是「主張一切存在的學派」，中文稱說一切有部，簡稱有部。它是印度部派佛教中極重要的一個學派，尤其以阿毘達磨（Abhidharma）的系統化著稱。

三、為什麼會出現說一切有部？

佛陀時代的教法主要是如何離苦、如何修行、如何證涅槃。例如《阿含經》大量討論五蘊、六處、十二因緣、四聖諦、八正道、禪定、戒律、無我。

但是佛教僧團逐漸發展後，開始產生另一類問題：「五蘊究竟可以怎麼分析？」例如：

  • 色是什麼？受是什麼？想與行有什麼差別？
  • 心是什麼？心所是什麼？
  • 善法與不善法如何分類？煩惱如何存在？
  • 業如何產生果報？
  • 過去的業已經消失了，為什麼現在還能產生果報？

於是佛教思想開始出現「法」的系統化分析。這就是阿毘達磨思想的重要背景。

四、什麼是「法」？

這是理解說一切有部的第一個關鍵。

這裡的法（dharma）不能只理解成「佛法」。在阿毘達磨中，「法」更接近構成經驗與現象世界的基本要素。

例如：色、受、想、思、觸、作意、貪、瞋、癡、信、慚、愧、無明、智、無為。

於是佛教開始嘗試：把我們所經驗的世界拆解成許多「法」。

九、「法體恆有，三世遷流」

理解說一切有部，可以記一個非常重要的概念：法體恆有，三世遷流。意思大致是：法的存在性具有某種持續性，而它在不同時間呈現不同的作用狀態。

但這句話是後來對有部思想的概括，不能把它當成所有有部論師唯一、完全一致的表述。

十一、說一切有部並不是「主張有一個永恆的我」

這一點一定要分清楚。它雖然主張三世諸法有，但它仍然否定一個永恆不變的「我」。

這就是有部思想非常特殊的地方：「無我」與「法有」可以同時成立。

而大乘中觀後來會進一步追問：如果「人無我」，為什麼「法」還可以有自性？於是提出人無我 ＋ 法無我，這是中觀思想的重要突破。

三十三、說一切有部的歷史影響

說一切有部曾經在北印度、犍陀羅、迦濕彌羅、中亞等地具有重要影響。尤其迦濕彌羅說一切有部形成高度系統化的毘婆沙傳統。

後來這些思想又透過中亞 → 西域 → 中國進入漢傳佛教，因此中國佛教的阿毘達磨研究受到很大影響。

三十四、玄奘與說一切有部

玄奘赴印度求法後，深入研究印度佛教論書傳統。他翻譯的重要作品包括《阿毘達磨大毘婆沙論》以及《阿毘達磨俱舍論》等。

因此中國佛教後來能夠非常系統地接觸說一切有部 → 毘婆沙 → 俱舍這一思想鏈。

三十五、說一切有部最重要的「三個問題」

如果不想陷入七十五法的細節，先抓住三個問題即可：

問題一：法是什麼？

→ 法的分類

問題二：法如何在時間中存在？

→ 三世實有

問題三：法如何產生果報？

→ 因、緣、果

所以：說一切有部 = 法 + 三世 + 因果，這是最好的入門公式。

三十六、與佛陀原始教法相比，發生了什麼變化？

可以看到明顯的思想風格變化。

佛陀

主要問：苦怎麼產生？怎麼止息？

阿毘達磨

開始問：苦是由哪些法構成？

進一步：哪些法是善？哪些是不善？哪些煩惱？哪些因？哪些果？

所以佛陀的解脫論 → 阿毘達磨的法分析，這就是一個非常重要的轉變。

三十七、說一切有部的優點與問題

它的優點

① 分析非常精細——把心理、物質、因果、修行分解得非常細。

② 建立完整佛教心理學——可以精細分析：感知 → 受 → 想 → 思 → 煩惱 → 業。

③ 解釋因果相續——尤其試圖回答：無我之下，業果如何成立？

④ 建立修行地圖——哪些煩惱需要斷、哪些智慧需要修，都能系統分類。

它的哲學難題

最大的問題：如果法三世皆有，那法是不是具有某種「自性」？如果法具有固定存在性，又如何真正做到「諸行無常」？如果法完全沒有固定性，又如何解釋因果？

這個矛盾正是後來中觀哲學的重要突破口之一。
