# 印度密教：起源、發展、思想與傳入西藏的歷史

印度密教（Indian Esoteric Buddhism），通常也稱為印度佛教密續傳統、金剛乘（Vajrayāna），是印度大乘佛教發展過程中形成的重要傳統。它吸收了大乘佛教的菩薩道、空性與菩提心思想，並發展出咒語、曼荼羅、本尊觀想、灌頂、手印及密續儀軌等修行方法。

理解印度密教，最重要的是把握一個觀念：

印度密教不是脫離大乘佛教而獨立產生的宗教，而是在大乘佛教思想與修行傳統中，逐漸形成的一套密續教法與修行體系。

它後來深刻影響藏傳佛教，也透過不同的傳播路線影響東亞佛教，例如中國唐代的密教，以及日本真言宗、天台密教等。不過，這些傳統並非完全相同，不能直接視為同一套教法。

## 一、印度密教的歷史發展

### 第一階段：早期佛教與大乘佛教的基礎

約公元前 5 世紀至公元 3 世紀

印度佛教逐步發展出菩薩道、般若空性、陀羅尼與佛菩薩信仰等傳統。陀羅尼、護身咒及儀式性修持，為後來密教的形成提供了重要背景，但此時尚不能將所有相關實踐都稱為成熟的密教。

### 第二階段：初期密教形成

約公元 3 至 6 世紀

佛教經典中逐漸出現更完整的咒語、護摩、壇場、佛菩薩召請及儀軌。密教元素開始系統化，但形成時間與不同經典的年代仍有學術爭議。

### 第三階段：中期密教與儀軌體系化

約公元 6 至 8 世紀

大日如來、曼荼羅、灌頂、三密修行等觀念與儀軌逐步發展。這一時期的印度密教也經由唐代譯師傳入中國，成為東亞密教的重要來源。

### 第四階段：晚期密教與金剛乘發展

約公元 8 至 12 世紀

金剛乘、瑜伽續、無上瑜伽續等傳統發展，部分教法採用更複雜的本尊瑜伽、壇城及生起次第、圓滿次第等修行架構。那爛陀寺、超戒寺等佛教學術中心，與晚期印度佛教思想及跨區域傳播有重要關係。

這四個階段是便於學習的概略分期，不代表各地、各經典都依照完全一致的順序發展。

## 二、印度密教的核心思想

印度密教並非只有咒語與儀式，而是將大乘佛教的哲學思想、佛菩薩信仰與特定修行方法結合起來。

| 核心概念  | 主要內容                    | 在修行中的作用         |
| ----- | ----------------------- | --------------- |
| 菩提心   | 為利益一切眾生而追求佛果            | 確立修行的根本動機       |
| 空性    | 一切法皆無獨立、固定的自性           | 避免將本尊、儀軌及境界執為實體 |
| 本尊瑜伽  | 透過觀想本尊及其壇城修行            | 培養對佛果智慧與功德的認識   |
| 咒語與真言 | 以特定音聲及儀軌進行修持            | 構成身、語、意修行的一部分   |
| 曼荼羅   | 呈現佛、菩薩、本尊及其清淨世界的秩序      | 作為觀想、灌頂及儀式的核心結構 |
| 灌頂    | 由具傳承資格的上師授予特定密法的修學資格    | 建立特定修法的傳承與修行關係  |
| 方便與智慧 | 方便代表利他及實踐智慧的方法，智慧以空性為核心 | 共同構成大乘修道的理想     |

要注意：不同密續的思想與修行規定並不完全相同。有些特別重視佛身、真言與曼荼羅，有些則進一步發展複雜的本尊瑜伽與身心修行。

## 三、印度密教的重要經典

印度密教不是由單一經典創立，而是經過多部經典、密續及論書逐步形成。

![Mahayana Buddha Vairocana | Celestial Buddha of Infinite Light](https://images.openai.com/static-rsc-4/e4lqh_faAj90ULereE3TzKNTZU5KH-H67WQGbGpn78OqSeLuqNv8Qz_5KG3StHSz86aL878FurQd7VgNJDSGm4RVUVrV0QMPE_kY8M7Xs-hKsXsZgLc1PxGKsoBMTRBRbx-hQFiVTYIgOFU8aw_DyMgRU-V--gpp2ph5VitWsFQ?purpose=inline)

1.《大日經》

Mahāvairocana Tantra

以大日如來為核心，涉及曼荼羅、灌頂、真言、印契及菩提心等教法，是東亞密教的重要經典之一。中國唐代善無畏等人所傳譯的《大日經》，對後世真言宗等傳統影響深遠。

![Handmade Tibetan Vajra Thunderbolt, 24k Gold Plated Vajra for Meditation – Evamratna](https://images.openai.com/static-rsc-4/6WLVY0qobW4jQBFa_qBiAOGfboQRBOQ40aBN9lJ4vJymLc1MMHv8d7xKfec90o2MhFFhA0hYINaZj9TeIcb6VcRVHGhT7eYKZBqP9UkGhbp3S1r6C6DjD9sTzGvImuNl-rtq2G3Dchn6MgbdCl5Oqqrp2ckxPqIp6TjULvmASwY?purpose=inline)

2.《金剛頂經》系統

Sarvatathāgatatattvasaṃgraha 等相關密續

發展金剛界曼荼羅、金剛乘儀軌及佛的身語意修行體系。漢傳佛教中的《金剛頂經》及其相關傳承，與這一印度密教經典系統有密切關係。

![Guhyasamaja Akshobhyavajra With Silk Brocade, Union of Wisdom and Compassion, Tantric Meditations and Rituals - Etsy](https://images.openai.com/static-rsc-4/sX5e8rL9B4pq9Lj3WKBIKgUsWYt-iSVUcFnVvmlh6KmmXJnz3b4uxbIXjv_Y0_VJeAupmGReEFdZuA3oUVyfdaVDU2sLkBG3eVpcpuq8KMDzuRwN0WkzqqU8IZ3xEdv_Guiei_tq7x7qyPCgOsPdjWnHLT3q_J95NBLd5rMQknw?purpose=inline)

3.《秘密集會續》

Guhyasamāja Tantra

是印度晚期密教的重要代表之一，對後來部分藏傳佛教無上瑜伽續的修行體系、壇城觀想及生起次第與圓滿次第的發展具有重要影響。

4.《喜金剛續》

Hevajra Tantra

是印度晚期密教的重要密續之一，與瑜伽續及無上瑜伽續傳統的發展有關，後來在薩迦派等藏傳佛教傳承中具有重要地位。

以上經典分屬不同時期與密續系統，不能視為同時產生，也不能假設它們具有完全相同的教義。

## 四、印度密教的主要發展類型

密教的分類會因傳承與文獻而異。以下以藏傳佛教常用的四部續分類，回看印度密教的發展。

| 分類    | 梵文                  | 主要特色                   |
| ----- | ------------------- | ---------------------- |
| 事續    | Kriyā Tantra        | 重視儀式、供養、潔淨及外在修持規範      |
| 行續    | Caryā Tantra        | 強調儀式與內在觀修的配合           |
| 瑜伽續   | Yoga Tantra         | 著重本尊瑜伽、曼荼羅及身語意修行       |
| 無上瑜伽續 | Anuttarayoga Tantra | 發展更深入的本尊瑜伽、細微身心觀修等修行體系 |

重要提醒： 這套四部續分類主要是後來藏傳佛教整理印度密續時使用的分類架構。不能直接假設所有印度佛教密續傳統都曾以完全相同的四分法組織教法。

## 五、印度密教與那爛陀寺、超戒寺的關係

這是理解印度密教歷史的關鍵。

印度大乘佛教

菩薩道、菩提心、般若空性

那爛陀寺

Nālandā

大乘哲學、因明、唯識、中觀與佛教論學的重要中心。

超戒寺

Vikramaśīla

波羅王朝時期的重要佛教中心，與晚期大乘、密續傳統及跨區域傳法密切相關。

印度晚期密教與金剛乘

哲學論學、密續儀軌、灌頂、本尊瑜伽與修行傳承

傳入西藏

阿底峽、譯師及後弘期傳承，影響藏傳佛教的形成。

傳入中國

唐代密教譯經與儀軌傳承，成為東亞密教的重要來源。

這張圖呈現的是思想與傳承的關係，不表示密教完全由那爛陀寺或超戒寺單獨創立。印度密教的發展還涉及其他寺院、地方傳承、師徒系統及不同地區的宗教文化。

## 六、印度密教如何傳入其他地區？

| 傳播路線    | 代表人物或傳統               | 歷史影響                   |
| ------- | --------------------- | ---------------------- |
| 印度 → 中國 | 善無畏、金剛智、不空            | 唐代密教的重要譯經與傳法傳統         |
| 印度 → 西藏 | 蓮花生、寂護、阿底峽及後來的印度譯師與論師 | 影響藏傳佛教的教義、儀軌、寺院教育與各派傳承 |
| 中國 → 日本 | 空海、最澄及相關密教傳承          | 發展日本真言宗、天台密教等傳統        |

其中要特別區分：

* 唐密：主要承接印度中期密教的重要傳統。

* 藏傳佛教密續：承接不同時期的印度密續，尤其包含晚期印度金剛乘的多種傳承。

* 日本真言宗：以唐代傳入日本的密教傳承為重要根源，並在日本形成自身的宗派體系。

因此，藏傳佛教與東亞密教有共同的印度源流，但在經典翻譯、密續分類、儀軌系統及歷史發展上各有特色。

## 七、印度密教與中觀、唯識的關係

理解印度密教時，最好不要只研究儀式，而應將它放回印度佛教哲學史中。

| 思想傳統  | 核心問題           | 與密教的關係                     |
| ----- | -------------- | -------------------------- |
| 中觀    | 一切法如何是空？       | 空性與二諦思想為部分密教修行提供哲學基礎       |
| 唯識    | 認識、心識與所知境如何成立？ | 部分密教論師運用瑜伽行派的思想資源，但各傳統詮釋不同 |
| 大乘菩薩道 | 如何為利益眾生而成佛？    | 菩提心與利他目標是許多大乘密教的重要基礎       |
| 金剛乘   | 如何透過密續方法修行佛道？  | 結合特定儀軌、本尊瑜伽及不同層次的修行方法      |

尤其要注意：密教不是「只有儀式的佛教」，也不是「中觀或唯識的另一個名稱」。 它是一個包含多種經典、哲學詮釋與實踐傳承的歷史性宗教傳統。

## 八、印度密教學習藍圖

若要把印度密教放入完整的佛教學習系統，可以採用以下順序：

第一層：早期佛教

四聖諦、八正道、緣起、無我

第二層：部派佛教與阿毘達磨

法的分析、業果、心與心所

第三層：印度大乘佛教

般若、中觀、唯識、菩薩道

第四層：印度密教

陀羅尼、初期密教、中期密教、晚期金剛乘

東亞密教

唐密、真言宗、天台密教

藏傳佛教

寧瑪、噶舉、薩迦、格魯等傳承

這是方便理解的學習順序，不代表密教必然由所有前述階段線性演變而來，也不表示研究密教前必須先精通全部部派佛教。

## 九、最值得深入研究的五個問題

1. 印度密教何時真正形成？ 如何區分早期陀羅尼信仰、初期密教與成熟的金剛乘？

2. 密教與大乘佛教的關係是什麼？ 密教究竟在哪些方面延續大乘，又在哪些方面發展出不同的修行體系？

3. 中觀與密教如何結合？ 空性思想如何影響本尊觀想、曼荼羅及密續修行？

4. 印度密教為何在印度衰退，卻在西藏延續？ 應從政治、寺院制度、傳承與跨文化翻譯等因素綜合理解，而非歸結為單一原因。

5. 唐密與藏密有何異同？ 兩者都承接印度佛教密續，但傳入年代、經典系統及後續宗派發展並不相同。

總結： 印度密教是印度大乘佛教歷史中一條重要的發展脈絡。若將它與中觀、唯識、那爛陀寺、超戒寺及藏傳佛教放在同一張學習地圖中，就能看出印度佛教如何從哲學論學、菩薩道與陀羅尼傳統，逐步發展出多樣的密續修行體系，並經由不同傳播路線影響亞洲佛教。
