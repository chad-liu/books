大眾部是佛教早期部派佛教的重要派別之一，梵語為 Mahāsāṃghika，巴利語形式為 Mahāsaṅghika，字面意思是「大眾」或「廣大僧團」。

它的重要性不只在於僧團分裂的歷史，也在於它對佛陀、菩薩、阿羅漢及佛法的理解，呈現出與部分上座系部派不同的思想方向。後世有時將它視為大乘佛教發展的重要思想背景之一，但不能直接把大眾部等同於大乘佛教。

## 一、歷史背景：大眾部如何形成？

佛陀入滅後的早期僧團

共同傳承戒律、教法與修行制度

僧團分歧與部派形成

戒律、僧團制度、教義詮釋等問題逐漸產生不同立場

### 大眾部

Mahāsāṃghika

重視佛陀的超越性等思想特色

### 上座系統

Sthavira 傳統

形成多個不同部派，並非單一思想體系

### 傳統記載與歷史研究的差別

傳統佛教史常將早期分裂與第二次結集、戒律爭議聯繫起來，但各部派對分裂原因的記載並不一致。現代研究也提醒我們，部派的形成可能是長期發展的結果，不能完全視為某一天突然發生的分裂。

* 大眾部：早期印度佛教部派之一。

* 上座部：早期的上座系統，不能直接等同於今日的南傳上座部佛教。

* 大乘佛教：後來發展出的廣泛思想與修行傳統，不是大眾部的另一個名稱。

## 二、大眾部的主要思想特色

### 1. 佛陀具有超越凡夫的特性

大眾部思想中一個重要特色，是強調佛陀的超越性。

| 思考面向  | 大眾部相關思想特色               |
| ----- | ----------------------- |
| 佛陀的身  | 佛陀的身與能力具有超越一般凡夫的特性      |
| 佛陀的智慧 | 佛陀的智慧與覺悟具有殊勝、廣大的意義      |
| 佛陀的言教 | 佛陀的教法可能具有超越表面語言的深層意義    |
| 佛陀的示現 | 佛陀在人間的活動，可被理解為具有特殊的示現性質 |

這些概括是大眾部思想發展中的重要方向，但大眾部內部存在不同支派，不能將所有命題都視為每個支派共同接受的固定教義。

### 2. 阿羅漢是否完全沒有缺失？

大眾部若干思想傳統對阿羅漢的能力與境界採取較具限制性的理解。部分傳統認為，阿羅漢仍可能存在某些不足，例如：

* 對佛法的理解不及佛陀圓滿。

* 在智慧、能力或教法理解方面，與佛陀仍有差異。

* 阿羅漢的解脫境界不應與佛陀的圓滿覺悟完全混為一談。

不過，這並不代表大眾部認為阿羅漢沒有解脫，而是涉及阿羅漢解脫與佛陀圓滿覺悟之間的差別。

### 3. 佛陀與阿羅漢的差別，應如何理解？

佛陀（Buddha）

自行覺悟，並能開示解脫之道；大眾部相關思想特別強調佛陀的超越性與圓滿性。

![Sculpture of Preaching Buddha](https://images.openai.com/static-rsc-4/FKZPbfDHxCqr_WJFnl7iU8h0jwEsF1SnWO18h8rXV3l0DZ8dZ6De8LsSClWTDS5ZkPlryPyD7C-CFhF50TrKhXnmZZfqsnHG6dY2t1cyPf9u6HOtMaQxPsd_KlKdSzdOQHrIQ4-TnG5alk0HHjfS0Sylx5FvXEjxKL8uvhLuCwq44Ur4xohRezKFafDhnfe_?purpose=inline)

阿羅漢（Arhat）

透過修行斷除煩惱、達到解脫；但在若干大眾部思想中，其智慧與能力仍不同於佛陀。

這種區分有助於理解後來佛教思想中，為什麼會進一步討論佛陀的功德、菩薩道，以及佛果與聲聞果位的差異。

### 4. 有為法與無為法的區分

大眾部相關論書也討論有為法與無為法。

* 有為法：由因緣條件所生起的現象。

* 無為法：不以一般因緣造作方式生起的法，涅槃是重要例子。

然而，各部派對無為法的數量、性質及分類並不完全一致。不能只根據「大眾部」這個名稱，就推定它對所有法的分類都與其他部派相同。

## 三、大眾部與其他早期部派比較

| 比較面向  | 大眾部              | 說一切有部        | 經量部                | 犢子部              |
| ----- | ---------------- | ------------ | ------------------ | ---------------- |
| 梵語    | Mahāsāṃghika     | Sarvāstivāda | Sautrāntika        | Vātsīputrīya     |
| 思想焦點  | 佛陀的超越性、佛與阿羅漢的差別等 | 三世諸法、法的分類與因果 | 剎那生滅、種子與因果相續       | 補特伽羅與個體相續        |
| 核心問題  | 佛陀的境界有何特殊性？      | 諸法如何存在並發生作用？ | 業力如何跨越時間產生果報？      | 無我之下，誰在造業受報？     |
| 思想史意義 | 提供研究早期佛陀觀的重要材料   | 發展出精密的阿毘達磨分析 | 對後來佛教認識論與種子理論有重要影響 | 以補特伽羅問題挑戰其他部派的解釋 |

要特別注意：這張表比較的是各部派的代表性思想方向，不表示每個部派只關心表格中的單一問題。

## 四、大眾部與大乘佛教有什麼關係？

這是研究大眾部時最值得注意的問題之一。

### 大眾部的思想特色

對佛陀超越性、佛的功德，以及佛與阿羅漢的差別提出不同於部分其他部派的理解。

思想背景與歷史關聯，不等於單線傳承

### 大乘佛教的發展

逐漸形成以菩薩道、廣大佛果、般若、空性等為重要內容的多元傳統。

### 可以說有關聯，但不能說完全相同

學術研究常討論大眾部的部分思想是否為大乘佛教提供了有利的思想背景，例如：

1. 佛陀觀：對佛陀超越性與殊勝功德的強調。

2. 佛與阿羅漢的差異：有助於理解佛果與聲聞解脫之間的不同定位。

3. 菩薩思想的歷史背景：可放在早期佛教多種佛陀觀與菩薩觀的發展中考察。

但大乘佛教並非單純從大眾部直接分化而來。大乘佛教的形成涉及不同地區、僧俗群體、經典傳承與思想交流。大眾部與大乘之間的具體歷史關係，仍是學術研究中的重要議題。

## 五、大眾部的分支

傳統部派史記載，大眾部後來分出多個支派，常見名稱包括：

* 一說部（Ekavyāvahārika）

* 說出世部（Lokottaravāda）

* 雞胤部（Kukkuṭika）

* 多聞部（Bahuśrutīya）

* 說假部（Prajñaptivāda）

不同佛教史料所列的支派名稱、分裂次序與年代並不完全一致，因此不宜把所有分支硬排成一條毫無爭議的時間線。

其中，說出世部尤其值得注意，因為其思想與文獻對佛陀超越性有鮮明的表述，能幫助我們觀察大眾部系統內部思想的發展。

## 六、重要文獻與研究線索

| 文獻       | 用途與注意事項                             |
| -------- | ----------------------------------- |
| 《異部宗輪論》  | 了解傳統佛教對部派分裂、支派及教義差異的整理              |
| 《舍利弗問經》  | 可作為早期部派史傳統的參考，但須留意其成書與史料性質          |
| 《摩訶僧祇律》  | 研究大眾部律藏傳統的重要資料                      |
| 《俱舍論》    | 觀察其他部派如何整理與批判不同教義，不能把其中的批評直接當作大眾部自述 |
| 說出世部相關文獻 | 研究大眾部支派佛陀觀的重要材料                     |

閱讀這些資料時，最好區分三個層次：大眾部自己的傳承資料、其他部派對大眾部的描述，以及現代學者的歷史重建。這三者不一定完全一致。

### 大眾部的學習速記卡

* 名稱：大眾部（Mahāsāṃghika）

* 歷史定位：早期印度佛教重要部派之一

* 代表性思想特色：佛陀的超越性，以及佛與阿羅漢的差異

* 重要研究問題：大眾部思想與大乘佛教形成的關係

* 不可混淆：大眾部不等於大乘佛教；上座部也不等於所有上座系部派

* 關鍵文獻：《異部宗輪論》、《摩訶僧祇律》等

一句話總結： 如果說說一切有部著重分析「法如何存在」，經量部著重解釋「因果如何相續」，犢子部探討「無我之下個體如何成立」，那麼大眾部的一個重要切入點，就是追問「佛陀究竟具有何種超越凡夫與阿羅漢的特殊性」，並由此理解早期佛教佛陀觀的多元發展。
