南傳上座部佛教，英文通常稱 Theravāda Buddhism，是當今仍延續的重要佛教傳統之一，主要流傳於斯里蘭卡、泰國、緬甸、柬埔寨與寮國，也在世界其他地區發展。

其核心特色包括：以巴利語三藏為主要經典依據、重視戒定慧三學、四聖諦、八正道、緣起、無我，以及透過禪修培養智慧、斷除煩惱而證得涅槃。

在你的佛學學習藍圖中，可以把南傳上座部理解為：早期佛教教法在上座部傳承中的延續與發展，但不宜把它簡單視為佛陀時代佛教的原封不動版本。

## 一、南傳上座部的歷史發展

佛陀時代與早期僧團

四聖諦、八正道、緣起、無我、涅槃

早期部派佛教

僧團分化，形成不同的經典、戒律與教義傳承

斯里蘭卡的上座部傳承

建立重要的經典保存、僧團教育與註釋傳統

巴利語三藏的書寫與註釋發展

口傳傳統逐漸以書面形式保存，論書與註釋持續發展

南傳上座部的區域發展

斯里蘭卡、緬甸、泰國、柬埔寨、寮國等地形成各自的傳承特色

僧團制度與戒律

## 3. 論藏（Abhidhamma Piṭaka）

心、心所、色法與法的系統分析

以高度分類化的方式分析心理與現象，包括心識、心所、色法及其關係，形成南傳阿毘達磨的特色。

### 經藏的五部

| 巴利名稱             | 中文常用名稱 | 主要特色                    |
| ---------------- | ------ | ----------------------- |
| Dīgha Nikāya     | 長部     | 篇幅較長的經典                 |
| Majjhima Nikāya  | 中部     | 中等篇幅的經典                 |
| Saṃyutta Nikāya  | 相應部    | 按主題與教法分類                |
| Aṅguttara Nikāya | 增支部    | 常以數目與項目組織教法             |
| Khuddaka Nikāya  | 小部     | 多種不同體裁的經典，包括《法句經》《本生經》等 |

巴利語經藏與漢譯阿含經有大量可比較的內容，但不是每部經都能一一對應，兩套傳承也有各自的編排與文本差異。

## 三、南傳上座部的核心教義

### 1. 四聖諦：理解苦與解脫

# 苦

苦諦

生命經驗具有不圓滿與不穩定性，包括生、老、病、死，以及對無常事物的執取。

# 集

集諦

渴愛與執取是苦的重要成因，尤其涉及對欲望、存在與不存在的渴求。

# 滅

滅諦

渴愛與煩惱止息，指向涅槃與苦的止息。

# 道

道諦

八正道是通往苦滅的實踐道路。

四聖諦不是單純的哲學命題，而是把問題、成因、目標與實踐方法組合起來的修行架構。

### 2. 八正道：戒、定、慧的完整修行

| 三學 | 八正道項目     | 修行重點                   |
| -- | --------- | ---------------------- |
| 慧  | 正見、正思惟    | 正確理解苦、因果與解脫，培養離貪與不害的思考 |
| 戒  | 正語、正業、正命  | 使言語、行為與生活方式符合不傷害等原則    |
| 定  | 正精進、正念、正定 | 培養持續的修習、清明覺察與心的安定      |

八正道的排列雖然分成三學來理解，但三者彼此支持，並不是只能按照表格中的順序依次修完。

### 3. 三法印與三相：無常、苦、無我

南傳上座部的經典與論書特別重視對經驗現象的觀察。

* 無常（anicca）：因緣所生的現象持續變化。

* 苦（dukkha）：受條件限制、不能完全掌控的現象，無法提供恆常滿足。

* 無我（anattā）：五蘊之中找不到可掌控、永恆不變的自我實體。

透過觀察色、受、想、行、識五蘊的生滅與非我性，修行者逐步削弱對「我」與「我所」的執取。

要注意，南傳經典常以「三相」（tilakkhaṇa）說明有為法的無常、苦、無我；漢傳佛教常見的「三法印」用語與其有密切關係，但兩種傳統的分類語境並非處處完全相同。

### 4. 緣起：苦如何形成，又如何止息？

南傳上座部重視十二因緣的分析：

1

無明 (avijjā)

對苦、因果與現象實相的無明

2

行 (saṅkhārā)

受無明影響的造作與業行

3

識 (viññāṇa)

識的生起與相續

4

名色 (nāmarūpa)

心理與物質現象

5

六處 (saḷāyatana)

六種感官與認知基礎

6

觸 (phassa)

根、境、識相遇

7

受 (vedanā)

苦受、樂受、不苦不樂受

8

愛 (taṇhā)

渴愛

9

取 (upādāna)

執取

10

有 (bhava)

導向後續生存的業與存在過程

11

生 (jāti)

出生

12

老死 (jarāmaraṇa)

衰老、死亡及相關苦惱

十二因緣不宜只理解成一條機械式的時間線。南傳經典依不同經文，會從生命歷程、當下經驗與苦的條件關係等角度闡述緣起。

其修行意義是：當無明與渴愛等條件止息，苦的生起條件也能逐步被解除。

## 四、南傳上座部如何理解「解脫」？

南傳上座部重視由戒、定、慧逐步斷除煩惱，並以四種聖者果位說明解脫的進程。

| 聖者果位 | 巴利名稱       | 主要意義                     |
| ---- | ---------- | ------------------------ |
| 預流果  | Sotāpanna  | 斷除三種結，進入不退失的聖道           |
| 一來果  | Sakadāgāmi | 貪、瞋、癡進一步減弱，尚須再來人間一次的傳統描述 |
| 不還果  | Anāgāmi    | 斷除五下分結，不再投生欲界            |
| 阿羅漢果 | Arahant    | 斷除所有導致輪迴的煩惱，達到解脫         |

此處的果位說明是南傳上座部傳統中的典型整理。不同經文與註釋會從不同角度解釋各種結、煩惱與道果的關係。

### 阿羅漢與佛陀的差別

南傳上座部承認佛陀是自行覺悟、開示解脫道路的正等正覺者；阿羅漢則透過佛陀所開示的道路而達到解脫。

兩者都與煩惱的止息有關，但在覺悟的方式、教法開創性與佛陀的特殊功德方面，並不完全相同。

這與大眾部部分傳統強調佛陀超越性、討論佛與阿羅漢差異的問題形成可比較的思想脈絡；但兩者各自的教義細節仍須分別研究。

南傳上座部的修行不是只有一種禪法，而是包含多種禪修與培養心的方法。

### 主要修習方向

| 修習方法 | 巴利語          | 目的與作用              |
| ---- | ------------ | ------------------ |
| 止禪   | Samatha      | 培養心的安定、專注與定力       |
| 觀禪   | Vipassanā    | 觀察身心現象的無常、苦、無我     |
| 四念處  | Satipaṭṭhāna | 觀身、受、心、法，培養正念與如實觀察 |
| 安般念  | Ānāpānasati  | 以呼吸為所緣培養正念與定力      |
| 慈心修習 | Mettā        | 培養善意、無瞋與對眾生的慈心     |

止與觀可以在修行過程中相互支持。不同傳承對禪修次第、禪那的定位、觀智的發展與教學方法，可能存在差異。

例如，緬甸近代的內觀傳統、泰國森林派，以及斯里蘭卡的不同禪修系統，雖然共享許多經典基礎，實際教學方法並不完全一致。

## 六、南傳上座部與漢傳佛教比較

| 面向       | 南傳上座部                         | 漢傳佛教                       |
| -------- | ----------------------------- | -------------------------- |
| 主要經典語言傳承 | 巴利語三藏                         | 以漢譯佛典為主，包含阿含、般若、中觀、唯識等多種傳統 |
| 重要經典     | 巴利四部及小部、律藏、論藏                 | 四阿含、律藏、般若經、中觀論典、唯識論典等      |
| 共同教法     | 四聖諦、八正道、緣起、無我、涅槃              | 同樣重視上述早期佛教核心教法             |
| 思想發展     | 南傳阿毘達磨、註釋學、禪修傳承               | 部派佛教傳承、大乘中觀、唯識、如來藏等多種發展    |
| 常見修行形式   | 止觀、四念處、戒定慧、慈心等                | 禪宗、淨土、天台、華嚴、密教及其他修行傳統      |
| 解脫與菩薩道   | 以聲聞解脫與阿羅漢果等為重要架構，也有佛陀與菩薩的相關教說 | 大乘傳統尤其重視菩薩道與佛果             |

這是概括性的比較，並不代表南傳佛教只重視個人解脫，或漢傳佛教只重視菩薩道。兩大傳統內部都存在豐富的修行與思想差異。

### 學習速記卡

* 名稱：南傳上座部（Theravāda）

* 核心經典：巴利語三藏

* 核心教法：四聖諦、八正道、緣起、三相、無我

* 主要修行架構：戒、定、慧

* 解脫目標：煩惱止息、涅槃、四道四果

* 重要著作：《清淨道論》

* 重要人物：佛音（Buddhaghosa）

* 主要流傳地區：斯里蘭卡與東南亞部分國家

一句話總結： 南傳上座部以巴利語三藏為經典核心，透過戒定慧、四聖諦、緣起與無我的修行與分析，建立了具有連續傳承的佛教思想體系；它是早期上座系統中的一支，而不是所有早期上座部派的總稱。
