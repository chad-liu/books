# 三論宗：以中觀思想為核心的漢傳佛教宗派

三論宗是中國佛教的重要宗派，以印度大乘佛教的中觀思想為理論基礎，主要依據龍樹與提婆的論著，透過吉藏等人的整理，形成完整的教義體系。

三論宗的核心問題是：

一切事物既然都是因緣和合而生，就沒有獨立、固定、不依賴其他條件的自性。修行者應破除對各種概念與立場的執著，體悟空性與中道。

三論宗並不是主張世界什麼都不存在，而是反對把任何事物、觀念，甚至「空」本身，當成永恆不變、獨立存在的實體。

## 一、三論宗的名稱與三部核心論典

「三論宗」之名，來自其主要依據的三部論典。

| 論典     | 作者            | 核心內容                      |
| ------ | ------------- | ------------------------- |
| 《中論》   | 龍樹（Nāgārjuna） | 以緣起、空性、八不中道等思想，破除對諸法自性的執著 |
| 《十二門論》 | 傳統歸於龍樹        | 從十二個方面論證諸法無自性，闡明空義        |
| 《百論》   | 提婆（Āryadeva）  | 批判各種執著與錯誤見解，深化中觀的論辯方法     |

三論宗以這三部論書為核心，故稱「三論宗」。

另外，龍樹的《大智度論》、吉藏的《三論玄義》等，也對理解三論宗思想非常重要。

## 二、三論宗的歷史發展

### 1. 印度中觀思想的建立

龍樹（約公元 2 至 3 世紀）

中觀思想的代表人物，以《中論》等論著闡明緣起性空，批判將事物理解為具有固定自性的觀點。

↓

提婆（約公元 3 世紀）

延續龍樹的論辯傳統，透過批判各種哲學立場，深化對空性與無自性的理解。

### 2. 中觀論典傳入中國

鳩摩羅什（344–413，年代有不同說法）於後秦時期翻譯《中論》《十二門論》《百論》等重要論典，使印度中觀思想得以在中國佛教界廣泛傳播。

他的譯經與講學，為後來三論學派的形成奠定了基礎。

### 3. 僧朗與僧詮的傳承

中國三論學的發展，與南北朝時期的僧朗、僧詮等人的講學傳承有關。三論思想逐漸形成具有自身特色的研究與教學傳統。

### 4. 吉藏建立完整的三論宗體系

吉藏（549–623） 是三論宗最重要的思想家之一。

他在隋唐之際整理三論思想，深入闡釋二諦、中道、破邪顯正等理論，並透過大量著作建立較完整的宗派教義。

### 5. 唐代以後的影響

隋唐時期是三論宗教義成熟的重要階段。此後，三論思想雖未持續以獨立宗派的形式占據主流，卻對中國佛教的中觀研究、天台、華嚴、禪宗等思想環境產生不同程度的影響。

## 三、三論宗的五個核心思想

| 核心思想 | 意義                  | 重要提醒              |
| ---- | ------------------- | ----------------- |
| 緣起性空 | 一切法依條件而生，因此沒有獨立自性   | 空不等於不存在           |
| 八不中道 | 不落入生滅、常斷、一異、來去等極端執著 | 不是單純否定一切現象        |
| 二諦   | 從世俗與勝義兩個層次理解佛法      | 勝義諦不是另一個永恆實體      |
| 破邪顯正 | 透過批判錯誤的自性見，顯明中道     | 不只是與人辯論，而是破除執著    |
| 無所得  | 不將任何觀念或境界執為可獨立把握的實體 | 連「空」與「無所得」也不能僵化執取 |

### 1. 緣起性空

例如，一張桌子由木材、加工技術、工具、工人與使用情境等條件共同形成。

如果拆解它，就會發現「桌子」不是一個獨立存在、完全不依賴其他條件的實體，而是依條件成立的名稱與事物。

三論宗借此指出：

* 桌子在世俗生活中確實可以使用。

* 桌子不是完全獨立、自存不變的實體。

* 因此，桌子是緣起而空。

這不是說桌子不存在，而是說它的存在方式並非具有固定不變的自性。

### 2. 八不中道

《中論》開篇以著名的「八不」說明中道：

> 不生亦不滅，不常亦不斷，不一亦不異，不來亦不出。

八不的目的，是破除對事物存在方式的極端理解。

| 八不    | 所破除的極端觀念               |
| ----- | ---------------------- |
| 不生、不滅 | 不把生與滅理解成具有固定自性的絕對過程    |
| 不常、不斷 | 不執著永恆不變，也不執著因果完全斷絕     |
| 不一、不異 | 不把事物看成完全相同，也不把它們看成毫無關聯 |
| 不來、不出 | 不把來去理解成具有獨立自性的移動或出現    |

八不並非否認世俗層面的生滅、因果和移動，而是指出這些現象都依賴因緣與關係成立。

### 3. 二諦：世俗諦與第一義諦

三論宗重視二諦思想。

* 世俗諦：在日常生活與共同約定中成立的事物與道理，例如語言、因果、倫理和社會規範。

* 第一義諦：從勝義的角度觀察，任何事物都沒有獨立不變的自性。

兩者不是兩個互不相關的世界。

例如，世俗層面上，種子可以發芽、植物可以生長；勝義觀察則指出，種子、土壤、水分與生長條件皆依緣而成立。

因此，理解空性並不要求否定世俗因果。

### 4. 破邪顯正

「破邪」不是單純批評其他人，而是指出某個主張若將事物執為固定自性，就會遇到理論上的困難。

「顯正」則是透過破除這些執著，使緣起與中道的理解更加清楚。

三論宗的論辯方法常常不急著建立一個新的、不可動搖的本體，而是先檢查既有觀念是否暗中預設了獨立自性。

### 5. 無所得

無所得不是什麼都不學，也不是放棄思考，而是不把任何概念、修行成果或哲學體系執著為絕對實體。

例如：

* 執著「一切存在」，可能落入常見。

* 執著「一切完全不存在」，可能落入斷見。

* 若把「空」當成永恆不變的本體，也仍然是一種執著。

因此，空性本身也不能被當成一個獨立自存的實體。

## 四、三論宗的重要人物與著作

| 人物   | 時代           | 重要性                |
| ---- | ------------ | ------------------ |
| 龍樹   | 約公元 2 至 3 世紀 | 印度中觀思想的重要奠基者       |
| 提婆   | 約公元 3 世紀     | 延續中觀論辯傳統           |
| 鳩摩羅什 | 4 至 5 世紀     | 翻譯三論核心論典，使其在中國廣泛流傳 |
| 僧朗   | 南北朝          | 中國三論學傳承的重要人物       |
| 僧詮   | 南北朝          | 延續三論講學與教學傳統        |
| 吉藏   | 549–623      | 三論宗教義體系化的關鍵人物      |

吉藏的重要著作包括：

* 《三論玄義》：介紹三論宗的基本思想、宗旨與論典架構。

* 《中論疏》：深入解釋《中論》的思想。

* 《十二門論疏》：闡述《十二門論》的空義。

* 《百論疏》：解釋《百論》的論辯與教義。

## 五、三論宗與其他佛教思想的比較

| 比較項目    | 三論宗           | 天台宗             | 唯識學                    |
| ------- | ------------- | --------------- | ---------------------- |
| 主要思想來源  | 龍樹、提婆的中觀論典    | 《法華經》及中國佛教的判教傳統 | 印度瑜伽行派論典               |
| 核心關注    | 緣起性空、二諦、中道    | 一念三千、三諦圓融、止觀    | 心識結構、認識與種子             |
| 主要方法    | 破除自性執，顯明中道    | 以三諦與止觀統攝修行      | 分析識、所緣境與認知過程           |
| 對「空」的理解 | 著重一切法無自性及不執著空 | 空、假、中三諦圓融       | 以唯識理論分析認識與所知境，並有不同空義詮釋 |
| 重要人物    | 吉藏            | 智顗              | 玄奘、窺基等漢傳唯識代表人物         |

要注意，唯識學並非簡單主張「世界只有心而沒有任何其他東西」，天台宗也不是單純把空性與世俗存在拼在一起。各宗思想都具有更複雜的理論脈絡。

## 七、三論宗的學習順序

若要深入學習，建議按照以下順序：

1. 先讀《中論》：掌握緣起性空與八不中道。

2. 再讀《十二門論》：理解從不同角度論證諸法無自性的方法。

3. 接著讀《百論》：認識中觀的論辯方式與破執方法。

4. 閱讀《三論玄義》：理解吉藏如何統整三論宗的宗旨。

5. 研讀吉藏的注疏：進一步掌握二諦、中道、破邪顯正與無所得。

6. 比較天台與唯識：了解中國佛教如何以不同方法詮釋空性、認識與修行。

一句話總結三論宗：

三論宗以龍樹、提婆的中觀思想為根本，透過緣起性空、八不中道、二諦與破邪顯正，破除對一切法乃至「空」本身的執著，從而彰顯不落兩邊的中道智慧。
