一、總體學習地圖

二、第一層：先建立「唯識學地基」

在讀《成唯識論》以前，建議先掌握四個背景。

基礎要理解什麼重要程度
原始佛教無我、緣起、五蘊、十二處、十八界★★★★★
阿毘達磨心、心所、法、因果分析★★★★★
中觀空性、二諦、破自性★★★★☆
瑜伽行派阿賴耶識、種子、三性、唯識★★★★★
《成唯識論》不是突然出現的，它是印度大乘佛教長期心識分析的集大成。

三、第二層：唯識的核心問題

學《成唯識論》可以先抓住六個大問題。

問題①：我們如何認識世界？

問題②：「我」究竟是什麼？

問題③：過去經驗為什麼會影響現在？

這就進入種子 → 現行 → 熏習 → 種子的循環，是理解唯識因果論的關鍵。

問題④：錯誤認識是怎麼產生的？

進入遍計所執性。

問題⑤：世界究竟是什麼？

進入依他起性。

問題⑥：如何從錯誤認識中解脫？

進入圓成實性 → 修行 → 轉識成智。

《成唯識論》不是只有八識，還要理解心王＋心所——心王是識的主體活動，心所則是伴隨識而起的心理作用。

七、第六層：阿賴耶識與種子論

這是整個學習藍圖的「地下核心」。

種子生現行，現行熏種子。

八、第七層：三性三無性

這是《成唯識論》的哲學核心。

三性

遍計是「錯認」，依他是「緣起」，圓成是「如實」。

三無性

這裡是唯識與「空」思想銜接的重要位置。

九、第八層：唯識與空

這是非常容易誤解的地方。唯識並不是簡單地說「一切都是我想出來的」，而是在分析：所認識的境、能認識的識，以及能所關係是否具有我們所執著的獨立自性。

這也是研究中觀與唯識差異的核心入口。

十、第九層：我執與法執

唯識修行不能只理解為「不要想太多」。真正的問題是：

我執 → 生死煩惱；法執 → 更深層的無明。

十六、與其他唯識經論的關係

建立這張「文獻地圖」會非常有幫助：

《成唯識論》不是唯識學的起點，而是玄奘將印度唯識諸家思想加以整理、綜合的重要成果。

十七、推薦的實際學習順序

如果目標是「真正讀懂」，建議依六個階段推進：

  1. 第一階段：建立詞彙
    五蘊 → 十二處 → 十八界 → 五位 → 心王心所
  2. 第二階段：建立八識
    前五識 → 第六識 → 末那識 → 阿賴耶識
  3. 第三階段：理解心識運作
    心所 → 相應 → 四分 → 種子 → 現行 → 熏習
  4. 第四階段：進入哲學核心
    唯識 → 三性 → 三無性 → 二障 → 我執 → 法執
  5. 第五階段：進入修行
    四尋思 → 四如實智 → 五位 → 見道 → 修道
  6. 第六階段：最後理解佛果
    轉依 → 轉識成智 → 四智 → 佛果
