# 唯識學的「八識」學習藍圖

在唯識學中，「八識」是理解《成唯識論》的核心入口。可以先用一句話掌握：

> **前五識負責感官認知，第六識負責分別思考，第七識執著「我」，第八識保存業種並維持生命與心識的相續。**

其基本架構是：

```text
                         八識
                          │
          ┌───────────────┴───────────────┐
          │                               │
       前六識                            後二識
          │                               │
 ┌────────┴────────┐              ┌───────┴───────┐
 │                 │              │               │
前五識            第六識         第七識          第八識
 │                 │              │               │
眼耳鼻舌身        意識          末那識          阿賴耶識
 │                 │              │               │
感官資料          分別思考      執著「我」      種子、業果、相續
```

---

## 一、八識總表

| 識       | 名稱   | 主要功能      | 所緣      | 核心問題       |
| ------- | ---- | --------- | ------- | ---------- |
| **眼識**  | 眼識   | 視覺認知      | 色境      | 看見         |
| **耳識**  | 耳識   | 聽覺認知      | 聲境      | 聽見         |
| **鼻識**  | 鼻識   | 嗅覺認知      | 香境      | 聞到         |
| **舌識**  | 舌識   | 味覺認知      | 味境      | 嘗到         |
| **身識**  | 身識   | 觸覺認知      | 觸境      | 感受到        |
| **第六識** | 意識   | 分別、判斷、思考  | 法境      | 「這是什麼？」    |
| **第七識** | 末那識  | 恆審思量、我執   | 第八識     | 「這是我」      |
| **第八識** | 阿賴耶識 | 含藏種子、維持相續 | 種子及所現行境 | 「為何經驗會相續？」 |

可以把它簡化成：

```text
眼 ─┐
耳 ─┤
鼻 ─┤
舌 ─┤ → 感官世界 → 第六識 → 分別、判斷
身 ─┘                    │
                         ↓
                    第七識：我執
                         │
                         ↓
                第八識：種子與相續
```


前五識（眼耳鼻舌身）：非恆非審——外境來了才起作用。
第六意識：審而非恆——它能判斷、能分析，但會中斷。
第七末那識：亦恆亦審——既不中斷，又一直在認定。
第八識：恆而非審——它一直在運轉，但不做判斷。

---

# 二、前五識：直接面對感官世界

前五識就是：

> **眼識、耳識、鼻識、舌識、身識**

分別對應：

```text
眼識 → 色
耳識 → 聲
鼻識 → 香
舌識 → 味
身識 → 觸
```

例如你看到一朵花：

```text
眼睛
 ↓
視覺刺激
 ↓
眼識
 ↓
「看到某種色、形」
```

這時候還不一定產生完整的「概念」。

真正開始進行：

> 「這是一朵花。」

> 「這朵花很好看。」

> 「我喜歡這種花。」

主要已經涉及**第六識**。

---

# 三、第六識：意識——「分別世界」

第六識是我們日常最容易理解的「意識」。

它具有非常強大的：

* 分別
* 判斷
* 推理
* 記憶
* 想像
* 比較
* 語言
* 概念化
* 情緒反應

例如：

```text
眼識
 ↓
看到紅色物體
 ↓
第六識
 ↓
「這是一朵玫瑰」
 ↓
「玫瑰很漂亮」
 ↓
「我喜歡玫瑰」
 ↓
「以前有人送過我玫瑰」
```

所以唯識學會進一步問：

> **我們所認識的「世界」，究竟是世界本身，還是經過識的加工之後所呈現的世界？**

這就是「唯識」問題開始變得重要的地方。

---

# 四、第七識：末那識——「我」從哪裡來？

這是理解八識最關鍵、也最容易混淆的一識。

**末那識（manas）**的核心特徵是：

> **恆審思量**

它不是單純「思考事情」，而是具有非常深層的：

> **我執**

也就是把第八識執著為「我」。

可以用一個簡化模型理解：

```text
第八識
阿賴耶識
   ↑
   │ 被第七識誤認
   │
第七識
末那識
   │
   ├──「這是我」
   ├──「這是我的」
   ├──「我比他好」
   ├──「他傷害了我」
   └──「我要保護自己」
```

因此：

### 第六識問：

> 「這是什麼？」

### 第七識問：

> 「這跟我有什麼關係？」

甚至進一步變成：

> **「我怎麼樣？」**

---

# 五、第八識：阿賴耶識——唯識學的核心

第八識稱：

> **阿賴耶識（Ālayavijñāna）**

「阿賴耶」具有「藏」的意義，因此常稱：

> **藏識**

它是唯識學中非常重要的概念。

它主要涉及：

### ① 種子

過去的行為、經驗、心理活動等，形成「種子」。

```text
經驗
 ↓
熏習
 ↓
種子
 ↓
阿賴耶識
 ↓
遇到條件
 ↓
現行
 ↓
新的經驗／行為
 ↓
再次熏習
```

形成：

> **種子 → 現行 → 熏習 → 種子**

的循環。

---

# 六、什麼叫「種子」？

「種子」不是物質性的種子。

而是唯識學用來說明：

> **為什麼過去的行為會影響現在與未來？**

例如：

```text
第一次生氣
 ↓
留下心理傾向
 ↓
再次遇到刺激
 ↓
更容易生氣
 ↓
又生氣
 ↓
「生氣」的傾向更加強化
```

唯識學可以用：

> **熏習 → 種子 → 現行**

來說明這種心理相續。

---

# 七、八識不是八個「人」

這一點非常重要。

八識不是：

```text
我裡面住著八個小人
```

也不是：

```text
眼識 = 一個人
耳識 = 一個人
...
```

而是唯識學對**認知與心理活動不同功能層次**的分析模型。

可以把它理解成：

```text
                「一個生命的心識活動」
                         │
        ┌────────────────┼────────────────┐
        │                │                │
      感知             分別             深層相續
        │                │                │
     前五識             第六識          第七、八識
        │                │                │
     感官資料          思考判斷          我執／種子
```

---

# 八、八識與「我」的關係

唯識學非常有意思的一點，就是它並沒有找到一個固定不變的「我」。

反而分析：

```text
前五識
 ↓
感官經驗

第六識
 ↓
思想、記憶、判斷

第七識
 ↓
執著「我」

第八識
 ↓
業種、心識相續
```

因此：

> **「我」不是一個獨立不變的實體，而是識、種子、執著與經驗相續所形成的「我執」結構。**

這也可以與你前面學過的《阿含經》連接起來：

```text
《阿含經》
五蘊 → 無我
   ↓
《般若經》
人空 → 法空
   ↓
《中論》
緣起 → 無自性 → 空
   ↓
唯識學
八識 → 種子 → 我執／法執 → 三性
```

這裡是一條**學習上的概念連線**，不是說佛教思想真的按照這條單線歷史演化。

---

# 九、第六識與第七識的差別

這是學八識時最值得特別掌握的一組。

|        | 第六識     | 第七識         |
| ------ | ------- | ----------- |
| 名稱     | 意識      | 末那識         |
| 主要作用   | 分別      | 恆審思量        |
| 活動     | 思考、判斷   | 執著「我」       |
| 對象     | 廣泛的法境   | 主要執著第八識     |
| 是否容易察覺 | 很容易     | 非常不容易       |
| 核心問題   | 「這是什麼？」 | 「這是我的／我是誰？」 |
| 主要問題   | 分別心     | 我執          |

例如有人批評你：

```text
對方說了一句話
      ↓
耳識：聽見聲音
      ↓
第六識：理解意思
      ↓
第七識：這是在針對「我」
      ↓
第六識：他怎麼可以這樣說？
      ↓
瞋心產生
```

所以唯識學會追問：

> **真正讓我們痛苦的，是外境本身，還是「我」對外境的分別與執著？**

---

# 十、八識與「唯識」到底有什麼關係？

「唯識」並不是簡單地說：

> 「外面的世界不存在。」

更適合的理解是：

> **我們所經驗到的世界，必然透過識而呈現；因此必須分析「識如何構成我們所經驗的世界」。**

例如：

```text
外境刺激
    ↓
感官
    ↓
前五識
    ↓
第六識分別
    ↓
第七識加入「我」
    ↓
過去種子影響
    ↓
形成「我所經驗的世界」
```

所以唯識學真正關心的是：

> **「我們如何認識世界？」**

以及：

> **「錯誤的認識如何形成？」**

最後才進一步問：

> **「如何轉變這套認知結構？」**

---

# 十一、八識與三性

這就開始進入《成唯識論》的核心。

可以建立：

```text
八識
 │
 ├── 前五識
 ├── 第六識
 ├── 第七識
 └── 第八識
        │
        ↓
     種子、現行
        │
        ↓
     三性問題
        │
 ┌──────┼──────┐
 ↓      ↓      ↓
遍計所執 依他起性 圓成實性
 │        │        │
錯誤執著   緣起識流   真實如實
 │        │        │
我執法執   因緣相續   離妄顯真
```

這也是為什麼學習《成唯識論》不能只背「八識名稱」。

真正的學習路徑是：

> **八識 → 心所 → 四分 → 種子 → 現行 → 熏習 → 三性 → 二障 → 修行 → 轉識成智**

---

# 十二、八識最重要的「功能定位」

可以用一句話記憶：

```text
眼耳鼻舌身
    ↓
「感覺到了什麼？」

第六識
    ↓
「這是什麼？」

第七識
    ↓
「跟我有什麼關係？」

第八識
    ↓
「為什麼我的經驗會如此相續？」
```

再進一步：

```text
前五識 → 感知
第六識 → 分別
第七識 → 我執
第八識 → 種子／相續
```

---

# 十三、從「八識」走向「轉識成智」

唯識學最後不是要我們建立一個更精密的「八識理論」而已。

真正目的是：

> **轉識成智。**

可以把整套唯識學畫成：

```text
                 凡夫心
                    │
           ┌────────┴────────┐
           ↓                 ↓
        八識運作            種子熏習
           │                 │
           └────────┬────────┘
                    ↓
                 我執、法執
                    ↓
                 煩惱、業
                    ↓
                  生死
                    │
                    │ 修行
                    ↓
              唯識觀／三性觀
                    ↓
              轉依（根本轉變）
                    ↓
                轉識成智
                    │
       ┌────────────┼────────────┐
       ↓            ↓            ↓
   大圓鏡智      平等性智      妙觀察智
                                  │
                                  ↓
                              成所作智
```

---

## 十四、八識的終極記憶表

| 層次   | 八識  | 凡夫狀態   | 修行後的轉變 |
| ---- | --- | ------ | ------ |
| 感官   | 前五識 | 被境界牽動  | 成所作智   |
| 分別   | 第六識 | 妄想、分別  | 妙觀察智   |
| 我執   | 第七識 | 執著自我   | 平等性智   |
| 深層相續 | 第八識 | 含藏染淨種子 | 大圓鏡智   |

因此可以把《成唯識論》的整個修行方向濃縮成：

> **前五識 → 第六識 → 第七識 → 第八識 → 轉依 → 四智**

而最值得牢記的是：

> **第六識是「分別」的核心，第七識是「我執」的核心，第八識是「種子與相續」的核心。**

這三者掌握後，再進入《成唯識論》的**「五十一心所＋四分＋種子六義＋三性三無性」**，八識就會從「名詞記憶」真正變成一套完整的唯識心理學與解脫論架構。
