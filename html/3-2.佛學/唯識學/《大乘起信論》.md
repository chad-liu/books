# 《大乘起信論》：一心、二門、三大與修行成佛之道

《大乘起信論》是漢傳大乘佛教思想史上極具影響力的論典。它以簡潔而深刻的理論，試圖回答幾個根本問題：

- 眾生本具的覺悟可能性是什麼？
- 為什麼具有覺悟可能性的眾生，仍然會迷惑、執著與受苦？
- 真如與生滅、清淨與染污、眾生與佛之間，究竟有什麼關係？
- 凡夫如何透過信心、理解、修行，逐步走向覺悟？

本論最著名的思想架構是「一心、二門、三大」，並以「真如」與「生滅」兩個面向說明心的不同意義。

如果說《唯識二十論》著重分析心識與外境的關係，《辨中邊論》著重辨明虛妄分別與空性，那麼《大乘起信論》則進一步關心：眾生如何理解自身的迷悟關係，並由信心與修行走向覺悟。

不過，必須先說明一個重要的學術問題：傳統上，《大乘起信論》被歸於馬鳴（Aśvaghoṣa）造，並有真諦譯、實叉難陀譯等傳統版本；但現代佛教文獻研究對其印度起源、作者歸屬及漢地形成背景仍有爭論。因此，討論本論時，最好區分「傳統歸屬」與「現代歷史研究」兩個層次。

## 一、基本資料

## 《大乘起信論》

傳統作者

馬鳴（Aśvaghoṣa）

傳統譯者

真諦、實叉難陀各有漢譯傳本

思想背景

如來藏思想、真如思想、大乘心性論

核心架構

一心、二門、三大

主要議題

眾生心、真如、生滅、無明、熏習、信心與修行

《大乘起信論》在中國佛教思想史上影響深遠，尤其與華嚴、禪宗及東亞佛教的心性論傳統有密切關係。它也常被拿來與印度瑜伽行派、如來藏經典及中觀思想比較。

然而，它並不只是將某一印度佛教學派的理論原封不動地翻譯過來。它所呈現的整體架構，具有鮮明的漢傳佛教思想史意義。

## 二、全論的五大部分

《大乘起信論》可以分成五個主要部分，從說明寫作目的，進入核心教義，再走向實際修行。

| 部分    | 主要內容           | 要回答的問題        |
| ----- | -------------- | ------------- |
| 因緣分   | 說明造論的因緣與目的     | 為什麼要學習大乘佛法？   |
| 立義分   | 提出一心、二門、三大     | 大乘法的根本義理是什麼？  |
| 解釋分   | 解釋真如、生滅、熏習、修行等 | 眾生為何迷惑，又如何覺悟？ |
| 修行信心分 | 說明信心與修行方法      | 如何從理解走向實踐？    |
| 勸修利益分 | 勸勉修學並說明其利益     | 為什麼應當持續修行？    |

全論最具代表性的教義集中在第二、第三部分，但若只讀「一心、二門、三大」，而不繼續讀修行部分，就容易把它理解成純粹的形上學，而忽略它的實踐目的。

## 三、核心架構：「一心、二門、三大」

這是《大乘起信論》最重要的理論架構。

# 一心

眾生心

以一心統攝真如與生滅兩個面向

## 真如門

從不生不滅、離言說與分別的角度理解心的真實性。

## 生滅門

從因緣、無明、心識活動與染淨變化的角度理解心。

## 三大：體大、相大、用大

### 體大

真如之體平等，不因凡夫與佛而有本質上的增減。

### 相大

如來藏具足無量性功德。

### 用大

真如與佛的功德能成為眾生修行、成佛的依據與作用。

這個架構的關鍵，不是說人有兩顆心，也不是說世界分成真如世界與生滅世界兩個地方。

「一心」是統攝性的說法；「二門」是從兩種角度解釋同一心的真實性與生滅活動；「三大」則用體、相、用來說明大乘法的廣大意義。

### 1. 一心：眾生心

本論以眾生心作為大乘法的核心。這裡的「心」不只是平常所說的情緒、思想或個人意識，而是一個涵蓋真如與生滅的廣義概念。

它既能從真如的角度被理解，也能從無明、心識活動與染淨因果的角度被理解。

因此，不能直接把「一心」等同於現代心理學的意識，也不能不加區分地把它當成宇宙中唯一的精神實體。

### 2. 二門：真如門與生滅門

真如門著重諸法真實性，不以生滅、差別、名言分別來界定真如。

生滅門則分析心如何在因緣條件下呈現生滅、染污、清淨與修行轉變。

兩門不是彼此隔絕的兩個世界。它們是從不同角度理解眾生心：一方面，真如不能被簡化成隨因緣起伏的生滅現象；另一方面，眾生的迷惑與修行也必須在生滅因緣的脈絡中理解。

### 3. 三大：體大、相大、用大

- \*\*體大：\*\*真如之體廣大平等，不因凡夫的迷惑而被真正破壞，也不因佛的覺悟而變成另一種本質。
- \*\*相大：\*\*真如具有無量性功德，這是本論以如來藏與佛性思想說明覺悟可能性的方式。
- \*\*用大：\*\*真如與佛的功德能夠發揮作用，令眾生生起信心、修行並走向覺悟。

這三者共同回答一個問題：如果眾生目前充滿煩惱，為什麼仍然可能成佛？

本論的回答是，眾生的迷惑並不等於覺悟的可能性徹底消失；透過因緣、熏習與修行，迷惑可以逐步止息，智慧與功德可以顯現。

## 四、眾生為什麼會迷惑？——本覺、不覺與始覺

《大乘起信論》最重要的問題之一，是如何同時說明兩件看似矛盾的事：

1. 眾生具有覺悟的可能性。
2. 眾生仍然受到無明、煩惱與錯誤認知的支配。

本論透過「本覺、不覺、始覺」的架構，來說明迷悟的關係。

| 概念  | 意義                    | 在修行中的位置      |
| --- | --------------------- | ------------ |
| 本覺  | 從真如及覺悟可能性的角度，說明眾生心的本性 | 說明眾生為何有成佛的可能 |
| 不覺  | 由於無明而不能如實理解真如，產生虛妄分別  | 說明迷惑與煩惱如何成立  |
| 始覺  | 透過修行與智慧，逐步覺察並止息無明     | 說明實際修行的過程    |
| 究竟覺 | 覺悟達到究竟，不再有根本無明        | 說明佛果的完成      |

### 以日常生活作比喻

假設一個人長期認為「我只要犯一次錯，就代表我是毫無價值的人」。

- \*\*不覺：\*\*他把一次失敗當成固定不變的自我本質，反覆陷入自責。
- \*\*始覺：\*\*他開始觀察自己的想法，發現這個判斷受到過去經驗、恐懼與習慣影響。
- \*\*修行深化：\*\*他逐步減少對固定自我形象的執著，學習以智慧與慈悲面對自己和他人。
- \*\*究竟覺：\*\*在本論的宗教意義中，這不只是心理調適，而是徹底斷除根本無明、證得覺悟。

這個例子只是現代生活中的類比，不能把佛教所說的究竟覺直接等同於心理健康或情緒管理。

本覺不等於凡夫已經具備佛陀的一切智慧；它是說明迷惑並非不可改變，以及修行為何可能成功的理論基礎。

## 五、真如、生滅與阿賴耶識：本論如何解釋心的變化？

這是《大乘起信論》與《唯識三十頌》《成唯識論》比較時，最值得深入研究的部分。

本論在解釋生滅門時，使用了阿梨耶識（阿賴耶識）及「覺與不覺和合」等概念，試圖說明真如與生滅、染污與清淨如何在同一眾生心的架構中被理解。

### 1. 無明與生滅

依本論的理論，眾生因無明而不能如實認識真如，於是產生心的動搖、主客分別，以及後續的染污活動。

這並不是說真如本身真的變成了污濁的東西，而是說眾生在無明的條件下，對經驗產生了不如實的認識。

### 2. 熏習：迷惑如何延續，覺悟如何增長？

「熏習」是本論的重要概念，可以先理解為某種條件對心的持續影響。

本論以熏習說明染污與清淨兩個方向：

- 染法熏習：無明與染污活動互相影響，使迷惑持續。
- 淨法熏習：真如、信心、佛法教導及修行等因素，成為眾生逐步走向覺悟的條件。

因此，修行不只是偶爾產生一個正確觀念，而是持續改變認知、習慣與行為的過程。

### 3. 與《成唯識論》的比較

| 比較面向   | 《大乘起信論》       | 《成唯識論》           |
| ------ | ------------- | ---------------- |
| 核心架構   | 一心、真如門、生滅門    | 八識、三性、種子、轉依      |
| 迷惑的說明  | 無明、不覺與染污熏習    | 識的活動、種子、現行及煩惱障礙  |
| 覺悟的可能性 | 本覺與真如熏習等理論    | 透過智慧修行、轉依及斷除障礙   |
| 理論表達   | 以一心統攝真如與生滅    | 以識的結構與認知活動建立系統   |
| 研究上的難題 | 如何理解真如與生滅的關係？ | 如何理解八識、三性與空性的關係？ |

兩部論典有可比較之處，但不能直接把《大乘起信論》的「一心」等同於《成唯識論》的第八識，也不能把本覺直接等同於阿賴耶識中的某種種子。

兩者的概念系統與思想背景並不完全相同。

## 六、四信與五行：如何從信心走向修行？

《大乘起信論》並非只建立心性理論，也提出具體的修行方向。

### 四信

| 信心  | 主要意義                  |
| --- | --------------------- |
| 信根本 | 信受真如是大乘法的根本           |
| 信佛  | 信佛的智慧、功德與覺悟           |
| 信法  | 信受佛法所揭示的真理與修行道路       |
| 信僧  | 信受僧團及修行者在正法傳承與實踐上的重要性 |

這裡的信不是要求人停止思考，而是指對大乘法的根本方向建立信受，使理解能夠進一步轉化為實踐。

### 五行

本論以布施、持戒、忍辱、精進、止觀等修行來說明如何培養菩薩的實踐能力。

| 修行 | 核心意義             | 日常實踐例子           |
| -- | ---------------- | ---------------- |
| 布施 | 減少慳貪，培養施予與利他     | 分享資源、知識與時間       |
| 持戒 | 約束行為，減少傷害        | 不欺騙、不傷害、不以私利損人   |
| 忍辱 | 面對逆境與傷害時不被瞋恨支配   | 遇到批評時先理解情境，不急於報復 |
| 精進 | 持續修善斷惡           | 建立穩定的學習與修行習慣     |
| 止觀 | 令心安定，並以智慧觀察身心與諸法 | 練習專注，再觀察執著如何形成   |

其中「止觀」尤其重要：止有助於令心安定，觀則引導智慧觀察真如、無明及身心活動。兩者並非互相排斥，而是相互配合。

## 七、止觀雙修：如何理解修行的內在方法？

本論把止觀修行視為重要的實踐方法。

- \*\*止：\*\*令心逐步安定，減少散亂與躁動。
- \*\*觀：\*\*透過智慧觀察因緣、無明、執著及諸法的真實性。

如果只有止而缺乏觀，可能過度追求安靜，卻沒有真正理解煩惱的根源；如果只有觀而缺乏止，則可能陷入概念思辨，心仍然散亂。

兩者的配合，才能使修行不只是理論知識，也不只是短暫的寧靜經驗。

以瞋怒為例：

1. 先透過止，避免立即被情緒推動而作出傷害性的行為。
2. 再透過觀，檢視瞋怒所依賴的判斷、執著與因緣。
3. 在反覆練習中，逐步減少煩惱對行為的支配。

這種練習是現代生活中的初步應用；本論所說的完整止觀，仍以大乘的真如理解及解脫目標為根本。

## 八、《大乘起信論》的思想史地位與作者問題

這部論在東亞佛教史上極為重要，對華嚴、禪宗及後來的佛教心性論產生深遠影響。它的「一心二門」與本覺思想，提供了一套容易與修行實踐連結的理論架構。

但現代學術研究對其起源仍有爭論。

- \*\*傳統說法：\*\*本論歸於印度馬鳴，並傳為真諦譯。
- \*\*現代研究中的一種主流看法：\*\*由於現存文本只有漢文傳本，且尚無可確認的梵文原本，許多研究者認為它可能是在中國形成的論典。
- \*\*不同學術立場：\*\*也有研究者根據古代經錄、譯經史料及真諦思想的關聯，主張傳統翻譯說仍有值得認真考慮的證據。

例如，牛津大學出版社的佛教研究書目指出，本論的起源不確定；曼徹斯特大學收錄的研究則將其視為以印度論師名義流傳、對東亞佛教極具影響力的漢地佛教著作。另一方面，也有學者從經錄及譯經史料出發，支持真諦翻譯說。

## 十、總結

《大乘起信論》最值得掌握的四個核心是：

1. \*\*一心二門：\*\*從真如與生滅兩個面向理解眾生心。
2. \*\*三大：\*\*以體大、相大、用大說明大乘法的意義。
3. \*\*本覺與始覺：\*\*說明眾生為何有覺悟的可能，以及如何透過修行實現覺悟。
4. \*\*信心與止觀：\*\*將理論落實為菩薩道的實踐。

一句話總結：《大乘起信論》試圖說明，眾生雖因無明而迷惑，但迷惑並非不可改變；透過正確理解、信心、熏習與修行，便能逐步走向覺悟。
