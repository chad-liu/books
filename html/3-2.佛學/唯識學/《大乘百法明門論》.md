# 《大乘百法明門論》：用一百種法分析身心與世界

《大乘百法明門論》，簡稱《百法明門論》，是漢傳唯識學的重要入門論典，傳統上歸於世親（Vasubandhu）造，玄奘譯。

這部論的核心任務，是把佛教所分析的身心與現象，整理成一套有系統的分類架構，總計一百種「法」。

如果說《唯識二十論》主要追問「外境是否必須獨立於心識而存在」，那麼《百法明門論》則進一步追問：

我們所經驗的世界，可以分解成哪些基本的心理活動、心理因素、物質現象，以及其他存在與變化的條件？

它不是單純列出一百個名詞，而是透過分類，幫助修學者辨識心識如何運作、煩惱如何生起，以及如何理解無我與空性。

## 一、基本資料

## 《大乘百法明門論》

作者

世親（Vasubandhu，傳統歸屬）

譯者

玄奘

所屬

印度大乘瑜伽行派、漢傳法相唯識學

核心內容

將諸法歸納為五位百法

主要用途

建立唯識學的基本分類、理解心識與心理活動

《百法明門論》的篇幅不長，但它的分類系統與《成唯識論》密切相關。學習者通常會先以百法建立概念架構，再深入閱讀《成唯識論》及相關注疏。

其中最重要的分類原則是「五位百法」：

* 心法：8 種

* 心所有法：51 種

* 色法：11 種

* 心不相應行法：24 種

* 無為法：6 種

合計：

8+51+11+24+6=1008+51+11+24+6=1008+51+11+24+6=100

這一百法是唯識學的教義分類，不應直接理解成現代自然科學所說的一百種物質或一百個獨立實體。

## 二、五位百法：整體架構

## 一百法

分析一切法的五大類

### 一、心法

# 8

認知活動本身

### 二、心所有法

# 51

伴隨心識而起的心理活動

### 三、色法

# 11

物質與感官對象

### 四、心不相應行法

# 24

依其他法建立的關係與概念

### 五、無為法

# 6

不屬於生滅造作的法

這五類並不是把世界分成五個互不相干的區域，而是用不同的角度，分析經驗中的認知、心理因素、物質現象、抽象關係及無為法。

## 三、第一位：心法（8 種）

心法指八種識，是唯識學理解認知活動的核心。

| 編號 | 心法   | 基本意義          |
| -- | ---- | ------------- |
| 1  | 眼識   | 依眼根而起的視覺認知    |
| 2  | 耳識   | 依耳根而起的聽覺認知    |
| 3  | 鼻識   | 依鼻根而起的嗅覺認知    |
| 4  | 舌識   | 依舌根而起的味覺認知    |
| 5  | 身識   | 依身根而起的觸覺認知    |
| 6  | 意識   | 思考、判斷、概念分別等活動 |
| 7  | 末那識  | 執著於「我」的深層心識活動 |
| 8  | 阿賴耶識 | 攝持種子、維繫生命相續的識 |

### 八識如何理解？

以「看到一朵花」為例：

* 眼識：產生視覺認知。

* 意識：辨認它是花，聯想到名稱、用途與記憶。

* 末那識：可能把經驗與「我喜歡」「這是我的」等自我執著聯繫起來。

* 阿賴耶識：在唯識理論中，與過去熏習所形成的種子及經驗相續有關。

這只是便於理解的示例。實際的唯識理論對八識的生起條件、同時活動及彼此關係，有更精細的分析。

## 四、第二位：心所有法（51 種）

「心所有法」又稱心所，指與心識相應的心理活動或心理因素。

例如，看見一朵花時，除了視覺認知，還可能產生注意、感受、喜愛、判斷及記憶。唯識學把這些心理因素進一步分類。

### 1. 五遍行（5 種）

遍行心所是心識活動中最基本的一組。

| 心所 | 意義                | 例子          |
| -- | ----------------- | ----------- |
| 作意 | 引導心識注意對象          | 注意到桌上的花     |
| 觸  | 根、境、識等條件和合而有的接觸作用 | 視覺認知與對象相接   |
| 受  | 對經驗的感受性           | 感到愉快、不愉快或中性 |
| 想  | 取相、辨認特徵           | 辨認花的顏色與形狀   |
| 思  | 推動心識造作與行動         | 決定靠近或摘下花    |

### 2. 五別境（5 種）

這些心所與特定認知對象或心理條件有關。

| 心所 | 意義               |
| -- | ---------------- |
| 欲  | 希求、想要            |
| 勝解 | 對所認知內容形成確定的理解或認可 |
| 念  | 記持、不忘失曾經經驗的內容    |
| 定  | 令心專注於所緣          |
| 慧  | 辨析、簡擇、理解         |

### 3. 十一善心所（11 種）

這組心所與善的心理狀態及修行有關。

| 心所  | 意義                |
| --- | ----------------- |
| 信   | 對實德能等生起清淨信受       |
| 精進  | 勇悍地努力修善斷惡         |
| 慚   | 依自身與正法等而羞恥於作惡     |
| 愧   | 顧及世間規範與他人評價而羞恥於作惡 |
| 無貪  | 不過度執取、不貪著         |
| 無瞋  | 不懷瞋恨、具有不害的心向      |
| 無癡  | 不愚昧，具有正確理解        |
| 輕安  | 身心調適、輕快安穩         |
| 不放逸 | 防止惡法生起，促進善法增長     |
| 行捨  | 心保持平衡，不過度躁動或偏執    |
| 不害  | 不損害眾生，具有悲憫精神      |

### 4. 六根本煩惱（6 種）

根本煩惱是其他許多煩惱與不善心理活動的重要根源。

| 心所  | 意義              |
| --- | --------------- |
| 貪   | 貪著、渴求           |
| 瞋   | 憤怒、敵意           |
| 癡   | 無明、愚昧           |
| 慢   | 自高、比較而生的傲慢      |
| 疑   | 對真理、因果或正確道路產生疑惑 |
| 不正見 | 錯誤的見解           |

「不正見」還可細分為五種：身見、邊見、邪見、見取見、戒禁取見。

### 5. 二十隨煩惱（20 種）

隨煩惱是伴隨或依附煩惱而起的心理活動。依傳統分類，可分為小、中、大三組。

| 分組       | 心所                       |
| -------- | ------------------------ |
| 小隨煩惱（10） | 忿、恨、覆、惱、嫉、慳、誑、諂、害、憍      |
| 中隨煩惱（2）  | 無慚、無愧                    |
| 大隨煩惱（8）  | 惛沈、掉舉、不信、懈怠、放逸、失念、散亂、不正知 |

例如：

* 忿：遇到不如意的事，立即生起憤怒。

* 恨：對過去的傷害長期懷怨。

* 嫉：見到他人得到利益或成就而心生嫉妒。

* 慳：對財物、知識或資源過度吝惜。

* 掉舉：心躁動不安，難以安住。

* 散亂：心識四處攀緣，不能專注。

* 失念：忘失應當記持的對象或正念。

* 不正知：對自己的身心活動或行為缺乏正確辨識。

### 6. 四不定心所（4 種）

這四種心所的性質，須依其具體條件判斷，不能一概判定為善或惡。

| 心所 | 意義             |
| -- | -------------- |
| 睡眠 | 心識活動與睡眠狀態相關    |
| 惡作 | 對已做或未做之事產生追悔   |
| 尋  | 對對象進行較粗略的思索、尋求 |
| 伺  | 對對象進行較細緻的觀察、推求 |

五遍行、五別境、十一善、六根本煩惱、二十隨煩惱與四不定心所相加：

5+5+11+6+20+4=515+5+11+6+20+4=515+5+11+6+20+4=51

## 五、第三位：色法（11 種）

色法指物質性或具有質礙、變礙特徵的法。百法分類中共有十一種。

| 分類       | 內容             |
| -------- | -------------- |
| 五根（5）    | 眼根、耳根、鼻根、舌根、身根 |
| 五境（5）    | 色境、聲境、香境、味境、觸境 |
| 法處所攝色（1） | 歸於法處的色法        |

### 如何理解五根、五境？

* 五根：感官認知所依的根。

* 五境：感官所緣取的對象。

* 法處所攝色：歸入法處的特殊色法，不能簡單等同於一般可見、可觸的物體。

要注意，唯識學中的「色法」不能直接等同現代物理學所定義的物質。它是佛教論典依自身的認知與存在分類所建立的概念。

## 六、第四位：心不相應行法（24 種）

這一類最容易令人困惑。

「心不相應行法」並不是心識本身，也不是一般意義上的物質，而是指依色、心等法的關係或變化而安立的法。

以下列出傳統百法分類的二十四種：

| 編號 | 法    | 簡要說明           |
| -- | ---- | -------------- |
| 1  | 得    | 成就、獲得某種法的關係    |
| 2  | 命根   | 維持一期生命的條件      |
| 3  | 眾同分  | 同類眾生或事物的共同性    |
| 4  | 異生性  | 凡夫與聖者在修證上的區別   |
| 5  | 無想定  | 令某些心、心所活動止息的禪定 |
| 6  | 滅盡定  | 令受、想等心所活動止息的禪定 |
| 7  | 無想報  | 無想天的異熟果報       |
| 8  | 名身   | 名稱的集合          |
| 9  | 句身   | 句子的集合          |
| 10 | 文身   | 構成名句的文字單位      |
| 11 | 生    | 生起、出現          |
| 12 | 老    | 衰變、老化          |
| 13 | 住    | 暫時安住           |
| 14 | 無常   | 壞滅、變化          |
| 15 | 流轉   | 因果相續、流轉不息      |
| 16 | 定異   | 因果差別及其確定性      |
| 17 | 相應   | 諸法依條件相互關聯      |
| 18 | 勢速   | 迅速變化、運行        |
| 19 | 次第   | 前後次序           |
| 20 | 方    | 方位、空間方向        |
| 21 | 時    | 時間             |
| 22 | 數    | 數量、數目          |
| 23 | 和合性  | 諸法和合的關係        |
| 24 | 不和合性 | 諸法不和合的關係       |

這一類的學習關鍵是：唯識學把某些關係、秩序與變化特徵獨立分類，但不因此就把它們視為不依條件而獨立存在的實體。

例如，「時間」可以用來描述事件的先後與持續；「次第」用來描述排列順序。這些概念在百法中有其分類位置，但其存在方式與心法、色法並不相同。

## 七、第五位：無為法（6 種）

「無為」與「有為」相對。有為法是依因緣造作而生滅變化的法；無為法則不屬於這類生滅造作。

傳統百法分類的六種無為法如下：

| 編號 | 無為法   | 基本意義           |
| -- | ----- | -------------- |
| 1  | 虛空無為  | 不受障礙的空間性之安立    |
| 2  | 擇滅無為  | 由智慧簡擇而證得的滅     |
| 3  | 非擇滅無為 | 不由智慧簡擇而成立的滅    |
| 4  | 不動滅無為 | 與特定禪定境界相關的滅    |
| 5  | 想受滅無為 | 與滅盡定所說的想、受止息相關 |
| 6  | 真如無為  | 諸法真實如是的理性      |

不同注疏對個別無為法的解釋，可能在細節上有所不同。尤其「真如」不是普通意義上的物質，也不能直接理解為藏在萬物背後的一個永恆自我。

在唯識學的脈絡中，無為法的分類涉及如何理解解脫、滅除煩惱，以及對諸法真實性的認識。

## 八、百法與唯識修行有什麼關係？

百法不是只供背誦的名詞清單。它的修學意義，在於幫助我們分析經驗與煩惱。

例如，當一個人受到批評而憤怒，可以試著依百法的概念來觀察：

1. **心法：**意識正在理解對方說了什麼。

2. **心所有法：**受、想、思等心理活動參與其中。

3. **煩惱心所：**瞋、忿、恨或其他隨煩惱可能生起。

4. **因果與熏習：**反覆採取相同的反應方式，可能形成更強的習慣。

5. **修行方向：**藉由正確理解、正念與智慧，逐步減少煩惱的支配。

這只是把唯識分類用於日常反省的示例，不是說每次生氣都必然同時具備所有上述心所。

百法幫助修學者從「我就是生氣」的整體感受，轉而分析：哪些認知活動、感受、執取及煩惱正在發生？這種分析有助於減少把暫時的心理狀態認作固定不變的「我」。

## 十、總結

《百法明門論》最值得掌握的，不是單純記住一百個名詞，而是理解它如何建立一套分析身心與現象的分類系統。

* **心法八種：**認知活動的基本分類。

* **心所有法五十一種：**心理活動、善法與煩惱的細緻分析。

* **色法十一種：**物質性與感官對象。

* **心不相應行法二十四種：**關係、秩序、變化及其他安立的法。

* **無為法六種：**理解不屬於生滅造作的法。

學習百法之後，便能更有系統地閱讀《唯識二十論》的外境辯論，以及《唯識三十頌》對八識、三性和轉依的論述。

一句話總結：《百法明門論》提供唯識學的「分類工具」；《唯識二十論》提供唯識學的「論證方法」；《唯識三十頌》則提供唯識學的「核心理論綱要」。
