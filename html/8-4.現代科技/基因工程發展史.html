基因工程發展史（Genetic Engineering History）

基因工程是現代生物科技最重要的發展之一，主要透過人工技術，直接改變生物體的遺傳物質（DNA），以達到改良生物性狀、製造藥物、治療疾病、提高農業生產力及研究生命運作機制等目的。

基因工程的發展與分子生物學、遺傳學、微生物學、生物化學及生物資訊學密切相關。從孟德爾的遺傳定律、DNA雙螺旋結構，到重組DNA、基因定序、人類基因組計畫，再到CRISPR基因編輯，逐步改變了人類對生命的理解與運用。

以下按照歷史年代，整理基因工程的重要發展、科學家、技術突破及重大事件。

2. 基因工程誕生前的三大科學突破

（1）DNA雙螺旋結構

1953年，詹姆斯・華生（James Watson）與法蘭西斯・克里克（Francis Crick）提出DNA雙螺旋結構模型。

這項發現解釋了：

  • 遺傳資訊如何儲存在DNA中。
  • DNA如何進行複製。
  • 遺傳資訊如何傳遞給下一代。

（2）限制酶的發現

限制酶（Restriction Enzyme）能辨識特定DNA序列並切割DNA，使科學家能夠像使用剪刀一樣，精確切開DNA片段。

（3）DNA連接酶的發展

DNA連接酶（DNA Ligase）能將不同DNA片段連接起來，讓科學家有能力將不同來源的基因組合成新的DNA分子。

這三項技術共同構成早期基因工程的基礎。

1975年阿西洛馬會議的重要性

隨著科學家開始人工組合DNA，學界擔心可能產生具有危險性的微生物，甚至造成環境或公共衛生問題。

因此，1975年在美國加州阿西洛馬舉行國際科學會議，討論：

  1. 重組DNA研究的潛在危險。
  2. 實驗室生物安全與防護措施。
  3. 不同風險研究應採取的防護等級。
  4. 科學研究自由與社會責任之間的平衡。

這是現代生物科技倫理與安全管理的重要里程碑。

重要突破一：基因工程胰島素

1982年，美國食品藥物管理局（FDA）批准由基因工程技術製造的人類胰島素 Humulin。

其基本原理是：

  1. 取得人類胰島素基因。
  2. 將基因導入大腸桿菌等宿主細胞。
  3. 利用微生物大量製造胰島素相關蛋白質。
  4. 經過加工、純化及品質檢驗後，製成藥品。

歷史意義： 這項突破使基因工程正式成為現代製藥產業的重要生產技術。

重要突破二：PCR技術

PCR（Polymerase Chain Reaction，聚合酶連鎖反應）由凱利・穆利斯於1983年提出。

主要功能：

  • 大量複製特定DNA片段。
  • 協助遺傳疾病診斷。
  • 用於病毒及細菌檢測。
  • 用於法醫DNA鑑定。
  • 支援基因研究及DNA定序。

穆利斯因此獲得1993年諾貝爾化學獎。

四、人類基因組計畫與基因體革命（1990～2000）

1990年代是基因工程從單一基因研究邁向整個基因組研究的重要階段。

1. 人類基因組計畫（Human Genome Project）

1990年，美國國家衛生研究院（NIH）及能源部（DOE）正式啟動人類基因組計畫，並逐步發展為國際合作研究。

其主要目標是：

  • 解讀人類約30億個DNA鹼基對。
  • 確認人類基因的數量與位置。
  • 建立完整的人類基因組圖譜。
  • 研究基因與疾病之間的關係。
  • 發展基因診斷及個人化醫療。

  • 促進遺傳疾病的研究。

重要突破二：合成生物學

2010年，克雷格・凡特（Craig Venter）研究團隊宣布成功製造合成細菌基因組，並將其導入細胞，使細胞依照合成基因組運作。

這項研究是合成生物學的重要里程碑。

合成生物學主要研究：

  1. 人工設計DNA序列。
  2. 合成生物體所需的基因組。
  3. 設計具有特定功能的生物系統。
  4. 利用生物細胞製造藥物、燃料及化學產品。

六、CRISPR基因編輯革命（2012～2020）

2012年是基因工程發展史上另一個重大轉折。

2. CRISPR-Cas9的基本原理

CRISPR-Cas9可以想像成一套具有定位功能的分子剪刀。

主要由兩個部分組成：

  • Cas9蛋白質： 負責切割DNA。
  • 引導RNA（Guide RNA）： 負責尋找特定的DNA目標位置。

基本過程：

  1. 引導RNA辨識目標DNA序列。
  2. Cas9蛋白質在符合條件的位置切割DNA。
  3. 細胞啟動DNA修復機制。
  4. 科學家利用修復機制，達到基因破壞、修正或插入等效果。

2. Casgevy：基因編輯治療的重大突破

2023年12月，美國FDA批准Casgevy（exa-cel），用於治療鐮刀型紅血球疾病。

這是CRISPR-Cas9技術從實驗室走向正式醫療應用的重要里程碑。

其治療概念：

  1. 從患者身上取得造血幹細胞。
  2. 在體外利用CRISPR-Cas9進行基因編輯。
  3. 調整與胎兒血紅素相關的基因調控機制。
  4. 經過處理後，將細胞重新輸回患者體內。
  5. 促進胎兒血紅素產生，改善鐮刀型紅血球疾病。

2024年，美國FDA又批准Casgevy用於輸血依賴型β型地中海型貧血。

這代表基因編輯已不再只是研究工具，而是開始成為實際的治療方式。

3. 新一代基因編輯技術

CRISPR-Cas9

透過引導RNA定位DNA，再利用Cas9切割DNA，進行基因修改。

2012年成為基因編輯的重要突破

鹼基編輯（Base Editing）

不必先造成DNA雙股斷裂，就能直接改變特定DNA鹼基。

2016年起快速發展

先導編輯（Prime Editing）

結合改造的Cas9與逆轉錄酶，讓研究者能進行更靈活的DNA序列修改。

2019年發表

CRISPR-Cas12

另一類重要的CRISPR基因編輯系統，具有不同的DNA辨識及切割特性。

2015年起受到廣泛研究

事件引起國際科學界強烈譴責，主要爭議包括：

  • 研究倫理審查問題。
  • 人體試驗風險與知情同意。
  • 基因編輯可能產生非預期突變。
  • 修改生殖細胞可能影響後代。
  • 科學研究是否應受到更嚴格的國際規範。

這件事也使人類基因編輯的倫理監管成為全球重要議題。
