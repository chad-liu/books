程式語言發展史（History of Programming Languages）

程式語言的發展史，是人類從「直接控制機器」逐漸走向「以自然語言風格描述問題」，再進一步發展到「讓人工智慧協助撰寫程式」的歷史。

早期電腦必須透過繁複的機器指令操作，程式設計師需要理解電腦硬體的運作方式。後來，高階程式語言逐漸出現，使人類能以比較接近數學與日常語言的方式，指揮電腦完成工作。

從 Fortran、COBOL、C、Java、Python，到今日的 Rust、Go 與 AI 輔助程式設計，程式語言不斷改變，也深刻影響科學研究、商業管理、網際網路及人工智慧的發展。

一、程式語言發展大事記

第一階段：程式設計的起源（19世紀～1940年代）

這個階段的核心，是建立讓機器按照一連串指令自動工作的概念。

時間重要事件發展意義
1801年雅卡爾提花織布機使用穿孔卡片以卡片控制機械動作，成為早期自動化控制的重要先例
1837年巴貝奇提出分析機設計出現可依照指令進行通用計算的構想
1843年愛達・勒芙蕾絲撰寫分析機伯努利數演算法被視為早期電腦程式設計的重要先驅
1936年艾倫・圖靈提出圖靈機建立計算理論的重要基礎
1940年代機器語言與二進位指令開始應用電腦透過 0 和 1 的指令執行運算
1945年馮・紐曼提出儲存程式架構的相關報告程式指令可以與資料一起儲存在記憶體中

這個階段的重要觀念：

  • 機器語言（Machine Language）：使用二進位指令直接控制電腦。
  • 穿孔卡片（Punched Cards）：透過卡片上的孔洞代表指令或資料。
  • 演算法（Algorithm）：將問題拆解成有順序的運算步驟。

第二階段：組合語言與第一批高階語言（1940～1950年代）

程式設計師逐漸發現，直接使用 0 和 1 撰寫程式太過困難，因此開始發展比較容易理解的語言。

時間語言／事件發展意義
1947年組合語言（Assembly Language）逐漸發展使用助記符號取代部分二進位指令
1949年Short Code 出現早期以較接近數學表達方式撰寫的高階程式語言之一
1952年Grace Hopper 推動 A-0 編譯系統推動以較高階的指令轉換成機器碼
1954年FORTRAN 開始開發IBM 開始研發適合科學與數值計算的高階語言
1957年FORTRAN 正式推出第一批廣泛使用的高階程式語言之一
1958年LISP 誕生成為人工智慧研究與符號運算的重要語言
1959年COBOL 誕生以商業資料處理為主要用途
1960年ALGOL 60 發表對後來程式語言的語法設計影響深遠

代表性語言

1. FORTRAN（1957）

全名為 Formula Translation，主要用於數學、物理、工程及科學計算，是早期重要的高階語言。

2. LISP（1958）

由約翰・麥卡錫提出，擅長符號處理、遞迴及人工智慧研究。

3. COBOL（1959）

全名為 Common Business-Oriented Language，適合銀行、財務及企業大量資料處理。

4. ALGOL（1960）

對區塊結構、程式語法及後來的 Pascal、C 等語言產生重要影響。

第四階段：物件導向與網際網路程式語言（1980～2000年）

三、程式語言的五大類型

程式語言除了依照年代分類，也可以依照「程式設計思想」分類。這種分類有助於理解不同語言為什麼會出現，以及它們適合解決什麼問題。

1. 機器語言（Machine Language）

  • 使用 0 和 1 表示指令。
  • 電腦可以直接執行。
  • 人類閱讀與撰寫非常困難。
  • 與特定處理器架構密切相關。

2. 組合語言（Assembly Language）

  • 使用助記符號代表機器指令。
  • 例如 MOV、ADD、SUB。
  • 可以直接控制處理器及硬體。
  • 常用於嵌入式系統與硬體底層開發。

3. 程序式語言（Procedural Programming）

  • 將工作拆解為一系列執行步驟。
  • 使用函式、條件判斷及迴圈。
  • 強調執行順序與程式流程。
  • 代表語言：C、Pascal、Fortran。

4. 物件導向語言（Object-Oriented Programming）

  • 將資料與功能組合成物件。
  • 使用類別、繼承、封裝及多型。
  • 適合大型、複雜的軟體系統。
  • 代表語言：Java、C++、C#、Python。

5. 函數式與宣告式語言（Functional & Declarative Programming）

  • 函數式：強調透過函數組合完成運算。
  • 宣告式：描述想要得到什麼結果，而非逐步指定如何完成。
  • 常用於資料處理、數學運算與邏輯推理。
  • 代表語言：Haskell、LISP、Prolog、SQL。

四、程式語言的世代演進

程式語言也可以依照與人類語言的接近程度，區分為不同世代。

世代名稱特色代表
第一代機器語言使用二進位指令0、1
第二代組合語言使用助記符號Assembly
第三代高階語言接近數學與人類表達方式C、Python、Java
第四代非程序式語言強調描述需求與結果SQL、MATLAB 等
第五代邏輯與限制式語言透過邏輯、規則與條件描述問題Prolog 等

這種分類主要是歷史上的教學分類，並不代表第五代語言一定比第三代語言更先進。例如，Python 雖然是現代語言，仍屬於第三代高階語言。

七、程式語言發展史的重要轉折

可以將整個發展過程歸納為六次重要變革：

時代重要轉折核心變化
1940年代機器語言人類直接控制電腦
1950年代高階語言人類開始使用較容易理解的語法
1970年代結構化與物件導向程式變得容易管理與維護
1990年代網際網路程式語言程式開始連結全球使用者
2000年代行動與雲端開發程式跨越裝置與運算平台
2020年代AI 輔助程式設計人類以自然語言與 AI 協同開發

最值得理解的歷史脈絡是：

程式語言的發展，不只是語法越來越簡單，而是人類逐漸提高了對電腦的抽象控制能力。

從一開始必須告訴電腦每一個電子指令，到後來只需要描述計算步驟，再到今天可以透過自然語言說明需求，讓 AI 協助產生程式。
