CRISPR基因編輯發展史（CRISPR Gene Editing History）

CRISPR基因編輯是21世紀生命科學最重要的技術革命之一。它讓人類首次能夠以相對簡便、快速且具有高度可設計性的方式，對生物體的DNA進行定點修改。

CRISPR技術最初並不是為了基因工程而發明，而是科學家在研究細菌如何抵抗病毒時，意外發現細菌具有一套特殊的免疫防禦系統。

經過數十年的研究，CRISPR從細菌的天然免疫機制，逐漸發展成為基因編輯工具，並進一步衍生出鹼基編輯、先導編輯、表觀遺傳調控及體內基因治療等技術。

CRISPR的歷史可以概括為：

細菌免疫現象發現 → CRISPR序列辨識 → Cas蛋白功能研究 → CRISPR-Cas9基因編輯 → 基因編輯工具多元化 → 臨床治療應用 → AI輔助基因設計。

一、CRISPR的基本概念與運作原理

1. 什麼是CRISPR？

CRISPR是英文：

Clustered Regularly Interspaced Short Palindromic Repeats

中文通常翻譯為：

規律成簇間隔短回文重複序列。

它是細菌及古菌基因組中的一種特殊DNA序列，具有抵抗病毒及其他外來遺傳物質的功能。

CRISPR系統通常與Cas蛋白（CRISPR-associated proteins）共同運作。

2. CRISPR-Cas9的基本構造

CRISPR-Cas9基因編輯系統主要包含三個重要部分：

組成英文功能
Cas9蛋白Cas9 Nuclease負責切割DNA
引導RNAGuide RNA引導Cas9尋找特定DNA序列
PAM序列Protospacer Adjacent MotifCas9辨識目標DNA所需的鄰近序列

其基本運作方式：

  1. 設計一段與目標DNA互補的引導RNA。
  2. 引導RNA與Cas9蛋白結合。
  3. 複合體尋找符合條件的DNA目標位置。
  4. Cas9辨識PAM序列並檢查目標序列。
  5. Cas9切割DNA雙股。
  6. 細胞利用自身DNA修復機制修補切口。

3. DNA修復的兩種主要方式

修復方式英文主要作用常見應用
非同源末端接合NHEJ直接連接DNA斷裂端，可能產生小型插入或缺失基因敲除
同源導向修復HDR利用同源DNA模板進行修復基因精準修改或插入

因此，CRISPR不只是剪斷DNA的工具，也能利用細胞修復機制達到不同的基因修改目的。

二、CRISPR發展史第一階段：細菌特殊DNA序列的發現（1980～2001）

CRISPR的歷史起源於細菌基因組研究。

當時科學家並不知道這些重複DNA序列具有免疫功能，只是逐漸發現某些細菌具有排列規律的特殊DNA片段。

1. 1987年：CRISPR序列的早期發現

1987年，日本大阪大學的石野良純及其研究團隊，在研究大腸桿菌（Escherichia coli）某個基因時，意外發現一段排列特殊的DNA序列。

這段序列具有：

  • 重複出現的短DNA片段。
  • 重複序列之間夾有不同序列。
  • 整體排列呈現規律性。

當時尚未了解這些序列的生物學功能。

這項發現後來被視為CRISPR研究的重要起點。

2. 1993年：微生物重複序列研究

荷蘭科學家Ruud Jansen及其研究團隊研究細菌基因組中的特殊重複序列，發現不同微生物具有類似的DNA排列模式。

他們進一步觀察到這些重複序列附近經常存在一群相關基因。

這些基因後來被稱為Cas基因。

3. 2001年：CRISPR正式命名

研究者Ruud Jansen等人在2002年正式發表相關命名研究，使用CRISPR作為這類DNA序列的名稱。

這項命名讓不同國家的研究者能夠以統一術語研究這種特殊的基因組結構。

三、CRISPR發展史第二階段：細菌免疫機制的揭開（2002～2011）

這個階段是CRISPR歷史最重要的基礎研究時期。

科學家逐漸發現，CRISPR並非毫無功能的DNA重複序列，而是細菌用來抵抗病毒入侵的一種「適應性免疫系統」。

1. 重要發展大事記

年代科學家／重要事件歷史意義
2002年Jansen等人正式提出CRISPR名稱及Cas相關基因命名建立統一研究名稱
2005年Mojica、Bolotin及Pourcel等研究團隊發現Spacer與病毒等外來遺傳物質具有關聯提出細菌免疫功能的關鍵線索
2006年Makarova等人提出CRISPR可能具有類似免疫防禦的作用建立理論模型
2007年Barrangou與Horvath研究團隊證實CRISPR可以使細菌獲得噬菌體抗性首次重要實驗證據
2008年Brouns等人證實CRISPR序列可轉錄成RNA，參與病毒辨識揭示RNA引導機制
2008年Marraffini與Sontheimer證明部分CRISPR系統以外來DNA為攻擊目標確認DNA干擾機制

2. 2005年：發現Spacer與病毒DNA的關聯

CRISPR序列中有一種重要結構稱為Spacer（間隔序列）。

科學家發現，部分Spacer的DNA序列與噬菌體及其他外來遺傳物質的序列相似。

這帶來一個重要推論：

細菌可能把曾經入侵的病毒DNA片段保存下來，作為未來辨識病毒的記憶。

這個概念成為CRISPR適應性免疫理論的基礎。

3. 2007年：細菌適應性免疫獲得實驗證實

2007年，法國研究者Rodolphe Barrangou與Philippe Horvath等人，以嗜熱鏈球菌（Streptococcus thermophilus）進行研究。

他們發現：

  • 細菌受到噬菌體攻擊後，可以取得病毒DNA片段。
  • 這些DNA片段會被加入CRISPR序列。
  • 細菌因此能夠辨識曾經入侵過的病毒。
  • 再次遭遇相同病毒時，能夠利用CRISPR-Cas系統抵抗感染。

這項研究證實CRISPR是細菌的適應性免疫系統。

其重要意義在於：科學家開始真正理解CRISPR的生物學功能。

4. CRISPR天然免疫的三個步驟

步驟英文作用
第一階段Adaptation擷取外來DNA片段並儲存為Spacer
第二階段Expression and Processing將CRISPR序列轉錄並加工成crRNA
第三階段Interference利用crRNA引導Cas蛋白辨識及破壞外來遺傳物質

這套機制有點類似免疫系統的記憶功能。

細菌可以將過去病毒感染的資訊保存在自己的基因組中，以便下次防禦。

四、CRISPR發展史第三階段：CRISPR-Cas9成為基因編輯工具（2011～2013）

這是CRISPR發展史最關鍵的轉折。

科學家原本研究的是細菌如何抵抗病毒，後來逐漸發現：

如果可以人為設計引導RNA，就能讓Cas9蛋白依照指定位置尋找DNA並進行切割。

這代表CRISPR可能成為一種可程式化的基因編輯工具。

1. 2011年：tracrRNA的重要發現

法國科學家艾曼紐・夏彭提耶（Emmanuelle Charpentier）及其研究團隊，深入研究化膿性鏈球菌（Streptococcus pyogenes）的CRISPR系統。

他們發現一種稱為tracrRNA（trans-activating CRISPR RNA）的RNA分子。

這種RNA與crRNA共同參與Cas9系統的運作。

2. 2012年：CRISPR-Cas9基因編輯技術問世

2012年，夏彭提耶與美國科學家珍妮佛・道納（Jennifer Doudna）及其研究團隊發表重要論文。

他們證明可以利用人工設計的RNA，引導Cas9蛋白在指定DNA位置進行切割。

另一個重要突破是將原本參與辨識的crRNA與tracrRNA結合，設計成單一引導RNA（sgRNA）。

這使CRISPR-Cas9成為容易設計及操作的基因編輯工具。

2012年被普遍視為現代CRISPR基因編輯革命的起點。

3. 2013年：CRISPR進入真核細胞基因編輯

2013年，多個研究團隊分別證明CRISPR-Cas9可以應用於哺乳動物細胞，包括：

  • George Church研究團隊。
  • Feng Zhang研究團隊。
  • Jin-Soo Kim研究團隊。

這些研究證明CRISPR-Cas9不只可以在細菌中運作，也能應用於動物及人類細胞。

主要應用開始擴大至：

  • 遺傳疾病研究。
  • 癌症基因研究。
  • 動物疾病模型建立。
  • 作物基因改良。
  • 基礎生命科學研究。

五、CRISPR發展史第四階段：基因編輯技術快速擴張（2014～2019）

CRISPR-Cas9問世後，科學家開始思考如何讓基因修改更加精準。

傳統Cas9需要切斷DNA雙股，可能造成非預期突變或DNA修復問題。

因此，研究者陸續發展出不需要雙股DNA斷裂，或能夠更加精準修改DNA的技術。

1. 重要發展大事記

年代重要事件歷史意義
2014年CRISPR技術廣泛應用於動物及植物研究基因編輯進入普及期
2015年CRISPR用於人類胚胎研究引發胚胎基因編輯倫理討論
2015年高精準Cas9變體研究發展降低部分非目標切割
2016年CRISPR表觀遺傳調控工具發展不切割DNA也能調控基因
2016年CBE胞嘧啶鹼基編輯技術發表可以直接修改特定DNA鹼基
2017年ABE腺嘌呤鹼基編輯技術發表擴大精準鹼基修改能力
2018年CRISPR胚胎基因編輯嬰兒事件引發全球倫理爭議
2019年先導編輯（Prime Editing）技術發表發展更靈活的DNA修改方式

2. 2016年：鹼基編輯技術（Base Editing）

2016年，David Liu研究團隊發表胞嘧啶鹼基編輯技術（Cytosine Base Editor，CBE）。

2017年，他們進一步發表腺嘌呤鹼基編輯技術（Adenine Base Editor，ABE）。

兩項技術的突破在於：

不必像傳統Cas9一樣切斷DNA雙股，就能直接改變特定DNA鹼基。

技術主要修改
CBEC·G → T·A
ABEA·T → G·C

這使科學家能夠更精準地修正部分單一鹼基突變。

3. 2018年：人類基因編輯嬰兒事件

2018年，中國研究者賀建奎宣布利用CRISPR-Cas9技術修改人類胚胎的CCR5基因，並宣稱已有基因編輯嬰兒出生。

這件事引起國際社會強烈爭議。

主要問題包括：

  • 胚胎基因編輯的安全性。
  • 是否存在非目標突變。
  • 基因修改是否可能遺傳給下一代。
  • 是否取得充分的倫理審查。
  • 是否有合理的醫療必要性。

這個事件成為基因編輯倫理史的重要分水嶺。

4. 2019年：先導編輯（Prime Editing）

2019年，美國科學家David Liu研究團隊發表先導編輯技術。

其主要組成包括：

  • Cas9切口酶（Cas9 nickase）。
  • 逆轉錄酶（Reverse Transcriptase）。
  • 先導編輯RNA（pegRNA）。

先導編輯可以在特定條件下進行：

  • DNA鹼基替換。
  • 小片段DNA插入。
  • 小片段DNA刪除。

與傳統雙股DNA切割方式相比，它提供了另一種更靈活的基因修改途徑。

六、CRISPR發展史第五階段：諾貝爾獎與臨床治療突破（2020～2024）

2020年代，CRISPR開始從實驗室研究走向正式醫療應用。

其中最重要的兩件事：

  1. CRISPR-Cas9研究獲得諾貝爾化學獎。
  2. 第一種CRISPR基因編輯療法獲得監管機關批准。

2. 2020年：諾貝爾化學獎

2020年，瑞典皇家科學院將諾貝爾化學獎頒發給：

  • 珍妮佛・道納（Jennifer Doudna）。
  • 艾曼紐・夏彭提耶（Emmanuelle Charpentier）。

獲獎理由是開發基因組編輯方法。

這項榮譽象徵CRISPR從基礎微生物學研究，正式成為現代生命科學的重要技術平台。

3. 2023年：Casgevy成為第一種獲准的CRISPR療法

2023年11月16日，英國成為第一個批准CRISPR-Cas9療法的國家。

2023年12月8日，美國FDA批准Casgevy（exa-cel），用於治療12歲以上、反覆發生血管阻塞危象的鐮刀型紅血球疾病患者。

2024年1月16日，美國FDA再批准其用於12歲以上的輸血依賴型β地中海型貧血患者。

Casgevy的作用原理

Casgevy並不是直接修復鐮刀型紅血球疾病患者的血紅素基因突變，而是利用CRISPR-Cas9修改患者的造血幹細胞。

主要流程：

  1. 從患者身上取得造血幹細胞。
  2. 在體外利用CRISPR-Cas9編輯BCL11A基因的紅血球特異性增強子區域。
  3. 降低BCL11A在紅血球中的調控作用。
  4. 促進胎兒血紅素（HbF）生成。
  5. 將編輯後的造血幹細胞移植回患者體內。
  6. 使患者產生較多胎兒血紅素，減少紅血球鐮刀化。

這項技術的重要性在於，基因編輯不再只是實驗室中的研究工具，而是正式進入遺傳疾病治療。

七、CRISPR發展史第六階段：個人化基因編輯與新一代技術（2025～2026）

2025年以後，CRISPR研究逐漸從治療特定疾病，朝向依照個別患者的基因突變設計專屬治療。

這代表基因編輯技術正在朝向個人化醫療發展。

1. 2025年：全球首例個人化CRISPR基因編輯治療

2025年2月，美國費城兒童醫院（CHOP）與賓夕法尼亞大學研究團隊，為一名患有罕見代謝疾病的嬰兒KJ，開發個人化基因編輯療法。

患者患有CPS1缺乏症（Carbamoyl Phosphate Synthetase 1 Deficiency）。

這種疾病會使人體無法正常處理蛋白質代謝所產生的氨，造成血液氨濃度過高，可能危及生命。

研究團隊採用CRISPR鹼基編輯技術：

  • 根據患者的特定基因突變設計編輯工具。
  • 利用脂質奈米粒子包覆基因編輯成分。
  • 將編輯工具送入肝臟細胞。
  • 修正患者特定的CPS1基因突變。

2025年2月25日，患者接受首次治療，之後陸續接受追加劑量。

2025年5月，研究成果正式發表於《新英格蘭醫學雜誌》（New England Journal of Medicine）。

初期治療結果顯示，患者可以攝取更多蛋白質，並減少部分藥物需求，但仍需要長期追蹤安全性與療效。

這項突破具有三項重要意義：

  1. 從通用型基因療法走向個人化基因療法。
  2. 展現針對極罕見單基因疾病設計治療的可能性。
  3. 為未來建立可快速修改的個人化基因編輯平台提供範例。

2. 2026年：Casgevy擴大兒童治療適應年齡

2026年7月1日，美國FDA核准Casgevy擴大適應年齡，讓年滿2歲的鐮刀型紅血球疾病及輸血依賴型β地中海型貧血患者也能使用。

這使CRISPR療法的臨床應用向更年幼的患者延伸。

八、CRISPR基因編輯技術的主要類型

CRISPR發展至今，已經不再只有Cas9一種工具，而是形成多種不同的基因編輯技術。

1. 主要技術比較

技術發展年代主要功能

2. 五種重要技術的差異

CRISPR-Cas9：DNA剪刀

切斷DNA雙股，利用細胞修復機制修改基因。

CRISPR-Cas12a：另一種DNA剪刀

具有不同PAM辨識及切割特性，可擴大基因編輯的選擇。

Base Editing：DNA文字修改器

直接修改特定鹼基，通常不需要DNA雙股斷裂。

Prime Editing：DNA精準文字編輯器

利用pegRNA及逆轉錄酶進行指定序列修改。

CRISPR-Cas13：RNA剪刀

主要作用於RNA，不直接修改DNA基因組。

九、CRISPR基因編輯的主要應用領域

1. 醫療與遺傳疾病治療

  • 遺傳性失明。

  • 部分遺傳性免疫疾病。

2. 癌症治療

CRISPR可以協助修改免疫細胞的基因，使其具有更好的癌細胞辨識及攻擊能力。

主要研究方向：

  • CAR-T細胞基因改造。
  • T細胞免疫功能調整。
  • 癌細胞抗藥性研究。
  • 腫瘤免疫逃脫機制研究。

CRISPR在農業上的應用包括：

  • 改善小麥品質。
  • 延長水果保存期限。
  • 改善植物營養成分。

4. 生物製藥與工業生物科技

CRISPR也可以用來改造微生物，使其生產：

  • 胰島素。

  5. 農業基因改良： 培育抗病、耐旱及高營養價值作物。
  6. 合成生物學： 結合人工基因組設計，建立新的生物系統。
