微軟公司（Microsoft）大事記

微軟（Microsoft Corporation）

  • 創辦人：比爾・蓋茲（Bill Gates）、保羅・艾倫（Paul Allen）
  • 創立時間：1975年4月4日
  • 創立地點：美國新墨西哥州阿布奎基
  • 總部：美國華盛頓州雷德蒙（Redmond）
  • 產業：軟體、作業系統、雲端運算、人工智慧、電腦硬體、遊戲
  • 現任執行長：薩提亞・納德拉（Satya Nadella）

微軟是全球最具影響力的科技公司之一。它最初以個人電腦的程式語言與作業系統起家，後來發展出 Windows、Office、Xbox、Azure、Microsoft 365 和 Copilot 等產品與服務。

微軟的發展歷程，可以分成六個重要階段：

  1. 1975～1985年：創立與個人電腦軟體市場
  2. 1986～1999年：Windows 與 Office 崛起
  3. 2000～2013年：網路、遊戲與行動裝置時代
  4. 2014～2019年：納德拉領導與雲端轉型
  5. 2020～2024年：人工智慧全面發展
  6. 2025～2026年：AI 基礎建設與智慧代理時代

一、1975～1985年：創立與個人電腦軟體市場

年份重要事件
19754月4日，比爾・蓋茲與保羅・艾倫共同創立 Microsoft，最初名稱為 Micro-Soft，主要為 Altair 8800 電腦開發 BASIC 程式語言。
1976微軟開始專注於個人電腦軟體開發，提出軟體應透過授權方式商業化的經營模式。
1977推出 Microsoft FORTRAN 等程式語言產品，擴大軟體市場。
1978在日本設立第一個海外銷售據點，開始拓展國際市場。
1979公司總部從新墨西哥州阿布奎基遷往華盛頓州貝爾維尤（Bellevue）。
1980IBM 開始尋找個人電腦作業系統，微軟因此迎來重大商業機會。
19816月25日，微軟正式公司化；8月12日，IBM 推出個人電腦 IBM PC，搭載微軟提供的 MS-DOS 1.0。
1983推出 Microsoft Word 前身 Multi-Tool Word；比爾・蓋茲提出 Windows 圖形介面作業系統構想。
198511月20日，正式推出第一代 Windows 1.0，讓使用者可以透過圖形介面操作電腦。

歷史意義：

微軟與 IBM 的合作，使 MS-DOS 成為個人電腦市場的重要作業系統。微軟也逐漸確立一項重要商業模式：不必自己製造電腦，而是透過提供作業系統與軟體，讓不同廠商都能使用。

二、1986～1999年：Windows 與 Office 崛起

年份重要事件
19862月，公司總部遷往雷德蒙；3月13日，微軟股票正式上市。
1987推出 Windows 2.0，改進視窗操作與圖形介面。
1989推出 Microsoft Office 初期版本，整合 Word、Excel 等辦公軟體。
1990推出 Windows 3.0，大幅改善操作介面與記憶體管理，開始廣泛普及。
1991微軟逐步擴展 Windows 與 Office 的全球市場。
1992推出 Windows 3.1，進一步改善圖形顯示與多媒體功能。
1993推出 Windows NT 3.1，建立面向企業與工作站的作業系統產品線。
19958月24日，推出 Windows 95，首次將開始功能表（Start Menu）與工作列等設計帶入主流 Windows。
1995比爾・蓋茲發表網路策略，微軟開始全面投入網際網路市場。
1996推出 Internet Explorer 3.0，積極參與網頁瀏覽器市場競爭。
1998推出 Windows 98，強化網路、USB 與多媒體支援。
1998美國司法部與多個州政府對微軟展開反壟斷訴訟。
1999推出 Windows 98 Second Edition，改善網路與硬體支援。

歷史意義：

這是微軟成為全球科技巨頭的關鍵時期。

  • Windows 成為全球個人電腦最重要的作業系統之一。
  • Office 成為企業、學校與家庭常用的辦公軟體。
  • Internet Explorer 進入瀏覽器市場，與 Netscape 展開競爭。
  • 微軟逐漸形成 Windows + Office 的軟體生態系。

三、2000～2013年：網路、遊戲與行動裝置時代

年份重要事件
20001月，史蒂夫・鮑默（Steve Ballmer）接任執行長，比爾・蓋茲轉任董事長。
2000推出 Windows 2000，強化企業伺服器與商業運算功能。
2000宣布 .NET 技術策略，布局網路服務與軟體開發平台。
200110月25日，推出 Windows XP，成為微軟歷史上極具代表性的作業系統之一。
200111月15日，推出第一代 Xbox，正式進入家用遊戲主機市場。
2002比爾・蓋茲提出 Trustworthy Computing（可信賴運算）理念，強調資訊安全與軟體可靠性。
2003推出 Windows Server 2003，擴大企業伺服器市場。
2005推出 Xbox 360，與 Sony PlayStation 3 展開新一代遊戲主機競爭。
2006推出 Zune 數位音樂播放器，試圖進入數位音樂市場，與 Apple iPod 競爭。
2007推出 Windows Vista 與 Office 2007，Office 開始採用 Ribbon（功能區）介面。
2008比爾・蓋茲退出日常管理工作，將更多時間投入慈善事業。
2009推出 Bing 搜尋引擎，挑戰 Google 的搜尋市場地位。
2009推出 Windows 7，改善 Vista 的使用體驗。
2010推出 Windows Phone 7，進軍智慧型手機作業系統市場。
2011推出 Office 365，將辦公軟體服務轉向雲端訂閱模式。
2011以約85億美元收購 Skype，擴展網路通訊與視訊會議服務。
2012推出 Windows 8，採用適合觸控螢幕的操作介面。
2012推出 Surface 平板電腦，開始發展自有品牌電腦硬體。
2013宣布收購 Nokia 手機設備與服務業務，試圖強化 Windows Phone 生態系。
2013推出 Xbox One，進一步整合遊戲、影音與家庭娛樂服務。

歷史意義：

這個時期，微軟開始面對新的競爭者：

  • Google：搜尋引擎與網路服務。
  • Apple：iPhone、iPad 與行動裝置生態系。
  • Sony：PlayStation 遊戲主機。
  • Amazon：雲端運算服務。

微軟雖然在 Windows 與 Office 市場仍占有重要地位，但在智慧型手機市場未能成功建立優勢。Windows Phone 最終也逐漸退出市場。

四、2014～2019年：納德拉領導與雲端轉型

年份重要事件
20142月4日，薩提亞・納德拉接任微軟執行長，成為第三任執行長。
2014提出「Mobile First, Cloud First」（行動優先、雲端優先）的經營方向。
2014推出 Office for iPad，開始積極將自家軟體帶入 Apple 生態系。
2014完成收購 Nokia 手機設備與服務業務，但後續手機硬體策略遭遇挫折。
2014宣布收購 Minecraft 遊戲開發商 Mojang，拓展遊戲市場。
20157月29日，推出 Windows 10，強調跨裝置與統一平台體驗。
2016以約262億美元收購 LinkedIn，進入全球職業社群與企業人脈服務市場。
2016發表 Dynamics 365，整合企業資源規劃與客戶關係管理服務。
2017推出 Microsoft Teams，進入企業團隊協作與視訊會議市場。
2018以約75億美元收購 GitHub，強化開發者社群與軟體開發平台。
2018推出 Azure AI 等人工智慧雲端服務，擴大企業 AI 應用。
2019宣布向 OpenAI 投資10億美元，展開人工智慧技術合作。

歷史意義：

納德拉上任後，微軟進行了重要的經營轉型：

  1. 從以 Windows 為中心，轉向以雲端服務為核心。
  2. 不再只強調自家作業系統，積極支援 iOS、Android 等平台。
  3. 透過 LinkedIn、GitHub 等收購，建立更完整的企業與開發者生態系。
  4. 大力發展 Azure，成為全球主要雲端運算服務供應商之一。

其中，Microsoft Azure 是這次轉型最重要的成果之一，讓微軟從傳統軟體公司逐漸轉型為雲端與平台服務公司。

五、2020～2024年：人工智慧全面發展

年份重要事件
2020推出 Microsoft 365，整合 Office、雲端儲存與協作服務品牌。
2020因 COVID-19 疫情，Teams、雲端服務與遠距辦公工具需求大幅增加。
20216月24日，發表 Windows 11，重新設計使用者介面。
2021推出 Windows 365，讓使用者透過雲端使用 Windows 電腦環境。
20223月4日，完成收購 Nuance Communications，強化語音辨識與醫療人工智慧技術。
2022推出 GitHub Copilot，利用人工智慧協助程式設計師撰寫程式碼。
20231月18日，宣布擴大與 OpenAI 的合作關係，進一步投入生成式人工智慧。
20232月7日，推出整合人工智慧技術的新版 Bing 搜尋引擎與 Edge 瀏覽器。
20233月16日，發表 Microsoft 365 Copilot，將生成式 AI 整合至 Word、Excel、PowerPoint、Outlook 等產品。
20239月21日，宣布推出 Microsoft Copilot，將 AI 助理整合至多項產品與服務。
202310月13日，以約687億美元完成收購 Activision Blizzard，成為遊戲產業的重要力量。
2024推出 Copilot Pro，提供進階 AI 助理服務。
20245月，發表 Copilot+ PC，推動具備專用 AI 運算能力的新一代個人電腦。
2024發表 Phi 系列小型語言模型，拓展自有 AI 模型技術。
2024持續擴充 Azure AI、Microsoft 365 Copilot 與企業生成式 AI 服務。

歷史意義：

這是微軟第二次重大的戰略轉型。

第一次是1980年代從程式語言進入個人電腦作業系統市場；第二次則是2020年代從雲端服務進入生成式人工智慧市場。

其中三項發展特別重要：

  • OpenAI 合作：取得重要的生成式 AI 技術合作機會。
  • Copilot：將 AI 助理導入辦公軟體、搜尋引擎、程式開發與 Windows。
  • Activision Blizzard：透過大型遊戲公司收購，擴大 Xbox 的內容與遊戲產業布局。

六、2025～2026年：AI 基礎建設與智慧代理時代

年份重要事件
20254月4日，微軟成立50週年，回顧公司從個人電腦軟體商發展為全球科技平台公司的歷程。
20252月19日，發表 Majorana 1 量子運算晶片，探索拓樸量子運算技術。
2025持續擴大 AI 資料中心投資，強化 Azure 的人工智慧運算能力。
202510月28日，宣布與 OpenAI 合作關係進入新階段，調整雙方合作架構。
20261月26日，發表新一代 AI 加速器 Maia 200，強化自有 AI 晶片與資料中心運算能力。
20262月18日，宣布達成全球年度用電量100%以再生能源匹配的里程碑。
2026持續發展 AI Agent（人工智慧代理），讓 AI 不只回答問題，也能執行工作流程。
202611月，於 Microsoft Ignite 發表多項企業 AI、Azure 基礎設施與 AI Agent 新技術。

歷史意義：

微軟的競爭核心已經不再只是 Windows 與 Office，而是逐漸擴展到：

  1. AI 模型與人工智慧平台。
  2. AI 晶片與大型資料中心。
  3. 雲端運算與企業資料管理。
  4. AI Agent 與自動化工作流程。
  5. 量子運算與下一代運算技術。

資料截至2026年11月。

九、微軟發展歷程的重要轉折

微軟的六次重要戰略轉型

  1. 1975：軟體公司誕生

為個人電腦開發程式語言，建立軟體授權商業模式。

  1. 1981：進入作業系統市場

與 IBM 合作，MS-DOS 成為個人電腦的重要作業系統。

  1. 1990：Windows 與 Office 普及

  1. 2001：拓展遊戲與娛樂市場

Xbox 進入遊戲主機產業。

  1. 2014：雲端服務轉型

納德拉推動 Azure 與訂閱制服務，改變微軟的經營模式。

  1. 2023：生成式 AI 轉型

與 OpenAI 深化合作，將 Copilot 導入各種產品。

值得思考的歷史問題：

微軟的成功並非只來自某一項產品，而是多次掌握科技產業轉型的機會：

  • 1980年代：掌握個人電腦普及。
  • 1990年代：掌握圖形化作業系統與辦公軟體。
  • 2000年代：進入遊戲與網路服務。
  • 2010年代：掌握雲端運算。
  • 2020年代：積極投入生成式 AI。

這也反映出科技公司的長期競爭力，除了技術創新之外，還包括商業模式、平台生態系與策略轉型能力。
