甲骨文公司（Oracle Corporation）大事記

甲骨文公司（Oracle Corporation）是美國最重要的企業軟體與資料庫公司之一，成立於1977年，創辦人包括賴瑞・艾利森（Larry Ellison）、鮑伯・邁納（Bob Miner）及艾德・歐茲（Ed Oates）。

Oracle最初以關聯式資料庫管理系統（RDBMS）起家，後來逐步擴展至企業資源規劃（ERP）、客戶關係管理（CRM）、企業應用軟體、雲端運算及人工智慧。

Oracle的發展史可以分為六個階段：

  1. 1977～1985年：公司創立與關聯式資料庫發展
  2. 1986～1999年：資料庫市場崛起與全球擴張
  3. 2000～2009年：企業軟體與大型併購時代
  4. 2010～2019年：雲端運算與資料中心轉型
  5. 2020～2024年：雲端基礎設施與AI布局
  6. 2025～2026年：AI資料中心與雲端運算競爭

一、公司創立與關聯式資料庫發展（1977～1985年）

年代重要事件
1977Larry Ellison、Bob Miner及Ed Oates在美國加州共同創立Software Development Laboratories（SDL）。
1977公司開始研究關聯式資料庫技術，受到IBM研究論文及關聯式資料庫理論的啟發。
1979推出Oracle Version 2，成為早期商業化SQL關聯式資料庫系統之一。
1980公司開始擴大資料庫軟體銷售，客戶逐漸涵蓋企業及政府機構。
1982公司更名為Relational Software Inc.（RSI），凸顯關聯式資料庫的核心業務。
1983推出Oracle Version 3，開始支援C語言開發，並能在不同電腦平台上運作。
1984推出Oracle Version 4，進一步改善資料庫功能與穩定性。
1985推出Oracle Version 5，持續擴展資料庫產品的企業應用能力。
1985公司更名為Oracle Systems Corporation，正式以Oracle作為企業品牌。

歷史意義：

Oracle早期最大的貢獻，是將關聯式資料庫理論轉化為企業可以購買及使用的商業產品。

關聯式資料庫以資料表（Table）儲存資料，利用SQL（Structured Query Language，結構化查詢語言）進行資料查詢、修改及管理，後來成為全球企業資訊系統的重要基礎。

二、資料庫市場崛起與全球擴張（1986～1999年）

年代重要事件
1986Oracle股票首次公開上市（IPO），進入NASDAQ市場。
1987Oracle成為全球重要的關聯式資料庫軟體供應商之一。
1988推出Oracle Version 6，強化交易處理及資料庫效能。
1992推出Oracle Database 7，增加儲存程序、觸發器及完整性管理等功能。
1995公司名稱正式改為Oracle Corporation。
1995推出Oracle Database 7.3，持續強化企業級資料庫功能。
1996推出Oracle Universal Server概念，朝向整合多種類型資料的資料庫平台發展。
1997推出Oracle8，強化大型資料庫、物件關聯式資料庫及網際網路應用能力。
1998推動網際網路運算架構，將資料庫與企業應用系統整合。
1999推出Oracle8i，將網際網路技術更深入整合至資料庫系統。

歷史意義：

1990年代是Oracle建立全球資料庫市場地位的重要時期。

隨著銀行、電信、航空、政府及大型企業逐漸採用資訊系統，資料庫成為企業營運不可或缺的核心設備。Oracle也因此成為全球大型企業資訊系統的重要供應商。

三、企業軟體與大型併購時代（2000～2009年）

年代重要事件
2000推出Oracle E-Business Suite 11i，整合財務、人力資源、供應鏈及企業管理功能。
2000Larry Ellison提出網路運算與企業軟體網路化的發展方向。
2001推出Oracle9i，強化網際網路應用、資料庫管理及企業運算功能。
2003推出Oracle Database 10g，強調Grid Computing（網格運算），讓多台電腦共同提供運算資源。
2004Oracle宣布收購PeopleSoft，進軍更完整的企業資源規劃（ERP）軟體市場。
2005完成對PeopleSoft的收購，正式擴大企業管理軟體市場版圖。
2005推出Oracle Database 10g Release 2，持續改善資料庫效能與管理功能。
2006完成對Siebel Systems的收購，強化客戶關係管理（CRM）軟體業務。
2006推出Oracle Fusion Middleware，整合企業應用程式與資訊系統中介軟體。
2007Oracle成立30週年，全球客戶與企業軟體市場規模持續擴大。
2008收購BEA Systems，強化Java應用伺服器及企業中介軟體市場。
2008推出Oracle Database 11g，增加資料庫管理、自動化及效能改善功能。
2009宣布以約74億美元收購Sun Microsystems，開始進入伺服器、硬體及Java生態系統。

歷史意義：

這個階段Oracle不再只是一家資料庫公司，而是透過大量併購，建立完整的企業資訊系統產品線。

幾項重要併購：

四、雲端運算與資料中心轉型（2010～2019年）

年代重要事件
2010正式完成對Sun Microsystems的收購，取得Java、Solaris及SPARC等重要技術與產品。
2010推出Exadata資料庫機器，結合伺服器、儲存設備及資料庫軟體，提供整合式運算平台。
2011推出Oracle Fusion Applications，整合企業財務、人力資源及客戶管理等應用軟體。
2011收購RightNow Technologies，擴大雲端客戶服務及CRM市場。
2012推出Oracle Database 12c，導入多租戶（Multitenant）資料庫架構，支援雲端資料庫服務。
2013Oracle Team USA贏得美洲盃帆船賽冠軍，成為公司品牌行銷的重要事件。
2013收購Nimbula，強化雲端基礎設施技術。
2014收購MICROS Systems，擴展餐飲、旅館及零售業資訊系統市場。
2015推出Oracle Cloud的新一代企業雲端服務，擴大SaaS、PaaS及IaaS業務。
2016收購NetSuite，進一步擴展雲端ERP市場，尤其是中小企業客戶。
2016收購Dyn，強化網域名稱系統（DNS）及網路流量管理服務。
2017推出Oracle Cloud Infrastructure（OCI）第二代雲端基礎設施服務的發展布局。
2018推出Oracle Autonomous Database（自主資料庫），利用自動化技術執行資料庫維護、調校及安全管理。
2018推出Oracle Cloud Infrastructure Gen 2，重新設計雲端基礎設施架構，強調安全性與效能。
2019推出Oracle Database 19c，成為企業廣泛採用的重要長期支援版本。

歷史意義：

這個時期Oracle面臨Amazon AWS、Microsoft Azure及Google Cloud等雲端服務商的競爭。

Oracle開始將傳統資料庫與企業軟體轉型為雲端訂閱服務，形成三大主要雲端業務：

  • SaaS（軟體即服務）：直接提供企業使用的雲端軟體。
  • PaaS（平台即服務）：提供應用程式開發與資料庫平台。
  • IaaS（基礎設施即服務）：提供雲端伺服器、儲存及網路資源。

年代重要事件
2020推出Oracle Database 21c，持續發展區塊鏈、JSON及多模型資料庫技術。
2020擴大Oracle Cloud Infrastructure全球資料中心布局。
2021宣布在全球增加多個雲端區域（Cloud Regions），擴大OCI服務範圍。
2022完成以約283億美元收購Cerner，跨入醫療資訊系統與電子病歷市場。

2022Oracle Cloud Infrastructure持續擴大GPU運算及高效能運算服務。
2023推出Oracle Database 23c的開發者版本，強化JSON、微服務及應用程式開發功能。
2023擴大OCI生成式AI服務，並與Cohere等AI業者合作發展企業生成式AI應用。
2023宣布與Microsoft Azure合作，讓Oracle資料庫服務能與Azure雲端環境整合。
2024正式推出Oracle Database 23ai，加入AI Vector Search（AI向量搜尋），支援企業建置生成式AI應用。
2024持續擴大OCI GPU超級叢集，鎖定大型AI模型訓練與推論需求。
2024擴大與Microsoft、Google等雲端業者的多雲合作，讓客戶能在不同雲端環境使用Oracle資料庫。

歷史意義：

Oracle開始從傳統企業資料庫公司轉變為AI時代的雲端運算供應商。

尤其是Oracle Database 23ai，將AI向量搜尋直接整合至資料庫，讓企業可以利用既有資料建立語意搜尋、檢索增強生成（RAG）及生成式AI應用。

另一方面，收購Cerner也使Oracle進入醫療資訊產業，將資料庫、雲端及AI技術延伸至醫療服務。
