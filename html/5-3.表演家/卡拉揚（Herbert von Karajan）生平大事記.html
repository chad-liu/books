音樂家生平・卡拉揚

卡拉揚（Herbert von Karajan）生平大事記

赫伯特・馮・卡拉揚（Herbert von Karajan，1908年4月5日—1989年7月16日）是20世紀最具影響力的指揮家之一，也是古典音樂錄音、音樂影像與國際音樂節發展的重要推動者。

他出生於奧地利薩爾斯堡，先後擔任柏林愛樂首席指揮、維也納國立歌劇院藝術總監及薩爾斯堡音樂節藝術總監等重要職務。他以音色華麗、樂團整體音響精緻、弦樂連奏流暢，以及對錄音與影像技術的積極運用聞名。

卡拉揚的職業生涯橫跨兩次世界大戰、戰後歐洲重建、唱片工業的黃金時代，以及數位音樂媒體的興起。他的藝術成就與納粹時期的政治經歷，也使他成為20世紀古典音樂史上備受討論的人物。

以下按照早年教育、職業生涯、納粹時期、戰後復出、柏林愛樂時代、音樂科技與晚年，整理他的生平大事記。

一、出生與早年音樂教育（1908—1928）

1908年：出生於薩爾斯堡

  • 4月5日：卡拉揚出生於奧匈帝國的薩爾斯堡（Salzburg，今屬奧地利）。
  • 出生時使用的名字為 Heribert Ritter von Karajan，後來以 Herbert von Karajan 之名聞名於世。
  • 父親恩斯特・馮・卡拉揚（Ernst von Karajan）是醫師，母親瑪莎（Martha）具有斯洛伐克家族背景。
  • 卡拉揚成長於具有文化與音樂氣氛的家庭環境，薩爾斯堡本身則是莫札特的出生地，也是歐洲重要的音樂城市。

1912年：開始學習鋼琴

  • 四歲左右開始跟隨法蘭茲・萊德溫卡（Franz Ledwinka）學習鋼琴。
  • 早年主要接受鋼琴訓練，逐漸展現音樂方面的才能。
  • 鋼琴訓練使他熟悉音樂的和聲、節奏、樂句及作品結構。

1916年：進入莫札特音樂院

  • 開始在薩爾斯堡莫札特音樂院（Mozarteum）接受較完整的音樂教育。
  • 學習鋼琴、和聲、作曲及室內樂。
  • 主要教師包括法蘭茲・萊德溫卡、法蘭茲・紹爾（Franz Sauer）及伯恩哈德・鮑姆加特納（Bernhard Paumgartner）。

這一階段的重要性，在於卡拉揚並非一開始就以指揮為唯一目標。他先從鋼琴與音樂理論出發，後來才逐步轉向管弦樂團指揮。

1926年：完成中學教育，赴維也納深造

  • 完成薩爾斯堡人文中學的學業。
  • 最初進入維也納工業大學相關學程，對技術、機械及工程問題具有興趣。
  • 同時在維也納音樂與表演藝術學院繼續音樂學習。
  • 在鋼琴與指揮方面接受更進一步的訓練。

卡拉揚對科技的興趣並未隨著他成為指揮家而消失。這種興趣後來也表現在他對立體聲錄音、音樂影像與數位媒體的積極投入上。

本階段的關鍵： 卡拉揚從鋼琴演奏與音樂理論起步，在薩爾斯堡及維也納接受訓練，逐漸形成結合音樂、技術與舞台表現的藝術觀念。Karajan

二、初入職業樂壇：烏爾姆與亞琛時期（1929—1936）

1929年：首次公開指揮，開啟職業生涯

1月22日，卡拉揚在薩爾斯堡莫札特音樂院舉行首次公開指揮演出。

  • 當天演出由莫札特音樂院管弦樂團擔任演奏。
  • 觀眾中有德國烏爾姆市立劇院的藝術主管，注意到他的指揮才能。
  • 隨後，他受邀前往烏爾姆試演，並獲聘為劇院的首席指揮之一（Kapellmeister）。

這次演出是他由音樂學生轉變為職業指揮家的重要起點。

1930—1932年：在烏爾姆累積歌劇經驗

  • 在烏爾姆市立劇院參與歌劇與管弦樂演出。
  • 熟悉歌劇排練、歌手合作、舞台調度與樂團管理。
  • 逐步建立快速排練、精確控制及整體音響規劃的能力。

卡拉揚早期主要透過歌劇院累積經驗。歌劇指揮不只需要控制樂團，還必須同時配合歌手、舞台動作與戲劇節奏，這對他日後的歌劇製作工作具有重要意義。

1933年：首次參與薩爾斯堡音樂節

  • 夏季首次正式參與薩爾斯堡音樂節。
  • 為歌德的《浮士德》演出配樂，參與演出製作的戲劇導演是馬克斯・萊因哈特（Max Reinhardt）。
  • 透過這次經驗，他進一步接觸國際級藝術節的運作模式。

這次經歷也使他開始與薩爾斯堡音樂節建立長期聯繫。此後數十年間，薩爾斯堡一直是他藝術活動的重要基地。

1934年：轉往亞琛劇院

  • 烏爾姆的合約結束後，卡拉揚前往亞琛市立劇院（Stadttheater Aachen）應試。
  • 隨後獲聘為首席指揮。
  • 同年8月21日，他在薩爾斯堡的一場私人音樂聚會中，首次與維也納愛樂樂團的音樂家進行藝術合作。

這一時期，他逐漸從地方劇院的年輕指揮家，轉變為德國音樂界備受注意的新秀。

1935年：成為德國最年輕的音樂總監之一

  • 卡拉揚獲任亞琛劇院音樂總監（Generalmusikdirektor）。
  • 當時他年僅27歲。
  • 這項任命使他取得更大的藝術自主權，可以參與規劃歌劇曲目、管弦樂演出與劇院音樂活動。

這是他早年事業的重大突破，也為他日後進入柏林國立歌劇院及柏林愛樂奠定基礎。

1936年：逐步擴展演出範圍

  • 持續在亞琛領導歌劇與交響樂演出。
  • 透過密集的排練及演出，累積大型管弦樂團的指揮經驗。
  • 逐漸形成對音響均衡、演奏精確度與樂團整體效果的重視。

本階段的關鍵： 卡拉揚在不到十年的時間內，從第一次公開指揮發展到重要劇院的音樂總監，展現出極強的職業發展能力。

資料來源：卡拉揚研究機構官方生平年表。Karajan

三、國際成名與納粹時期（1937—1945）

這一階段是卡拉揚生平中極為重要、也最具歷史爭議的時期。

他在1930年代後半迅速成名，但其事業發展與納粹德國的政治環境密切相關。理解這段歷史，必須同時考慮他的藝術成就、納粹黨籍、職業發展，以及戰後的政治審查。

1937年：維也納國立歌劇院初登場

  • 6月1日：卡拉揚首次在維也納國立歌劇院指揮演出華格納的《崔斯坦與伊索德》。
  • 這是他進入維也納重要歌劇舞台的關鍵一步。
  • 透過這類大型歌劇的演出，他逐漸建立起在德奧歌劇傳統中的聲望。

1938年：在柏林愛樂取得突破

這一年是卡拉揚早期事業的轉折點。

4月：首次指揮柏林愛樂

  • 4月8日：首次與柏林愛樂管弦樂團合作。
  • 演出獲得高度關注。
  • 當時柏林愛樂的主要指揮是福特萬格勒，兩人日後的關係成為德國指揮史的重要篇章。

福特萬格勒與卡拉揚代表了不同的指揮風格。前者以速度彈性、音樂張力及即時詮釋聞名；後者則逐漸發展出音響精緻、控制精確、重視整體一致性的風格。

9月：指揮貝多芬《費黛里奧》

  • 卡拉揚首次在柏林國立歌劇院指揮演出。
  • 作品是貝多芬的歌劇《費黛里奧》（Fidelio）。
  • 這次演出提升了他在德國音樂界的知名度。

10月：華格納《崔斯坦與伊索德》獲得矚目

  • 10月21日：指揮《崔斯坦與伊索德》的演出，使他取得重要的國際突破。
  • 同年與德意志留聲機公司（Deutsche Grammophon）簽訂首份錄音合約。

錄音合約對他日後的發展具有深遠影響。他不再只是透過現場演出建立聲望，也開始進入唱片工業，為後來成為全球最具知名度的指揮家之一奠定基礎。

1939年：進入柏林國立歌劇院體系

  • 卡拉揚獲任柏林國立歌劇院指揮，並指揮普魯士國立管弦樂團的交響樂音樂會。
  • 他仍與亞琛的音樂活動保持一定聯繫。
  • 這一時期，他在德國音樂體制中的地位快速上升。

1940年：登上米蘭史卡拉歌劇院舞台

  • 5月9日：首次在義大利米蘭的史卡拉歌劇院（Teatro alla Scala）指揮演出。
  • 這代表他的事業開始深入德國以外的歐洲歌劇界。

1941—1943年：持續國際演出

  • 1941年，帶領柏林國立歌劇院相關樂團赴羅馬及佛羅倫斯演出。
  • 1942年，與第二任妻子安妮塔・古特曼（Anita Gütermann）結婚。
  • 1943年，與阿姆斯特丹皇家大會堂管弦樂團（Royal Concertgebouw Orchestra）合作演出及錄音。

然而，這些音樂成就都發生在納粹政權與第二次世界大戰的背景下。

卡拉揚與納粹黨的關係

卡拉揚於1935年加入納粹黨，並在納粹統治期間取得重要的音樂職位。其迅速上升的事業與當時的政治體制密切相關。

這與福特萬格勒的情況並不完全相同：福特萬格勒沒有加入納粹黨，並曾因欣德米特事件與納粹文化政策發生衝突；卡拉揚則有正式黨籍，戰後因此受到審查。

不過，分析卡拉揚在納粹時期的生涯，也不能只看他的職務與黨籍，還需要分別考察其個人動機、實際行動，以及他的音樂活動如何被當時的政治環境影響或利用。

1944—1945年：戰爭末期

  • 1944年，卡拉揚仍在歐洲不同城市指揮演出。
  • 1945年2月18日：他最後一次指揮柏林國立管弦樂團的演出。
  • 隨著戰爭接近尾聲，他大部分時間在義大利活動。
  • 納粹德國戰敗後，他的公開指揮事業受到政治審查影響。

本階段的歷史意義： 1937—1945年是卡拉揚從年輕指揮家成為國際知名音樂家的時期，但也是其政治經歷成為終身爭議的重要原因。

資料來源：卡拉揚研究機構官方年表、柏林議會人物資料。Karajan

四、戰後審查與國際復出（1946—1954）

1946年：受到指揮禁令影響

第二次世界大戰結束後，卡拉揚因加入納粹黨而受到盟軍當局審查。

  • 1月，他與維也納愛樂合作舉行戰後音樂會。
  • 隨後受到指揮禁令限制，暫時無法正常進行公開指揮活動。
  • 同年秋季，他開始與英國唱片製作人華特・李格（Walter Legge）合作。
  • 他也開始與李格創立的愛樂管弦樂團（Philharmonia Orchestra）建立重要的藝術合作關係。

這項合作十分重要。李格對錄音製作具有敏銳眼光，而卡拉揚對樂團音響與演奏效果有很高要求。兩人的合作，促成了許多具有代表性的唱片錄音。

1947年：正式重返指揮舞台

  • 10月：卡拉揚的指揮禁令解除。
  • 10月26日：他重新指揮維也納愛樂，在維也納音樂之友協會大樓演出布魯克納《第八號交響曲》。
  • 這場演出象徵他在戰後重新獲得公開指揮的機會。

戰後復出並不代表其納粹時期的經歷已不再受到爭議，而是意味著他重新取得從事音樂工作的資格。

1948年：與倫敦愛樂管弦樂團合作

  • 開始與倫敦的愛樂管弦樂團（Philharmonia Orchestra）密切合作。
  • 同年4月11日，首次指揮該團演出。
  • 他也開始定期參與瑞士琉森音樂節的活動。
  • 同時與維也納交響樂團建立長期合作關係。

這一階段，卡拉揚的事業逐漸由德語地區擴展至英國及其他歐洲國家。

1949年：擴展南美演出

  • 赴古巴及阿根廷等地進行巡演。
  • 透過跨國演出，逐步恢復國際指揮家的地位。
  • 他的事業開始呈現真正全球化的發展趨勢。

1950年：首次參與拜魯特音樂節

  • 首次在拜魯特指揮演出。
  • 華格納作品是他的重要曲目，而拜魯特音樂節則是華格納歌劇傳統的核心舞台之一。
  • 這使他進一步進入德國歌劇藝術的最高層級。

1951年：在拜魯特音樂節獲得重要地位

  • 指揮華格納的《紐倫堡的名歌手》。
  • 參與《尼貝龍指環》系列演出。
  • 這些演出進一步鞏固他在德國歌劇界的地位。

1953年：重新指揮柏林愛樂

  • 9月8日：卡拉揚在戰後首次與柏林愛樂合作演出。
  • 這是他日後接掌樂團的重要前奏。

1954年：福特萬格勒逝世，事業迎來轉折

  • 4月至5月，卡拉揚與日本放送協會交響樂團（NHK交響樂團）合作，展開首次日本巡演。
  • 隨後與倫敦愛樂管弦樂團進行歐洲巡演。
  • 11月30日，福特萬格勒逝世。

福特萬格勒的離世，使柏林愛樂面臨尋找新任主要指揮的問題。卡拉揚逐漸成為最重要的接班人選之一。

本階段的關鍵： 戰後十年間，卡拉揚從受到指揮禁令限制的音樂家，逐漸恢復國際聲望，並為接掌柏林愛樂做好準備。Karajan

五、接掌柏林愛樂與維也納國立歌劇院（1955—1964）

1955年：成為柏林愛樂的接班人

這是卡拉揚職業生涯中最重要的轉折之一。

  • 1955年初，他率領柏林愛樂前往美國巡演。
  • 這次巡演取得成功，使他與樂團的合作關係更加穩固。
  • 5月25日，他簽署合約，出任柏林愛樂的藝術總監與首席指揮，並獲得終身任命。

卡拉揚接掌柏林愛樂後，逐步將樂團塑造成兼具演奏精確度、音響美感與國際影響力的世界級管弦樂團。

1956年：出任薩爾斯堡音樂節藝術總監

  • 卡拉揚開始擔任薩爾斯堡音樂節藝術總監。
  • 他希望提高音樂節的國際地位，並使其成為歌劇、交響樂與音樂錄音的重要中心。
  • 同年，他也獲任維也納國立歌劇院的藝術總監，職務自1956年宣布，1957年正式展開。

這使他同時掌握柏林愛樂、薩爾斯堡音樂節及維也納國立歌劇院等重要音樂機構的藝術資源。

1957年：正式領導維也納國立歌劇院

  • 4月2日：以華格納《女武神》的演出，正式展開維也納國立歌劇院藝術總監任期。
  • 同年秋季，首次率領柏林愛樂赴日本巡演。
  • 他開始進一步拓展亞洲市場，使歐洲古典音樂與亞洲觀眾建立更密切的聯繫。

1958年：與德意志留聲機簽訂重要合約

  • 與第二任妻子離婚。
  • 10月6日：與艾莉葉特・穆雷（Eliette Mouret）結婚。
  • 同年與德意志留聲機公司簽訂五年錄音合約。
  • 重要計畫之一，是錄製貝多芬九首交響曲的完整版本。

這項錄音計畫反映出卡拉揚的藝術理念：他不希望只留下零散的現場演出，而是希望透過系統性的錄音，建立完整且具有長期價值的音樂作品集。

1959年：維也納愛樂世界巡演

  • 卡拉揚與維也納愛樂展開國際巡演。
  • 巡演涵蓋印度、菲律賓、中國、日本及美國等地。
  • 透過國際巡演，歐洲古典音樂的世界影響力進一步擴大。

1960年：薩爾斯堡大音樂廳開幕

  • 7月26日：卡拉揚指揮理查・史特勞斯的《玫瑰騎士》，為薩爾斯堡新建的大音樂廳揭幕。
  • 新音樂廳大幅提升了薩爾斯堡舉辦大型歌劇及音樂會的能力。
  • 同年，他的長女伊莎貝爾（Isabel）出生。

1963年：柏林愛樂音樂廳落成啟用

  • 10月15日：柏林愛樂音樂廳（Berliner Philharmonie）舉行開幕音樂會。
  • 演出曲目包括貝多芬《第九號交響曲》。
  • 新音樂廳由建築師漢斯・夏隆（Hans Scharoun）設計，以舞台居中、觀眾席環繞的形式，改變了傳統音樂廳的空間安排。

這座音樂廳成為柏林愛樂的重要象徵，也與卡拉揚時代的樂團發展密切相關。

1964年：離開維也納國立歌劇院

  • 卡拉揚宣布辭去維也納國立歌劇院藝術總監職務。
  • 他仍與薩爾斯堡音樂節保持密切合作。
  • 同年，他的次女阿拉貝爾（Arabel）出生。

卡拉揚雖然離開維也納國立歌劇院的管理職位，卻仍然透過演出、錄音及音樂節活動，持續影響歐洲歌劇界。

本階段的關鍵： 1955—1964年，卡拉揚建立了以柏林愛樂為核心的藝術體系，並在歌劇院、音樂節、國際巡演及唱片錄音等領域同步擴大影響力。Karajan

六、薩爾斯堡音樂節與藝術帝國的建立（1965—1974）

1965年：積極投入歌劇影像製作

  • 卡拉揚開始更積極地參與歌劇及音樂會的電影拍攝。
  • 與法國電影導演亨利－喬治・克魯佐（Henri-Georges Clouzot）合作。
  • 透過電影及影像紀錄，探索如何將音樂會的視聽經驗帶給更廣泛的觀眾。

他不滿足於傳統唱片的聲音紀錄，而是希望連演奏者的動作、舞台氣氛、燈光與視覺構圖，都能成為音樂欣賞的一部分。

1966年：籌備薩爾斯堡復活節音樂節

  • 正式推動薩爾斯堡復活節音樂節的籌備工作。
  • 計畫以柏林愛樂為主要演出樂團，建立與夏季薩爾斯堡音樂節不同的藝術品牌。
  • 特別重視大型歌劇製作及高品質管弦樂演出。

1967年：創辦薩爾斯堡復活節音樂節

3月19日，第一屆薩爾斯堡復活節音樂節正式開幕。

  • 開幕歌劇為華格納的《女武神》。
  • 柏林愛樂除參與歌劇演出，也舉行交響樂音樂會。
  • 卡拉揚希望透過這個音樂節，建立自己與柏林愛樂之間更緊密的藝術合作。

復活節音樂節與一般音樂節最大的不同之一，在於它讓同一支樂團能夠長時間投入歌劇製作，從排練、演出到錄音，形成完整的藝術計畫。

1968年：成立卡拉揚基金會

  • 卡拉揚在柏林成立以自己命名的基金會。
  • 基金會後續支持音樂研究、指揮比賽及相關文化活動。
  • 他希望透過制度性的安排，培養年輕指揮家，並擴大音樂研究的範圍。

1969年：設立指揮比賽

  • 舉辦國際指揮比賽，讓年輕指揮家有機會在國際舞台上展示才能。
  • 這類比賽為新一代指揮家提供重要的職業發展機會。
  • 同年，卡拉揚基金會也推動與音樂心理學有關的研究。

卡拉揚不只關心演奏效果，也對音樂如何影響聽眾的感知、情緒與注意力具有興趣。

1970年：擴大貝多芬交響曲的國際演出

  • 與柏林愛樂赴日本巡演，演出貝多芬九首交響曲。
  • 同年也在維也納音樂節期間指揮貝多芬九首交響曲。
  • 這種以完整作曲家作品為主題的演出，逐漸成為他建立藝術品牌的重要方式。

1971年：持續經營大型歌劇製作

  • 繼續在復活節音樂節及薩爾斯堡音樂節製作歌劇。
  • 他的藝術理念不只強調指揮，也強調歌劇的整體視覺效果、舞台節奏與聲音平衡。
  • 他逐漸成為同時影響演奏、歌劇製作及錄音產業的文化人物。

1972年：成立柏林愛樂管弦樂團學院

這是卡拉揚對音樂教育的重要貢獻之一。

  • 推動成立柏林愛樂管弦樂團學院（Orchestra Academy）。
  • 主要目標是培養年輕管弦樂演奏家。
  • 學員可透過專業訓練，了解大型職業樂團的演奏標準、排練方式與合作要求。

這項制度的影響延續至今，學院後來以卡拉揚之名命名，成為培養職業樂團演奏家的重要機構。

1973年：創辦薩爾斯堡聖靈降臨節音樂活動

  • 卡拉揚推動薩爾斯堡聖靈降臨節音樂節（Salzburg Whitsun Festival）的發展。
  • 演出內容包括布魯克納等作曲家的重要作品。
  • 同年，他獲得柏林榮譽市民身分。

這一時期，他的影響力已不只來自指揮演出，也來自他對音樂節制度、人才培養與音樂文化傳播的長期投入。

1974年：持續擴張國際演出

  • 帶領柏林愛樂赴美國巡演。
  • 持續在薩爾斯堡及歐洲其他音樂中心指揮歌劇與交響樂。
  • 他的錄音、演出及影像作品逐漸構成彼此連結的藝術體系。

本階段的關鍵： 卡拉揚逐漸從著名指揮家轉變為具有廣泛影響力的音樂文化經營者。他同時掌握樂團、音樂節、人才培養與影音製作等資源。

資料來源：卡拉揚研究機構官方年表、柏林愛樂歷史資料。Karajan

七、錄音藝術、數位科技與晚年（1975—1989）

1975年：健康開始影響工作

  • 12月，卡拉揚因嚴重椎間盤問題接受大型手術。
  • 這次健康事件影響了他的工作安排。
  • 儘管如此，他仍持續規劃歌劇製作、錄音及國際演出。

1976年：繼續推動大型歌劇製作

  • 在薩爾斯堡復活節音樂節推出華格納《羅恩格林》。
  • 持續與重要歌劇歌手合作。
  • 透過高規格的舞台製作與錄音，建立其歌劇詮釋的代表性。

1977年：獲頒恩斯特・馮・西門子音樂獎

  • 4月13日：獲得恩斯特・馮・西門子音樂獎（Ernst von Siemens Music Prize）。
  • 該獎項是國際音樂界的重要榮譽之一。
  • 同年，他也持續在維也納國立歌劇院指揮演出。

1978年：獲得重要學術榮譽

  • 獲得薩爾斯堡大學榮譽博士學位。
  • 同年也獲得牛津大學榮譽博士學位。
  • 9月，他在柏林排練期間曾發生中風。

健康問題開始更加明顯地影響他的工作，但他仍繼續進行錄音與指揮活動。

1979年：擴大亞洲演出

  • 柏林愛樂赴東京巡演，並首次前往北京演出。
  • 這次演出對中國與歐洲古典音樂交流具有象徵意義。
  • 卡拉揚持續透過巡演，擴大柏林愛樂的國際知名度。

1980年：開始數位錄音

  • 卡拉揚開始積極接觸數位錄音技術。
  • 早期的重要數位錄音計畫包括莫札特《魔笛》。
  • 他相信新的錄音技術能更精確地保存音樂細節，並為聽眾帶來更好的聆聽體驗。

這是他與新興音樂科技結合的重要一步。

1981年：積極推廣 CD 數位音樂格式

4月15日，卡拉揚在薩爾斯堡復活節音樂節期間，與索尼高層共同參與 CD 數位音訊系統的公開展示活動。

當時的 CD（Compact Disc，雷射唱片）代表音樂媒體的一項重大轉變。

相較於傳統黑膠唱片，CD 具有以下特點：

  1. 採用數位方式儲存音訊。
  2. 播放時不需要唱針直接接觸唱片表面。
  3. 便於大量複製、保存及攜帶。
  4. 有利於唱片公司重新發行經典錄音。

卡拉揚積極支持 CD 技術，顯示他不只關心音樂的演奏，也關心音樂如何被保存、傳播與消費。

1982年：成立 Telemondial

  • 卡拉揚成立影音製作公司 Telemondial。
  • 目標是將其重要歌劇及音樂會錄製成高品質影像。
  • 他希望建立一套能夠長期保存其藝術成果的影音紀錄。

這項工作也使卡拉揚成為少數積極參與自身藝術形象與影音遺產規劃的指揮家之一。

同年：薩賓娜・邁耶事件

  • 卡拉揚希望聘用單簧管演奏家薩賓娜・邁耶（Sabine Meyer）進入柏林愛樂。
  • 這項人事安排遭到樂團內部反對。
  • 雙方在聘用程序、樂團傳統與藝術領導權方面產生嚴重分歧。

這場衝突成為卡拉揚晚年與柏林愛樂關係惡化的重要原因。

1983年：75歲生日

  • 4月5日：卡拉揚迎來75歲生日。
  • 獲得多項唱片與音樂界榮譽。
  • 持續進行錄音、歌劇製作及音樂會演出。

此時，他已是全球最具知名度的古典音樂指揮家之一。

1984年：與柏林愛樂的衝突加深

  • 薩賓娜・邁耶事件持續影響卡拉揚與樂團的關係。
  • 卡拉揚與柏林愛樂之間的藝術合作受到嚴重影響。
  • 同年，雙方一度恢復部分合作，但彼此的信任已不如以往。

這場衝突反映出一個重要問題：當指揮家擁有極大的藝術權力時，樂團成員是否仍應保有對人事與組織決策的自主權？

卡拉揚的藝術成就很高，但他強勢的領導風格也使他與樂團之間容易產生權力衝突。

1985年：持續國際演出

  • 繼續參與薩爾斯堡復活節音樂節。
  • 仍然錄製歌劇與交響樂作品。
  • 健康問題使他的工作安排逐漸需要調整。

1986年：健康狀況轉差

  • 因健康問題減少部分工作。
  • 仍持續參與音樂節與錄音計畫。
  • 他開始更加重視保存音樂作品的影音紀錄。

1987年：首次也是唯一一次指揮維也納新年音樂會

1月1日，卡拉揚首次指揮維也納愛樂新年音樂會。

這也是他唯一一次指揮這場著名的年度音樂盛事。

維也納新年音樂會以約翰・史特勞斯家族的圓舞曲、波卡舞曲等作品為重要曲目。卡拉揚的參與，使這場原本具有鮮明維也納傳統的音樂會，與國際唱片及電視傳播產生更緊密的聯繫。

1988年：80歲生日與晚年演出

  • 4月5日：卡拉揚迎來80歲生日。
  • 獲得多項榮譽，唱片公司也推出紀念性作品集。
  • 5月，他進行最後一次日本演出。
  • 8月28日，他最後一次在薩爾斯堡音樂節指揮演出，曲目為布拉姆斯《德意志安魂曲》。
  • 12月31日，他進行最後一場柏林音樂會。

他的健康狀況已不如以往，但仍持續工作，並努力完成部分重要的錄音與演出計畫。

1989年：辭職與逝世

1989年是卡拉揚人生的最後一年。

3月：最後一次指揮柏林愛樂

  • 3月27日：最後一次指揮柏林愛樂。
  • 長期以來與樂團之間的矛盾，加上人事與藝術管理上的分歧，使雙方關係難以維持。

4月：辭去柏林愛樂職務

  • 4月24日：宣布辭去柏林愛樂的藝術領導職務。
  • 這項決定結束了他與柏林愛樂長達數十年的密切合作。

7月：逝世

  • 7月16日：卡拉揚在奧地利薩爾斯堡附近的阿尼夫（Anif）住所因心臟衰竭逝世，享年81歲。
  • 當時，他仍在準備威爾第歌劇《假面舞會》的製作。
  • 他的逝世結束了20世紀古典音樂史上一個極具影響力的指揮時代。

資料來源：卡拉揚研究機構官方生平年表及薩爾斯堡音樂節資料。Karajan

八、卡拉揚的主要藝術特色

1. 追求精緻、飽滿的管弦樂音響

卡拉揚最鮮明的藝術特色之一，是他對樂團音響的高度控制。

在他的錄音中，弦樂通常呈現圓潤、連貫的音色，木管與銅管則在整體音響中形成清晰而有層次的結構。

這種聲音美學特別適合呈現德奧浪漫主義交響曲中的宏大情緒與長篇幅發展。

不過，這並不代表他的演出只追求音響美感。他對節奏、結構、演奏精確度及音樂整體方向同樣有很高要求。

2. 重視弦樂連奏與整體一致性

卡拉揚非常重視樂團各聲部之間的協調。

他經常透過大量排練，使弦樂群形成一致的運弓與音色，並讓不同樂器之間的銜接更加自然。

這種處理方式，使他的演出具有流暢、連續且高度統一的音樂效果。

3. 以貝多芬、布拉姆斯與布魯克納為核心

卡拉揚的代表曲目包括：

  • 貝多芬：九首交響曲、歌劇《費黛里奧》。
  • 布拉姆斯：四首交響曲、《德意志安魂曲》。
  • 布魯克納：第四、七、八、九號交響曲。
  • 華格納：《尼貝龍指環》、《崔斯坦與伊索德》、《帕西法爾》。
  • 理查・史特勞斯：《玫瑰騎士》、《查拉圖斯特拉如是說》。
  • 莫札特：《魔笛》、《唐・喬望尼》、《費加洛婚禮》。

此外，他也指揮德布西、拉威爾、史特拉汶斯基及第二維也納樂派等作曲家的作品。

4. 將錄音視為獨立的藝術作品

傳統上，指揮家的主要成就通常以現場演出為核心。

卡拉揚則更積極地將錄音視為可以反覆修訂、長期保存及廣泛傳播的藝術成果。

他願意反覆排練、錄製及比較不同版本，追求理想的音響效果。

因此，他的錄音遺產特別豐富，許多作品甚至留下多個不同年代的版本，讓聽眾可以比較他的詮釋如何隨時間變化。

5. 重視音樂影像與數位科技

卡拉揚積極參與電影、電視、雷射影碟及 CD 等媒體的發展。

他希望透過影像與聲音，將古典音樂帶給不一定能親臨音樂廳的觀眾。

這種理念使他不只是一位指揮家，也成為古典音樂影音傳播的重要推動者。

建議的聆聽順序

如果想逐步理解卡拉揚的風格，可以依照以下順序聆聽：

  1. 貝多芬《第五號交響曲》：先感受他如何控制節奏、動機與整體音響。

十一、卡拉揚的歷史評價

1. 對柏林愛樂的影響

卡拉揚在柏林愛樂的長期任期，使他得以持續建立樂團的音色、排練文化與國際形象。

他重視弦樂音色、整體音響與演奏精確度，並透過大量錄音，讓柏林愛樂成為全球觀眾熟悉的樂團。

2. 對古典音樂錄音的影響

卡拉揚是古典音樂錄音史上最具代表性的指揮家之一。

他留下大量交響曲與歌劇錄音，也積極推動立體聲、數位錄音及音樂影像的發展。

他的作品讓聽眾可以跨越地理限制，反覆聆聽同一支樂團與同一位指揮家對作品的詮釋。

3. 對音樂人才培養的影響

透過柏林愛樂管弦樂團學院及國際指揮比賽，他對年輕音樂家的培養留下長期影響。

這也顯示他並非只關心自己的演出，而是希望建立能夠延續音樂傳統的制度。

4. 納粹時期的政治爭議

卡拉揚的藝術成就與其政治經歷必須分開考察，但也不能完全切割。

他的納粹黨籍、戰時職業發展及戰後指揮禁令，都是其生平不可忽略的部分。

因此，對他的評價應同時考慮藝術成就、個人選擇、歷史背景及其在納粹體制中的實際位置，而不是只以音樂成就來取代歷史責任的討論。

十三、總結：如何理解卡拉揚的一生？

卡拉揚的生平，可以從四個相互關聯的面向理解。

第一，指揮藝術的發展。 他從薩爾斯堡的鋼琴學生起步，逐漸成為柏林愛樂的長期領導者。他以音色、連奏、精確度與整體音響控制，建立鮮明的指揮風格。

第二，音樂機構的經營。 他不只指揮音樂會，也參與音樂節、歌劇製作、人才培養與樂團制度建設。薩爾斯堡復活節音樂節及柏林愛樂管弦樂團學院，都是他留下的重要制度性成果。

第三，錄音與科技的創新。 他積極投入唱片、電影、數位錄音及 CD 的發展，使古典音樂不再只依賴現場演出，而能透過媒體進入全球家庭。

第四，藝術與政治的歷史問題。 他的納粹黨籍與戰後審查，是評價其生平不可忽略的一部分。理解卡拉揚，既要認識他的藝術成就，也要正視他在20世紀政治史中的位置。

如果說福特萬格勒代表了20世紀指揮傳統中強調現場張力與音樂生成的面向，那麼卡拉揚則代表了將指揮藝術、樂團音響、錄音工業與現代媒體結合起來的另一條重要道路。

卡拉揚最深遠的影響，不僅在於他如何指揮音樂，也在於他如何改變了現代人聆聽、保存與傳播古典音樂的方式。
