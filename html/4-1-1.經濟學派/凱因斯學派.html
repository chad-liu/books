凱因斯學派（Keynesian School of Economics）非常完整詳細大事記

從新古典經濟學背景、1936年《通論》到後疫情時代的凱因斯經濟學

凱因斯學派（Keynesian Economics）是20世紀最重要、最具影響力的經濟學派之一。
它的出現，徹底改變了人類對資本主義經濟、失業、通貨膨脹、經濟衰退、政府財政政策及中央銀行貨幣政策的理解。
凱因斯學派最重要的歷史轉折，是1936年英國經濟學家約翰・梅納德・凱因斯（John Maynard Keynes）出版《就業、利息和貨幣通論》（The General Theory of Employment, Interest and Money）。
這本書挑戰傳統古典經濟學及新古典經濟學對市場自我調節的部分假設，提出：
市場經濟可能長期處於有效需求不足及非充分就業狀態，政府必須在必要時運用財政與貨幣政策穩定經濟。
凱因斯思想不僅影響1930年代大蕭條後的經濟政策，也深刻影響第二次世界大戰後的西方福利國家、國際金融制度、中央銀行政策及現代總體經濟學。

第一篇：凱因斯學派的歷史背景與思想起源

一、1870年至1914年：新古典經濟學時代

凱因斯學派的形成，必須先理解19世紀後期至20世紀初期的新古典經濟學。
1870年代開始，經濟學出現邊際革命，逐漸從古典經濟學的勞動價值分析，轉向主觀效用、邊際效用及市場均衡分析。
重要人物：

  • 威廉・斯坦利・傑文斯（William Stanley Jevons）。
  • 卡爾・門格爾（Carl Menger）。
  • 里昂・瓦爾拉斯（Léon Walras）。
  • 阿爾弗雷德・馬歇爾（Alfred Marshall）。
  • 亞瑟・庇古（Arthur Cecil Pigou）。

重要事件年表

年代重大事件經濟思想意義

1871年門格爾出版《國民經濟學原理》奧地利學派形成。
1874年瓦爾拉斯出版《純粹經濟學要義》一般均衡理論發展。

1900年西方主要工業國持續擴張現代工業及金融市場逐漸成熟。

1913年美國聯邦準備制度法案通過美國聯邦準備制度建立。
1914年第一次世界大戰爆發國際金融、貨幣及財政制度受到重大衝擊。

這個時代的主流經濟思想

當時的新古典經濟學普遍重視：

  1. 市場價格調節供需。
  2. 工資及價格變動有助於市場恢復均衡。
  3. 個人理性選擇。
  4. 邊際效用與邊際成本。
  5. 市場競爭與資源配置。
  6. 長期經濟均衡。

不過，這些理論對於大規模失業、金融崩潰及長期經濟蕭條的解釋能力，逐漸受到質疑。
這正是凱因斯革命的重要歷史背景。

第二篇：第一次世界大戰與凱因斯經濟思想轉變（1914年至1929年）

四、1914年至1918年：第一次世界大戰與國際金融危機

第一次世界大戰使歐洲經濟秩序遭受嚴重破壞。
主要經濟問題：

  1. 政府軍事支出大幅增加。
  2. 國家債務快速上升。
  3. 貨幣發行增加。
  4. 通貨膨脹。
  5. 國際貿易中斷。
  6. 黃金本位制度受到衝擊。
  7. 戰後財政重建問題。

凱因斯在英國財政部工作，親身參與戰時金融政策。
這段經歷讓他深刻理解貨幣、財政、國際貿易及政府政策之間的關係。

五、1919年：《和平的經濟後果》

《和平的經濟後果》（The Economic Consequences of the Peace）
出版年份：1919年
作者：凱因斯

1. 歷史背景

第一次世界大戰於1918年結束。
1919年，戰勝國在巴黎和會討論戰後國際秩序。
《凡爾賽條約》要求德國承擔戰爭責任及巨額賠款。
凱因斯認為，過度嚴苛的賠款條件可能造成德國經濟崩潰，並破壞歐洲整體經濟復甦。

2. 凱因斯的重要主張

  • 德國必須具備恢復生產的能力。
  • 歐洲國家之間需要恢復貿易。
  • 戰爭賠款應考慮經濟承受能力。
  • 國際經濟復甦需要合作。
  • 不應以政治報復取代經濟重建。

3. 歷史影響

這本書使凱因斯成為國際知名的經濟評論家，也使他開始從傳統貨幣與財政問題，逐步走向更完整的宏觀經濟分析。

英文書名：
A Tract on Monetary Reform
主要思想：

  1. 貨幣購買力應受到重視。
  2. 穩定物價比單純維持固定匯率更重要。

2. 1925年：英國恢復金本位制度

英國財政大臣邱吉爾決定恢復戰前英鎊與黃金的兌換平價。
凱因斯認為，戰後英國物價與工資結構已經改變，恢復過高的英鎊金平價可能造成：

  • 英鎊高估。
  • 出口競爭力下降。
  • 工業生產受到壓力。
  • 工資與價格下調。
  • 失業增加。

這是凱因斯批判傳統貨幣制度的重要事件。

3. 1926年：《自由放任的終結》

英文書名：
The End of Laissez-Faire
主要觀點：

  • 市場不一定能夠自動達成理想結果。
  • 現代企業與金融制度已經十分複雜。
  • 政府應適當改善經濟制度。
  • 經濟政策需要考慮公共利益。
  • 完全放任市場並不是所有經濟問題的答案。

這是凱因斯思想轉型的重要里程碑。

為什麼市場經濟在遭遇重大衝擊後，不能迅速恢復充分就業？

十一、《通論》的主要理論內容

全書共六篇、二十四章。

篇章研究主題核心內容
第一篇導論古典經濟學理論的基本問題。
第二篇定義與觀念就業、所得及儲蓄等概念。
第三篇消費傾向消費與所得之間的關係。

十二、凱因斯學派十大核心理論

1. 有效需求理論（Effective Demand）

有效需求是凱因斯理論最重要的概念。
凱因斯認為，短期內經濟產出及就業主要受到有效需求影響。
當社會總需求不足時，企業銷售減少，便會減少生產及僱用員工。
因此，經濟可能長期停留在低產出及高失業的狀態。

2. 總需求理論（Aggregate Demand）

現代凱因斯總體經濟學常用以下公式表示：

AD = C + I + G + (X − M)

其中：

  • C：民間消費。
  • I：民間投資。
  • G：政府支出。
  • X：出口。
  • M：進口。

當總需求下降，經濟產出與就業可能跟著下降。

3. 消費函數（Consumption Function）

凱因斯認為，消費主要受到可支配所得影響。

C = C0 + c·Yd

其中：

  • C：消費支出。
  • C0：自主消費。
  • c：邊際消費傾向。
  • Yd：可支配所得。

邊際消費傾向（MPC）：

MPC = ΔC / ΔYd

例如，收入增加1,000元，消費增加800元：

MPC = 800 / 1000 = 0.8

代表新增所得中有80%用於消費。

4. 乘數理論（Multiplier Effect）

乘數理論說明，最初的投資或政府支出增加，可能透過所得及消費的連鎖效果，使國民所得增加更多。
簡化乘數公式：

k = 1 / (1 − MPC)

假設：

MPC = 0.8

則：

k = 1 / (1 − 0.8) = 5

如果政府增加100億元支出，在簡化模型條件下，均衡所得可能增加500億元。
實際乘數大小會受到稅收、進口、物價、貨幣政策及經濟閒置程度等因素影響。

5. 流動性偏好理論（Liquidity Preference）

凱因斯認為，人們持有貨幣主要有三種動機：

  1. 交易動機：日常購買及支付。
  2. 預防動機：應付意外支出。
  3. 投機動機：因應債券價格及利率變化。

貨幣需求可以簡化表示為：

M = L(Y, r)

其中：

  • M：貨幣供給。
  • L：貨幣需求。
  • Y：所得。
  • r：利率。

一般而言，所得增加會提高交易性貨幣需求；利率變化則會影響持有貨幣與債券的選擇。

6. 流動性陷阱（Liquidity Trap）

當利率已經非常低時，人們可能更願意持有貨幣，而不願意購買債券。
此時，即使中央銀行增加貨幣供給，也可能無法有效降低利率及刺激投資。
因此，凱因斯認為在特定情況下，財政政策可能比單純貨幣寬鬆更有效。

7. 資本邊際效率（Marginal Efficiency of Capital）

企業投資決策取決於預期投資報酬與資金成本。
當企業預期未來獲利增加，投資意願通常會提高。
相反地，當企業對未來缺乏信心，即使利率下降，也可能不願意增加投資。

8. 投資與預期心理

凱因斯強調投資受到不確定性與市場信心影響。
投資並不是完全由目前利率決定。
企業家對未來銷售、利潤及經濟環境的預期，同樣十分重要。

9. 非自願失業（Involuntary Unemployment）

傳統理論常以工資調整解釋勞動市場均衡。
凱因斯則指出：
即使勞工願意接受現行工資，也可能因為企業沒有足夠訂單，而無法找到工作。
這就是非自願失業。

10. 政府財政干預

當民間消費與投資不足時，政府可以增加公共支出，支持總需求及就業。
例如：

  • 建設交通設施。
  • 投資公共工程。
  • 增加公共住宅。
  • 提高失業救濟。
  • 擴大教育及醫療支出。
  • 減稅以刺激民間消費。

十四、1937年：IS-LM模型的重要發展

1937年，英國經濟學家約翰・希克斯發表：
Mr. Keynes and the Classics: A Suggested Interpretation
他將凱因斯《通論》的部分核心思想，整理成後來廣為人知的IS-LM模型。

IS曲線

代表商品市場均衡。

Y = C(Y − T) + I(r) + G

LM曲線

代表貨幣市場均衡。

M / P = L(Y, r)

IS-LM模型的用途

  • 分析政府支出增加的效果。
  • 分析貨幣供給變化。
  • 研究利率與所得的關係。
  • 分析財政政策與貨幣政策。
  • 研究商品市場與貨幣市場的共同均衡。

這個模型後來成為戰後凱因斯總體經濟學的重要教學工具。
但要注意，IS-LM是希克斯對凱因斯理論的一種整理方式，並不能完全代表凱因斯本人對不確定性及貨幣經濟的全部思想。

十五、1937年至1939年：凱因斯與古典學派的辯論

1937年，凱因斯在《經濟學季刊》發表〈就業的一般理論〉等重要文章，進一步解釋《通論》的思想。
主要討論：

  1. 貨幣經濟與實物經濟的差異。
  2. 投資決策與不確定性。
  3. 利率及流動性偏好。
  4. 工資調整與失業。
  5. 市場均衡是否能夠自動恢復充分就業。

這段時期，凱因斯學派開始形成自己的學術研究群體。

十八、1943年至1944年：凱因斯的國際清算聯盟計畫

凱因斯提出戰後國際貨幣制度改革方案，稱為國際清算聯盟（International Clearing Union）。
其中最重要的概念是：
班柯（Bancor）
這是一種構想中的國際記帳貨幣。
主要目標：

  1. 建立國際多邊支付制度。
  2. 減少國際收支失衡。
  3. 避免各國競相貶值。
  4. 改善國際貿易融資。
  5. 避免國際金融體系再次陷入戰前危機。

凱因斯希望，國際貨幣制度不應只要求赤字國調整，也應讓長期順差國承擔一定調整責任。
這個方案並未成為最後採用的布列敦森林制度，但對國際貨幣改革思想具有深遠影響。

戰後國際貨幣制度使各國能夠在相對穩定的匯率環境中進行貿易及投資。
這套制度一直運作至1971年美國停止美元對外兌換黃金，並在1970年代初期逐步瓦解。

二十七、1970年代：停滯性通貨膨脹（Stagflation）

1970年代是凱因斯學派發展史上的重大轉折。
1950至1960年代，許多經濟學家相信政府可以透過財政政策及貨幣政策，調節總需求，維持經濟成長及充分就業。
但1970年代發生了一個嚴重問題：
通貨膨脹與失業率同時上升。
這種現象稱為停滯性通貨膨脹。

1. 1970年代重要事件年表

年份重大事件經濟影響
1970年美國經濟成長放緩失業及通膨問題逐漸浮現。

1973－1974年全球經濟衰退生產成本及失業率上升。

1975年美國經濟衰退失業問題嚴重。

2. 1973年第一次石油危機

1973年，中東戰爭後，阿拉伯石油輸出國採取石油禁運及減產措施。
主要結果：

  1. 國際石油價格大幅上升。
  2. 工業生產成本增加。
  3. 企業獲利下降。
  4. 物價上漲。
  5. 經濟成長放緩。
  6. 失業率增加。

這是一種供給面衝擊，不能單純用增加或減少總需求來解釋。

3. 停滯性通膨對凱因斯學派的挑戰

傳統的短期菲利普斯曲線曾被理解為失業與通膨之間存在某種政策取捨。
但1970年代卻出現：

  • 高通膨。
  • 高失業。
  • 低經濟成長。

這使經濟學家重新思考：

  1. 通膨是否只由需求過度造成？
  2. 預期通膨如何影響工資？
  3. 能源價格上漲如何影響物價？
  4. 政府財政政策是否存在限制？
  5. 貨幣政策應如何控制通膨？

二十八、1970年代：貨幣學派崛起

米爾頓・傅利曼（Milton Friedman）

二十九、1970年代：新古典學派的興起

羅伯特・盧卡斯（Robert Lucas Jr.）
1937－2023年
新古典總體經濟學的重要代表人物，1995年諾貝爾經濟學獎得主。

1. 理性預期理論（Rational Expectations）

1970年代，理性預期理論逐漸成為總體經濟學的重要研究方向。
主要思想：

  • 經濟參與者會利用可取得的資訊形成預期。
  • 政府政策可能被市場提前預期。
  • 政策效果取決於政策是否能夠改變實質經濟行為。
  • 單純、可預期的政策可能無法長期改變實質產出。

2. 1976年：盧卡斯批判（Lucas Critique）

盧卡斯指出：
經濟政策改變時，個人及企業會調整自己的行為，因此不能直接將過去經濟數據建立的政策關係，當成政策改變後仍然有效的固定關係。
這項批判對傳統凱因斯總體經濟模型造成重大影響。

2. 新凱因斯學派的核心理論

（1）價格僵固性（Price Stickiness）
企業不一定會立即調整商品價格。
原因可能包括：

  • 調價成本。
  • 長期契約。
  • 市場競爭。
  • 消費者預期。
  • 企業定價策略。

因此，總需求下降可能先造成產出及就業下降，而非價格立即大幅下降。
（2）工資僵固性（Wage Stickiness）
工資不一定會隨景氣立即調整。
例如：
企業面臨需求下降時，可能先減少招聘及裁員，而不是全面降低工資。
（3）效率工資理論（Efficiency Wage Theory）
企業支付較高工資，有時能提高員工生產力、降低離職率及改善工作效率。
因此，工資可能高於市場立即出清的水準。
（4）不完全競爭（Imperfect Competition）
市場不一定符合完全競爭條件。
企業具有一定定價能力，價格調整可能受到市場結構影響。
（5）貨幣政策傳遞機制
利率改變會透過消費、投資、資產價格及信用市場影響總需求。

二、凱因斯學派重要經濟公式

1. 總需求公式

Y = C + I + G + (X − M)

這是現代總體經濟學最基本的國民所得支出恆等式。

2. 消費函數

C = C0 + c·Yd

其中 c 是邊際消費傾向。

3. 簡單乘數公式

k = 1 / (1 − MPC)

4. 均衡所得公式

在沒有政府及國際貿易的簡化經濟中：

Y = C + I

代入消費函數：

Y = C0 + cY + I

整理後：

Y = (C0 + I) / (1 − c)

5. 政府支出乘數

在簡化的封閉經濟模型中：

kG = 1 / (1 − MPC)

6. 租稅乘數

kT = − MPC / (1 − MPC)

代表政府增加稅收可能降低均衡所得。

7. IS曲線

商品市場均衡：

Y = C(Y − T) + I(r) + G

8. LM曲線

貨幣市場均衡：

M / P = L(Y, r)

9. 費雪方程式

MV = PY

其中：

  • M：貨幣供給。
  • V：貨幣流通速度。
  • P：物價水準。
  • Y：實質產出。

這是貨幣理論的重要基礎公式，但不能將它簡化成所有情況下貨幣供給與物價一對一變動的關係。

10. 泰勒法則

現代中央銀行政策分析常使用：

i = r* + π + a(π − π*) + b(y − y*)

其中：

  • i：政策利率。
  • r*：均衡實質利率。
  • π：實際通膨率。
  • π*：通膨目標。
  • y − y*：產出缺口。
  • a, b：政策反應係數。

泰勒法則不是凱因斯原始理論，而是後來現代總體經濟政策的重要分析工具。

一、傳統凱因斯學派（Traditional Keynesian Economics）
