目錄

世界經濟思想各大學派：完整、詳細介紹與發展史

經濟思想史（History of Economic Thought）是研究人類如何理解財富、生產、分配、交換、貨幣、市場、國家干預及經濟發展的一門學科。

從古希臘哲學家探討財富與交易，到亞當・斯密建立古典經濟學，再到馬克思批判資本主義、凱因斯提出政府干預理論，以及現代的行為經濟學、制度經濟學、賽局理論與新興古典經濟學，經濟思想經歷了數千年的演變。

理解經濟思想，不能只看各學派的代表人物，更要理解它們所處的歷史背景、核心假設、理論主張、政策建議，以及不同學派之間的爭論。

以下按照歷史年代、思想淵源及理論發展，建立一套完整的世界經濟思想學派知識體系。

第一篇：經濟思想的起源與古代經濟思想

一、古代經濟思想（Ancient Economic Thought）

發展時期：約西元前3000年－西元15世紀

這個階段尚未形成現代意義上的獨立經濟學科，經濟思想主要包含在哲學、政治、倫理、法律及宗教之中。

1. 古埃及與美索不達米亞經濟思想

主要時期：西元前3000年－西元前500年。

主要思想：

  • 土地、農業及灌溉系統的管理。
  • 國家對糧食、勞動及商品的控制。
  • 稅收、貢賦與公共工程。
  • 貨幣出現以前的物物交換及計價制度。
  • 債務、利息、契約與財產權。

代表性歷史制度：

  • 漢摩拉比法典（約西元前18世紀）。
  • 古代埃及的中央糧食管理制度。
  • 美索不達米亞的商業契約與借貸制度。

這些制度是後來財產權、金融制度、稅收制度與市場經濟思想的重要歷史來源。

2. 古希臘經濟思想

主要時期：西元前6世紀－西元前3世紀。

代表人物：

  • 色諾芬（Xenophon，約前430－前354年）
  • 柏拉圖（Plato，約前427－前347年）
  • 亞里斯多德（Aristotle，前384－前322年）

核心思想：

色諾芬

  • 研究家庭管理、農業及財富管理。
  • 強調有效利用資源。
  • 著作《經濟論》（Oeconomicus）是早期經濟管理思想的重要作品。

柏拉圖

  • 提出社會分工思想。
  • 認為不同的人具有不同能力，應從事不同職業。
  • 主張理想國家應具有適當的社會階層與職業安排。
  • 在《理想國》中討論財產、分工與政治秩序。

亞里斯多德

  • 區分家庭經濟管理與無限制追求財富的活動。
  • 討論商品交換、貨幣及公平價格。
  • 批判單純以貨幣增殖為目的的高利貸活動。
  • 對使用價值與交換價值提出早期分析。

3. 古羅馬經濟思想

代表人物：

  • 西塞羅
  • 加圖
  • 瓦羅

核心思想：

  • 私有財產與財產權。
  • 農業生產及莊園管理。
  • 契約與商業交易。
  • 貿易、法律與市場秩序。
  • 土地所有權及奴隸勞動制度。

4. 中國古代經濟思想

主要時期：西元前11世紀－西元3世紀。

重要學派與人物：

（1）管仲經濟思想

  • 代表人物：管仲。
  • 重要文獻：《管子》。
  • 重視國家財政、貨幣、物價與市場。
  • 主張因勢利導調節經濟。
  • 提出輕重理論，討論商品價格、供需及國家經濟調控。
  • 強調富國與富民之間的關係。

（2）儒家經濟思想

  • 代表人物：孔子、孟子。
  • 重視義利關係。
  • 強調民生、農業及社會倫理。
  • 孟子提出「制民之產」的思想，強調人民應有基本生活保障。
  • 主張合理賦稅與穩定民生。

（3）法家經濟思想

  • 代表人物：商鞅、韓非。
  • 強調國家權力及法律制度。
  • 重農抑商。
  • 鼓勵農業生產。
  • 強調國家財政與軍事力量。

（4）道家經濟思想

  • 代表人物：老子。
  • 主張無為而治。
  • 反對過度干預人民生活。
  • 重視自然秩序與社會自發運作。

（5）墨家經濟思想

  • 代表人物：墨子。
  • 提倡節用。
  • 反對奢侈浪費。
  • 重視生產、勞動與社會實用性。

二、中世紀經院經濟思想（Scholastic Economic Thought）

發展時期：約5世紀－15世紀

這個時期歐洲經濟思想深受基督教神學影響。

代表人物：

  • 聖奧古斯丁
  • 聖托馬斯・阿奎那
  • 尼古拉・奧雷姆

主要理論：

  1. 公平價格（Just Price）：商品價格應符合合理交換與道德原則。
  2. 高利貸批判：反對不合理的利息與剝削。
  3. 私有財產：承認私有財產，但強調財產應服務社會公益。
  4. 公平交易：商業活動必須遵守道德與契約規範。
  5. 財富觀：反對將無限制積累財富視為人生最高目標。

歷史意義：

經院經濟思想將倫理、法律、財產權及市場交易結合，成為後來自然法、商業法及經濟倫理的重要思想來源。

第二篇：近代經濟思想的形成

三、重商主義（Mercantilism）

1. 歷史背景

重商主義興起於歐洲民族國家形成、海外殖民擴張及國際貿易快速發展的時代。

當時歐洲各國競爭殖民地、貴金屬、海外市場與海上貿易控制權。

2. 代表人物

  • 托馬斯・孟
  • 安東尼奧・塞拉
  • 讓・巴蒂斯特・柯爾貝爾
  • 威廉・佩蒂

3. 核心理論

  • 國家財富與貴金屬儲備密切相關。
  • 鼓勵出口，限制進口。
  • 追求貿易順差。
  • 保護國內工業。
  • 國家積極干預經濟。
  • 發展海運、殖民貿易及國家商業力量。

4. 政策主張

  1. 提高進口關稅。
  2. 補助出口產業。
  3. 限制外國商品競爭。
  4. 建立殖民地貿易體系。
  5. 發展國家商船與海軍。
  6. 以政策扶植國內製造業。

5. 歷史貢獻與限制

貢獻：

  • 促進國際貿易及商業資本發展。
  • 推動國家財政與經濟政策形成。
  • 促進民族國家經濟整合。

限制：

  • 將國際貿易過度理解為零和競爭。
  • 過度重視貴金屬累積。
  • 容易形成保護主義與殖民剝削。

四、重農主義（Physiocracy）

1. 歷史背景

重農主義誕生於18世紀法國，反對重商主義過度干預經濟，主張自然秩序與農業生產的重要性。

2. 代表人物

  • 法蘭索瓦・魁奈
  • 安・羅伯特・杜爾哥
  • 維克多・米拉波

3. 核心理論

（1）自然秩序

經濟活動具有自然規律，政府不應過度干預。

（2）農業剩餘理論

認為農業是能創造純產品（Produit net）的生產活動。

（3）經濟循環理論

魁奈提出《經濟表》（Tableau économique），分析農業剩餘如何在地主、農業生產者及製造業者之間流動。

（4）自由放任

主張自由貿易、自由生產及減少不必要的經濟管制。

4. 歷史貢獻

  • 建立早期總體經濟循環分析。
  • 啟發國民所得與經濟流量研究。
  • 影響亞當・斯密及古典經濟學。
  • 將經濟視為相互依存的整體系統。

第三篇：古典經濟學與社會主義思想

五、古典經濟學派（Classical Economics）

古典經濟學是現代經濟學的主要起點。1776年亞當・斯密出版《國富論》，通常被視為現代經濟學建立的重要里程碑。

1. 代表人物

人物代表著作主要貢獻
亞當・斯密《國富論》1776分工、市場、自利與經濟成長
大衛・李嘉圖《政治經濟學及賦稅原理》1817比較利益、地租、分配
湯瑪斯・馬爾薩斯《人口論》1798人口與糧食生產關係
尚巴蒂斯特・賽伊《政治經濟學概論》1803賽伊定律
約翰・斯圖亞特・彌爾《政治經濟學原理》1848生產與分配、自由主義
約翰・雷《資本的社會經濟理論》1834資本形成與經濟發展

2. 核心理論

（1）自由市場理論

市場價格透過供給與需求調整，協調不同經濟主體的決策。

（2）看不見的手

斯密認為，個人追求自身利益，在適當制度與競爭條件下，可以促進社會整體利益。

（3）勞動分工理論

分工能提高勞動生產力，主要來源包括：

  • 熟練程度提高。
  • 減少工作轉換時間。
  • 促進機械與生產技術發明。

（4）勞動價值論

古典經濟學部分代表人物以勞動投入及生產成本解釋商品價值。斯密、李嘉圖與馬克思對此有不同論述。

（5）比較利益理論

李嘉圖指出，即使一個國家在所有產品的絕對生產效率都較低，只要各國專業生產機會成本較低的商品，仍可能透過貿易獲益。

（6）人口理論

馬爾薩斯認為人口具有快速增加的傾向，而糧食供給的增加受到土地及生產條件限制，因此可能產生人口與資源的衝突。

（7）地租理論

李嘉圖以土地肥沃程度與土地稀缺性解釋差額地租。

（8）賽伊定律

賽伊定律的經典表述是供給會創造相應的需求。這不表示任何商品都不可能滯銷，而是強調生產活動本身創造收入與購買力。

3. 政策主張

  • 保障私有財產。
  • 鼓勵自由競爭。
  • 促進國際自由貿易。
  • 降低不必要的市場管制。
  • 建立穩定的法律與市場制度。
  • 政府負責國防、司法及部分公共建設。

4. 歷史貢獻

古典經濟學建立了現代經濟學的基本架構，包括：

  • 生產與分工。
  • 資本累積。
  • 工資與利潤。
  • 地租與所得分配。
  • 國際貿易。
  • 經濟成長。

六、空想社會主義（Utopian Socialism）

1. 歷史背景

工業革命使工廠制度迅速擴張，但同時出現：

  • 工人低工資。
  • 勞動時間過長。
  • 童工問題。
  • 貧富差距。
  • 城市貧民窟。
  • 勞動條件惡化。

部分思想家開始批判早期資本主義，並提出更公平的社會制度。

2. 代表人物

（1）羅伯特・歐文

  • 改善工廠勞動條件。
  • 重視工人教育。
  • 推動合作社。
  • 嘗試建立合作社社區。

（2）聖西門

  • 主張社會應由生產者與專業人才有效組織。
  • 重視工業、科學與技術。
  • 強調生產活動對社會進步的重要性。

（3）傅立葉

  • 提出法郎吉（Phalanstère）共同生活社區。
  • 主張透過合作改善社會關係。
  • 批判資本主義競爭造成的社會弊端。

3. 核心思想

  • 追求社會公平。
  • 重視合作而非單純競爭。
  • 改善工人生活。
  • 強調教育及社會改革。
  • 探索共同生產與共同生活制度。

4. 歷史意義

空想社會主義雖然缺乏完整的經濟轉型理論，但對合作社運動、工人運動及後來的社會主義思想產生重要影響。

七、馬克思主義經濟學派（Marxian Economics）

1. 代表人物

  • 卡爾・馬克思
  • 弗里德里希・恩格斯
  • 羅莎・盧森堡
  • 魯道夫・希法亭
  • 列寧

2. 重要著作

年代著作
1848《共產黨宣言》
1859《政治經濟學批判》
1867《資本論》第一卷
1885《資本論》第二卷
1894《資本論》第三卷

第二、三卷由恩格斯根據馬克思遺稿整理出版。

3. 核心理論

（1）歷史唯物主義

社會發展與物質生產方式、經濟結構及生產關係密切相關。

（2）生產力與生產關係

  • 生產力：勞動者、工具、技術及生產能力。
  • 生產關係：生產過程中的所有權、控制權及分配關係。

當生產關係阻礙生產力發展時，可能引發社會制度變革。

（3）勞動價值論

馬克思以社會必要勞動時間解釋商品價值。

（4）剩餘價值理論

勞動者創造的價值超過其勞動力價值，兩者差額構成剩餘價值的重要來源。

（5）資本積累理論

資本家將部分剩餘價值轉化為新的資本，擴大生產規模。

（6）資本集中與集中化

競爭、規模經濟及資本累積可能導致企業擴張與資本集中。

（7）經濟危機理論

馬克思分析資本主義可能出現：

  • 生產過剩。
  • 資本過度累積。
  • 利潤率下降趨勢。
  • 有效需求與生產能力失衡。
  • 經濟週期性波動。

4. 政策與制度主張

不同馬克思主義傳統有不同主張，但主要包括：

  • 批判資本主義生產關係。
  • 強調生產資料所有權。
  • 重視勞動者的經濟地位。
  • 追求減少階級剝削。
  • 探索社會化生產與社會主義制度。

5. 主要分支

  1. 正統馬克思主義。
  2. 列寧主義。
  3. 西方馬克思主義。
  4. 新馬克思主義。
  5. 分析馬克思主義。
  6. 結構馬克思主義。
  7. 依附理論。
  8. 世界體系理論。
  9. 馬克思主義政治經濟學。
  10. 生態馬克思主義。

八、社會主義經濟學派（Socialist Economics）

社會主義經濟學是一個範圍很廣的思想傳統，與馬克思主義有重要交集，但並非所有社會主義思想都以馬克思主義為基礎。

1. 核心主張

  • 生產資料的社會所有或公共所有。
  • 降低所得及財富不平等。
  • 透過制度保障基本生活。
  • 強調經濟活動的社會責任。
  • 限制私人資本對重要資源的控制。

2. 主要分支

3. 社會主義與共產主義的區別

社會主義是涵蓋多種制度與思想的廣泛概念；共產主義在馬克思主義理論中通常指向階級消失、國家消亡及生產資料共同占有的高階段社會理想。兩者不宜簡單視為完全相同。

第四篇：19世紀末的經濟學革命

九、邊際主義學派（Marginalism）

1. 歷史背景

古典經濟學主要以生產成本、勞動及分配解釋價值，但難以充分解釋商品價格為何會隨消費者偏好與稀缺程度改變。

1870年代，三位經濟學家幾乎同時發展出邊際效用分析，形成邊際革命。

2. 三位代表人物

  • 威廉・史丹利・傑文斯
  • 卡爾・門格爾
  • 里昂・瓦爾拉斯

3. 核心理論

（1）邊際效用

消費者從額外一單位商品獲得的效用。

（2）邊際效用遞減

在其他條件不變下，隨著消費數量增加，額外一單位商品帶來的效用通常下降。

（3）主觀價值論

商品價值不只是由生產成本決定，也受到消費者主觀評價與稀缺性影響。

（4）邊際分析

以額外增加一單位的成本與收益來判斷經濟決策。

4. 歷史貢獻

邊際主義改變了經濟學的價值分析基礎，成為新古典經濟學的重要理論來源。

十、新古典經濟學派（Neoclassical Economics）

1. 代表人物

  • 阿爾弗雷德・馬歇爾
  • 維爾弗雷多・帕雷托
  • 亞瑟・庇古
  • 歐文・費雪
  • 約翰・貝茲・克拉克

2. 核心理論

（1）供給與需求決定價格

市場價格由供給與需求共同決定。

（2）邊際效用與邊際成本

消費者依據邊際效用選擇消費，企業依據邊際成本決定產量。

（3）消費者均衡

消費者在預算限制下選擇效用最大的商品組合。

（4）廠商理論

企業追求利潤最大化，在一定市場條件下選擇最適產量。

（5）一般均衡理論

瓦爾拉斯的理論分析不同商品市場如何透過價格體系同時達成均衡。

（6）福利經濟學

研究資源配置與社會福利之間的關係。

3. 重要分支

  • 消費者理論。
  • 生產者理論。
  • 一般均衡理論。
  • 市場均衡理論。
  • 福利經濟學。
  • 資訊經濟學。
  • 不完全競爭理論。

4. 新古典經濟學的基本假設

  • 個人具有一定程度的理性。
  • 消費者追求效用最大化。
  • 企業追求利潤最大化。
  • 資源具有稀缺性。
  • 價格具有市場協調功能。
  • 經濟主體在限制條件下進行最適化選擇。

十一、奧地利學派（Austrian School）

1. 代表人物

  • 卡爾・門格爾
  • 歐根・馮・龐巴維克
  • 路德維希・馮・米塞斯
  • 弗里德里希・海耶克
  • 莫瑞・羅斯巴德

2. 核心理論

（1）主觀價值論

商品價值取決於個人的需求、偏好與判斷。

（2）邊際效用理論

商品的價值與額外一單位商品所帶來的效用有關。

（3）企業家理論

企業家透過發現市場機會、承擔不確定性及創新活動推動經濟發展。

（4）市場價格機制

價格傳遞分散的資訊，使不同經濟主體能夠協調決策。

（5）知識分散理論

海耶克認為，經濟資訊分散在無數個人手中，中央計畫者很難完整掌握所有資訊。

（6）商業週期理論

奧地利學派的部分代表人物認為，過度的信用擴張與人為壓低利率可能造成錯誤投資及經濟繁榮、衰退。

3. 政策主張

  • 重視自由市場。
  • 反對過度貨幣與信用擴張。
  • 強調私有財產。
  • 重視企業家自由。
  • 警惕中央經濟計畫的資訊問題。

4. 歷史貢獻

奧地利學派對自由市場、企業家精神、知識分散、資本結構及貨幣制度的研究具有重要影響。

十二、洛桑學派（Lausanne School）

代表人物：

  • 里昂・瓦爾拉斯
  • 維爾弗雷多・帕雷托

核心思想：

  1. 一般均衡理論。
  2. 市場之間的相互依存。
  3. 價格體系的協調作用。
  4. 數學方法應用於經濟分析。
  5. 帕雷托最適與經濟福利分析。

重要貢獻：

洛桑學派使經濟學逐漸從文字論述轉向數學化、系統化分析，對現代微觀經濟學影響深遠。

十三、劍橋學派（Cambridge School）

主要代表人物：

  • 阿爾弗雷德・馬歇爾
  • 亞瑟・庇古
  • 約翰・梅納德・凱因斯

主要研究：

  • 價格理論。
  • 供給與需求。
  • 消費者剩餘。
  • 生產成本。
  • 福利經濟學。
  • 貨幣與總體經濟。

注意：劍橋學派在不同年代有不同內涵，不能把馬歇爾時期的劍橋傳統與後來的後凱因斯學派完全等同。

第五篇：20世紀初的經濟思想發展

十四、德國歷史學派（German Historical School）

代表人物

  • 威廉・羅雪爾
  • 古斯塔夫・施穆勒
  • 布魯諾・希爾德布蘭德
  • 馬克斯・韋伯

歷史貢獻

  • 重視國家制度與社會環境。
  • 影響制度經濟學及發展經濟學。

十五、瑞典學派（Stockholm School）

代表人物

  • 克努特・維克塞爾
  • 古納爾・繆達爾
  • 貝蒂爾・俄林
  • 埃里克・林達爾

核心理論

  • 累積因果關係。
  • 動態經濟分析。
  • 貨幣利率與自然利率。
  • 投資與儲蓄的相互關係。
  • 景氣循環。
  • 國際貿易與要素稟賦。

歷史貢獻

瑞典學派對總體經濟、貨幣理論、社會福利政策及國際貿易理論有重要影響。

十六、制度經濟學派（Institutional Economics）

1. 歷史背景

制度經濟學興起於美國，反對只透過個人理性選擇及市場價格解釋全部經濟現象。

它認為法律、文化、組織、習慣及政治權力都會影響經濟活動。

2. 代表人物

  • 索爾斯坦・凡勃倫
  • 約翰・康芒斯
  • 衛斯理・米契爾
  • 道格拉斯・諾斯
  • 奧利佛・威廉森

3. 核心理論

（1）制度影響經濟行為

制度包含：

  • 法律制度。
  • 財產權制度。
  • 金融制度。
  • 企業制度。
  • 政治制度。
  • 社會規範。

（2）凡勃倫的炫耀性消費

人們消費商品不只是為了滿足實際需求，也可能為了展示財富、地位及社會身分。

（3）交易成本理論

威廉森等人研究交易成本如何影響企業組織、契約安排及市場交易。

（4）產權理論

諾斯等人研究產權制度如何影響投資、經濟成長與長期發展。

（5）制度變遷理論

制度會隨著政治、技術、經濟及社會環境變化而改變。

4. 兩大分支

  • 舊制度經濟學：重視習慣、權力、社會演化與制度。
  • 新制度經濟學：運用經濟分析研究產權、交易成本、契約及組織。

5. 歷史貢獻

制度經濟學使經濟學不再只關注市場價格，而是進一步研究市場如何形成、制度如何運作，以及制度為何造成不同國家的發展差異。

十七、福利經濟學派（Welfare Economics）

代表人物

  • 亞瑟・庇古
  • 維爾弗雷多・帕雷托
  • 尼古拉斯・卡爾多
  • 約翰・希克斯

核心理論

  1. 經濟效率。
  2. 帕雷托最適。
  3. 社會福利函數。
  4. 外部性。
  5. 公共財。
  6. 所得分配。
  7. 成本效益分析。

重要理論

庇古稅（Pigouvian Tax）

對造成負外部性的活動課稅，使私人決策者承擔部分社會成本。

例如：

  • 污染排放稅。
  • 碳稅。
  • 塞車費。

帕雷托最適

如果無法在不使任何人變差的情況下改善至少一個人的處境，就達到帕雷托最適。

注意：帕雷托最適不代表所得分配公平。

第六篇：凱因斯革命與現代總體經濟學

十八、凱因斯學派（Keynesian Economics）

1. 歷史背景

1929年美國華爾街股市崩盤，隨後爆發大蕭條。

當時許多國家出現：

  • 大規模失業。
  • 企業倒閉。
  • 投資急劇下降。
  • 消費需求萎縮。
  • 銀行危機。
  • 經濟長期衰退。

傳統古典經濟學無法充分解釋為什麼市場無法迅速恢復充分就業。

1936年，凱因斯出版《就業、利息與貨幣的一般理論》，開啟總體經濟學的重要革命。

2. 代表人物

  • 約翰・梅納德・凱因斯
  • 約翰・希克斯
  • 阿爾文・漢森
  • 保羅・薩繆爾森
  • 詹姆斯・托賓

3. 核心理論

（1）有效需求理論

總體經濟的產出與就業，受到有效需求的影響。

總需求包括：

AD=C+I+G+(X-M)

其中：

  • C：消費。
  • I：投資。
  • G：政府支出。
  • X：出口。
  • M：進口。

（2）消費函數

凱因斯認為消費與可支配所得密切相關。

簡化表示：

C=a+bY_d

其中：

  • a：自主消費。
  • b：邊際消費傾向。
  • Y_d：可支配所得。

（3）乘數效果

政府增加支出可能透過所得與消費的連鎖反應，使國民所得增加超過最初支出。

簡化模型下：

k=1/(1-MPC)

其中 MPC 是邊際消費傾向。

（4）流動性偏好理論

人們持有貨幣的動機包括：

  • 交易動機。
  • 預防動機。
  • 投機動機。

（5）流動性陷阱

當利率非常低時，民眾可能偏好持有貨幣，使傳統貨幣政策刺激投資的效果減弱。

（6）非充分就業均衡

經濟可能在低於充分就業的產出水準達成均衡，並不一定能自動恢復充分就業。

4. 政策主張

  • 景氣衰退時增加政府支出。
  • 適度採取財政赤字。
  • 降低利率以刺激投資。
  • 透過公共建設創造就業。
  • 以逆景氣循環政策穩定經濟。

5. 歷史影響

凱因斯學派對第二次世界大戰後的政府財政政策、總體經濟管理及社會福利國家形成具有深遠影響。

十九、新古典綜合學派（Neoclassical Synthesis）

代表人物

  • 保羅・薩繆爾森
  • 約翰・希克斯
  • 佛朗哥・莫迪利安尼
  • 詹姆斯・托賓

核心理論

新古典綜合學派嘗試結合：

  • 新古典微觀經濟學。
  • 凱因斯總體經濟學。

主要觀點：

  1. 長期市場價格具有調整能力。
  2. 短期工資與價格可能具有僵固性。
  3. 短期總需求不足可能造成失業。
  4. 財政與貨幣政策可以穩定經濟。
  5. 長期經濟成長仍取決於資本、勞動與技術進步。

重要工具：IS-LM模型

由希克斯提出早期版本，用來分析商品市場與貨幣市場的均衡。

  • IS曲線：商品市場均衡。
  • LM曲線：貨幣市場均衡。

它成為戰後總體經濟學教學及政策分析的重要工具。

二十、貨幣學派（Monetarism）

1. 歷史背景

1970年代世界出現停滯性通貨膨脹，即高通貨膨脹與高失業率同時發生。

傳統凱因斯模型難以完整解釋這種現象，因此貨幣學派受到重視。

2. 代表人物

  • 米爾頓・傅利曼
  • 安娜・施瓦茨
  • 卡爾・布朗納
  • 艾倫・梅爾澤

3. 核心理論

（1）貨幣數量理論

MV=PY

其中：

  • M：貨幣供給量。
  • V：貨幣流通速度。
  • P：物價水準。
  • Y：實質產出。

（2）通貨膨脹與貨幣供給

傅利曼提出著名觀點：

通貨膨脹在重要意義上是一種貨幣現象。

但實際通膨也會受到供給衝擊、預期及制度等因素影響。

（3）自然失業率

經濟存在與結構、摩擦及制度因素有關的自然失業率。

（4）預期適應理論

人們會根據過去的通膨經驗調整對未來物價的預期。

（5）貨幣政策的時間落差

貨幣政策的影響存在時間落差，過度頻繁地進行政策微調可能造成不穩定。

4. 政策主張

  • 維持貨幣穩定。
  • 避免貨幣供給劇烈波動。
  • 控制通貨膨脹。
  • 減少政策的不確定性。
  • 重視中央銀行的貨幣政策紀律。

二十一、芝加哥學派（Chicago School）

芝加哥學派是一個具有多種研究傳統的經濟學思想群體，並非只有貨幣學派。

1. 代表人物

  • 弗蘭克・奈特
  • 米爾頓・傅利曼
  • 喬治・史蒂格勒
  • 蓋瑞・貝克
  • 羅伯特・盧卡斯
  • 尤金・法馬
  • 理查・波斯納

2. 核心理論

（1）自由市場機制

強調價格機制與市場競爭在資源配置上的重要性。

（2）理性選擇

分析個人如何在限制條件下追求自身利益。

（3）貨幣穩定

研究貨幣供給與通貨膨脹之間的關係。

（4）人力資本理論

教育、訓練與技能可以視為人力資本投資。

（5）理性預期與經濟政策

研究政策如何影響市場參與者的預期及行為。

（6）有效市場假說

金融市場價格會反映不同程度的可取得資訊。

（7）法律經濟學

以經濟學分析法律制度、犯罪、契約及財產權。

3. 政策傾向

  • 重視市場競爭。
  • 反對不必要的政府管制。
  • 強調貨幣穩定。
  • 重視私有財產及契約自由。
  • 倡議以市場機制處理部分公共問題。

二十二、供給面經濟學派（Supply-Side Economics）

1. 歷史背景

1970年代，許多西方國家面臨：

  • 高通貨膨脹。
  • 經濟成長停滯。
  • 高失業率。
  • 高稅負爭論。
  • 生產力成長放緩。

供給面經濟學主張，經濟政策不應只刺激需求，更要改善生產能力與投資誘因。

2. 代表人物

  • 亞瑟・拉弗
  • 羅伯特・蒙代爾
  • 馬丁・費爾德斯坦
  • 裘德・萬尼斯基

3. 核心理論

（1）減稅刺激生產

降低邊際稅率可能提高：

  • 工作意願。
  • 投資意願。
  • 儲蓄誘因。
  • 企業擴張意願。

（2）拉弗曲線

稅率與稅收收入之間可能不是單純線性關係。

在極高稅率下，進一步提高稅率可能降低經濟活動及稅基。

（3）投資與資本形成

降低投資成本，可能促進資本累積及生產力。

（4）放寬管制

減少妨礙生產、投資與競爭的不必要規範。

4. 政策主張

  • 降低所得稅。
  • 降低企業稅。
  • 鼓勵私人投資。
  • 改善企業經營環境。
  • 放寬部分產業管制。
  • 促進長期供給能力。

5. 歷史影響

供給面經濟學深刻影響1980年代美國雷根政府及英國柴契爾政府的部分經濟政策。

但減稅是否能增加政府稅收，取決於原有稅率、經濟行為反應及其他財政條件，不能一概而論。

二十三、新古典總體經濟學派（New Classical Macroeconomics）

1. 代表人物

  • 羅伯特・盧卡斯
  • 湯瑪斯・薩金特
  • 尼爾・華萊士
  • 愛德華・普雷斯科特

2. 核心理論

（1）理性預期理論

經濟主體會運用可取得的資訊與經濟理論形成預期，而非只依賴過去經驗。

（2）市場出清

部分新古典模型假設價格可以迅速調整，使市場達成均衡。

（3）政策無效命題

在特定模型假設下，預期到的貨幣政策可能無法持續改變實質產出與就業。

（4）代表性個體模型

以個體或家庭的最適化決策建立總體經濟模型。

（5）跨期最適化

分析家庭與企業如何在現在及未來之間配置消費、投資與資源。

3. 歷史貢獻

  • 將理性預期引入總體經濟學。
  • 改變傳統政策評估方法。
  • 推動動態隨機一般均衡模型的發展。

二十四、新凱因斯學派（New Keynesian Economics）

1. 歷史背景

新古典總體經濟學強調理性預期與市場均衡，但現實經濟中經常存在價格僵固、工資僵固及市場不完全競爭。

新凱因斯學派試圖以微觀經濟基礎解釋凱因斯式的短期總體經濟現象。

2. 代表人物

  • 葛瑞格里・曼昆
  • 約瑟夫・史迪格里茲
  • 史丹利・費雪
  • 麥可・伍德福
  • 珍妮特・葉倫

3. 核心理論

（1）價格僵固性

企業不會隨時調整價格，可能因為重新訂價有成本。

（2）工資僵固性

工資不一定會立即隨市場需求變動。

（3）不完全競爭

許多企業具有一定程度的定價能力。

（4）資訊不對稱

市場參與者掌握的資訊不同，可能造成市場失靈。

（5）新凱因斯菲利浦曲線

通膨與經濟閒置程度之間存在動態關係，且受到通膨預期影響。

4. 政策主張

  • 穩定通貨膨脹。
  • 穩定經濟產出。
  • 適當使用利率政策。
  • 在嚴重衰退時運用財政政策。
  • 透過政策預期管理降低經濟波動。

5. 與傳統凱因斯學派的差異

比較傳統凱因斯學派新凱因斯學派
主要方法總體經濟分析微觀基礎總體模型
價格短期僵固僵固性有微觀解釋
預期早期模型較簡化重視理性預期
政策財政與貨幣政策規則、預期管理與穩定政策
模型IS-LM等新凱因斯動態模型

二十五、後凱因斯學派（Post-Keynesian Economics）

代表人物

  • 瓊・羅賓遜
  • 尼古拉斯・卡爾多
  • 保羅・戴維森
  • 海曼・明斯基
  • 米哈爾・卡萊茨基

核心理論

  1. 經濟具有根本不確定性。
  2. 貨幣不是中性的。
  3. 投資具有自主性與波動性。
  4. 有效需求決定經濟產出。
  5. 所得分配影響消費與投資。
  6. 金融體系可能內生產生不穩定性。

明斯基金融不穩定假說

明斯基認為，長期經濟繁榮可能使金融機構與投資人逐漸承擔更多風險。

他區分三種融資型態：

  • 對沖融資：現金流足以支付利息與本金。
  • 投機融資：現金流足以支付利息，但需要再融資償還本金。
  • 龐氏融資：現金流甚至不足以支付利息，必須依賴新融資或資產價格上漲。

這種融資結構可能使金融體系在繁榮期累積脆弱性。

第七篇：市場制度、政策與經濟治理思想

二十六、公共選擇學派（Public Choice Theory）

1. 代表人物

  • 詹姆斯・布坎南
  • 戈登・塔洛克
  • 鄧肯・布萊克
  • 曼瑟・奧爾森

2. 核心理論

公共選擇學派將經濟學的理性選擇方法運用於政治領域。

主要觀點：

  • 政治人物也有自身利益。
  • 官僚組織也可能追求預算與權力擴張。
  • 選民可能受到資訊不足影響。
  • 利益團體可能透過政治活動爭取特定利益。
  • 政府政策不一定自動代表公共利益。

3. 重要理論

尋租理論（Rent-seeking）

個人或企業可能透過政治活動爭取特許、補貼、保護或壟斷利益，而不是透過生產創造新價值。

憲政經濟學

研究如何透過憲法、法律及制度限制政府權力，建立長期穩定的政策規則。

4. 歷史貢獻

公共選擇學派把政府本身也納入經濟分析，對政府失靈、管制政策、民主制度及財政制度研究具有重要影響。

二十七、賽局理論學派（Game Theory）

1. 代表人物

  • 約翰・馮紐曼
  • 奧斯卡・摩根斯坦
  • 約翰・納許
  • 萊因哈德・澤爾騰
  • 約翰・哈薩尼

2. 核心理論

賽局理論研究多個參與者在相互依賴的情況下如何作出決策。

3. 重要概念

（1）納許均衡

當其他參與者策略固定時，任何一方都沒有誘因單方面改變自己的策略。

（2）囚徒困境

個人理性選擇可能造成集體不理想的結果。

（3）零和賽局

一方所得等於另一方所失。

（4）非零和賽局

參與者可能透過合作共同創造利益。

（5）重複賽局

同一參與者反覆互動，可能促成合作。

（6）不完全資訊賽局

參與者不一定了解其他人的成本、偏好或類型。

4. 應用領域

  • 寡占市場。
  • 國際貿易談判。
  • 價格競爭。
  • 拍賣制度。
  • 企業策略。
  • 政治經濟。
  • 國際關係。
  • 金融市場。

賽局理論是一套跨領域分析工具，不能簡單視為某一種完整經濟政策立場。

二十八、資訊經濟學派（Information Economics）

代表人物

  • 喬治・阿克洛夫
  • 麥可・史賓賽
  • 約瑟夫・史迪格里茲

核心理論

（1）資訊不對稱

交易雙方掌握的資訊不一致。

（2）逆向選擇

在交易發生之前，資訊不對稱可能使低品質商品或高風險參與者更容易進入市場。

（3）道德風險

交易或契約成立之後，因為監督困難或風險分擔方式不同，可能產生不適當行為。

（4）訊號理論

資訊較充分的一方，可以透過教育、認證或其他可觀察行為傳遞品質訊號。

（5）篩選理論

資訊較不足的一方，可以設計契約或制度，辨別不同類型的參與者。

歷史貢獻

資訊經濟學改變了傳統市場完全資訊的簡化假設，對保險、銀行、勞動市場、公司治理及金融監管產生重大影響。

二十九、行為經濟學派（Behavioral Economics）

1. 代表人物

  • 丹尼爾・康納曼
  • 阿莫斯・特沃斯基
  • 理查・塞勒
  • 丹・艾瑞利

2. 歷史背景

傳統經濟學常假設人類具有理性、穩定的偏好，並能有效處理資訊。

行為經濟學結合心理學，研究人類實際決策為何經常偏離傳統理性模型的預測。

3. 核心理論

（1）有限理性

人類的資訊處理能力、時間及認知資源有限。

（2）展望理論（Prospect Theory）

康納曼與特沃斯基指出，人們對收益與損失的評價並不對稱。

主要特徵：

  • 損失厭惡。
  • 參考點依賴。
  • 機率加權。
  • 對收益與損失具有不同的風險態度。

（3）心理帳戶

人們可能將金錢分別放入不同的心理帳戶，導致消費與投資決策不一致。

（4）現狀偏誤

人們傾向維持現有選擇，而不願意改變。

（5）過度自信

人們可能高估自己的判斷能力。

（6）錨定效應

決策可能受到最初接觸的數字或資訊影響。

4. 助推理論（Nudge Theory）

塞勒與桑斯坦提出助推概念，透過調整選擇環境，引導人們作出較有利的決策，同時保留選擇自由。

例如：

  • 預設加入退休金制度。
  • 改善健康食品陳列。
  • 使用節能提醒。
  • 簡化公共服務申請流程。

5. 歷史貢獻

行為經濟學使現代經濟學更重視真實人類心理、認知偏誤及決策環境。

三十、實驗經濟學派（Experimental Economics）

代表人物

  • 弗農・史密斯
  • 查爾斯・普洛特
  • 阿爾文・羅斯

核心理論與方法

透過設計實驗，觀察人們在不同市場條件下的真實行為。

研究內容：

  • 市場價格形成。
  • 拍賣制度。
  • 合作與競爭。
  • 信任與互惠。
  • 公平偏好。
  • 市場設計。
  • 社會規範。

歷史貢獻

使經濟學能夠透過實驗資料檢驗理論，而不只是依靠數學模型與歷史資料。

三十一、演化經濟學派（Evolutionary Economics）

代表人物

  • 約瑟夫・熊彼得
  • 理查・納爾森
  • 西德尼・溫特
  • 喬瓦尼・多西

核心理論

經濟體系不是靜態均衡，而是一個不斷變化、適應與演化的系統。

主要內容：

  1. 技術創新。
  2. 企業能力。
  3. 組織學習。
  4. 路徑依賴。
  5. 市場選擇。
  6. 產業演化。
  7. 制度變遷。

熊彼得的創造性破壞

熊彼得認為，創新會創造新產業、新產品及新商業模式，同時淘汰部分舊企業與舊技術。

例如：

  • 汽車取代部分馬車產業。
  • 數位攝影改變底片產業。
  • 網路平台改變傳統零售模式。
  • 人工智慧改變部分知識工作。

比較舊制度經濟學新制度經濟學

  • 排放交易制度。
  • 永續發展。
  • 世代間公平。

主要政策工具

  1. 碳稅。
  2. 碳排放交易。
  3. 污染者付費原則。
  4. 環境補貼。
  5. 自然資源使用費。
  6. 環境影響評估。

四十一、生態經濟學派（Ecological Economics）

代表人物

  • 赫爾曼・戴利
  • 羅伯特・科斯坦扎
  • 瓊・馬丁內斯－阿利爾

核心理論

生態經濟學認為，經濟活動是自然生態系統的一部分，不能脫離能源、物質及環境承載能力。

主要研究：

  • 經濟成長與生態限制。
  • 自然資本。
  • 能源與物質流。
  • 生態系統服務。
  • 循環經濟。
  • 永續發展。
  • 經濟規模與資源限制。

與環境經濟學的差異

環境經濟學通常運用市場失靈及外部性工具處理環境問題；生態經濟學則更強調經濟活動必須受到生態系統承載能力的限制。

四十二、女性主義經濟學派（Feminist Economics）

代表人物

  • 瑪麗蓮・沃林
  • 南西・福布雷
  • 黛安・埃爾森
  • 朱莉・尼爾森

核心理論

傳統經濟學往往較重視市場交易，而女性主義經濟學將家庭照顧、無酬勞動及性別分工納入分析。

研究主題：

  1. 性別薪資差距。
  2. 家庭內部資源分配。
  3. 無酬照顧勞動。
  4. 勞動市場歧視。
  5. 福利制度。
  6. 經濟權力關係。
  7. 家庭與社會再生產。

歷史貢獻

擴大了經濟學對勞動、家庭、生產與社會福利的研究範圍。

四十三、複雜性經濟學（Complexity Economics）

代表人物

  • 布萊恩・亞瑟
  • 肯尼斯・阿羅
  • 保羅・克魯曼
  • 艾瑞克・拜恩豪克

核心理論

傳統經濟模型常以均衡作為重要分析起點，複雜性經濟學則強調經濟體系可能具有：

  • 非線性。
  • 自我組織。
  • 湧現現象。
  • 路徑依賴。
  • 網絡效應。
  • 適應性。
  • 非均衡動態。

研究應用

  • 金融市場崩盤。
  • 產業網絡。
  • 經濟危機。
  • 技術創新。
  • 全球供應鏈。
  • 系統性風險。
  • 人工智慧與經濟預測。

四十四、現代貨幣理論（Modern Monetary Theory，MMT）

代表人物

  • 華倫・莫斯勒
  • 蘭德爾・雷
  • 史蒂芬妮・凱爾頓
  • 比爾・米契爾

核心理論

MMT主要研究具有貨幣主權、發行本國非可兌換貨幣及採浮動匯率的政府，其財政與貨幣制度的運作方式。

主要觀點：

  1. 貨幣發行國政府與一般家庭的財務限制不同。
  2. 政府支出不宜單純以家庭收支邏輯理解。
  3. 稅收具有調節總需求及貨幣制度等功能。
  4. 政府支出的主要限制之一是通貨膨脹及實質資源。
  5. 就業保障可以作為穩定經濟的政策工具。

政策主張

  • 以財政政策促進充分就業。
  • 透過稅收管理總需求。
  • 重視實質資源限制。
  • 探討政府就業保障計畫。

重要爭論

MMT對財政空間、通膨控制、利率政策及貨幣主權的解釋，與主流總體經濟學存在重要分歧。

四十五、後成長經濟學與去成長經濟學（Post-growth / Degrowth）

代表人物

  • 蒂姆・傑克森
  • 傑森・希克爾
  • 塞爾日・拉圖什

核心理論

傳統經濟政策經常以GDP持續成長作為重要目標，而後成長及去成長思想則質疑：

經濟規模不斷擴大，是否必然代表人民生活品質、社會公平及環境永續同步改善？

主要研究：

  • GDP與生活品質的差異。
  • 資源使用與經濟成長。
  • 環境承載能力。
  • 社會公平。
  • 永續消費。
  • 生產與消費模式轉型。

最後的總結：

世界經濟思想史最重要的特色，就是不同學派對同一個問題提出不同答案。

  • 古典經濟學重視市場調整。

  • 貨幣學派重視貨幣穩定。
  • 奧地利學派關注信用擴張與錯誤投資。
  • 馬克思主義分析資本累積與生產關係。
