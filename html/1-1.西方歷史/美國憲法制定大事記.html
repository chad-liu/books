美國憲法制定大事記（1776－1791）

THE MAKING OF THE UNITED STATES CONSTITUTION

美國憲法的制定，是近代世界政治制度發展史上的重大事件。1787年，美國各州代表在費城召開制憲會議，制定一部全新的聯邦憲法，建立以人民主權、聯邦主義、三權分立、權力制衡及憲法至上為核心的政治制度。

這部憲法於1787年9月17日完成簽署，1788年達到生效所需的批准州數，1789年正式開始運作，1791年再透過《權利法案》確立人民基本權利。

美國憲法制定的歷史過程，可以分成六個階段：

  1. 英國殖民統治與北美自治制度的形成。
  2. 美國獨立與《獨立宣言》的發表。
  3. 《邦聯條例》的制定及制度危機。
  4. 費城制憲會議與憲法起草。
  5. 各州批准憲法與聯邦政府成立。
  6. 《權利法案》通過與美國憲政制度確立。

一、英國殖民統治與北美自治制度的形成（1607－1775）

美國憲法並非突然產生，而是建立在英國政治傳統、北美殖民地自治經驗及歐洲啟蒙思想之上。

《獨立宣言》的核心思想

《獨立宣言》主要由湯瑪斯・傑佛遜（Thomas Jefferson）起草，其核心思想包括：

  1. 人人生而平等。
  2. 人民享有不可剝奪的基本權利。
  3. 生命、自由與追求幸福是基本權利。
  4. 政府的正當權力來自被統治者的同意。
  5. 政府若破壞人民權利，人民有權改變或廢除政府。

《獨立宣言》與美國憲法的差別

三、《邦聯條例》的制定與制度危機（1776－1787）

美國獨立後，十三州面臨一個重要問題：如何在不重新建立英國式中央集權政府的情況下，組成一個可以共同運作的國家？當時各州對中央政府權力非常警惕，因此最初選擇較鬆散的邦聯制度。

3. 邦聯制度的主要危機

1780年代，美國面臨財政困難、州際貿易障礙、外交問題及社會動亂。

年代重要事件歷史意義
1783年紐約邦聯國會遭士兵威脅顯示中央政府缺乏有效保護與維持秩序的能力。
1784年西北領地問題促使國會思考如何有效管理新領土。
1785年土地法令（Land Ordinance）建立西部土地測量與出售制度。
1786年安納波利斯會議討論州際貿易問題，建議召開更大規模的會議。
1786－1787年謝司起義（Shays' Rebellion）馬薩諸塞州農民起義，暴露中央政府維持秩序的能力不足。
1787年西北法令（Northwest Ordinance）建立西北領地治理與未來加入聯邦的制度。

4. 謝司起義：制憲運動的重要催化劑

1786年，馬薩諸塞州農民因債務、稅收及司法執行等問題發動抗議，退伍軍人丹尼爾・謝司（Daniel Shays）成為起義領導者之一。這場起義使美國政治領袖意識到：

  • 邦聯政府無法有效徵稅。
  • 中央政府缺乏足夠軍事力量。
  • 各州政策不一致，容易引發經濟與政治衝突。
  • 國家需要一個更具治理能力的聯邦政府。

因此，改革《邦聯條例》的呼聲逐漸增強，最終促成1787年費城制憲會議。

四、費城制憲會議的召開（1787年5月－6月）

1787年，美國各州代表齊聚賓夕法尼亞州費城，原本的任務是修改《邦聯條例》，但會議最後決定制定一部全新的憲法。這是美國憲政史上最重要的轉折點。

五、兩大制憲方案與大州、小州之爭（1787年5月－7月）

制憲會議中最重要的爭議之一，是新國家的國會應如何分配各州代表權。人口較多的大州，希望依人口比例分配國會席次；人口較少的小州，則希望維持各州平等的政治地位。

1. 維吉尼亞方案（Virginia Plan）

大州方案

1787年5月29日，由維吉尼亞州代表埃德蒙・倫道夫（Edmund Randolph）提出，主要內容由詹姆斯・麥迪遜事先規劃。主要主張：

  1. 建立具有實質權力的全國政府。
  2. 採取立法、行政、司法三權分立。
  3. 建立兩院制國會。
  4. 國會席次依人口或各州貢獻分配。
  5. 建立具有獨立權力的聯邦行政部門。
  6. 建立聯邦司法體系。
  7. 允許聯邦政府對違反聯邦義務的州採取行動。

2. 紐澤西方案（New Jersey Plan）

小州方案

1787年6月15日，由紐澤西州代表威廉・帕特森（William Paterson）提出。主要主張：

  1. 保留邦聯制度的基本架構。
  2. 建立具有較強執行能力的中央政府。
  3. 各州在國會維持平等代表權。
  4. 聯邦政府有權徵稅及管理州際貿易。
  5. 建立聯邦司法制度。

維吉尼亞方案的最大特色是：國會代表權以人口為主要考量，大州因此具有較大優勢。紐澤西方案的最大特色是：各州不論人口多寡，在中央立法機關中都應具有平等地位。

4. 康乃狄克妥協（Connecticut Compromise）：制憲會議重大突破

1787年7月16日，制憲會議通過大妥協方案，主要由羅傑・謝爾曼與奧利弗・埃爾斯沃思（Oliver Ellsworth）等人推動。其主要內容如下：

國會機構代表權分配主要職能
眾議院（House of Representatives）依各州人口比例分配席次反映人民的人口代表權
參議院（Senate）每州兩席保障各州平等代表權

這項妥協成功調和大州與小州的利益衝突，也奠定了美國國會至今仍採行的兩院制。

5. 三分之五妥協（Three-Fifths Compromise）

1787年7月，制憲代表針對奴隸人口如何計算國會代表權及直接稅問題進行協商。主要內容：

  • 自由人口全數計入。
  • 其他人口，包括當時被奴役的人口，按五分之三比例計入。
  • 這項計算影響南方蓄奴州在眾議院的代表席次及聯邦直接稅分配。
歷史爭議這項妥協在歷史上具有重大爭議，因為被奴役者既沒有公民自由，也沒有投票權，卻被納入南方州政治代表權的計算。它反映了美國建國初期民主理念與奴隸制度之間的深刻矛盾。

6. 其他重要妥協

妥協內容主要規定歷史意義
奴隸貿易妥協國會在1808年前不得禁止各州輸入奴隸延後處理奴隸貿易問題。
逃奴條款規定逃往其他州的奴隸不得僅因逃離原州而免於原州法律下的勞役義務強化蓄奴州利益。
州際商業條款聯邦國會取得管理州際及對外貿易的權力避免各州各自制定貿易政策。

六、美國憲法草案的完成與簽署（1787年7月－9月）

大州與小州的主要爭議解決後，制憲會議開始整理憲法條文，並針對總統、國會、法院及各州權力進行細節協商。

9月15日制憲會議完成主要表決多數代表接受最終憲法方案。
9月17日美國憲法正式簽署39位代表簽署憲法，制憲會議結束。

2. 1787年9月17日：美國憲法簽署

1787年9月17日，代表們在費城獨立廳簽署憲法。當天有39位代表簽署文件。並非所有參與制憲會議的人都支持最終版本，也有部分代表拒絕簽署或提前離開。

富蘭克林在簽署前，曾表達對這份憲法雖然仍有疑慮，但願意接受並支持的態度。

值得注意憲法在1787年9月17日簽署，並不代表當天就正式成為全美有效的最高法律。它還必須經過各州批准程序。

七、聯邦黨與反聯邦黨的憲法辯論（1787－1788）

1787年憲法草案完成後，美國並未立即形成一致意見。各州必須透過特別召集的批准會議，決定是否接受新憲法。當時形成兩大政治陣營：

1. 聯邦黨（Federalists）

代表人物
  • 漢彌爾頓（Alexander Hamilton）
  • 麥迪遜（James Madison）
  • 約翰・傑伊（John Jay）
  • 喬治・華盛頓（George Washington）
主要主張
  1. 美國需要強大的中央政府。
  2. 邦聯制度無法有效處理財政、軍事及外交問題。
  3. 聯邦政府必須具有直接治理人民的權力。
  4. 三權分立及權力制衡可以避免中央政府走向專制。
  5. 應建立統一的國家市場與法律制度。

2. 反聯邦黨（Anti-Federalists）

代表人物
  • 喬治・梅森（George Mason）
  • 埃爾布里奇・格里（Elbridge Gerry）
  • 帕特里克・亨利（Patrick Henry）
  • 理查・亨利・李（Richard Henry Lee）
主要主張
  1. 中央政府權力可能過度集中。
  2. 聯邦政府可能逐漸演變為新的專制政府。
  3. 憲法沒有明確列出人民基本權利。
  4. 州政府的自治權可能受到侵害。
  5. 應加入保障人民自由的《權利法案》。

3. 《聯邦黨人文集》（The Federalist Papers）

4. 反聯邦黨的主要批評與妥協

反聯邦黨最大的疑慮，是憲法沒有明文列出人民的基本權利。因此，在馬薩諸塞州等地的批准辯論中，出現了「先批准憲法，再承諾提出修正案」的妥協方式。

這個政治承諾為1789年麥迪遜提出憲法修正案，以及1791年《權利法案》的通過，奠定了基礎。

八、各州批准美國憲法（1787－1791）

美國憲法第七條規定，必須有九個州的特別批准會議同意，憲法才能在批准州之間生效。這是制憲程序中最關鍵的政治考驗。

2. 最關鍵的三個州

（1）新罕布夏州1788年6月21日
  • 新罕布夏州成為第九個批准憲法的州，達到第七條規定的生效門檻。
  • 這一天通常被視為美國聯邦憲法正式獲得法律效力的重要日期。
（2）維吉尼亞州1788年6月25日
  • 維吉尼亞州是人口及政治影響力極大的州。
  • 其批准使華盛頓、傑佛遜等政治人物所在的州加入新聯邦體制，也大幅提升新憲法的政治正當性。
（3）紐約州1788年7月26日
  • 紐約是重要的商業與金融中心。
  • 其加入使新聯邦政府在政治及經濟上更具穩定性。

3. 為什麼羅德島州最後才批准？

羅德島州長期擔心中央政府權力過大，也對聯邦政府可能徵稅及干預州內事務抱持強烈疑慮。該州甚至曾在1788年3月的公民投票中拒絕憲法。直到1790年5月29日，才以極小的票數差距通過批准。

這也反映出美國建國初期，各州對聯邦主義及州權問題存在相當大的歧見。

4. 佛蒙特州的特殊情況

佛蒙特州當時並非原十三殖民地之一，而是獨立存在的政治共同體。1791年1月10日，佛蒙特州批准美國憲法；同年3月4日正式成為美國第14州。因此，不能將佛蒙特州列為原十三州之一。

十、美國《權利法案》的制定（1789－1791）

1787年憲法完成時，並沒有包含一份完整的人民權利清單。反聯邦黨人認為，如果沒有明文保障人民自由，強大的聯邦政府仍可能侵犯個人權利。因此，麥迪遜在第一屆國會中推動憲法修正案。

1. 《權利法案》的制定過程

日期重要事件歷史意義
1787年9月17日美國憲法簽署原始憲法未包含完整的權利清單。
1788年各州批准會議提出修正建議多個州要求保障人民基本權利。
1789年6月8日麥迪遜向眾議院提出憲法修正案正式推動《權利法案》的制定。
1789年8月24日眾議院通過17條修正案版本開始與參議院協商。
1789年9月25日國會提出12條憲法修正案送交各州批准。
1789年10月2日華盛頓將12條修正案送交各州正式展開批准程序。
1791年12月15日前10條修正案獲批准《權利法案》正式生效。

2. 《權利法案》前十條修正案

修正案主要內容保障目的
第一修正案宗教、言論、出版、集會及請願自由保障政治與思想自由
第二修正案人民持有及攜帶武器的權利保障武器持有權
第三修正案限制和平時期軍隊強迫人民提供住宿保障住宅及私人生活
第四修正案禁止不合理搜索及扣押保障人身及財產安全
第五修正案正當法律程序及禁止強迫自證其罪等保障刑事司法權利
第六修正案迅速、公開及公平審判保障刑事被告權利
第七修正案特定民事案件陪審團審判權保障民事司法程序
第八修正案禁止過度保釋金及殘酷刑罰限制刑罰權力
第九修正案未列舉的權利不代表人民不享有防止權利保障被狹義解釋

3. 12條提案為何最後只剩10條？

1789年國會原本提出12條修正案。其中：

  • 第一條涉及眾議院席次及人口比例計算，沒有獲得足夠州數批准。
  • 第二條涉及國會議員薪酬調整，直到1992年才成為第二十七修正案。
  • 其餘10條在1791年獲得批准，成為今日所稱的《權利法案》。

這是美國憲法史上一個很有趣的現象：一項1789年提出的修正案，竟然經過兩百多年才正式成為憲法的一部分。

十五、總結：美國憲法制定的歷史意義

美國憲法的制定，不只是建立一套政府組織制度，更是人類政治思想從殖民地自治、共和主義，走向現代憲政民主的重要里程碑。其歷史發展可以歸納為：

  1. 1776年解決國家獨立問題，建立人民主權的政治理念。
  2. 1781年透過《邦聯條例》建立第一套全國性政府制度。
  3. 1787年透過費城制憲會議建立新的聯邦憲法。
  4. 1788年經九州批准，使新憲法取得生效條件。
  5. 1789年聯邦政府正式運作，華盛頓就任第一任總統。
  6. 1791年《權利法案》生效，人民基本權利獲得明文保障。
最重要的歷史觀念美國憲法制定的核心，不是單純追求強大的中央政府，而是在政府治理能力與人民自由之間尋找平衡。

它透過聯邦制度解決中央與地方的權力分配問題，透過三權分立防止政府權力集中，再透過《權利法案》保障人民基本自由。

這套制度成為後來法國革命、19世紀拉丁美洲憲政發展，以及世界各國制定現代成文憲法時的重要參考。需要注意，各國憲政發展仍有自身的歷史背景，並非單純複製美國模式。
