東鄉平八郎（とうごう へいはちろう，Tōgō Heihachirō，1848年1月27日－1934年5月30日），日本明治時代至昭和初期著名海軍將領，曾任日本聯合艦隊司令長官，因在1905年日俄戰爭的對馬海峽海戰中擊敗俄羅斯波羅的海艦隊而聞名世界。

他出身於薩摩藩武士家庭，青年時期經歷薩英戰爭與戊辰戰爭，明治維新後赴英國學習海軍技術。返日後加入日本帝國海軍，歷經甲午戰爭與日俄戰爭，逐步成為日本海軍最具代表性的人物之一。

東鄉平八郎的生涯，反映日本從幕末封建藩國海軍，轉型為近代化國家海軍的過程；同時，他也與日本近代對外軍事擴張及帝國主義發展密切相關。

1848年：出生於薩摩藩

  • 1月27日，東鄉平八郎出生於日本薩摩國鹿兒島（今鹿兒島縣鹿兒島市）。
  • 父親東鄉實友是薩摩藩士，家族屬於薩摩藩武士階層。
  • 東鄉家世代服務於島津氏。
  • 當時日本仍處於江戶幕府統治之下，西方列強逐漸要求日本開放港口，幕府體制開始面臨危機。

1853年：美國佩里艦隊來航

  • 美國海軍准將馬修・佩里率領艦隊抵達日本浦賀。
  • 美國要求日本開放港口，促使日本面臨前所未有的外交與軍事壓力。
  • 東鄉當時年僅5歲。
  • 西方軍事力量的出現，成為幕末日本推動軍事改革的重要背景。

1863年：薩英戰爭

  • 薩摩藩與英國因生麥事件及賠償問題發生衝突。
  • 8月，英國艦隊砲擊鹿兒島，史稱薩英戰爭。
  • 年輕的東鄉平八郎參與薩摩藩的海岸防衛及軍事活動。
  • 薩摩藩親身體認到英國海軍的技術優勢。
  • 這次經驗使薩摩藩更加重視西方軍事技術與近代海軍建設。

1866年：加入薩摩藩海軍

  • 東鄉進入薩摩藩海軍服役。
  • 開始接受近代艦船操作、砲術及海軍作戰訓練。
  • 當時薩摩藩積極引進西方船艦與軍事技術，逐漸建立自己的海軍力量。

1868年：戊辰戰爭

  • 1月，戊辰戰爭爆發。
  • 明治新政府與支持幕府的勢力展開戰爭。
  • 東鄉在薩摩藩海軍服役，搭乘春日號等軍艦參與海上作戰。
  • 參與阿波沖海戰等戰事。
  • 戊辰戰爭最終以幕府勢力失敗、明治新政府建立而告終。

1869年：箱館戰爭結束

  • 明治政府軍持續攻打北海道箱館的舊幕府軍。
  • 東鄉參與新政府方面的海軍行動。
  • 6月，舊幕府軍投降，戊辰戰爭正式結束。
  • 日本新政府開始推動中央集權與軍事制度現代化。

二、赴英留學與近代海軍教育（1871－1878）

1871年：奉派赴英國留學

  • 明治政府為建立近代化海軍，選派年輕海軍軍官及學生赴歐洲學習。
  • 東鄉平八郎被派往英國，學習海軍技術、航海、數學及相關軍事知識。
  • 他在英國接受訓練，主要搭乘英國海軍訓練船伍斯特號（HMS Worcester）。
  • 英國當時是世界海軍強國，其海軍制度與技術對日本海軍現代化具有深遠影響。

1872－1874年：接受英國海軍訓練

  • 在英國接受海軍專業訓練。
  • 學習航海、海軍砲術、數學、機械製圖及海軍相關知識。
  • 透過英國海軍訓練制度，了解近代海軍的組織、紀律及戰術。
  • 這段經歷對他日後指揮日本聯合艦隊具有重要影響。

1875年：搭乘訓練船環球航行

  • 東鄉搭乘英國訓練船 Hampshire 號進行遠洋航行。
  • 透過實際航行熟悉海洋環境、航海技術及遠洋船艦運作。
  • 這次經驗使他對全球海上交通與海軍活動有更廣泛的認識。

1876－1878年：繼續研習海軍技術

  • 在英國繼續學習海軍相關知識。
  • 曾接觸英國軍艦建造及近代造船技術。
  • 1878年，搭乘日本向英國訂購的軍艦比叡號返國。
  • 長達約七年的英國留學，使東鄉成為日本海軍中具有西方教育背景的軍官。

1878年：返回日本

  • 返回日本帝國海軍服役。
  • 逐步擔任海軍軍官及艦艇職務。
  • 日本明治政府正積極建立近代化海軍，東鄉的海外經歷使他獲得進一步發展的機會。

8

1880年代：逐步累積海軍實務經驗

  • 東鄉返國後歷任海軍艦艇及岸上相關職務。
  • 曾擔任軍艦艦長，累積艦艇管理、航海及作戰指揮經驗。
  • 日本海軍持續購買西方軍艦，並建立海軍軍官教育與艦隊編制制度。
  • 東鄉逐漸成為具有實務經驗的海軍軍官。

1890年：擔任浪速號艦長

  • 東鄉出任巡洋艦浪速號艦長。
  • 浪速號是日本海軍重要的巡洋艦之一。
  • 此後他與浪速號的關係，成為其軍事生涯的重要一環。

1894年：甲午戰爭爆發

  • 7月，中日兩國因朝鮮問題爆發戰爭。
  • 東鄉以浪速號艦長身分參與日本海軍作戰。
  • 日本海軍開始在黃海及朝鮮半島周邊展開軍事行動。

1894年8月25日：高陞號事件

  • 英國商船高陞號（Kowshing）受清朝方面租用，載運清軍前往朝鮮。
  • 東鄉指揮浪速號在豐島海戰相關行動中，命令擊沉高陞號。
  • 船上有大量清軍士兵及英國船員，事件造成重大傷亡。
  • 由於高陞號懸掛英國旗，事件引發國際外交爭議。
  • 英國方面後續進行法律及外交調查，事件並未演變為英日戰爭。

歷史意義： 高陞號事件使東鄉平八郎受到國際關注，也顯示甲午戰爭期間日本海軍行動所涉及的國際法與外交問題。

1894年9月17日：黃海海戰

  • 日本聯合艦隊與清朝北洋艦隊在黃海交戰。
  • 東鄉指揮浪速號參戰。
  • 日本海軍在戰鬥中展現較強的機動能力與火力運用。
  • 北洋艦隊遭受重大損失，但並未在此戰後立即完全消失。

1895年：甲午戰爭結束

  • 清朝戰敗，與日本簽訂《馬關條約》。
  • 日本取得台灣、澎湖及遼東半島等利益；但遼東半島後因三國干涉還遼而歸還清朝。
  • 東鄉升任海軍少將。
  • 此後陸續擔任海軍教育及艦隊相關職務。

1895年：升任海軍少將

  • 甲午戰爭結束後，東鄉升任海軍少將。
  • 開始從艦艇指揮官轉向海軍高層管理職務。
  • 日本海軍在甲午戰爭勝利後，進一步擴大軍艦建造與海軍組織。

1896年：擔任海軍大學校校長

  • 出任海軍大學校校長。
  • 負責海軍高級軍官的教育與訓練。
  • 海軍大學校是日本培養高級海軍指揮官及參謀人員的重要機構。
  • 東鄉在此期間參與海軍人才培養與軍事教育。

1898年：升任海軍中將

  • 東鄉升任海軍中將。
  • 此後陸續擔任常備艦隊司令長官、舞鶴鎮守府司令長官等重要職務。
  • 日本海軍逐步擴大艦隊規模，並將俄羅斯視為東亞地區的重要戰略競爭對手。

1900年：參與日本海軍戰略整備

  • 日本海軍持續引進英國及其他歐洲國家的軍艦與技術。
  • 東鄉在海軍高層任職，參與艦隊管理與戰備相關工作。
  • 此時俄羅斯勢力向中國東北及朝鮮半島周邊擴張，日本與俄羅斯的矛盾日益加深。

1902年：英日同盟成立

  • 1月30日，英國與日本簽訂《英日同盟協約》。
  • 日本藉由與英國結盟，改善其國際戰略地位。
  • 英國是當時世界主要海軍強國，對日本海軍的發展具有重要影響。

1903年：出任聯合艦隊司令長官

  • 日本與俄羅斯在滿洲、朝鮮問題上的談判陷入僵局。
  • 12月，東鄉平八郎出任日本聯合艦隊司令長官。
  • 升任海軍大將。
  • 接掌日本海軍主要作戰艦隊。
  • 開始制定對俄羅斯海軍作戰的準備與部署。

歷史意義： 東鄉在日俄戰爭前夕被任命為聯合艦隊司令長官，成為日本海軍對俄作戰的最高指揮者之一。這項任命使他在日本近代軍事史上的地位大幅提升。

1904年2月：日俄戰爭爆發

  • 日本與俄羅斯因滿洲及朝鮮半島的勢力範圍問題爆發戰爭。
  • 2月8日至9日，日本海軍對旅順港的俄羅斯太平洋艦隊發動攻擊。
  • 東鄉平八郎指揮日本聯合艦隊參與作戰。
  • 日本試圖削弱俄羅斯在遠東的海軍力量，確保日本軍隊能夠在朝鮮半島及中國東北沿海地區運輸與作戰。

1904年2月：旅順口外海戰

  • 日本海軍對旅順港外的俄羅斯艦隊發動魚雷攻擊。
  • 俄羅斯艦隊部分軍艦受損。
  • 日本未能一次摧毀俄羅斯太平洋艦隊。
  • 隨後日本海軍對旅順港實施封鎖，試圖限制俄軍艦艇出港。

1904年8月10日：黃海海戰

  • 俄羅斯旅順艦隊企圖突破日本海軍封鎖。
  • 日本聯合艦隊與俄羅斯艦隊在黃海交戰。
  • 東鄉指揮日本艦隊攔截俄軍。
  • 俄羅斯艦隊未能成功突破封鎖，部分艦艇返回旅順港。
  • 日本海軍繼續控制旅順外海的重要海域。

1904年末：旅順陷落

  • 日本陸軍持續圍攻旅順。
  • 203高地攻防戰造成雙方重大傷亡。
  • 1905年1月，俄軍旅順守備部隊投降。
  • 旅順俄羅斯艦隊的主要作戰能力受到嚴重打擊。
  • 日本海軍因而能夠將更多注意力集中於俄羅斯波羅的海艦隊的到來。

1905年5月：俄羅斯波羅的海艦隊抵達遠東

  • 俄羅斯為扭轉遠東戰局，派遣波羅的海艦隊遠航至亞洲。
  • 這支艦隊自歐洲出發，經過非洲及印度洋，航行距離極為遙遠。
  • 日本海軍密切監視其航線，準備在朝鮮半島與日本之間的海域迎戰。

1905年5月27日至28日：對馬海峽海戰

usni.org

這是東鄉平八郎軍事生涯中最重要的一場戰役，也是近代海戰史上具有重大影響的事件。

戰役背景

  • 俄羅斯波羅的海艦隊經長途航行抵達東亞。
  • 俄軍希望突破日本海軍封鎖，前往海參崴。
  • 日本聯合艦隊在東鄉指揮下，於對馬海峽附近迎擊俄軍。

戰役經過

1. 5月27日：日本艦隊發現俄軍

  • 日本艦隊掌握俄羅斯艦隊行蹤。
  • 東鄉命令聯合艦隊出動迎戰。
  • 日本旗艦為戰艦三笠號（Mikasa）。

2. 日本艦隊實施「丁字戰法」

  • 東鄉指揮艦隊轉向，利用艦隊隊形與火力集中攻擊俄軍。
  • 日本艦隊逐步取得戰術優勢。
  • 俄羅斯艦隊受到密集炮火攻擊。

3. 俄羅斯艦隊遭受重大損失

  • 俄軍多艘戰艦被擊沉或遭到俘虜。
  • 俄軍艦隊的組織與作戰能力迅速瓦解。
  • 部分俄羅斯軍艦成功逃離，但未能完成原定任務。

4. 5月28日：戰役結束

  • 日本海軍取得決定性勝利。
  • 俄羅斯波羅的海艦隊主力幾乎被摧毀。
  • 日本取得對日本海及朝鮮半島周邊海域的制海權。

歷史意義

  • 日本成為近代亞洲第一個在大型海戰中擊敗歐洲列強海軍的國家。
  • 俄羅斯遠東海軍力量遭受重大打擊。
  • 日俄戰爭的戰略形勢因此明顯向日本傾斜。
  • 東鄉平八郎的國際聲望大幅提升，西方媒體常將他比作英國海軍名將納爾遜。

1905年9月：日俄戰爭結束

  • 日本與俄羅斯在美國調停下簽訂《朴茨茅斯條約》。
  • 日俄戰爭正式結束。
  • 日本取得朝鮮半島的優勢地位，並獲得俄羅斯在中國東北部分租借權益及南樺太等利益。
  • 東鄉因對馬海戰的勝利，成為日本最受尊崇的海軍將領之一。

1905年：出任海軍軍令部長

  • 日俄戰爭結束後，東鄉出任海軍軍令部長。
  • 參與日本海軍戰略規劃與組織整備。
  • 日本海軍開始檢討日俄戰爭的經驗，進一步發展戰艦、砲術與艦隊作戰理論。

1906年：獲英國功績勳章

  • 東鄉獲英國授予功績勳章（Order of Merit）。
  • 這項榮譽反映他在國際海軍界的聲望。
  • 同年，日本國內持續以對馬海戰勝利作為國家軍事成就的重要象徵。

1907年：受封伯爵

  • 日本政府因其日俄戰爭的軍事貢獻，授予東鄉伯爵爵位。
  • 他正式進入日本華族制度中的高級貴族階層。
  • 在日本社會中，他被視為國家英雄。

1909年：卸下海軍軍令部長職務

  • 東鄉逐步退出海軍日常作戰及行政決策。
  • 仍然在日本海軍中具有極高威望。
  • 日本海軍開始由下一代將領接掌主要職務。

1913年：獲授元帥稱號

  • 東鄉獲授日本海軍元帥稱號。
  • 元帥是日本軍界極高的榮譽性地位。
  • 此後他主要以海軍元老身分參與國家軍事與教育相關事務。

1914年：出任東宮御學問所總裁

  • 日本進入大正時代。
  • 東鄉出任東宮御學問所總裁，負責皇太子裕仁（後來的昭和天皇）的教育事務。
  • 他在這個職位上服務多年，對皇太子的教育及軍事思想形成具有一定影響。
  • 此時東鄉已不再直接指揮艦隊，而是以海軍元老身分參與皇室教育及國家事務。

1918年：第一次世界大戰結束前後

  • 第一次世界大戰進入尾聲。
  • 日本作為協約國成員參戰，並在戰後國際秩序中取得更大的國際影響力。
  • 東鄉持續以海軍元老身分受到日本政府及海軍界尊重。

1921年：卸下東宮御學問所職務

  • 東鄉結束長期擔任的東宮御學問所總裁職務。
  • 此後主要以海軍元老及國家重要人物身分活動。
  • 日本海軍內部仍高度重視他在日俄戰爭中的指揮經驗。

1920年代：成為日本海軍象徵性人物

  • 東鄉逐漸成為日本海軍精神與傳統的象徵。
  • 日本海軍官兵經常以他在對馬海峽海戰中的表現作為學習典範。
  • 他也受到日本國內民族主義與軍事紀念文化的推崇。
  • 另一方面，日本海軍逐步擴大軍備，與美國、英國等國之間的海軍競爭也日益受到關注。

1930年代初期：晚年生活

  • 東鄉已退出實際軍事指揮職務。
  • 仍受到日本政府、皇室及海軍界高度尊崇。
  • 他的對馬海戰勝利經驗，持續被日本海軍作為戰術及軍事教育的重要教材。

1934年5月30日：逝世

  • 東鄉平八郎於1934年5月30日在東京逝世。
  • 享年86歲。
  • 日本政府為他舉行國葬。
  • 他去世後，日本社會仍長期以對馬海戰作為紀念其軍事生涯的重要象徵。

4. 對馬海峽海戰（1905年）

指揮日本聯合艦隊擊敗俄羅斯波羅的海艦隊，是東鄉軍事生涯最具代表性的戰役。

對馬海戰的戰術特色

東鄉平八郎在對馬海戰中所採取的戰術，常被視為近代海戰的重要案例。

  1. 集中艦隊火力：利用艦隊隊形，使日本主力艦艇能夠集中攻擊俄羅斯艦隊。
  2. 掌握敵軍航線：透過情報及海上監視，掌握俄羅斯艦隊通過對馬海峽的行動。
  3. 機動轉向：利用艦隊轉向與航速，調整攻擊位置。
  4. 形成火力優勢：日本艦隊在戰鬥中取得較有利的交戰位置，使俄軍艦艇遭受集中打擊。

其中著名的「丁字戰法」（Crossing the T），是指一方艦隊以橫向隊形迎向敵方縱列，使己方多艘軍艦能夠集中火力攻擊敵方前導艦艇，而敵方能夠有效還擊的火炮數量相對受限。

不過，對馬海戰的勝利並非單靠這一種戰術，也與日本艦隊的訓練、情報、通信、砲術、艦艇性能，以及俄羅斯艦隊長途航行後的疲憊等因素有關。

十二、歷史評價與歷史定位

東鄉平八郎在日本近代史上的地位，主要可從以下四個方面理解：

1. 日本近代海軍建設的重要代表人物

他青年時期經歷幕末戰亂，明治維新後赴英國學習海軍技術，回國後投入日本帝國海軍建設。他的生涯呈現日本海軍從藩國艦隊走向現代化國家海軍的過程。

2. 對馬海戰的主要指揮者

1905年對馬海戰的勝利，使日本在日俄戰爭中取得重要戰略優勢，也使東鄉平八郎成為國際知名的海軍將領。

3. 日本軍事民族主義的重要象徵

日俄戰爭勝利後，東鄉被日本政府與社會塑造成國家英雄。他的形象逐漸與日本海軍榮譽、國家威望及軍事民族主義結合。

4. 需要放在帝國主義歷史脈絡中理解

東鄉的軍事成就與日本近代國家擴張密切相關。甲午戰爭與日俄戰爭不只是海軍技術競爭，也涉及朝鮮半島、中國東北及東亞國際秩序的重組。對台灣及東亞歷史而言，這些戰爭也與日本取得台灣、擴大殖民統治及區域勢力有直接關係。

總結： 東鄉平八郎是日本近代海軍史上最具代表性的將領之一。他的生涯可分為幕末薩摩藩海軍時期、英國留學時期、甲午戰爭時期、日俄戰爭指揮時期，以及晚年海軍元老時期。其中，1905年的對馬海戰是其一生最重要的歷史事件。
