春秋五霸大事記

春秋五霸是中國東周春秋時期（公元前770年－公元前476年，另有公元前453年等分期說法）先後崛起的五位諸侯霸主。他們以強大的軍事、政治及外交實力，取得諸侯盟主地位，並在一定程度上維持周王室名義下的諸侯秩序。

春秋五霸並沒有完全統一的名單。最常見的兩種說法是：

  • 《史記索隱》等傳統說法：齊桓公、宋襄公、晉文公、秦穆公、楚莊王。
  • 《荀子・王霸》等另一種說法：齊桓公、晉文公、楚莊王、吳王闔閭、越王勾踐。

以下以第一種傳統名單為主，並補充吳王闔閭、越王勾踐的相關歷史，建立完整的春秋五霸時間軸。

一、春秋五霸的時代背景

2. 春秋時代的政治特徵

  1. 周天子權威下降：諸侯逐漸不再服從周王室的實際控制。
  2. 諸侯兼併戰爭：各國為爭奪土地、人口及戰略資源而發動戰爭。
  3. 霸主制度形成：強國諸侯以「尊王攘夷」為號召，取得諸侯盟主地位。
  4. 外交與會盟興盛：諸侯透過會盟、朝聘及軍事合作維持政治秩序。
  5. 華夏與周邊勢力互動：楚、吳、越等國逐漸進入中原政治競爭。

3. 齊桓公的重要改革

（1）政治改革

  • 任用管仲，推行中央行政改革。
  • 設置三官、五官等行政體系，強化國家治理。
  • 以官職分工提高行政效率。

（2）經濟改革

  • 發展農業與工商業。
  • 改善賦稅制度。
  • 利用魚鹽資源發展國家經濟。
  • 加強貨幣與市場管理。

（3）軍事改革

  • 推行軍政合一的管理制度。
  • 編制軍隊，強化軍事動員能力。
  • 使齊國具備長期對外作戰的實力。

4. 齊桓公的外交與霸權

召陵之盟（前656年）

齊桓公聯合魯、宋、陳、衛、鄭、許、曹等諸侯，南下對抗楚國。

楚國派遣使者屈完與齊國交涉，最後雙方達成協議，齊軍撤退。

這場外交行動顯示齊桓公不只依靠軍事力量，也能透過諸侯聯盟迫使強國妥協。

葵丘會盟（前651年）

  • 齊桓公召集諸侯會盟。
  • 周王室派遣代表參與。
  • 諸侯共同確認盟約及政治秩序。
  • 齊桓公霸主地位達到巔峰。

3. 盂地會盟（前639年）

宋襄公希望取代齊桓公，成為中原諸侯的領袖，因此召集楚國及其他諸侯會盟。

然而，楚成王並不願意接受宋國領導，會盟期間宋襄公被楚軍拘捕。

後來楚國釋放宋襄公，宋國試圖稱霸的計畫受到重大打擊。

4. 泓水之戰（前638年）

來源：qulishi.com

戰爭雙方：

  • 宋國：宋襄公
  • 楚國：楚成王

戰爭經過：

  1. 楚軍進攻宋國。
  2. 宋軍在泓水一帶迎戰。
  3. 楚軍渡河時，宋軍將領建議趁機攻擊。
  4. 宋襄公認為敵軍尚未完成渡河，不應攻擊。
  5. 楚軍渡河後，尚未完成列陣，宋軍將領再次建議進攻。
  6. 宋襄公仍然拒絕，認為必須等待敵軍列陣完成。
  7. 楚軍完成部署後發動攻擊，宋軍大敗。
  8. 宋襄公受傷，後來傷重去世。

這場戰役成為中國歷史上討論戰爭倫理與軍事現實的重要案例。

5. 宋襄公的歷史評價

宋襄公的政治理想是恢復傳統禮制，並以仁義取得諸侯尊重。

然而，春秋時代的霸權競爭已經逐漸轉向實力政治。他過度拘泥於戰爭禮儀，未能掌握戰場時機，最終導致失敗。

歷史意義： 宋襄公的故事反映出西周傳統禮制與春秋現實政治之間的衝突。

2. 流亡期間的重要故事

（1）退避三舍

重耳流亡楚國時，楚成王以諸侯之禮接待他，並詢問如果重耳日後回國執政，將如何報答楚國。

重耳回答：如果晉楚兩國未來發生戰爭，晉軍將主動後退三舍（一舍約三十里，古代里制有變）。

這個承諾後來成為城濮之戰的重要背景。

（2）秦穆公支持重耳

秦穆公看好重耳的政治能力，將宗室女子嫁給他，並在前636年出兵協助重耳回國。

這使秦、晉兩國形成重要的政治與外交關係。

4. 城濮之戰（前632年）

來源：chiculture.org.hk

戰爭雙方：

  • 晉國：晉文公、先軫
  • 楚國：楚成王方面的軍隊，主將子玉

戰爭背景：

楚國長期向北方擴張，控制中原南部及部分諸侯。晉文公則希望建立晉國在中原的領導地位。

宋國受到楚國攻擊，向晉國求援，晉楚衝突因此爆發。

戰爭經過：

  1. 晉軍出兵援助宋國。
  2. 晉文公履行當年對楚成王的承諾，主動退避三舍。
  3. 晉軍退至城濮一帶，尋找有利地形。
  4. 晉軍採取戰術，攻擊楚軍兩翼。
  5. 楚軍陣形混亂，最終敗退。
  6. 晉國取得勝利，奠定中原霸主地位。

5. 踐土之盟（前632年）

城濮之戰後，晉文公在踐土召集諸侯會盟。

  • 周襄王派遣使者參與。
  • 晉文公接受周王室冊命。
  • 諸侯承認晉國的領導地位。
  • 晉國正式取得中原霸權。

6. 晉文公的歷史評價

晉文公是春秋時期最具政治才能的霸主之一。

其成功因素包括：

  1. 長期流亡所累積的政治經驗。
  2. 任用狐偃、趙衰、先軫等賢能人才。
  3. 秦國的軍事與外交支持。
  4. 晉國強大的軍事組織。
  5. 善於利用周王室名義取得政治正當性。

歷史意義： 晉文公的崛起，使春秋霸權由齊國轉向晉國，也開啟晉國長期主導中原政治的局面。

3. 秦穆公的重要政治改革

（1）任用百里奚

百里奚是秦穆公的重要政治人才。

（2）任用蹇叔

蹇叔是秦穆公的重要謀臣，曾經反對秦軍遠征鄭國，認為長途行軍容易遭到敵軍伏擊。

（3）重視西方人才

秦穆公亦重用由余。由余熟悉西戎各部族的政治與社會情況，協助秦國制定對西戎的策略。

4. 秦晉韓原之戰（前645年）

戰爭背景：

晉惠公即位時，曾得到秦穆公的支持，但即位後並未完全履行承諾，兩國關係逐漸惡化。

前645年，秦晉兩國在韓原交戰。

戰爭結果：

  • 秦軍擊敗晉軍。
  • 晉惠公被秦軍俘虜。
  • 秦穆公取得對晉國的外交優勢。
  • 秦晉兩國的政治關係重新調整。

5. 崤之戰（前627年）

來源：feeds-drcn.cloud.huawei.com.cn

戰爭雙方：

  • 秦國：秦穆公派遣的遠征軍。
  • 晉國：晉襄公。

戰爭背景：

秦穆公希望向東方擴張，派兵遠征鄭國。秦軍途中得知鄭國已有防備，於是撤軍。

但秦軍返回時經過崤山，遭到晉軍伏擊。

戰爭經過：

  1. 秦軍遠征鄭國。
  2. 鄭國早有防備，秦軍無法達成目標。
  3. 秦軍撤退，經過崤山。
  4. 晉軍利用地形發動伏擊。
  5. 秦軍遭到重大損失，三名主將被俘。

歷史意義：

崤之戰阻止秦國短期內向東方擴張，也使秦國更加重視西方發展。

6. 秦穆公稱霸西戎

秦穆公在中原爭霸受挫後，將發展重心轉向西方。

  • 擊敗部分西戎部族。
  • 擴大秦國在關中及周邊地區的勢力。
  • 改善秦國的戰略安全。
  • 取得周王室對其西方軍事成就的肯定。

秦穆公因而被視為春秋時期西方的重要霸主。

7. 秦穆公的歷史評價

秦穆公的霸業與齊桓公、晉文公不同。他並未長期掌握中原諸侯盟主地位，而是透過向西擴張，建立秦國在西方的區域優勢。

歷史意義： 秦穆公奠定秦國日後向東發展的國力基礎，其政治與軍事建設也為秦國長期崛起提供條件。

1. 楚莊王即位與初期政治

楚國是春秋時期南方最強大的國家之一，長期與中原諸侯及晉國爭奪霸權。

楚莊王即位初期，並未立即展現政治才能，而是先觀察國內局勢。

「三年不鳴，一鳴驚人」便是後世對楚莊王早期政治經歷的著名描述。

3. 三年不鳴，一鳴驚人

來源：sohu.com

楚莊王即位初期，傳說他三年沒有積極處理政事，沉迷享樂。

大臣伍舉以隱語勸諫楚莊王，指出有一隻鳥停在高處，三年不飛也不鳴，但一旦飛翔，就會直衝雲霄；一旦鳴叫，就會令人震驚。

楚莊王理解其意，開始整頓朝政、任用賢臣。

這段故事反映楚莊王政治轉變的傳統形象，但細節帶有歷史傳說色彩。

4. 楚莊王任用孫叔敖

來源：sohu.com

孫叔敖是楚莊王的重要輔臣。

主要貢獻：

  1. 整頓楚國政治。
  2. 改善農業及水利建設。
  3. 推動地方經濟發展。
  4. 協助楚莊王建立軍事優勢。
  5. 提升楚國行政效率。

楚國透過政治改革與經濟建設，逐漸具備與晉國爭霸的實力。

5. 問鼎中原（前606年）

來源：kknews.cc

楚莊王北上討伐陸渾之戎，軍隊接近周王室所在地。

周定王派遣王孫滿前往慰勞楚軍。

楚莊王詢問周王室九鼎的大小、輕重。

九鼎是古代王權及天下統治正當性的象徵，因此楚莊王詢問九鼎，具有挑戰周王室權威的政治意涵。

王孫滿回答，真正重要的是德行與政治正當性，而不是鼎的大小與重量。

這段歷史後來形成著名成語：

問鼎中原： 比喻企圖奪取天下政權或爭奪最高權力。

6. 邲之戰（前597年）

來源：baike.qulishi.com

戰爭雙方：

  • 楚國：楚莊王。
  • 晉國：晉景公時期的軍隊，主要將領包括荀林父等。

戰爭背景：

晉國長期掌握中原霸權，楚國則不斷向北方擴張。鄭國在晉楚兩國之間反覆改變立場，成為雙方爭奪的焦點。

戰爭經過：

  1. 楚國出兵攻打鄭國。
  2. 鄭國向晉國求援。
  3. 晉國派兵救援鄭國。
  4. 楚軍與晉軍在邲地附近交戰。
  5. 晉軍內部指揮出現混亂。
  6. 楚軍乘勢進攻，晉軍大敗。
  7. 鄭國重新接受楚國影響。

歷史意義：

邲之戰是春秋時期重要的霸權轉折點，楚國由南方強國進一步成為中原霸主，晉國的霸權受到重大打擊。

7. 楚莊王的歷史評價

楚莊王是春秋時期軍事、政治及外交能力兼備的君主。

其重要成就包括：

  • 透過內政改革強化楚國。
  • 任用孫叔敖等人才。
  • 擴大楚國在中原的影響力。
  • 在邲之戰擊敗晉國。
  • 使楚國成為春秋霸權競爭中的重要領導者。

歷史意義： 楚莊王的崛起，代表春秋霸權不再只是北方諸侯的競爭，也反映南方楚國政治與軍事力量的全面提升。

臥薪嘗膽

來源：sohu.com

十二、春秋五霸對中國歷史的影響

1. 政治方面：周天子權威衰退

西周時期，周天子是天下名義上的最高統治者。

到了春秋時代，諸侯國逐漸強大，齊桓公、晉文公等霸主開始代替周王室主持諸侯會盟。

這代表中國政治秩序從周王室主導，逐漸轉向強國諸侯主導。

2. 軍事方面：戰爭規模擴大

春秋初期，諸侯戰爭主要圍繞邊境及領土爭奪。

隨著霸權競爭加劇，戰爭規模逐漸擴大，軍隊組織及戰略戰術也不斷發展。

城濮之戰、邲之戰及柏舉之戰，都是這一時期重要的軍事轉折點。

3. 經濟方面：各國改革與發展

為了支撐長期戰爭，各國開始重視：

  • 農業生產與土地開發。
  • 賦稅制度與國家財政。
  • 手工業及商業發展。
  • 人口與兵源管理。
  • 水利建設及交通運輸。

這些變化為戰國時代的經濟及政治改革奠定基礎。

4. 社會方面：士階層興起

春秋時代，各國逐漸重用具有政治、軍事及外交能力的人才。

管仲、百里奚、孫叔敖、伍子胥等人，都是這種人才流動現象的代表。

士階層的興起，也為戰國時代百家爭鳴創造了社會條件。

5. 歷史發展方面：由春秋走向戰國

春秋時代以諸侯爭霸為主要特色；戰國時代則逐漸轉變為大國兼併與領土統一的競爭。

三家分晉（前453年，另有前403年周威烈王正式冊封韓、趙、魏為諸侯的分期）是這個政治轉型的重要標誌。
