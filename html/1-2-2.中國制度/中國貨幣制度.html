目錄

中國貨幣制度大事記

中國貨幣制度的發展，是一部從實物交換、金屬貨幣、銅錢與布帛並行、銀本位、紙幣發行，逐步走向現代中央銀行與法定貨幣制度的歷史。

中國在世界貨幣史上有幾項重要創新：戰國時期多種形態的金屬貨幣、秦始皇統一貨幣、北宋交子的出現、明清白銀貨幣化，以及近代中央銀行與現代人民幣制度的建立。

以下按照歷史朝代，整理重要事件、貨幣種類、制度改革及其歷史意義。

二、原始社會至夏商周：實物貨幣與貝幣時代（約前3000年－前771年）

1. 原始社會：實物交換

時間重要事件貨幣制度發展
原始社會部落之間進行物品交換以物易物
新石器時代貝殼、玉器、陶器等物品被用於交換出現具有交換媒介功能的物品
新石器時代晚期貝殼逐漸具有財富象徵意義貝幣使用逐漸發展

2. 夏商時代：貝幣與金屬貨幣萌芽

時間重要事件貨幣制度發展
夏朝以物易物及貝類交換可能並存貨幣制度尚未成熟
商朝貝殼廣泛用作財富與交換媒介貝幣成為重要貨幣形式
商朝中晚期出現銅貝等金屬仿貝貨幣金屬鑄幣萌芽
商朝青銅器及金屬冶鑄技術發展為金屬貨幣製造提供技術基礎

3. 西周：貝幣與金屬貨幣並行

時間重要事件貨幣制度發展
前1046年左右周武王建立周朝延續商代貨幣使用
西周早期貝幣仍具有重要地位貝幣作為財富與賞賜媒介
西周中晚期金、銅等金屬用於賞賜與交易金屬貨幣功能逐漸擴大
西周晚期出現具有重量或形制特徵的金屬貨幣貨幣逐漸朝鑄幣方向發展

本階段特色：貝幣是中國早期貨幣的重要形式，但當時尚未形成全國統一、由國家規範的貨幣制度。

三、春秋戰國：金屬鑄幣多元化時代（前770年－前221年）

春秋戰國時期，各諸侯國政治、經濟與商業發展程度不同，形成多種不同形態的貨幣，是中國古代貨幣制度多元發展的重要階段。

1. 主要貨幣種類

貨幣種類主要流通地區外形特色
布幣韓、趙、魏、周等地農具鏟形
刀幣齊、燕等地刀形
圜錢秦、魏、趙等地圓形，有圓孔或方孔
蟻鼻錢楚國貝形或面文特殊的小型銅錢
金幣楚等地金版、金餅等形式

2. 春秋戰國貨幣大事記

時間重要事件制度意義
前770年東周建立周王室權威下降，貨幣制度逐漸多元
春秋時代各諸侯國發展地方鑄幣出現區域性貨幣市場
前7世紀齊國商業及貨幣經濟發展刀幣逐漸流通
前7至6世紀魏、趙、韓等地布幣發展農具形貨幣成為重要形式
前6至5世紀圜錢逐漸出現圓形金屬貨幣發展
前5至4世紀楚國鑄造蟻鼻錢及金版楚國形成自身貨幣體系
前4世紀各國鑄幣與市場交易擴大貨幣經濟逐漸普及

歷史意義：貨幣逐漸由具有實物價值的交換物，發展成為國家鑄造、具有規格與面額的金屬貨幣。

四、秦漢時代：統一貨幣與五銖錢制度（前221年－220年）

1. 秦朝：統一貨幣制度

時間重要事件制度意義

秦朝統一度量衡與貨幣促進跨地區交易及財政管理

秦代貨幣制度通常以黃金為上幣、銅質半兩錢為下幣。秦半兩錢的圓形方孔形式，對後世中國銅錢影響深遠。

本階段關鍵轉變：秦代統一幣制，漢武帝則透過五銖錢及上林三官制度，進一步將鑄幣權集中於中央。

3. 開元通寶的歷史意義

開元通寶是中國貨幣史的重要里程碑：

  • 名稱創新：錢文不再直接以重量命名。
  • 制度影響：建立通寶、元寶等錢文命名傳統。
  • 規格影響：唐代銅錢成為後世鑄幣的重要參考。
  • 國際影響：對日本、朝鮮半島及其他東亞地區的錢幣制度產生影響。

4. 飛錢：紙幣出現前的重要金融工具

唐代飛錢是商人或官員透過機構辦理異地匯兌的憑證，可以減少攜帶大量銅錢的風險。

但飛錢主要是匯兌工具，並不是現代意義上可普遍流通的紙幣。

八、宋遼金時代：紙幣興起與貨幣經濟發展（960－1279年）

宋代是中國貨幣史的重要轉折點，商業繁榮、銅錢流通擴大，紙幣逐漸從民間信用憑證發展為國家發行的貨幣。

1. 北宋：交子誕生

時間重要事件貨幣制度意義
960年宋朝建立統一五代十國主要地區的貨幣市場
10世紀末四川商業與金融活動發展民間匯兌及信用交易增加
1023年北宋設立益州交子務由政府管理交子發行
1024年官方交子正式發行中國早期官方紙幣制度形成
11世紀交子逐漸在四川流通紙幣成為區域性貨幣
11世紀中後期交子發行與兌換制度調整建立發行額度及界期管理
1107年北宋改交子為錢引調整四川紙幣制度
1127年北宋滅亡北方貨幣制度受到戰亂衝擊

交子最初是四川民間商人使用的信用憑證，後來由政府設立交子務，成為官方紙幣。它是世界貨幣史上最早的重要紙幣形式之一。

元代是中國紙幣制度發展的重要時代。政府曾試圖以紙鈔作為全國主要通貨，並建立中央統一發行及管理制度。

十、明朝：大明寶鈔與白銀貨幣化（1368－1644年）

明朝前期曾大力推行紙幣，但因紙鈔缺乏有效兌換及發行約束，逐漸貶值。到了明代中後期，白銀逐漸成為大額交易、稅收及商業活動的重要貨幣。

重要轉變：明代不是簡單地由紙幣改回金屬貨幣，而是逐漸形成以白銀為重要計價及支付工具、銅錢負責小額交易的多層次貨幣體系。

十一、清朝：銀兩與制錢並行（1644－1912年）

清朝前中期延續明代白銀貨幣化趨勢，形成銀兩與銅錢並行的貨幣制度。晚清則因外國銀元流入、機器鑄幣及新式銀行發展，逐漸進入近代貨幣制度。

1662年康熙帝即位延續銅錢鑄造及銀兩制度
1667年開始鑄造康熙通寶建立康熙年間主要銅錢
1700年代銀兩與制錢並行形成大額與小額支付分工
1736年乾隆帝即位延續清代貨幣制度
18世紀外國銀元逐漸流入中國沿海增加貨幣市場的多樣性
18世紀後期銀兩、制錢及外國銀元並行各地匯價及貨幣折算問題受到重視

1889年廣東開始鑄造龍洋近代機器銀元鑄造的重要發展

3. 清代主要貨幣種類

官票政府發行的紙幣
寶鈔清政府發行的紙幣
銀票、錢票銀號、錢莊等金融機構發行的信用憑證

4. 清代貨幣制度的主要問題

  • 各地銀兩重量與成色不完全一致。
  • 銀兩與銅錢的兌換比率經常波動。
  • 外國銀元與本國銀錠並行，增加交易成本。
  • 中央貨幣發行及鑄幣管理權不夠統一。
  • 地方紙幣與金融機構信用差異很大。

十四、中國歷代主要貨幣種類總整理

貝幣

商周時代的重要早期貨幣，貝殼具有交換及財富象徵功能。

布幣、刀幣

春秋戰國時代各諸侯國使用的金屬鑄幣。

半兩錢

秦始皇統一貨幣的重要代表。

五銖錢

漢武帝創立的重要標準銅錢，延續至隋末唐初。

開元通寶

唐代標準銅錢，開創通寶錢的重要傳統。

交子

北宋官方紙幣的重要代表，是世界早期紙幣發展的里程碑。

中統鈔、至元鈔

元代全國性紙幣制度的重要代表。

大明通行寶鈔

明初官方紙幣，後因貶值逐漸失去市場地位。

銀兩、銀錠

明清大額交易與財政結算的重要貨幣。

袁大頭銀元

民國時期的重要機制銀元。

法幣

1935年改革後的國民政府法定貨幣。

人民幣

1948年創立，成為中華人民共和國的法定貨幣。

總結：中國貨幣制度的演進有三條特別重要的主線：

  • 貨幣形態：貝幣 → 金屬鑄幣 → 銅錢 → 紙幣 → 銀元與銀行券 → 人民幣。
  • 貨幣管理：地方鑄幣 → 中央統一鑄幣 → 國家紙幣發行 → 中央銀行管理。
