中國租稅制度大事記

中國租稅制度（亦稱賦稅制度）發展史，是中國財政史、經濟史與土地制度史的重要組成部分。

從古代的貢納、井田制、初稅畝、租庸調、兩稅法，到明代一條鞭法、清代攤丁入畝，再到近現代的田賦、工商稅、增值稅及個人所得稅，中國租稅制度的核心變化，是從以土地、人口和勞役為主要課稅基礎，逐漸轉向以所得、交易、消費、財產及企業經營活動為課稅對象。

以下依歷史朝代，整理重要改革、稅種、徵收方式及制度影響。

一、先秦時代：貢納、井田與土地稅的形成（約前2070年－前221年）

1. 夏商時代：貢納與早期賦稅制度

時間租稅大事主要內容
夏代貢賦制度形成傳統文獻記載夏代有貢賦制度，向統治者提供農產品及其他物資
夏代禹貢九州制度《尚書．禹貢》記載九州土地、物產及貢納等級，反映早期地區貢賦觀念
商代王室貢納制度方國、部族向商王室進貢糧食、牲畜及其他物品
商代農業徵收王室依靠農業生產及臣屬貢納取得財政資源
商代田獵與戰爭資源徵集透過王室與地方貴族組織取得物資及勞動力

制度特色：

  • 以實物貢納為主要形式。
  • 王室、貴族與方國之間具有政治性貢賦關係。
  • 尚未形成後世完整的統一稅法與常態化稅收行政機構。

2. 西周：井田制與土地、勞役負擔

時間租稅大事主要內容
西周初期井田制傳統文獻記載土地分配與集體耕作制度
西周公田與私田公田收益及農民勞動與貴族土地權利相結合
西周助法傳統上以共同耕作公田的方式，說明農業負擔
西周貢納制度諸侯向周王室提供財物及物產
西周土地與勞役義務農民承擔耕作、修築及其他公共勞役
西周晚期土地交易增加傳統井田秩序逐漸受到土地實際占有及交易影響

注意：井田制的具體運作方式及實際普及程度，仍是歷史研究中的討論問題，不能將後世文獻描述直接視為西周全國統一實施的制度。

3. 春秋時代：初稅畝與土地稅制度的轉變

時間租稅大事主要內容
春秋早期井田制度逐漸瓦解土地私有及實際占有情形增加
前685年左右齊國管仲改革改革土地、財政及工商管理，實行相地而衰徵等措施
前594年魯國初稅畝魯宣公十五年開始按土地畝數徵稅
前594年後土地課稅發展土地面積逐漸成為重要的課稅依據
春秋中後期各國賦稅改革各諸侯國逐漸調整土地、人口及軍事負擔
春秋晚期土地私有化發展傳統公田與貴族土地制度逐漸改變

初稅畝的重要性：

魯國初稅畝是中國古代賦稅史上的重要轉折，代表土地面積逐漸成為正式課稅的依據之一，也反映傳統井田及公田制度的變化。

4. 戰國時代：土地稅與國家財政制度發展

時間租稅大事主要內容
前408年魏國李悝變法改革土地及農業政策，重視國家糧食儲備
前4世紀各國土地制度改革土地私有化、授田及農業稅收制度逐步發展
前356年商鞅第一次變法建立什伍連坐、獎勵耕戰等制度
前350年商鞅第二次變法推動縣制、土地制度及國家行政改革
戰國中期秦國重農政策鼓勵農業生產，強化農業稅收與國家徵發
戰國時期戶籍與賦役制度以戶籍、人口及土地作為國家徵稅徵役基礎
戰國晚期國家財政集中化稅收逐漸成為中央政府維持軍隊及行政的重要來源
前221年秦統一六國建立帝國統一的財政與賦役管理體系

先秦租稅制度的發展主線：

貢納制 → 公田與勞役負擔 → 土地課稅 → 國家化的農業賦稅制度。

3. 新莽：王莽財政與貨幣改革（9－23年）

時間租稅大事主要內容

4. 東漢：田租與人口賦稅並行（25－220年）

時間租稅大事主要內容

東漢中後期豪強地主勢力擴張大量土地與人口依附豪強，削弱國家稅基
184年黃巾之亂財政、土地及社會矛盾加劇

秦漢租稅制度的主要特徵：

田租＋人頭稅＋徭役＋專賣收入。

此時期的農業稅與人口稅並行，國家財政高度依賴農業生產及戶籍管理。

時間租稅大事主要內容

均田制的重要意義：

均田制並非現代意義的土地國有制，而是國家透過授田、還田及戶籍管理，調整農業人口與土地資源的制度。

它與租調制互為基礎，成為隋唐租庸調制度的重要前提。

唐代租庸調制的基本結構：

項目徵收內容課稅基礎

調絹、布、綿、麻丁口及地方規定

租庸調制的最大特色是以丁身為本，與均田制密切相關。

3. 唐中後期：兩稅法（780年）

時間租稅大事主要內容
755年安史之亂均田制及租庸調制度受到嚴重破壞
780年楊炎推行兩稅法唐德宗採納宰相楊炎建議，改革全國租稅制度
780年廢除租庸調制傳統以丁口為核心的租庸調制度正式退出主要財政體系
780年戶稅與地稅將主要賦稅整合為戶稅與地稅
780年以資產為課稅依據依家庭資產、土地等情況核定稅負
780年夏秋兩次徵稅夏稅不得晚於六月，秋稅不得晚於十一月
780年量出制入先估算政府財政支出，再確定應徵稅額
780年後商人課稅對不在當地定居的行商課徵相關商稅
9世紀兩稅法持續調整各地逐漸形成不同附加稅及徵收慣例
907年唐朝滅亡兩稅法成為後世重要稅制基礎

兩稅法的五大改革：

  1. 從以丁口為本轉向以資產為本。
  2. 將主要稅收整合為戶稅與地稅。
  3. 一年分夏、秋兩次徵收。
  4. 以貨幣計算稅額，實際繳納可依規定折納錢物。
  5. 依政府財政需求核定稅收總額。

兩稅法是中國古代租稅史最重要的制度轉折之一，使課稅基礎逐漸由人口轉向土地及家庭財產。

一條鞭法的主要內容：

  1. 把各種賦稅、徭役及雜派盡量合併。
  2. 將部分力役改為銀兩徵收。
  3. 由政府以銀雇人服役。
  4. 以土地和丁口等作為分攤基礎。
  5. 推動實物稅向貨幣稅轉型。

一條鞭法是中國古代賦役貨幣化的重要里程碑，但各地推行方式並不完全相同，也不是所有徭役都立即消失。

分稅制的基本架構：

  • 中央稅：由中央政府掌握的稅收。
  • 地方稅：主要歸地方政府的稅收。
  • 共享稅：中央與地方依規定比例分享。

這是中華人民共和國現代財政制度最重要的制度轉折之一。

  1. 均田制 → 租庸調制

  1. 租庸調 → 兩稅法

宋代

  1. 實物稅 → 貨幣稅

明代中後期

1994年至今

總結：中國租稅制度的長期演變，可以用五個階段概括：

  1. 先秦至秦漢：以貢納、土地及人口為主要課稅基礎。
  2. 魏晉南北朝至隋唐：戶調、均田與租庸調制度發展。
  3. 唐宋至元：兩稅法確立，商業稅及專賣收入擴大。
  4. 明清：白銀貨幣化、一條鞭法及攤丁入畝，逐漸完成傳統賦役制度轉型。
  5. 近現代：由田賦為主轉向所得稅、增值稅、消費稅及其他現代複合稅制。

最重要的歷史主線是：

以人丁為本 → 以土地資產為本 → 賦役貨幣化 → 人丁稅併入田賦 → 現代所得與交易課稅。
