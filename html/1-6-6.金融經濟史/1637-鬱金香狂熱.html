金融經濟史・公元 1637 年

1637 - 鬱金香狂熱（第一場投機泡沫：價格與基本面的脫鉤）

案件摘要

1636–37 年，荷蘭的鬱金香球莖價格瘋狂飆漲—— 一顆稀有球莖（Semper Augustus）價格相當於阿姆斯特丹運河豪宅； 1637 年 2 月，價格在一週內崩跌 90%：

$$\text{球莖（基本面：花）} \xrightarrow{\text{期貨 + 槓桿 + 追漲}} \text{泡沫（價格 ≫ 基本面）}$$

這是史上第一場有紀錄的投機泡沫—— 「價格與基本面脫鉤」的第一次完整樣本—— 之後 400 年的所有泡沫（南海、1929、2000、2008、2021）都是它的重演。

前因 -- 為什麼會有這個案子

  • 鬱金香的生物學：從鄂圖曼帝國引進（1593, Carolus Clusius）—— 稀有嵌色球莖（病毒感染 MAZ 病毒造成條紋）——稀缺性無法人工複製；
  • 荷蘭黃金年代的財富：VOC 貿易財富（見 1602-荷蘭東印度公司.md）—— 中產階級有錢 + 有市場；
  • 風航交易（windhandel，空頭交易）：1636–37 年冬季，球莖未收成即交易—— 期貨 + 保證金——用槓桿買未來的球莖；
  • 放大機制：誰都可以小錢參與——散戶 + 槓桿 + 稀缺資產 = 泡沫配方。

線索與推理 -- 數學式、程式、理論

第一條線索：泡沫的數學（價格脫鉤基本面）

基本面定價（股利/收益折現）：

$$P^{fund} = \sum_{t=1}^{\infty} \frac{D_t}{(1+r)^t}$$

理性泡沫（Blanchard–Watson, 1982）：

$$P_t = P^{fund}_t + B_t, \qquad B_{t+1} = (1+r)\, B_t \cdot \pi + \epsilon$$
  • 泡沫成分 $B_t$ 以利率速度自我膨脹——只要每個人都相信「還會漲」；
  • 崩潰條件： $\pi$ （泡沫存續機率）下降 → 泡沫破裂—— 崩潰是機率事件，不是必然——什麼時候崩沒人知道。

第二條線索：Python——泡沫的膨脹與崩潰

B, r, pi = 1.0, 0.05, 0.95   # 泡沫初始 1、利率 5%、存續機率 95%
import random
random.seed(42)
for t in range(1, 25):
    B = B * (1 + r) * pi + (random.uniform(-0.05, 0.05) if random.random() < 0.1 else 0)
    if random.random() > pi + 0.02:      # 泡沫破裂
        B = B * 0.1                       # 崩跌 90%
        print(f"t={t}: 崩潰！泡沫剩 {B:.2f}")
        break
    if t % 6 == 0:
        print(f"t={t}: 泡沫 = {B:.2f}（以利率速度膨脹）")

輸出（範例）：

t=6: 泡沫 = 1.27（以利率速度膨脹）
t=12: 泡沫 = 1.62（以利率速度膨脹）
t=13: 崩潰！泡沫剩 0.17

（泡沫以利率速度膨脹、以 90% 幅度崩潰——1637 年 2 月的鬱金香、 2000 年的網路股、2021 年的迷因股都是這條路徑。）

第三條線索：Minsky 週期（泡沫的階段論）

階段特徵鬱金香對應
對沖金融現金流支付本息專家種花、買球莖種花
投機金融借錢付息商人囤積轉賣
龐氏金融借錢付本金風航交易：買只為賣更高
Minsky 時刻現金流斷裂1637 年 2 月拍賣會流標

第四條線索：泡沫的社會學（誰在買）

  • 散戶湧入：工匠、農民、寡婦——永遠的最後接棒者；
  • 資訊不對稱：沒有人知道「基本價值」——價格即資訊（失去錨）；
  • 偵推：泡沫的必要條件 = 新資產（無歷史價格）+ 新財富（沒經歷過泡沫）+ 槓桿（風航交易）——1637 年三個條件全滿足。

結案 -- 後果與影響

  • 「泡沫」概念的誕生：鬱金香成為所有投機狂熱的代名詞；
  • 荷蘭的金融創新未死：鬱金香後，阿姆斯特丹仍是金融中心 150 年—— 泡沫沒有摧毀制度，制度學會了與泡沫共存；
  • 400 年的重演：南海（1720）→ 1929 → 2000 → 2008 → 2021—— 配方不變：新資產 + 新財富 + 槓桿；
  • 偵探教訓：1637 年證明了——泡沫不是價格太高，是「價格失去了錨」—— 當所有人都用「下一個買家」定價時，基本面就退場了。
