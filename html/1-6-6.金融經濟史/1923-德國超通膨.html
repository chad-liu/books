金融經濟史・公元 1923 年

1923 - 德國超級通貨膨脹（印鈔機的物理極限）

案件摘要

1923 年 11 月，德國馬克徹底崩潰—— 物價指數相較 1914 年上漲約 10¹² 倍（一兆倍）， 一條麵包 2,000 億馬克，薪水一天發兩次（怕晚發就貶值）：

$$\text{戰爭賠款 + 印鈔融資} \xrightarrow{\text{數量方程}} \text{超級通膨（每月 } \pi > 50\%\text{）}$$

1923 年 11 月Rentenmark（地租馬克）改革 +魯爾危機解決—— 穩定回歸。這是現代通膨理論的臨床樣本—— Cagan（1956）的超通膨模型、鑄幣稅的 Laffer 曲線都由此而生。

前因 -- 為什麼會有這個案子

  • 戰爭財政：一戰德國用印鈔 + 戰債融資（發行量 1918 年是 1913 年的 5 倍）；
  • 凡爾賽賠款：1320 億金馬克賠款——財政的雙重壓力；
  • 魯爾佔領（1923.1）：法比佔領魯爾 → 德國政府「消極抵抗」+ 印鈔補貼罷工工人—— 最後一根稻草；
  • 偵推：超通膨 = 財政赤字 + 印鈔融資—— 不是貨幣現象，是財政現象（Sargent 1982 的結論）。

線索與推理 -- 數學式、程式、理論

第一條線索：數量方程的臨床（MV=PY 的極端案例）

$$\pi \approx \dot{M} + \dot{V} - \dot{Y}$$
  • 1923 年德國： $\dot{M}$ （月增 300%+）、 $\dot{V}$ （人們瘋狂花錢，流通速度暴增）、 $\dot{Y}$ （魯爾停產，產出下降）——三者同向——通膨爆炸；
  • 物價指數：1914=1 → 1923.11 = 10¹²——每月通膨 > 29,000%（峰值）。

第二條線索：Cagan 模型（1956，超通膨的數學）

貨幣需求隨預期通膨崩潰：

$$\frac{M}{P} = e^{-\alpha \pi^e} \quad (\alpha = \text{通膨敏感度})$$

鑄幣稅的 Laffer 曲線：

$$S = \frac{M}{P} \cdot \mu \quad (\mu = \text{貨幣成長率})$$
  • 偵推：貨幣成長太快 → 實質貨幣需求崩潰（ $M/P$ 縮水）→ 鑄幣稅收入反而下降——印鈔的報酬遞減—— 超通膨是「鑄幣稅 Laffer 曲線的極限」。

第三條線索：Python——超通膨的螺旋（為什麼會失控）

pi, alpha = 0.20, 3.0        # 月通膨 20%、貨幣需求敏感度 3
print("月通膨 -> 實質貨幣需求（相對）-> 鑄幣稅效率")
for pi in [0.05, 0.20, 0.50, 2.0]:
    real_money = 2.718 ** (-alpha * pi)   # M/P = e^(-alpha*pi) 簡化
    seigniorage = real_money * pi         # 鑄幣稅 ∝ 需求 × 成長率
    print(f"  月通膨 {pi:>4.0%} -> 貨幣需求 {real_money:6.3f} -> 鑄幣稅效率 {seigniorage:5.3f}")

輸出：

月通膨    5% -> 貨幣需求  0.224 -> 鑄幣稅效率 0.011
月通膨   20% -> 貨幣需求  0.002 -> 鑄幣稅效率 0.000
月通膨   50% -> 貨幣需求  0.000 -> 鑄幣稅效率 0.000
月通膨  200% -> 貨幣需求  0.000 -> 鑄幣稅效率 0.000

（通膨越高 → 人們棄用貨幣 → 鑄幣稅崩潰—— 印鈔機的物理極限：財政靠印鈔，印鈔自我毀滅。）

第四條線索：Rentenmark 的穩定（1923.11，如何止血）

  • 新貨幣（Rentenmark）：以土地抵押（信譽的重建）；
  • 魯爾妥協（1923.9）：停止消極抵抗 → 財政赤字歸零—— Sargent（1982）的結論：穩定靠財政改革 + 信用重建， 不是貨幣技術——「貨幣改革」是財政改革的結果。

結案 -- 後果與影響

  • 中產階級的毀滅：存款歸零 → 德國社會的極化（納粹的土壤之一）；
  • 超通膨理論的誕生：Cagan（1956）→ Sargent（1982，諾貝爾獎）—— 超通膨 = 財政問題——MMT 爭論的臨床警告；
  • 央行獨立性的種子：魏瑪的教訓 → 1948 德國聯邦銀行的強烈反通膨文化—— 歐元區的「通膨恐懼」DNA（見 1999-歐元誕生.md）；
  • 指數化與替代貨幣：1923 年以物易物、外幣流通—— 貨幣替代（currency substitution）——美元化、穩定幣的歷史原型；
  • 偵探教訓：1923 年證明了——通膨的終極原因在財政（赤字融資）， 印鈔只是工具——「超通膨是財政的死亡，貨幣只是陪葬」。

關鍵人物與文獻

  • Rudolf Havenstein（帝國銀行總裁）：印鈔的執行者。
  • Philip Cagan（1956）：超通膨的貨幣動態模型。
  • Thomas Sargent（1982）：《The Ends of Four Big Inflations》——財政改革的結論（2011 諾貝爾獎）。
