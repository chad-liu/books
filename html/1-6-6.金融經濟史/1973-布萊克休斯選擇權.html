金融經濟史・公元 1973 年

1973 - 布萊克–休斯選擇權定價（衍生品革命：把「風險」算成價格）

案件摘要

1973 年 5 月，Fischer Black 與 Myron Scholes 發表 〈The Pricing of Options and Corporate Liabilities〉——BSM 公式； 同年 4 月芝加哥選擇權交易所（CBOE）開張：

$$\text{選擇權（議價、無理論）} \xrightarrow{\text{BSM 公式（閉式解）}} \text{衍生品的工業化}$$
$$C = S\,N(d_1) - K e^{-rT} N(d_2)$$

風險第一次有了「公式價格」——衍生品市場從零到 名目本金 $600+ 兆（2020s）——金融史上最大的理論-實務合流—— 1997 年諾貝爾獎（Scholes、Merton）。

前因 -- 為什麼會有這個案子

  • 選擇權的古老：希臘已有選擇權（Thales 的橄欖油榨機）—— 但沒有定價理論——買賣靠直覺；
  • 1971 年黃金窗口關閉（見 1971-尼克森震撼.md）→ 匯率與利率波動 → 避險需求爆發——CBOE 的成立動機；
  • 理論的積累：Bachelier（1900，布朗運動）、Samuelson（1960s）—— 隨機過程的數學已成熟；
  • Black 的路徑：MIT 的應用數學家 → Treynor 的資本資產定價 → 「用動態避險消除風險」的關鍵洞察。

線索與推理 -- 數學式、程式、理論

第一條線索：BSM 公式（衍生品的聖杯）

$$C = S\,N(d_1) - K e^{-rT} N(d_2)$$
$$d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}$$
  • $S$ ：標的價格； $K$ ：履約價； $T$ ：期限； $\sigma$ ：波動率；
  • 五個輸入 → 一個價格——定價的工業化；
  • 偵推：公式的前提是幾何布朗運動：
$$dS = \mu S\, dt + \sigma S\, dW$$

——價格 = 隨機漫步（Bachelier 1900 的遠祖）。

第二條線索：風險中性定價（無套利的哲學）

動態避險（delta hedging）：持有一單位買權，賣出 $\Delta$ 股標的—— 風險互相抵消 → 組合 = 無風險 → 報酬 = 無風險利率：

$$\Delta = N(d_1) \quad (\text{避險比率，每單位買權賣 }\Delta\text{ 股})$$
  • 偵推：「無套利」取代「效用」——不需要知道投資人的風險偏好， 只要沒有套利機會，價格就唯一確定—— 金融工程的方法論革命（後來的所有衍生品定價都是「無套利」框架）。

第三條線索：Python——BSM 定價實例

import math

def bs_call(S, K, r, T, sigma):
    d1 = (math.log(S/K) + (r + sigma**2/2)*T) / (sigma*math.sqrt(T))
    d2 = d1 - sigma*math.sqrt(T)
    N = lambda x: 0.5*(1 + math.erf(x/math.sqrt(2)))   # 常態 CDF
    return S*N(d1) - K*math.exp(-r*T)*N(d2)

S, K, r, T, sigma = 100, 100, 0.05, 0.5, 0.20
print(f"買權價格 = {bs_call(S,K,r,T,sigma):.2f}")
print(f"賣權價格 = {bs_call(S,K,r,T,sigma) - S + K*math.exp(-r*T):.2f}")  # put-call parity

輸出：

買權價格 = 6.89
賣權價格 = 4.42

（五個參數 → 唯一價格——風險被公式化了。）

第四條線索：希臘字母（風險的拆解）

希臘字母定義用途
Δ (delta)$\partial C/\partial S$避險比率
Γ (gamma)$\partial^2 C/\partial S^2$避險的再平衡頻率
Θ (theta)$\partial C/\partial t$時間價值衰減
V (vega)$\partial C/\partial \sigma$波動率風險
  • 偵推：Greeks = 風險的「座標系」——每一種風險都有名字與價格—— 風險管理的工業化。

結案 -- 後果與影響

  • 衍生品市場的爆發：CBOE（1973）→ 全球衍生品名目本金 $600+ 兆（2020s）——風險的商品化；
  • 1997 諾貝爾獎：Scholes、Merton——理論的加冕—— 1998 年 LTCM 崩潰（見 1998-LTCM崩潰.md）——理論的極限；
  • 金融工程的誕生：無套利框架 → 所有衍生品定價（Swaption、CDS、 CDO，見 2008-全球金融海嘯.md）——工程師進入華爾街；
  • 波動率微笑：實證發現 σ 不是常數（1987 後）—— 模型的缺陷——隨機波動率模型（Heston）的誕生；
  • 偵探教訓：1973 年證明了——「無套利」是比「均衡」更強的定價原理—— BSM = 金融的麥克斯韋方程（三個世紀的隨機數學匯於一條公式）。
