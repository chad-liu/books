金融經濟史・公元 1848 年

1848 - 芝加哥期貨交易所（標準化期貨：把「風險」變成可交易的商品）

案件摘要

1848 年，82 位芝加哥商人成立芝加哥期貨交易所（CBOT）—— 1865 年標準化期貨契約（數量、品質、交割日、保證金）：

$$\text{遠期合約（一對一議價）} \xrightarrow{\text{標準化 + 結算所 + 保證金}} \text{期貨（可交易的風險）}$$

風險第一次被拆成商品：避險者（農民）與投機者（承擔風險者）的市場—— 衍生品革命的起點——1973 年 CBOE（見 1973-布萊克休斯選擇權.md） 與 2008 年的 CDO 都是它的後代。

前因 -- 為什麼會有這個案子

  • 芝加哥的地理：五大湖 + 鐵路 + 糧倉——農產品的集散地—— 價格波動讓農民與商人無法規劃；
  • 遠期合約的缺陷：一對一議價、無標準、違約風險—— 沒有第三方擔保；
  • 1848 的成立動機：把穀物交易集中化、標準化—— 先解決品質分級，1865 年才標準化契約與保證金；
  • 偵推：CBOT 的誕生 = 市場基礎設施（規格、結算、保證金）的發明—— 交易成本的下降 = 市場的誕生（Coase 的交易成本理論的先聲）。

線索與推理 -- 數學式、程式、理論

第一條線索：期貨的定價（持有成本模型）

期貨價格 = 現貨價格 + 持有成本（利息 + 倉儲 - 收益）：

$$F = S \,(1 + r - y)^T \quad (\text{r：利率，y：持有收益，T：期限})$$
  • 順價差（contango）：F > S（正常）；逆價差（backwardation）：F < S（短缺時）；
  • 基差（basis）： $B = S - F$ ——避險者的殘餘風險—— 避險 = 把價格風險換成基差風險。

第二條線索：保證金與每日結算（風險管理的發明）

1865 年 CBOT 引入保證金（margin）+ 每日結算（mark-to-market）：

$$\text{每日損益} = (F_t - F_{t-1}) \times N \quad \text{（即時轉帳，違約風險歸零）}$$
  • 偵推：每日結算 = 把「未來的違約」變成「今天的現金」—— 結算所 = 所有交易者的對手方（中心化擔保）—— 這個設計 130 年後被繞過（2008 年的 OTC CDS，見 2008-全球金融海嘯.md） ——教訓重演。

第三條線索：避險與投機的共生（風險的市場化）

角色動機位置
農民（空頭避險）鎖定賣價賣期貨
磨坊主（多頭避險）鎖定買價買期貨
投機者承擔價格風險換利潤吸納風險
  • 偵推：投機者是避險市場的必要條件——沒有投機者， 避險者找不到對手——投機 = 風險的流動性提供者。

第四條線索：Python——期貨避險的基差（農民的算術）

S, F = 500, 505          # 現貨 500、期貨 505（cents/bushel）
N = 10_000               # 避險量 10,000 蒲式耳
# 三個月後：現貨跌到 470，期貨跌到 476
S2, F2 = 470, 476
spot_loss = (S2 - S) * N          # 現貨端損失
futures_gain = (F - F2) * N       # 期貨端獲利
print(f"現貨損失: {-spot_loss:,}  期貨獲利: {futures_gain:,}")
print(f"淨結果: {(spot_loss + futures_gain):,}（基差從 -5 收斂到 -6）")

輸出：

現貨損失: 300,000  期貨獲利: 290,000
淨結果: -10,000（基差從 -5 收斂到 -6）

（避險 = 把 30 美分的價格風險換成 1 美分的基差風險—— 風險沒有消失，是被縮小並轉移了。）

結案 -- 後果與影響

  • 衍生品市場的家譜：CBOT（1848 穀物）→ CME（1898 肉類） → 金融期貨（1972 外匯、1977 國債）→ CBOE（1973 選擇權）—— 風險商品化的 150 年；
  • 結算所 = 風險管理的心臟：每日結算 + 中心化擔保—— 2008 年 OTC 衍生品沒有結算所 → AIG 危機—— 教訓重演（Dodd-Frank 強制中央結算，2010）；
  • 芝加哥的金融中心地位：從糧倉到衍生品之都—— 地理 + 基礎設施 = 金融中心的配方；
  • 偵探教訓：1848 年證明了——風險本身可以成為商品， 但前提是「標準化 + 結算 + 保證金」的基礎設施—— 沒有基礎設施的衍生品 = 未爆彈。
