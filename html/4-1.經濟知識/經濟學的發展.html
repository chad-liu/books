三最重要的「五次革命」

如果要快速掌握經濟學史，我會把它濃縮成五個巨大轉折：

① 斯密革命：從「國家財富」到「市場與分工」

亞當・斯密把經濟問題從「國王如何累積財富」轉向：

人們如何透過分工、交換與市場形成繁榮？

核心：

分工 → 生產力 → 交換 → 市場 → 財富

② 邊際革命：從「勞動價值」到「邊際效用」

1870年代出現重大轉變。

核心問題：

一件商品為什麼有價值？

新古典傳統開始使用：

邊際效用 → 需求 → 價格 → 均衡

經濟學也因此逐漸數學化。

③ 凱因斯革命：從「市場均衡」到「總體失衡」

1929年大恐慌之後，問題變成：

如果市場不能自動恢復充分就業，政府應該做什麼？

凱因斯將焦點放在：

有效需求 → 投資 → 就業 → 所得 → 消費

於是現代總體經濟學（Macroeconomics）形成。

④ 賽局與資訊革命：從「單一市場」到「策略互動」

傳統模型常假定：

個人獨立做決策。

賽局理論則問：

如果我的選擇取決於你的選擇呢？

例如：

由此發展出：

寡占 → 賽局理論 → 策略行為 → 機制設計

而資訊經濟學進一步問：

如果雙方掌握的資訊不同呢？

⑤ 行為與因果革命：從「理性人」到「真實的人」

傳統經濟學常以理性選擇作為基礎。

行為經濟學則發現，人會受到：

  • 認知偏誤
  • 損失厭惡
  • 框架效應
  • 過度自信
  • 現時偏誤
  • 社會規範

影響。

而現代實證經濟學則進一步問：

X 到底有沒有造成 Y？

因此：

計量經濟學 → 自然實驗 → 隨機實驗 → 因果推論 → 大數據

成為21世紀經濟研究的重要方法。
