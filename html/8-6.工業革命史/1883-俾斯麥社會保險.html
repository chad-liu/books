工業革命史・公元 1883 年

1883-俾斯麥社會保險：鎮壓、收買與官僚化的多因案件

案件摘要

俾斯麥社會保險沒有單一兇手，它是反社會主義鎮壓、工業化工伤危機與容克官僚國家能力三者咬合的產物。此制度以強制納保大幅降低了勞工疾病與老年的不確定性成本（預防性儲蓄與社會動盪成本），卻開啟了國家干預勞動市場的福利國家之路。

前因 -- 多因素的局勢

  • 政治：1878年《反社會主義非常法》鎮壓社民黨（SPD）卻適得其反，SPD選票1884年翻倍，俾斯麥改採「胡蘿蔔加大棒」。
  • 經濟：德國重工業化工伤率飆升，礦工、鐵路工人疾病與殘廢使勞動力折損，雇主自辦互助金（Knappschaften）已不堪負荷。
  • 法律：普通法侵權救濟舉證困難，工人勝訴率低，慈善與教會救濟碎片化，亟需公法強制框架。
  • 金融：疾病基金已有互助基礎，精算與薪資扣繳技術成熟，使按工資比例繳費具備可行性。
  • 技術：俾斯麥1881年《帝國諭令》提出國家責任，文官體系可將保費徵收嵌入工廠薪資冊。
  • 心理：工人要保障而非施捨，中產恐懼革命，容克貴族恐懼議會民主擴張，三方恐懼促成妥協。

線索與推理 -- 因素咬合

線索1：負反饋立法 -- 用福利撲滅革命

俾斯麥的控制論直覺即社會立法的負反饋：以國家給付抵銷社會主義訴求。

$$\text{鎮壓失效} \to \text{強制保險給付} \to \text{工人依附國家} \to \text{SPD號召力下降（預期）} \to \text{帝國正當性回升}$$
法案年份財源給付
疾病保險法1883工人2/3＋雇主1/313週病假給付＋醫療
工伤事故保險法1884雇主全額＋行業協會醫療＋傷殘年金
老年殘廢保險法1889工人＋雇主＋國家補貼70歲年金＋殘廢年金

諷刺的是 SPD 仍持續壯大（1912年成第一大黨），負反饋未撲滅對手，卻永久改變了國家角色。

線索2：風險池的數學 -- 強制解決逆選擇

自願互助保險必陷逆選擇：健康者退出、病者留下導致保費螺旋。強制納保以法律打破此循環：

$$\text{強制投保} \to \text{大數法則生效} \to \text{平均保費下降} \to \text{給付可持續} \to \text{預防性儲蓄需求下降}$$

以疾病保險為例，1885年即納保約 460 萬工人（約從業人口 1/4），風險池一夜做大，行政成本被攤薄。這是國家降低交易成本的經典案例：用強制克服市場失靈。

線索3：雇主連帶 -- 行業協會的誘因設計

1884年工伤法創設行業事故協會（Berufsgenossenschaften），雇主按風險等級繳費，費率高低與本廠事故率掛鉤：

$$\text{費率與事故掛鉤} \to \text{雇主投資安全設備} \to \text{事故率下降} \to \text{整體費率下降}$$

此為早期經驗費率（experience rating），將外部性內部化，比單純懲罰性賠償更能預防事故，德國鋼鐵業事故率在1890年代顯著下降。

線索4：國家父權的代價 -- 道德風險與官僚化

保障亦滋生道德風險：小病請假、提前殘退誘因上升。俾斯麥以嚴格醫師審查、給付上限與等待期應對，代價是龐大官僚體系。簡化邏輯可用 pseudocode 理解：

if 工人請假 > 3天: 需官方醫師證明
if 年金申請: 審查繳費年資 + 殘廢等級
給付 = 基本率 * 工資等級 - 國家補貼審核

福利換馴服：工人獲得保障，卻被納入國家登記、分類與監控，工會自主互助空間被擠壓。

破案時刻

  • 1881-11：威廉一世《帝國諭令》，宣告國家負起工人保障責任。
  • 1883-06-15：疾病保險法通過，日薪工人強制納保。
  • 1884-07-06：工伤事故保險法通過，雇主責任原則確立。
  • 1889-06-22：老年與殘廢保險法通過，70歲起領年金（當時平均壽命僅約 45 歲）。
  • 1890：俾斯麥下台，《反社會主義法》廢止，但三法保留並成各國模仿範本。

後果 -- 改變了什麼

  • 制度：開創俾斯麥模式（社會保險型）福利國家，與貝佛里奇模式（稅收普惠型）並立，英（1908年金、1911年國民保險）、法、日相繼仿效。
  • 經濟：降低勞工生命週期風險，促進人力資本投資與城市化定居，罷工暴力烈度下降。
  • 技術：精算、社會統計、職業醫學大發展，疾病分類與工伤鑑定標準化。
  • 世界：1919年國際勞工組織（ILO）將社會保險列為核心勞工標準，1948年《世界人權宣言》確認社會保障權。
  • 教訓：負反饋維穩可能失靈（SPD 未被削弱），但制度一旦建立即具路徑依賴，給付只升難降。

因素影響筆記

  1. 鎮壓失效 → 改用收買策略 → 三法相繼出台 → 福利國家路徑鎖定。
  2. 工業工伤危機 → 雇主互助破產 → 國家強制＋行業協會 → 風險成本社會化。
  3. 強制納保 → 逆選擇消除 → 大池精算可行 → 保費可負擔。
  4. 經驗費率設計 → 雇主預防誘因 → 事故率下降 → 制度財政可持續。
  5. 官僚審查 → 道德風險受控 → 國家監控擴張 → 工人依附國家加深。
