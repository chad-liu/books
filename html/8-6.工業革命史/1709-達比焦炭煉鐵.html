工業革命史・公元 1709 年

1709-達比焦炭煉鐵：木炭危機、科爾布魯克谷與廉價鐵的第一案

案件摘要

1709 年，什羅普郡科爾布魯克谷（Coalbrookdale）的亞伯拉罕・達比一世（Abraham Darby I）用焦炭（coke）成功冶煉生鐵——此前煉鐵全靠木炭，英格蘭森林為鐵爐砍到「木材荒」，鐵價高企、產量卡死。達比把煤乾餾成焦炭替代木炭，看似一次燃料替換，實則是工業革命的「第一塊倒下的骨牌」：沒有廉價焦炭鐵，就沒有後來的攪拌法熟鐵、便宜鐵軌與蒸汽機汽缸。本案偵破的問題是：為什麼偏偏是 1709、偏偏是一個貴格會鍋具商人，解開了困擾全歐兩百年的燃料結？

前因 -- 多因素的局勢

  • 能源：17 世紀英格蘭木炭價格三十年漲三倍，海軍造艦、家庭取暖、鐵爐搶木材；詹姆斯一世 1612 年起多次下詔限制砍伐， Dud Dudley 1620 年代以煤煉鐵實驗失敗收場——煤含硫，煉出的鐵又脆又劣。
  • 經濟：英國鐵高度依賴瑞典、俄羅斯進口（年逾萬噸），戰時波羅的海一封鎖就斷料；鍋具、汽缸、農具需求上升，本土產能跟不上。
  • 技術：焦炭乾餾（隔絕空氣加熱煤、驅除揮發分與部分硫）已在釀酒、麥芽烘乾行之有年；達比把這套「烤」的技術轉用到鼓風爐。
  • 材料：什羅普煤含硫相對低、適於煉焦；科爾布魯克谷近煤又近鐵礦，水力鼓風充足。
  • 金融與組織：達比是貴格會（Quaker）商人網絡一員——教友間的信用借貸與技術互通（後來的威爾金森、雷諾茲皆屬此網），使其能承擔七年虧損的實驗期。
  • 勞動力：鑄鍋鑄釜屬薄壁鑄件，達比先從砂模鑄鍋切入（1708 年砂模專利），不直接挑戰鍛鐵條市場，迂迴包抄。

線索與推理 -- 因素咬合

線索1：木炭的天花板

木炭的能量密度與供應皆受限於林地再生速度：

$$\text{生鐵成本} = \text{礦石} + \text{燃料} \times \text{單耗} + \text{運費}$$
燃料單耗（噸燃料/噸鐵）供應彈性含硫成鐵品質
木炭2–3極低（靠林地）低優
原煤直煉2高高（脆）劣
焦炭1.5–2高（靠煤礦）中低可用（鑄造優、鍛造待改良）

推理：達比的勝利不在「更便宜的熱」，而在「供應彈性無限的熱」——煤礦不像林地需要三十年生長，產量可隨需求放大，這正是後續一切規模化的前提。

線索2：為什麼硫是兇手、焦炭是解藥

煤中硫進入鐵水形成硫化鐵（FeS），晶界脆化，鍛打即裂。焦炭化工序驅除約一半以上硫與揮發分，剩餘靠爐溫與爐渣配比容忍——達比 1709 年的鐵仍只適於鑄造（鍋、汽缸、橋件），不適鍛打；直到 1784 年考特攪拌法，才把焦炭生鐵變成可鍛熟鐵。這是「半成品革命」：先解決鑄鐵，再等七十年解決鍛鐵。

$$\text{原煤} \xrightarrow{\text{乾餾脫揮發分}} \text{焦炭} \to \text{鼓風爐鑄鐵} \xrightarrow{1784\,\text{攪拌法}} \text{可鍛熟鐵} \to \text{鐵軌與機器}$$

線索3：砂模鑄鍋的商業迂迴

達比 1708 年先取砂模鑄造專利，大量生產薄壁生鐵鍋——鑄鐵鍋比黃銅鍋便宜一半，農村家家要買。鑄鍋利潤養活煉焦實驗，產量從 1709 年的年產數十噸，爬到 1750 年代子孫輩的年產逾千噸。這是誘致性創新的商業版：用下游現金流餵上游研發。

利潤(鑄鍋) -> 補貼(焦炭爐實驗) -> 產量↑ -> 成本↓ -> 更多鑄件訂單（汽缸、鐵橋）

破案時刻

  • 1709-01：科爾布魯克谷第一爐焦炭鐵水流出，鑄成鍋具出售獲利。
  • 1720–1750：達比二世改良鼓風、擴爐膛，焦炭鐵成本逼近木炭鐵。
  • 1779：達比三世以焦炭鐵建成世界第一座鐵橋（Ironbridge），向全歐宣告「鐵的時代燃料已換」。
  • 1784：考特攪拌法接力，焦炭生鐵終成可鍛熟鐵，鐵價崩跌開始。

後果 -- 改變了什麼

  • 技術：鼓風爐擺脫林地束縛，可建於煤田旁；鐵產量 1700–1800 年成長逾十倍，為蒸汽機汽缸、鐵軌提供材料前提。
  • 經濟：進口鐵依賴下降，鍋具、農具、機械價格下跌，農村購買力釋放。
  • 社會：科爾布魯克谷成為工程師搖籃（威爾金森鏜床、特里維西克機車皆與此地緣相關），貴格會工業家階層崛起。
  • 世界：法國、普魯士直到 19 世紀中葉仍半靠木炭，燃料路徑差構成英法工業落差的第一因之一。
  • 教訓：革命的第一步常常是「難吃的半成品」（只能鑄不能鍛的焦炭鐵）——先讓新路徑活下去，再等互補技術把它變全。

因素影響筆記

  1. 木材荒＋進口依賴 → 燃料替代懸賞 → 達比以焦炭應標。
  2. 乾餾脫硫＋什羅普低硫煤 → 脆鐵變可用鑄鐵 → 半成品先行。
  3. 砂模鑄鍋利潤 → 研發長跑的現金流 → 產量爬坡。
  4. 貴格會信用網 → 容忍虧損的資本 → 家族三代接力。
  5. 鑄鐵先行＋攪拌法後至 → 燃料革命分兩段完成 → 鐵價崩跌。
