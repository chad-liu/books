工業革命史・公元 2015 年

2015-以太坊與智慧契約：圖靈完備區塊鏈、ICO與DAO事件的多因案件

案件摘要

2015 年以太坊上線沒有單一兇手，它是比特幣腳本受限、群眾募資需求與密碼龐克信任危機三者咬合的產物。此案以「程式即契約」大幅降低了募資與履約的信任中介成本，卻以 DAO 被駭、ICO 詐騙為學費，留下了契約自動執行究竟能否取代法律的永恆辯題。

前因 -- 多因素的局勢

  • 經濟：2008 後青年對銀行不信任，2009-2013 比特幣漲百倍證明去中心資產有價，創投追逐下一敘事。
  • 政治：塞普勒斯 2013 存戶減記、史諾登 2013 揭監控，避審查貨幣政治正確；各國對幣圈尚無明確禁令，窗口期存在。
  • 法律：群眾募資（美國 JOBS 法 2012）鬆綁小額融資，Howey 測試對代幣是否證券尚模糊，套利空間巨大。
  • 金融：比特幣 2013 門頭溝（Mt. Gox）丟 85 萬幣，證明「去中心幣、中心化所」脆弱；智能合約可代管之需求浮現。
  • 技術：Buterin 2013 白皮書指比特幣腳本非圖靈完備，Gavin Wood 黃皮書給 EVM，以太幣預售（2014，1800 萬美元）驗證新融資法。
  • 心理：Lessig「程式即法律」（code is law）＋ Szabo 1994 智慧契約舊夢重燃，極客相信數學比法官可靠。
  • 國際：瑞士楚格「加密谷」擁抱基金會模式，中國礦機＋美國 VC＋歐洲開發者三方合流，無國界協作。

線索與推理 -- 因素咬合

線索1：圖靈完備 -- 世界電腦的野心

以太坊虛擬機（EVM）讓任何邏輯皆可上鏈：if-then、循環、狀態儲存，Solidity 讓合約如 App 般撰寫。因果鏈：

$$\text{EVM} + \text{gas 計費} \to \text{停機問題可解(付費即停)} \to \text{DApp 爆發} \to \text{鏈上狀態共識}$$

代價：圖靈完備即漏洞完備，2016 年 DAO 的 reentrancy 攻擊正是無限調用之禍。比特幣派（Maximalist）譏其攻擊面無限擴大，一語成讖又一語未全中。

線索2：ICO -- 新融資的狂歡與濫觴

ERC-20（2015-11）標準化發幣，一紙白皮書＋智慧契約即募資，以太幣 2014 預售成模板：

融資法中介成本/門檻
IPO/VC投行＋律所＋監理高，數月數年
ICO一份合約＋交易所上幣低，數分鐘全球募資
$$\text{發幣零成本} \to \text{2017 ICO 募 60 億美元} \to \text{九成破發詐騙} \to \text{SEC 2017 DAO 報告＋中國九四禁令}$$

Howey 測試回魂：承諾獲利＋他人努力即證券，融資民主化與投資人保護正面撞擊。

線索3：DAO 事件 -- code is law 的審判

2016-04 The DAO 募 1.5 億美元（14% 以太幣），06-17 駭客以遞迴提領盜 6000 萬。社群兩難：

if 堅持 code_is_law:
    駭客所得合法，鏈不可改，信任崩於受害者
else: # 硬分叉追回
    以太坊分裂 ETH/ETC，證明人治高於程式

2016-07-20 硬分叉以 89% 算力通過，ETH 追回、ETC 留守原鏈。Szabo 派哀悼不可竄改之死，Buterin 派辯稱社會共識本即最終層。此即契約主題核心：自動執行省履約成本，卻無從處理不完備契約（Hart-Moore 視角）。

線索4：契約＋創投 -- 信任成本的重定價

Coase 契約理論遇上區塊鏈：當履約可由 EVM 保證，VC 的分期撥款、對賭條款可寫成合約自動觸發，2017-2020 DeFi（MakerDAO 超額抵押、Uniswap 自動做市）即延伸：

$$\text{履約自動} \to \text{中介（託管、清算）成本↓} \to \text{長尾融資可行} \to \text{預言機＋治理攻擊新成本↑}$$

新信任成本轉向程式審計、預言機餵價與治理代幣寡頭——舊中介倒下，新中介（審計公司、基金會多簽）站起。

破案時刻

  • 2013-11：Buterin 發表以太坊白皮書。
  • 2014-07~09：以太幣預售募 3.1 萬 BTC（約 1800 萬美元）。
  • 2015-07-30：Frontier 上線，世界電腦開機；2015-11 ERC-20 提出。
  • 2016-06-17：DAO 被駭 360 萬 ETH；07-20 硬分叉，ETH/ETC 分裂。
  • 2017-07：SEC 發 DAO 報告，代幣可屬證券；09-04 中國禁 ICO。
  • 2017-12~2018：以太幣 1400 美元見頂再崩 90%，DeFi 種子（Maker 2017 上線）萌芽。

後果 -- 改變了什麼

  • 金融：ICO 雖死，STO、IEO、空投系譜留存；DeFi 2020 年鎖倉破百億，證明可程式貨幣有真用例。
  • 市場：以太坊成 Web3 結算層，Gas 費擁堵逼出 Layer2（Arbitrum、Optimism）與 2022 合併（PoS）轉型。
  • 法律：SEC vs Ripple（2020-）、歐盟 MiCA（2023）皆起於 DAO/ICO 教訓：程式不免證券法，code 仍在 law 之下。
  • 世界：瑞士、新加坡奪加密融資樞紐，中國清退挖礦，以太坊開發者全球第一大社群。
  • 教訓：圖靈完備給自由也給災難；不可竄改與糾錯正義不可兼得，分叉即憲法時刻。

因素影響筆記

  1. 比特幣受限＋門頭溝教訓 → 可程式＋去託管需求 → 以太坊白皮書。
  2. EVM＋gas → 世界電腦可行 → DApp 與 ERC-20 爆發。
  3. ICO 低成本融資 → 狂歡＋詐騙 → 證券法（Howey）回歸管轄。
  4. DAO 遞迴漏洞 → code is law 破產 → 硬分叉分裂 ETH/ETC。
  5. 自動履約 → 契約中介成本降 → 新成本轉向審計、預言機與治理 → DeFi 接棒。
