# 台灣的唯識學研究：從印順法師到當代佛教學術

台灣的唯識學研究，可以理解為清末民初中國唯識學復興在戰後台灣的延續與轉型。它一方面承接玄奘、窺基的漢傳法相唯識傳統，另一方面受到印順法師的佛教史觀、現代佛教哲學、梵文研究及大學佛學研究的影響，逐漸形成兼具傳統義理與現代文獻研究的格局。

要理解這段發展，首先要區分兩件事：

* 唯識學的弘揚與修學：透過寺院、佛學院、佛學班與講經活動傳承唯識教理。

* 唯識學的學術研究：以經論原文、翻譯史、思想史、梵文及哲學分析，研究瑜伽行派與漢傳法相唯識。

兩者彼此相關，但研究目的、方法與成果形式並不完全相同。

## 一、台灣唯識學研究的發展階段

1940–50 年代

傳承建立

第一階段：中國佛教學術傳統移入台灣

戰後來台的僧俗佛教學者，帶來近代中國佛教的經論研究與佛教改革思潮。印順法師對印度佛教史、部派佛教、大乘佛教與唯識思想的研究，成為台灣佛教思想界的重要資源。

這個階段的特色，是在弘法、佛學教育與經典研讀中，逐漸建立近代佛教研究的基礎。

1960–80 年代

教育發展

第二階段：佛學教育與專題研究逐漸深化

佛學院、佛教刊物與學術出版持續發展，唯識學逐漸成為佛教哲學與佛教思想史研究的重要課題。學者不只講解八識、三性、三無性，也開始討論新譯唯識、舊譯唯識及印度瑜伽行派的歷史差異。

印順法師對唯識思想的歷史定位與批判性解讀，也成為台灣學界持續討論的議題。

1990 年代

學術制度化

第三階段：大學佛學研究逐漸制度化

台灣的大學佛學研究逐漸形成專業研究與學術出版的制度。國立台灣大學佛學研究中心於 1990 年代開始推動學術活動，其刊物於 1996 年創刊，後於 2006 年更名為《臺大佛學研究》。

唯識學研究也逐漸與印度哲學、佛教文獻學、東亞佛教思想及跨文化哲學比較結合。

2000 年代至今

多元深化

第四階段：原典研究與專題化發展

當代研究更深入分析阿賴耶識、三性、行相、種子、轉依、所知障等概念，也利用梵文、藏譯、漢譯與日本佛教文獻進行比較。

例如佛光大學陳一標教授的研究涵蓋唯識思想、阿賴耶識、三性、梵文與佛學日文；《臺大佛學研究》也曾刊載法相宗「轉依」及唯識學「所知障」等專題研究。

## 二、台灣唯識學研究的重要人物與思想路線

台灣唯識學研究並非只有一條傳承。若從思想史的角度觀察，可以分成三種相互交涉的路線：以印順法師為代表的佛教史與思想批判、承接玄奘系統的法相唯識研究，以及以現代文獻學與哲學分析為主的學術研究。

1. 印順法師（1906–2005）

路線：印度佛教史、唯識思想的歷史定位

印順法師不是單純以復興法相宗為目標的唯識學者，而是從印度佛教發展史出發，考察瑜伽行派的形成、大乘思想的演變，以及唯識學與中觀思想的差異。

他特別重視佛教思想的歷史脈絡，並對新譯唯識、舊譯唯識及不同大乘思想的定位提出自己的判斷。

研究入口可從《印度佛教思想史》及其有關唯識思想的論文著作開始。其早期論文〈抉擇三時教〉與新舊譯唯識相關論辯，也能呈現他如何處理唯識學問題。

2. 陳一標

路線：印度瑜伽行派、梵文與唯識哲學

陳一標是當代台灣唯識學研究的重要學者之一，研究專長包括唯識思想、部派佛教、梵文及佛學日文。

他的研究涉及阿賴耶識的形成與語義、三性說、種子與業、唯識學「行相」等問題，適合用來了解台灣學界如何從原典與思想史的角度研究唯識。

3. 台灣佛教哲學與文獻研究群體

路線：經論考證、概念分析、東亞比較

台灣的唯識研究也分布於大學佛學研究中心、佛教學系所與學術期刊之中。研究者會針對特定術語或論證展開細部分析，而不一定以建立某一宗派的完整教義體系為目標。

例如，《臺大佛學研究》刊載過法相宗「轉依」的概念研究，以及唯識學「所知障」的譯詞、研究史與思想源流分析。

## 四、台灣唯識學研究的六大主題

當代唯識研究往往不是籠統討論「萬法唯識」，而是把教義拆解成可以精確分析的研究問題。

| 研究主題   | 核心問題                    | 建議起點             |
| ------ | ----------------------- | ---------------- |
| 阿賴耶識   | 阿賴耶識如何形成？它與業力、生命相續有何關係？ | 《瑜伽師地論》《解深密經》    |
| 三性與三無性 | 遍計所執、依他起、圓成實如何說明經驗與空性？  | 《解深密經》《唯識三十頌》    |
| 種子與熏習  | 行為、認知及業力如何在心識相續中發生作用？   | 《攝大乘論》《成唯識論》     |
| 行相與認識論 | 認識如何呈現對象？識、所緣與表象如何關聯？   | 《唯識三十頌》及相關注釋     |
| 轉依與修行  | 如何從煩惱與錯誤認識轉向智慧？         | 《成唯識論》           |
| 唯識與中觀  | 唯識如何理解空性？與中觀的立場有何異同？    | 印順法師相關著作及唯識、中觀原典 |

這些題目都能在台灣相關學術研究中找到切入點。例如陳一標對阿賴耶識、三性及行相的研究，以及《臺大佛學研究》對轉依與所知障的專題分析，都顯示台灣唯識學研究具有明顯的原典與概念分析取向。

## 五、印順法師與玄奘系唯識學：台灣研究的一個重要問題

這是理解台灣唯識研究時，特別值得注意的議題。

| 比較面向  | 印順法師的研究取向                | 玄奘系法相唯識的典型研究取向       |
| ----- | ------------------------ | -------------------- |
| 主要關懷  | 印度佛教思想的歷史發展及其演變          | 系統理解法相、唯識的教義架構       |
| 研究方法  | 佛教史、經論比較、思想批判            | 經論疏釋、法相分類、教義辨析       |
| 重要問題  | 唯識思想如何在印度佛教史中形成？與中觀有何差異？ | 八識、三性、種子、轉依如何構成完整體系？ |
| 可能的爭論 | 對不同佛教思想的歷史定位與評價          | 對經論原義、各家注疏及教義體系的詮釋   |

這張表只是呈現研究重心的差異，並不代表兩種路線完全對立。印順法師同樣深入研讀唯識經論；玄奘系研究者也可能採用現代文獻學與思想史方法。

對學習者而言，最好的做法是同時閱讀原典、傳統注疏與現代研究，而不是只選擇一種立場作為唯一標準。

## 六、如果要深入研究，建議怎麼讀？

1

先建立唯識基本概念

先理解八識、阿賴耶識、三性、種子、熏習與轉依，再閱讀較深入的思想史論文。

2

閱讀玄奘系核心論典

以《成唯識論》為重要入口，搭配《唯識三十頌》及相關注釋，掌握漢傳法相唯識的概念體系。

3

加入印度佛教史的視角

閱讀印順法師對瑜伽行派、唯識思想及中觀的分析，理解不同思想在歷史中的形成與變化。

4

追蹤台灣當代學術論文

在《臺大佛學研究》及佛光大學佛教學系等學術資源中，以「阿賴耶識」「三性」「種子」「轉依」「瑜伽行派」等關鍵詞搜尋專題研究。

## 總結

台灣的唯識學研究，從戰後佛教思想傳承與印順法師的佛教史研究，逐步發展到大學佛學研究制度、原典考證與專題化的哲學分析。它並非單純復興某一古代宗派，而是持續探討印度瑜伽行派、玄奘系法相唯識與其他大乘思想之間的關係。

若要掌握台灣唯識學研究的特色，可以先記住三條主線：

* 思想史路線： 印順法師對唯識學在印度佛教史中的定位。

* 法相義理路線： 以玄奘系經論為核心，分析八識、三性、種子與轉依。

* 現代學術路線： 透過梵文、文獻比較、概念分析及學術論文，重新研究唯識思想。

三條路線交互參照，才能比較完整地理解台灣唯識學研究的歷史與現況。
