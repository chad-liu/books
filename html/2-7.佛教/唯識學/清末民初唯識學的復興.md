# 清末民初唯識學的復興

清末民初（約 19 世紀後半至 20 世紀上半葉）的唯識學復興，是近代中國佛教史上一場重要的思想與學術轉型。它不只是古代佛典的重新整理，更是佛教面對西學衝擊、傳統經學轉型、近代教育興起與民族危機時，重新建立自身思想體系的一次努力。

這場復興的核心，是重新發掘印度瑜伽行派與漢傳法相唯識的經典、論書和注疏，尤其重視玄奘、窺基所傳的唯識學系統，並透過刻經、校勘、翻譯、講學及學術研究，使唯識學成為近代佛教研究的重要領域。

## 一、為什麼清末民初會出現唯識學復興？

思想

1. 傳統佛教思想的重新整理

明清以來，漢傳佛教的禪宗、淨土等傳統在修行與弘法方面具有廣泛影響，而法相唯識學的部分重要論典與注疏，則相對缺乏持續、系統性的研究。近代學者希望重新建立對印度佛教思想及玄奘唯識學的完整理解。

文獻

2. 古籍、刻經與藏經整理

楊仁山等人推動佛典搜集、刊刻與流通，使一些不易取得的佛教論典及注疏重新進入學界視野。文獻的整理與流通，是唯識學復興的重要基礎。

時代

3. 西學傳入與近代思想競爭

西方哲學、心理學、邏輯學與科學觀念進入中國知識界，促使部分佛教學者重新思考心識、認識、主體、經驗與世界的關係。唯識學因其對認知過程與心識結構的細緻分析，成為近代思想家特別關注的佛學傳統。

教育

4. 新式佛教教育與學術研究興起

佛學社、研究會、佛學院與近代大學逐漸發展，佛教研究不再只依賴寺院傳承，也開始採用版本校勘、語文訓練、哲學比較及歷史研究等方法。

需要注意：唯識學在明清時期並非完全中斷。清末民初的「復興」，更準確地說，是重新整理文獻、恢復系統研究、建立近代學術傳承，並提升唯識學在思想界的能見度。

楊仁山創辦金陵刻經處

## 五、復興的思想核心：重新理解玄奘唯識學

唯識學復興並非只是把古籍重新印刷，而是重新研究一套完整的佛教認識論與修行理論。

### 1. 八識與阿賴耶識

唯識學通常以八識說明心識活動：

| 心識     | 基本功能              |
| ------ | ----------------- |
| 前五識    | 眼、耳、鼻、舌、身等感官認識    |
| 第六意識   | 思考、判斷、概念分析        |
| 第七末那識  | 持續執取自我，與我執密切相關    |
| 第八阿賴耶識 | 執持種子，說明業力、經驗與生命相續 |

近代研究者透過重新整理《瑜伽師地論》《成唯識論》等文獻，探討心識如何形成經驗、執取如何產生，以及修行如何轉化心識。

### 2. 萬法唯識與認識問題

「唯識」不是簡單地說「世界不存在，只有我的思想存在」。

其主要問題是：我們所經驗的對象，如何透過識的活動而呈現？認識者、所認識的對象與認識過程之間，有什麼關係？

這些問題使唯識學能與近代哲學、心理學及認識論展開比較，但不應直接把唯識等同於西方唯心論或現代心理學。

### 3. 種子、熏習與業力

唯識學以「種子」與「熏習」解釋經驗、行為與心識習慣如何形成延續性的作用。

* 種子：具有產生相應心理或經驗活動的潛在功能。

* 熏習：行為、認識與經驗對心識相續所留下的影響。

* 業力：有意志的行為及其因果作用。

* 修行轉化：透過戒、定、慧及相關修行，改變煩惱與錯誤認識的作用。

這套理論使唯識學成為近代學者重新探討心識、因果與人格轉化的重要思想資源。

## 六、復興的重要經典與論書

| 經典或論書      | 重要性                                |
| ---------- | ---------------------------------- |
| 《解深密經》     | 闡述唯識思想、三性、三無自性及瑜伽行派的重要教義           |
| 《瑜伽師地論》    | 瑜伽行派的重要綜合性論典，涵蓋修行、心識、菩薩道等內容        |
| 《唯識三十頌》    | 世親的重要著作，是後世唯識學研究的核心論書之一            |
| 《成唯識論》     | 玄奘譯場以護法等論師的思想為重要依據，糅譯整合而成的漢傳唯識核心論典 |
| 《攝大乘論》     | 系統闡述阿賴耶識、種子、唯識與菩薩道等思想              |
| 《大乘阿毘達磨集論》 | 探討心識、心所、修行及佛教法相分類                  |
| 《因明入正理論》   | 研究印度佛教邏輯、推理與論證的重要著作                |

其中，《成唯識論》與《瑜伽師地論》是理解近代漢傳唯識研究的兩個重要入口；若要深入印度瑜伽行派的思想源流，還應進一步閱讀《解深密經》《唯識三十頌》及《攝大乘論》。

## 七、唯識學復興中的重要思想爭論

### 1. 復興古代宗派，還是改革現代佛教？

支那內學院重視經論的精密研究，太虛則更積極地推動僧團改革、佛教教育與社會實踐。

兩者並非完全對立：都重視佛教的現代發展，只是在優先目標與實踐路線上有所不同。

### 2. 唯識學與其他大乘思想如何會通？

唯識、中觀、如來藏與華嚴等傳統，對心識、空性、佛性與成佛之道有不同的理論表述。

近代學者必須重新回答：這些思想是否能整合？若可以，應如何整合？若存在矛盾，又應如何理解？

這些問題不只是宗派之間的辯論，也推動了近代佛教哲學與思想史研究。

### 3. 佛教經論應如何研究？

近代唯識學復興的一個重要特徵，是逐漸重視版本、譯本、論師立場與思想形成的歷史脈絡，而不只依循既有宗派的解釋。

這使佛學研究逐步形成一種結合傳統義理與近代文獻學的學術方法。

## 八、唯識學復興的歷史意義

可以從四個層面總結：

1. 文獻層面： 重新搜集、刊刻與整理古代唯識經論及唐代注疏。

2. 教育層面： 建立專門研究機構，培養具備經論研究能力的佛學人才。

3. 思想層面： 使心識、認識、因果與修行轉化等問題重新成為近代思想界的重要議題。

4. 學術層面： 推動佛教研究由傳統講學進一步走向版本考證、思想史研究與跨文化比較。

不過，近代中國佛教的復興並不只有唯識學一條路線。華嚴學的重新受到重視、太虛推動的佛教改革，以及後來的人間佛教等，同樣構成這段歷史的重要部分。

第五階段：思想比較與現代研究

唯識與中觀、華嚴、如來藏，以及近代哲學的比較

一句話總結： 清末民初唯識學的復興，是以楊仁山的經典整理為基礎，以歐陽竟無及支那內學院、韓清淨及三時學會的研究為重要支柱，將玄奘系唯識學重新帶入近代中國的學術與思想舞台。

如果要深入理解這段歷史，最值得接著研究的題目是：「楊仁山、歐陽竟無、呂澂、韓清淨、太虛五人的佛學思想比較」，因為這能看出近代佛教如何在保存傳統、重建學術與回應現代社會之間，尋找新的方向。
