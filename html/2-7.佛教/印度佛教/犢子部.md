# 犢子部（Vātsīputrīya）——「無我」之下，誰在輪迴？誰承受業果？

如果把前面討論的部派佛教思想串起來：

> 說一切有部：三世諸法皆有。 經量部：法剎那生滅，如何透過因果相續產生果報？ 犢子部：如果沒有永恆的我，那麼究竟是誰在輪迴、造業與受報？

犢子部是部派佛教中非常值得研究的一個學派。它最著名的特色，是提出一種特殊的「補特伽羅」理論，試圖在佛教的無我思想與業果相續之間，建立合理的解釋。

這也讓它成為理解佛教「無我」爭論的一個重要節點。

## 一、什麼是犢子部？

梵文：Vātsīputrīya；巴利文相關名稱：Vajjiputtaka 傳統

犢子部是早期部派佛教的一支，傳統上被視為從說一切有部系統分出的部派之一。它與後來的正量部（Saṃmatīya）具有重要的傳承關係。

名稱「犢子」是部派名稱的音義傳承，不能單憑中文字面理解為與牛有關的教義。

犢子部最重要的思想主張是：

> 有「補特伽羅」（pudgala），但這個補特伽羅既不能簡單等同於五蘊，也不能完全說成與五蘊毫無關係。

這個主張被稱為「補特伽羅論」，也讓犢子部在其他佛教學派的批判中，經常被視為一個特殊的思想案例。

要注意：犢子部的原始論書保存並不完整，今天對它的理解，很大程度依靠其他佛教學派的論書記載與批判，因此不宜把所有細節都當成已經完全確定的歷史事實。

## 三、犢子部的核心問題：沒有「我」，誰在承受業果？

這是犢子部最重要的思想出發點。

佛教主張無我，但日常經驗中，我們又會說：

* 我昨天做了一件善事。

* 我今天承受昨天行為的結果。

* 我透過修行，將來可以證得解脫。

* 同一個生命相續，經歷生死輪迴。

於是產生一個哲學問題：

如果根本沒有「我」，那麼造業與受報之間，究竟是什麼在延續？

可以把這個問題拆成三個部分：

問題一：誰在造業？

如果只有五蘊的生滅，是否還需要解釋「行為者」的身分？

問題二：誰在受報？

造業的生命與受報的生命既不是永恆不變，也不是毫無關係，因果如何成立？

問題三：誰在解脫？

如果沒有永恆不變的自我，究竟如何理解一個生命從輪迴走向解脫？

犢子部認為，單靠對五蘊的分類，還需要進一步說明「補特伽羅」在生命相續與業果中的意義。

## 四、什麼是「補特伽羅」（Pudgala）？

梵文：Pudgala，音譯「補特伽羅」，通常可譯為「人」或「個體」。

在一般語言中，我們會說：

* 一個人出生。

* 一個人造業。

* 一個人輪迴。

* 一個人修行。

* 一個人解脫。

但在佛教哲學中，問題在於：這個「人」究竟是什麼？

犢子部認為，補特伽羅不能簡單地化約為五蘊中的某一蘊，也不能被理解為一個完全獨立於五蘊之外的實體。

這是它與其他部派之間爭論的核心。

### 犢子部的特殊立場

五蘊（pañcaskandha）

色、受、想、行、識

不可簡單等同，也不可完全割裂

補特伽羅（pudgala）

作為生命個體、業果相續與解脫的主體來理解

這裡最重要的限定是：

> 犢子部不是直接主張有一個與五蘊毫無關係、永恆不變的靈魂，而是認為補特伽羅與五蘊的關係，不能用簡單的「相同」或「完全不同」來描述。

不過，犢子部究竟如何精確界定補特伽羅的存在方式，歷來有不同解釋；其他部派也正是針對這一點提出批評。

## 五、補特伽羅與「阿特曼」有什麼不同？

這是理解犢子部時最容易混淆的地方。

印度婆羅門—奧義書傳統中，有一個重要概念：

Ātman（阿特曼），通常譯作「我」或「自我」。

部分奧義書思想將阿特曼理解為人的深層本質，並進一步討論它與梵（Brahman）的關係。

犢子部的補特伽羅理論，則是在佛教無我與業果問題的脈絡中提出。

| 比較項目     | 奧義書部分傳統的 Ātman  | 犢子部的 Pudgala   |
| -------- | --------------- | -------------- |
| 思想背景     | 婆羅門—奧義書哲學       | 佛教部派論辯         |
| 核心問題     | 自我的本質、梵我關係      | 無我之下如何理解個體與業果  |
| 與五蘊的關係   | 不能一概而論，依不同奧義書而異 | 不可簡單等同，也不能完全割裂 |
| 是否等於永恆靈魂 | 部分傳統賦予其常住、根本的地位 | 不宜直接等同永恆、獨立的靈魂 |
| 思想焦點     | 自我與終極實在         | 個體、輪迴、業果與解脫    |

結論：不能因為兩者都討論「我」或「個體」，就把犢子部視為重新承認奧義書的阿特曼。

## 六、犢子部如何理解「非一、非異」？

理解犢子部的一個有用方式，是思考「一個人從小到老」這個例子。

假設一個人從童年成長到成年：

* 身體改變了。

* 記憶與知識增加了。

* 心理狀態不斷變化。

* 過去的行為仍可能影響現在。

* 人們仍然會把他視為同一個生命個體。

於是產生兩個極端：

極端 A：完全相同

認為從童年到成年，有一個完全不變的實體始終存在。

極端 B：完全不同

認為童年與成年完全無關，前後沒有任何連續性。

犢子部的補特伽羅論試圖避免把生命個體簡單歸入這兩個極端。

但要特別注意：以上是幫助理解問題的現代化例子，不代表犢子部已用完全相同的方式表述這個例子。

## 七、犢子部與說一切有部：兩種不同的解釋策略

前面介紹過說一切有部，它的核心是「三世實有」與對諸法的精細分類。

犢子部則把注意力放在另一個問題上：在諸法與五蘊的分析之外，應如何理解補特伽羅？

| 問題       | 說一切有部           | 犢子部               |
| -------- | --------------- | ----------------- |
| 主要關注     | 法的分類、三世與因果      | 補特伽羅與業果相續         |
| 分析重心     | 諸法              | 五蘊與補特伽羅的關係        |
| 過去、現在、未來 | 主張三世諸法皆有        | 不能只靠三世實有概括其補特伽羅理論 |
| 業果問題     | 以法的存在、作用及因果理論說明 | 強調補特伽羅在生命相續中的意義   |
| 無我問題     | 不承認永恆的我，建立法的分析  | 主張補特伽羅，但不簡單等同獨立靈魂 |
| 思想爭點     | 法是否具有實在性？       | 補特伽羅是否可以成立？       |

這兩派並不是「一派相信我、一派不相信我」那麼簡單。

真正的分歧是：

> 佛教應該如何描述生命個體，才能同時維持無我、業果與解脫的教義？

## 八、為什麼其他佛教學派批判犢子部？

許多佛教學派認為，犢子部的補特伽羅概念可能產生一個問題：

> 如果補特伽羅既不等於五蘊，也不能完全說成與五蘊不同，那麼它究竟如何存在？

批判者擔心，這種說法可能變相保留一個難以分析的「我」。

犢子部則試圖避免把補特伽羅直接理解為常住靈魂。

因此雙方的爭論，並不只是「有我或無我」的口號之爭，而是對個體、語言、存在與因果的不同分析。

可以整理成：

```
佛教的無我教義
       ↓
業果與輪迴如何成立？
       ↓
犢子部：提出補特伽羅理論
       ↓
其他部派提出質疑
       ↓
補特伽羅究竟如何存在？
       ↓
成為部派佛教的重要哲學爭論
```

## 九、犢子部與經量部：都在處理因果相續，但路線不同

經量部與犢子部都涉及一個共同問題：

> 過去的行為如何與未來的果報連結？

但兩者的解釋重點不同。

### 經量部：以種子與相續說明

行為生起

因果潛能（種子）

相續與條件

未來果報

重點在法的生滅，以及因果潛能如何延續。

### 犢子部：以補特伽羅說明

生命個體

造業與受報

生死相續

修行與解脫

重點在補特伽羅與五蘊、業果及解脫的關係。

這是一種教學上的對照。經量部與犢子部各自的歷史發展、內部主張及論書傳統都更複雜，不能把它們簡化成完全互斥的兩種答案。

## 十、犢子部與正量部的關係

犢子部的思想並非孤立存在。

它與後來的**正量部（Saṃmatīya）**有重要傳承關係。正量部也是印度部派佛教的重要一支，在古代曾有相當影響力。

可以概括為：

```
部派佛教
    │
    ↓
犢子部
    │
    ├── 補特伽羅論
    │
    ↓
正量部等相關傳承
    │
    ↓
延續補特伽羅與業果的論辯
```

不過，部派分化的具體年代、支派關係及各部教義細節，歷來有不同記載，因此這張圖只表示主要思想傳承關係，不代表所有支派的完整系譜。

## 十一、犢子部在漢傳佛教中的文獻線索

由於犢子部自身文獻保存有限，我們對它的認識主要來自其他部派與大乘佛教論書對它的記載、引述和批評。

相關研究可以注意以下幾類文獻：

* 《異部宗輪論》：用於了解部派分化及各部派的傳統宗義。

* 《俱舍論》及相關注釋：可以從部派阿毘達磨論辯中觀察補特伽羅問題。

* 《成唯識論》等大乘論書：可了解後期佛教如何批判或討論補特伽羅相關主張。

閱讀時要區分兩件事：

1. 犢子部自身可能如何理解補特伽羅。

2. 其他學派如何轉述、分類或批評犢子部。

兩者不一定完全一致。

## 十二、犢子部與中觀：都要面對「我」與「法」的問題

犢子部的核心問題是：

> 補特伽羅如何成立？

中觀進一步追問：

> 不只人沒有自性，構成人與世界的諸法，是否也沒有自性？

可以用下列方式區分：

| 思想傳統  | 核心問題         | 主要關注     |
| ----- | ------------ | -------- |
| 說一切有部 | 法如何存在？       | 三世、法體、因果 |
| 經量部   | 法如何生滅並產生後果？  | 剎那、種子、相續 |
| 犢子部   | 個體如何在無我之下成立？ | 補特伽羅、業果  |
| 中觀    | 人與法是否有自性？    | 緣起、空、二諦  |

這並不是說中觀只是針對犢子部而產生，而是說犢子部讓我們看見：佛教內部對「無我究竟意味著什麼」有過非常細緻的討論。

## 十三、犢子部的歷史意義

犢子部最重要的價值，不是它提供了一個所有佛教學派都接受的答案，而是它把一個難題推到檯面上：

若不承認永恆的自我，應該如何理解「同一個人」的行為責任、業果相續與解脫？

它的補特伽羅理論讓佛教哲學不得不更精確地區分：

* 永恆靈魂與生命個體。

* 五蘊與補特伽羅。

* 個體連續性與實體不變性。

* 無我與否定因果。

* 造業者、受報者與修行者之間的關係。

因此，研究犢子部能幫助我們避免一種過度簡化的理解：

> 「佛教說無我，所以根本沒有個體，也不需要解釋業果。」

事實上，無我並不等於否定世俗層面的個體、行為責任與因果關係；真正的爭論在於，這些關係應如何在哲學上成立。
