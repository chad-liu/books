早期上座部是理解部派佛教形成的重要概念。梵語為 Sthavira，巴利語為 Thera，意為「長老」。它指早期佛教僧團分化過程中的一個傳統，後來分出多個部派。

最重要的觀念是：早期上座部不等於今日的南傳上座部佛教（Theravāda）。南傳上座部是上座系統中延續至今的一支，而早期上座部的歷史範圍更廣。

## 一、歷史定位：早期佛教如何分化？

佛陀時代的僧團

共同修行、傳承教法與戒律

佛陀入滅後，僧團逐漸出現不同立場

### 大眾部

Mahāsāṃghika

早期部派傳統之一

### 上座系統

Sthavira

另一早期部派傳統，後續分化出多個部派

上座系統後續發展

說一切有部、犢子部、法藏部、化地部等不同傳統；南傳上座部則是其中延續至今的重要支系。

這是一種方便學習的概念圖，而不是完全確定的歷史家譜。不同部派文獻對分裂原因、年代及分支次序有不同記載。

## 二、為什麼會有「上座部」？

「上座」原指僧團中的長老、資深僧人。後來，它成為部派傳統的名稱。

傳統佛教史通常把早期僧團的分裂與以下問題聯繫起來：

* 戒律問題：僧團應如何遵守與解釋戒律？

* 僧團制度：不同地區的僧團如何維持共同規範？

* 教義詮釋：對佛陀教法、修行境界及諸法性質，應如何理解？

* 論書發展：如何把經典中的教法整理成精細的分類與理論？

不能簡化成「大眾部代表改革、上座部代表保守」。早期分裂的實際原因複雜，而且各部派後來都持續發展教義。

## 三、早期上座部有哪些主要分支？

下表列出常見的部派名稱。不同傳統對分支關係的記載不盡相同。

| 部派    | 梵語／巴利語        | 重要思想或特色                           |
| ----- | ------------- | --------------------------------- |
| 說一切有部 | Sarvāstivāda  | 探討三世諸法的存在、因果與法的分類                 |
| 犢子部   | Vātsīputrīya  | 以補特伽羅（pudgala）問題聞名，探討無我與個體相續      |
| 法藏部   | Dharmaguptaka | 具有自身的律藏與教義傳統，對東亞佛教戒律史尤其重要         |
| 化地部   | Mahīśāsaka    | 具有自身的教義與部派傳承                      |
| 飲光部   | Kāśyapīya     | 早期上座系統中的一支                        |
| 經量部   | Sautrāntika   | 後來論書中重要的思想立場，強調經典依據，並批評說一切有部的若干主張 |
| 南傳上座部 | Theravāda     | 延續至今的上座部傳統，以巴利語三藏為核心經典傳承          |

補充： 經量部與說一切有部的關係尤其複雜。經量部常被視為從說一切有部傳統內部的論辯中發展出來的立場，不宜不加區分地把所有部派都排成一條固定的分裂樹。

## 四、早期上座系統的重要思想發展

早期上座系統並沒有一套所有部派完全相同的教義。不同支派對「法」「無我」「業力」「涅槃」等問題，有各自的分析方式。

### 1. 從經典教法走向阿毘達磨分析

早期佛教經典透過四聖諦、八正道、五蘊、十二處、十八界、十二因緣等架構，說明苦的形成與解脫之道。

後來，一些部派將這些教法進一步分類與系統化，發展出阿毘達磨（Abhidharma）論書。

經典中的修行問題

苦從何來？無我如何理解？業如何產生果報？如何達到涅槃？

阿毘達磨的分析方式

分類諸法、分析心與心所、研究因果條件，建立較精密的教義系統。

### 2. 說一切有部：諸法與三世

說一切有部的一項代表性主張是「三世實有」，即以特定方式承認過去、現在、未來諸法的存在。

它試圖解釋：如果過去的業已經過去，為什麼仍能在未來產生果報？

### 3. 經量部：種子與因果相續

經量部對說一切有部的部分理論提出批評，重視剎那生滅與因果相續，並透過「種子」等概念解釋業力如何產生後果。

### 4. 犢子部：無我與個體相續

犢子部則從另一個方向追問：如果沒有永恆不變的自我，究竟如何理解造業者、受報者，以及修行解脫者？

它提出了「補特伽羅」的特殊理論，但這個概念不能直接等同於婆羅門傳統中的永恆靈魂。

這幾種立場顯示，上座系統內部不是思想單一的團體，而是由不同的教義問題與論辯構成的多元傳統。

## 五、早期上座部與今日南傳上座部的差異

| 比較面向 | 早期上座部         | 今日南傳上座部                  |
| ---- | ------------- | ------------------------ |
| 名稱範圍 | 早期部派分化中的上座系統  | 延續至今的特定佛教傳統              |
| 歷史位置 | 早期印度部派佛教的重要傳統 | 主要傳承於斯里蘭卡、泰國、緬甸、柬埔寨、寮國等地 |
| 部派範圍 | 涉及多個不同支派      | 以 Theravāda 傳統為核心        |
| 主要文獻 | 各部派經、律、論及相關史料 | 以巴利語三藏及其註釋傳統為核心          |
| 思想特色 | 隨各支派而異        | 有自身相對連貫的經典、戒律與修行傳承       |

尤其要避免一種常見誤解：說一切有部不是今日南傳上座部的另一個名稱。兩者是不同的部派傳統，雖然都與早期佛教的傳承及論書發展有關。

## 六、早期上座部在佛教思想史中的位置

早期佛教的共同教法

四聖諦、八正道、緣起、無我、涅槃

部派佛教的多元發展

經典傳承、戒律制度、阿毘達磨與教義辯論

上座系統諸部派

說一切有部、經量部、犢子部、法藏部等

大眾部系統

發展出不同支派與佛陀觀傳統

後續佛教思想史

部派阿毘達磨、南傳上座部、大乘中觀、唯識等多種傳統

這個架構呈現的是佛教思想史的多條發展路線，而不是說所有後來的佛教傳統都由早期上座部直接產生。

## 七、學習速記卡

* 名稱：早期上座部（Sthavira）

* 字義：長老、資深僧人

* 歷史定位：早期佛教分化過程中的重要傳統

* 主要發展：分出多個部派，各自發展經典、戒律與教義

* 重要研究方向：阿毘達磨、諸法分類、業與因果、無我與解脫

* 重要區分：早期上座部 ≠ 今日南傳上座部；上座系統 ≠ 說一切有部

一句話總結： 大眾部與早期上座部是理解部派佛教形成的兩個重要起點；上座系統後來分化出多種思想傳統，其中說一切有部、經量部、犢子部及南傳上座部，各自以不同方式探索佛陀教法中的諸法、因果、無我與解脫問題。
