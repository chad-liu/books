# 東亞密教：從印度密教到中國、韓國與日本

東亞密教是印度佛教密續傳統傳入東亞後，經由翻譯、儀軌傳授、寺院制度與不同地區的文化發展，逐漸形成的佛教傳統。其主要發展中心包括中國、日本與韓國。

理解東亞密教，最重要的是掌握三條脈絡：

1. 印度密教的傳入：咒語、陀羅尼、曼荼羅、灌頂及本尊修法等傳統進入中國。

2. 唐代密教的體系化：善無畏、金剛智與不空等譯師、密教傳承者，促成經典翻譯與儀軌的系統化。

3. 日本密教的宗派化：唐代密教傳入日本後，發展出真言宗與天台密教等傳統，並延續至今。

與藏傳佛教相比，東亞密教主要承接印度中期密教的經典與傳承；藏傳佛教則進一步承接了多種晚期印度密續傳統。這是概括性的區分，兩者並非截然分開的兩種宗教。

### 1. 中國唐密（真言教）

核心時期：唐代

代表人物為善無畏、金剛智、不空。重要經典包括《大日經》與《金剛頂經》系統。

主要特色是曼荼羅、灌頂、真言、手印及護國儀式，並將密教融入中國佛教與帝國宗教生活。唐代密教曾十分興盛，但後來傳承與制度發展有所變化；不能簡單理解成所有密教實踐都完全消失。

### 2. 日本真言宗（東密）

代表人物：空海（774–835）

空海將唐代密教的經典與修行傳承帶回日本，以大日如來、兩部曼荼羅及「三密」修行為重要特色。

三密是：

* 身密：手印與身體儀式。

* 語密：真言、咒語及誦持。

* 意密：觀想與心念修持。

真言宗重視身、語、意與佛的智慧相應，並以即身成佛作為重要教義。

### 3. 日本天台密教（台密）

代表人物：最澄（767–822）及其後繼者

天台密教是在日本天台宗內發展的密教傳統，與真言宗的東密有所區別。

它將密教修法融入天台宗的教義、法華思想及其他佛教實踐。最澄曾向空海學習部分密教內容，但兩人的宗教理想與密教定位並不完全相同；台密的完整發展也經歷了後世多代僧人的努力。

## 三、東亞密教的重要經典

| 經典        | 核心內容             | 歷史地位             |
| --------- | ---------------- | ---------------- |
| 《大日經》     | 大日如來、菩提心、曼荼羅及灌頂  | 唐密與日本密教的重要根本經典   |
| 《金剛頂經》系統  | 金剛界曼荼羅、佛的智慧與密教儀軌 | 真言宗的重要經典系統       |
| 《蘇悉地羯羅經》  | 成就法、真言修持及儀式規範    | 東亞密教儀軌傳統的重要文獻    |
| 《理趣經》     | 清淨智慧、菩薩行及密教思想的詮釋 | 在東亞密教中具有重要地位     |
| 《大悲心陀羅尼經》 | 觀音信仰與大悲咒         | 廣泛影響東亞佛教的誦持與儀式傳統 |

其中，《大悲心陀羅尼經》及大悲咒在漢傳佛教中非常普及，但普遍誦持陀羅尼，不等於所有修持者都在修完整的密教灌頂與本尊瑜伽體系。

## 四、東亞密教與藏傳佛教的比較

| 比較項目   | 東亞密教                       | 藏傳佛教密續傳統                      |
| ------ | -------------------------- | ----------------------------- |
| 主要傳入路線 | 印度 → 中國 → 日本、韓國            | 印度 → 西藏                       |
| 主要發展時期 | 中國唐代，尤其 7 至 9 世紀；日本自 9 世紀起 | 早期傳入始於 7 至 8 世紀，後弘期於 10 世紀後發展 |
| 重要傳統   | 唐密、真言宗、天台密教                | 寧瑪、噶舉、薩迦、格魯等                  |
| 重要修法   | 真言、手印、曼荼羅、灌頂、護摩            | 除相關密教修法外，亦有多種本尊瑜伽及生起、圓滿次第     |
| 哲學背景   | 漢傳大乘、中觀、天台等思想資源            | 印度中觀、瑜伽行派及多種藏傳哲學詮釋            |
| 代表性教義  | 三密、即身成佛                    | 菩提心、空性、密續道次第與本尊修行             |

兩者不是誰比較「高級」的關係，而是承接印度佛教不同時期的傳承，並在不同文化與制度下發展。

## 六、最重要的歷史結論

第一，東亞密教不是中國自行創造的密教，而是以印度佛教密續為重要來源，在中國完成翻譯與體系化後，繼續向日本、韓國傳播。

第二，唐代密教與日本真言宗關係密切，但兩者不能完全畫上等號。真言宗是在日本特定的歷史、寺院與思想環境中形成的宗派。

第三，密教並非只有咒語、祈福或法事。若從佛教思想史研究，還需要理解曼荼羅、三密、灌頂、佛身觀、菩提心及即身成佛等概念。

第四，東亞密教雖然不是漢傳佛教的唯一主流，卻深刻影響佛教造像、寺院儀式、護國法會、陀羅尼誦持，以及日本佛教的思想發展。

建議下一步的學習順序：《大日經》→《金剛頂經》系統→善無畏、金剛智、不空→空海與真言宗→最澄與天台密教→東亞密教與藏傳佛教的比較。
