教學法比較與實務應用

探究式教學與直接教學

從教學理念、優缺點、學科應用到課程設計，理解兩種教學模式的差異，並學習如何依照學生需求靈活結合。

基本概念比較表優缺點教學案例引導式探究三階段設計自我檢核相關理論

一、兩種教學法的基本概念

探究式教學以問題為起點，讓學生透過探索建構理解；直接教學則由教師有系統地講解、示範與安排練習，協助學生掌握知識與技能。

學生主動探索

探究式教學（Inquiry-Based Learning）

學生從問題出發，經過觀察、提問、提出假設、蒐集資料、分析證據與討論，逐步形成解釋或結論。

核心：學生是知識的探索者與建構者。
教師有系統指導

直接教學（Direct Instruction）

教師明確說明學習目標與概念，示範方法，安排引導練習、回饋及獨立練習，協助學生熟練。

核心：教師是知識的組織者與學習的指導者。

三、兩種教學法的優缺點

探究式教學

優點
  1. 培養獨立思考與提問能力。
  2. 練習分析問題、蒐集證據及解決問題。
  3. 從好奇心出發，可能提升學習動機。
  4. 促進跨領域連結、合作與溝通。
限制與風險
  1. 探索耗時，學習效率不一定高。
  2. 缺乏背景知識時，容易形成錯誤理解。
  3. 需要教師精心設計問題與鷹架。
  4. 學生能力差異可能造成參與落差。

直接教學

優點
  1. 能有效率地傳授核心知識。
  2. 學習架構清楚，容易由淺入深。
  3. 適合建立基礎知識與程序技能。
  4. 便於即時檢查理解並提供回饋。
限制與風險
  1. 若長期單向講授，學生容易被動。
  2. 可能偏重記憶，忽略原理與應用。
  3. 學生較少練習自行提出問題。
  4. 統一進度未必符合所有學生需求。
重要提醒：探究式教學不等於放任學生自行摸索；直接教學也不等於只要求學生死記。兩者的效果取決於教學目標、教師設計、學生先備知識與實施品質。

四、實際案例：為什麼不同季節的白天長度不一樣？

選擇同一個問題，比較兩種教學方式如何安排學習歷程。

探究式教學流程

  1. 提出問題：為什麼夏天白天較長、冬天白天較短？
  2. 提出假設：是否因為地球離太陽較近？或地軸傾斜？
  3. 蒐集資料：使用地球儀、燈光模型與季節日照資料。
  4. 分析證據：比較南北半球不同季節的日照時間。
  5. 形成解釋：以地球自轉軸傾斜及公轉說明日照差異。
學習重點：假設、證據推理、科學解釋。

直接教學流程

  1. 說明概念：教師介紹地球自轉軸傾斜約23.5度。
  2. 示範模型：用地球儀與燈光呈現太陽照射情況。
  3. 解釋原理：說明太陽高度角與白晝長度如何隨季節改變。
  4. 整理重點：學生記錄地軸傾斜、公轉、日照時間等概念。
  5. 練習檢核：完成圖表判讀與概念題。
學習重點：快速掌握核心概念與基本知識。

五、橋接兩者：引導式探究（Guided Inquiry）

引導式探究不是完全自由探索，也不是教師提供所有答案。教師先提供必要知識、工具與問題架構，再讓學生進行有方向的探索。

案例：為什麼工業革命首先發生在英國？

  1. 教師先講解工業革命的時代背景與基本概念。
  2. 提出核心問題：「為什麼工業革命首先發生在英國？」
  3. 提供地圖、人口、煤礦、貿易與技術發展等資料。
  4. 學生分組分析地理、經濟、科技及社會條件。
  5. 學生提出解釋，並引用資料支持觀點。
  6. 教師補充、修正並統整不同因素之間的關係。

七、整合式課程：三階段教學設計

可採用「直接教學 → 引導式探究 → 自主應用」的漸進安排，先建立知識，再練習思考，最後獨立運用。

第一階段

建立知識基礎

直接教學

教師講解核心概念、必要背景與基本方法。

目標：知道是什麼（What）
→
第二階段

分析與探索

引導式探究

教師提出問題，學生蒐集資料、分析、討論並提出解釋。

目標：理解為什麼（Why）
→
第三階段

自主應用與創造

自主探究

學生自行提出問題、設計方案、發表成果。

目標：能夠應用與創造（How）

課程示例：世界人口變化

1. 建立概念

講解出生率、死亡率、自然增加率、人口轉型與人口金字塔。

2. 比較分析

比較日本、印度與部分非洲國家的人口結構與變化。

3. 自主研究

研究少子化、人口老化或人口快速成長的社會影響，提出建議。

設計原則：學生越缺乏先備知識，越需要明確教學與鷹架；學生越熟悉領域，越能逐步承擔問題設定、方法選擇與成果評估的責任。

八、互動自我檢核

選出較適合的教學方式，送出後查看參考答案。這是概念檢核，不代表只有一種教法才正確。

1. 學生第一次學習分數除法的基本程序，哪種方式較適合作為起點？
2. 學生已理解人口金字塔，接著研究人口老化的社會影響，哪種方式較合適？
3. 探究式教學是否代表教師完全不介入？
4. 哪一種安排最能整合兩種教學法？

九、相關教育學者與理論

約翰・杜威（John Dewey）

經驗教育、做中學、反思性思考；強調從真實問題與經驗中學習。

傑羅姆・布魯納（Jerome Bruner）

發現學習；重視學生主動探索概念與知識結構。

列夫・維高斯基（Lev Vygotsky）

近側發展區；說明教師或同儕提供適當支持的重要性。

大衛・奧蘇貝爾（David Ausubel）

有意義學習、前導組織；強調先備知識與新知識的連結。

巴魯・羅森夏因（Barak Rosenshine）

教學原則；強調小步驟教學、提問、示範、引導練習與回饋。

理查・梅耶（Richard Mayer）

多媒體學習認知理論；關注工作記憶、認知負荷與教材設計。

十、總結：不是二選一，而是適時搭配

直接教學回答「如何有效掌握已知知識」；探究式教學回答「如何運用知識探索問題」。學生需要先有足夠的知識工具，才更能進行有品質的探究；而探究又能讓知識從記憶走向理解、應用與創造。

核心建議：不要把教學法當成二選一。依照學習目標、學生先備知識與任務難度，安排明確教學、引導探究與自主應用的比例。
