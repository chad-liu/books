# 農業發展大事記：從採集狩獵到智慧農業

農業的發展史，也是人類從依賴自然、定居生活，逐步走向城市文明、工業化與現代科技的歷史。從約一萬多年前的新石器時代農業起源，到今日的基因編輯、無人機與人工智慧，農業技術不斷改變人類的飲食、人口、經濟與社會結構。

以下按照**世界農業史的時間順序**，整理重要事件、技術突破及其歷史影響，並特別標示中國與臺灣農業發展的重要節點。

## 一、史前時代：農業的起源（約西元前12,000年～前3000年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 約西元前12,000～前10,000年 | 部分人類社群逐漸從狩獵、採集轉向栽培植物與定居生活 | 農業開始發展，但各地轉型的時間與方式不同。 |

| 約西元前10,000～前8000年 | 西亞肥沃月灣地區逐漸馴化小麥、大麥、豌豆等作物，並馴養羊、山羊等動物 | 為定居農業與畜牧業奠定基礎。 |

| 約西元前9000～前7000年 | 西亞部分地區出現較穩定的農業村落 | 人類逐漸形成以農作物和家畜為基礎的生活方式。 |

| 約西元前8000～前6000年 | 中國長江流域逐步發展稻作農業；黃河流域逐步發展粟、黍等旱作農業 | 中國南北逐漸形成不同的農業傳統。 |

| 約西元前7000～前5000年 | 南亞、東亞等地陸續發展不同形式的農耕與畜牧 | 農業並非由單一地區一次發明，而是在多個地區分別發展。 |

| 約西元前6000～前4000年 | 部分農業社群開始建造糧倉、儲藏穀物 | 農產品儲存能力提高，讓社群得以因應季節變化。 |

| 約西元前5000～前3000年 | 部分地區發展灌溉、犁耕與更複雜的農具 | 擴大可耕作土地，提高農業生產的穩定性。 |

| 約西元前4000～前3000年 | 美索不達米亞、埃及等地的灌溉農業與城市文明逐漸發展 | 農業剩餘支撐城市、行政組織、手工業與貿易。 |

**本階段的重大轉變：**人類逐漸由依賴自然提供食物，轉向主動管理作物、動物與土地。農業剩餘使人口增長、定居村落擴大，也為城市文明創造條件。[National Geographic Education](https://education.nationalgeographic.org/resource/shift-agriculture/?utm\_source=chatgpt.com)

## 二、古代文明：灌溉、農具與農業制度（約西元前3000年～西元500年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 約西元前3000年 | 美索不達米亞、埃及等地形成以農業為基礎的早期國家 | 農業稅收、糧食儲備與水利管理成為國家治理的重要部分。 |

| 約西元前3000～前2000年 | 印度河流域發展農業與城市聚落 | 農業支撐哈拉帕等城市文明。 |

| 約西元前3000～前2000年 | 中國逐步發展粟、黍、稻等作物的栽培與利用 | 不同地區形成多樣化的農業生產方式。 |

| 約西元前2000年以後 | 各地逐步改良灌溉、耕地管理與畜力耕作 | 人力、畜力與水利設施相互配合，提升生產效率。 |

| 約西元前1000年以前後 | 鐵器在部分地區逐漸普及 | 鐵製農具逐步改善土地開墾與耕作能力；各地普及時間不同。 |

| 約西元前500年～西元初年 | 中國農業逐漸發展鐵製農具、牛耕、水利工程及農業管理制度 | 農業生產與國家財政、人口管理密切結合。 |

| 西元前2世紀～西元2世紀 | 絲路等長距離交通網絡逐步促進作物、技術與商品交流 | 農業不再只受限於地方環境，也受到跨區域交流影響。 |

| 西元1～3世紀 | 中國農業知識、耕作技術與水利經驗持續累積 | 為後世農書、農業制度及精耕細作奠定基礎。 |

### 本階段的重要發展

1. **灌溉農業：**透過渠道、水庫、堤防與引水設施，讓農業不完全依賴降雨。

2. **農具改良：**由石器、木器逐步發展到青銅器、鐵器，部分地區開始廣泛使用畜力。

3. **農業制度化：**土地管理、租稅、糧倉與水利工程逐漸成為政府治理的一部分。

4. **農業支撐文明：**糧食剩餘使部分人口得以從事行政、軍事、商業、宗教與學術活動。

## 三、中古時代：精耕細作與農業知識累積（約500～1500年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 約6世紀 | 中國農學家賈思勰的《齊民要術》已成為重要農書 | 系統整理農作、畜牧、食品加工等知識。 |

| 約6～10世紀 | 中國持續發展稻作、旱作、農田水利與多樣化農業技術 | 農業生產逐漸形成因地制宜的耕作模式。 |

| 約7～10世紀 | 阿拉伯世界與其他地區的貿易網絡促進農作物與農業知識交流 | 作物、灌溉方式及栽培知識在不同區域之間傳播。 |

| 約8～12世紀 | 中國南方稻作農業持續發展，水利與農業技術逐漸成熟 | 南方農業在中國經濟中的地位日益重要。 |

| 約10～13世紀 | 中國部分地區逐步推廣較適合不同生長季節的水稻品種與耕作方法 | 在適宜條件下提高複種能力與土地利用率。 |

| 約11～13世紀 | 歐洲部分地區逐漸採用較有效率的犁具、畜力與輪作制度 | 改善部分農業區的耕作效率與土壤利用。 |

| 13世紀 | 《王禎農書》相關農業知識逐步累積，至元代成書 | 系統記錄農具、農作與農業生產技術。 |

| 14～15世紀 | 歐亞各地持續發展農業灌溉、作物栽培與農業市場 | 農業生產與區域商業的關係更加密切。 |

### 中國農業的重要特色：精耕細作

中國傳統農業逐步形成一套重視土地利用與資源循環的生產方式：

- **精細整地：**改善土壤條件與種植環境。

- **施肥養地：**利用廄肥、堆肥及其他有機材料補充地力。

- **輪作與複種：**依照作物特性、季節及水土條件安排耕作。

- **農田水利：**利用灌溉、排水與蓄水設施調節水分。

- **農書傳承：**把農業經驗整理成可供學習與參考的知識。

這些技術並非同時在所有地區普及，而是隨著環境、人口與社會條件逐步發展。

## 四、近世農業：全球作物交流與農業革命（1500～1800年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 1492年以後 | 歐洲與美洲之間的持續接觸，帶動作物、動物與農業技術跨洲流動 | 全球農業與飲食文化開始出現深刻變化。 |

| 16世紀 | 玉米、馬鈴薯、番薯、番茄、辣椒等美洲作物逐步傳入歐亞及其他地區 | 部分地區增加了新的糧食來源與經濟作物。 |

| 16～17世紀 | 甘藷、玉米等作物逐步傳入中國部分地區 | 在適合的環境中，這些作物有助於擴展旱地農業與糧食來源。 |

| 17世紀 | 荷蘭東印度公司統治臺灣南部部分地區，鼓勵水稻與甘蔗等作物生產 | 臺灣逐漸納入東亞海上貿易與農產品出口網絡。 |

| 17～18世紀 | 歐洲部分農業地區改良輪作、排水、農場管理與家畜選育 | 農業生產逐步朝提高土地與牲畜生產力的方向發展。 |

| 18世紀初 | 英國農業改良者傑斯羅・塔爾（Jethro Tull）推廣播種機等農具改良 | 促進播種作業機械化及農業技術革新。 |

| 18世紀 | 英國部分地區推廣作物輪作、家畜選育、土地改良與農場管理 | 常被視為英國農業革命的重要內容。 |

| 18世紀後期 | 農業改良與人口成長、城市化、工業化逐漸相互影響 | 農業生產方式與勞動力結構開始發生重大變化。 |

### 全球作物交流的影響

大航海時代以後，原本分屬不同大洲的農作物逐漸傳播到世界各地。

| 作物 | 原始馴化或起源區域 | 傳播後的重要影響 |

|---|---|---|

| 玉米 | 美洲 | 成為非洲、亞洲及歐洲部分地區的重要糧食與飼料作物。 |

| 馬鈴薯 | 南美洲安地斯山區 | 成為歐洲及世界其他地區的重要糧食來源。 |

| 番薯 | 美洲 | 在中國等地的部分區域成為重要的旱地作物。 |

| 番茄 | 美洲 | 逐漸成為歐洲、亞洲等地的重要蔬菜作物。 |

| 辣椒 | 美洲 | 傳入亞洲、非洲等地後，深刻影響地方飲食文化。 |

| 小麥 | 西亞等地的早期農業區 | 隨人口遷徙與農業交流，在世界各地廣泛種植。 |

| 水稻 | 亞洲多個早期農業區，主要馴化中心包括中國長江流域 | 逐漸成為亞洲及世界其他適宜地區的重要主糧。 |

**重要提醒：**作物傳播通常是逐步發生的，並非某一年就完成全球普及；同一種作物在不同地區的經濟與飲食影響也不相同。

## 五、工業革命：農業機械化與科學化（1800～1900年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 18世紀末～19世紀 | 農業試驗、植物學、土壤學與化學研究逐漸發展 | 農業知識逐步從經驗傳承走向系統性的科學研究。 |

| 1830年代 | 美國等地的收割機技術逐步改良，機械收割開始發展 | 減少部分農作物收割所需的人力與時間。 |

| 1837年 | 約翰・迪爾（John Deere）改良並製造鋼製犁具 | 改善部分土壤條件下的耕作效率。 |

| 19世紀中期 | 農業機械、鐵路與農產品加工業逐漸發展 | 農產品更容易大量運輸、加工與銷售。 |

| 1840年代 | 德國化學家尤斯圖斯・馮・李比希（Justus von Liebig）等人的研究促進農業化學發展 | 土壤養分與植物生長的關係受到更系統性的研究。 |

| 1840年代以後 | 鉀肥、磷肥等肥料的生產與使用逐步發展 | 農民可透過補充養分改善部分土壤的生產力。 |

| 19世紀後半 | 農業試驗站、農業教育與專業研究逐漸擴展 | 品種選育、病蟲害防治及施肥方法更加科學化。 |

| 19世紀末 | 農業機械、肥料、農產品加工與市場網絡進一步發展 | 農業逐漸成為與工業、交通和商業緊密相連的產業。 |

### 工業革命帶來的農業變化

1. **機械化：**部分耕作、播種與收割工作開始由機器取代人力。

2. **科學化：**土壤、植物營養與病蟲害研究逐漸成為農業改良的基礎。

3. **市場化：**鐵路與運輸技術使農產品能夠進入更廣大的市場。

4. **專業化：**部分農場開始集中生產特定作物或畜產品。

5. **勞動力轉移：**農業生產效率提高，與工業化、城市化及人口流動相互影響。

## 六、20世紀上半葉：現代農業的技術基礎（1900～1945年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 1900年代 | 拖拉機與內燃機動力逐步應用於農業 | 為大規模機械化提供動力基礎。 |

| 1909年 | 弗里茨・哈伯（Fritz Haber）展示由氮氣合成氨的關鍵方法 | 人工固氮技術取得重要突破。 |

| 1910年代 | 哈伯－博施法（Haber–Bosch process）逐步工業化 | 大量生產合成氨成為可能，進而促進氮肥工業發展。 |

| 1910～1930年代 | 農業研究、種子選育、肥料與病蟲害防治技術持續發展 | 農業生產逐漸建立在更系統化的科學研究之上。 |

| 1920～1930年代 | 拖拉機、收割機及其他農機在部分國家逐漸普及 | 提高農場作業效率，但不同國家和地區的普及速度差異很大。 |

| 1930年代 | 美國發生嚴重沙塵暴與農業危機，促使土壤保育受到重視 | 保護土壤、控制侵蝕及改善耕作方式成為重要議題。 |

| 1930～1940年代 | 植物育種、農業化學與病蟲害研究持續進步 | 為戰後高產農業的發展奠定基礎。 |

### 哈伯－博施法為何重要？

植物生長需要氮、磷、鉀等養分，其中氮是植物合成蛋白質及其他重要物質所需的元素。

哈伯－博施法使工業界能夠大規模生產氨，進一步製造氮肥。這大幅擴展了農業補充氮素的能力，但也帶來新的環境問題，包括水體優養化、氮循環失衡及溫室氣體排放。

因此，**現代農業的關鍵不只是提高產量，也包括有效利用養分並減少環境代價。**

## 七、綠色革命：高產作物與化學農業（1940～1970年代）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 1940年代 | 墨西哥的小麥育種研究逐步發展 | 為後續高產小麥品種的培育奠定基礎。 |

| 1944年 | 墨西哥啟動與洛克斐勒基金會合作的小麥改良計畫 | 透過育種、農藝研究與技術推廣提高小麥生產力。 |

| 1950～1960年代 | 高產小麥品種逐步在多個國家推廣 | 在具備灌溉、肥料與適當管理的條件下，部分地區的糧食產量大幅增加。 |

| 1960年代 | 高產稻作品種與相關農業技術逐步推廣 | 亞洲部分地區的稻米生產能力顯著提高。 |

| 1960年代 | 國際農業研究機構逐步發展 | 加強小麥、水稻、玉米等重要作物的育種與研究。 |

| 1960～1970年代 | 肥料、農藥、灌溉與機械化在部分地區廣泛應用 | 形成以高產品種與現代投入資材相配合的生產模式。 |

| 1970年 | 諾曼・布勞格（Norman Borlaug）獲頒諾貝爾和平獎 | 肯定其在高產小麥育種與糧食生產方面的貢獻。 |

| 1971年 | 國際水稻研究所（IRRI）育成的半矮性高產稻品種 IR8 等技術成果持續擴大影響 | 促進亞洲部分地區稻作生產的改良。 |

### 綠色革命的主要技術

- **高產作物品種：**提高適當條件下的單位面積產量。

- **化學肥料：**補充植物生長所需的養分。

- **灌溉設施：**減少部分地區因缺水造成的產量波動。

- **農藥與病蟲害管理：**減少部分病蟲害造成的損失。

- **農業機械：**降低部分耕作與收穫工作的勞力需求。

### 綠色革命的正反面影響

| 正面影響 | 潛在問題 |

|---|---|

| 提高部分地區的糧食產量 | 肥料與農藥使用不當可能造成環境污染 |

| 改善部分地區的糧食供應 | 高產技術常需要灌溉、資金及穩定的農業投入 |

| 降低部分主糧的生產成本 | 過度依賴少數品種可能降低農業生物多樣性 |

| 促進農業研究與技術推廣 | 小農可能因資金與資源不足而難以平等受益 |

綠色革命提高了部分地區的糧食生產能力，但其成果並非所有國家、所有作物與所有農民都能同等享有。

## 八、臺灣農業發展大事記

臺灣農業具有稻作、水利工程、甘蔗產業、農地改革、農業試驗研究與高價值農產品等特色。以下依歷史時期整理。

### 1. 原住民族與早期農業

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 史前時代 | 臺灣史前社群依不同環境發展採集、狩獵、漁撈及逐步形成的農業活動 | 農業型態隨地區環境與文化而異。 |

| 歷史時期以前至近代 | 臺灣原住民族發展小米、旱稻、芋頭等不同作物的栽培與利用 | 形成多樣化的傳統農業與食物文化。 |

| 17世紀以前 | 臺灣各地逐步發展不同的土地利用、漁撈及農作方式 | 農業與當地生態、部落生活及季節變化密切相關。 |

### 2. 荷蘭與明鄭時期（1624～1683年）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 1624～1662年 | 荷蘭東印度公司統治臺灣南部部分地區，鼓勵水稻、甘蔗等作物生產 | 農業與對外貿易逐步結合。 |

| 17世紀中葉 | 臺灣部分農產品透過貿易網絡輸出 | 稻米、糖等農產品逐步成為貿易商品。 |

| 1662～1683年 | 明鄭政權推行屯田、開墾及水利建設 | 農業生產同時支援糧食供應與軍政需求。 |

| 19世紀 | 稻米、糖等農產品持續參與區域貿易 | 農業與地方商業、港口及移民經濟關係更加密切。 |

| 1920年代 | 臺灣農業水利建設與農業技術改良持續推進 | 擴大部分地區的灌溉能力與農業生產條件。 |

上述時期的農業建設促進了水利、研究與產業發展，但也應放在殖民統治、農產品輸出及土地資源分配的歷史背景下理解。[國立自然科學博物館](https://www.nmns.edu.tw/ch/learn/museum-education/theme/Theme-000218/?utm\_source=chatgpt.com)

### 5. 戰後至現代（1945年至今）

| 時間 | 重要事件 | 歷史意義 |

|---|---|---|

| 1945年以後 | 戰後重建農業生產與水利設施 | 優先恢復糧食供應與農業生產能力。 |

| 1949年 | 推行「三七五減租」 | 調整地主與佃農之間的租佃關係。 |

| 1950年 | 推行肥料換穀制度 | 以肥料供應與稻穀繳交制度配合農業生產政策。 |

| 1951年 | 推動公地放領 | 調整部分公有土地的使用與所有權安排。 |

| 1953年 | 推行「耕者有其田」政策 | 促進土地改革，改變部分農村土地所有權結構。 |

| 1950～1960年代 | 推廣農業試驗、品種改良、肥料使用與機械化 | 提高部分作物的生產效率與單位面積產量。 |

| 1960年代 | 工業化與都市化加速，農村勞動力逐漸轉移 | 農業面臨勞力成本上升與結構轉型。 |

| 1973年 | 推動加速農村建設相關措施，並制定《農業發展條例》 | 農業政策逐步從單純增加產量，擴展至農村建設與產業調整。 |

| 1970～1980年代 | 農業機械化、農田整治與農業結構調整持續推進 | 因應勞動力減少與生產成本上升。 |

| 1990年代 | 有機農業與環境友善耕作逐漸受到重視 | 農業開始更加關注環境、土壤及生態永續。 |

| 1990年代後期 | 臺灣加入世界貿易組織（WTO）的準備與農業調整加速 | 農業面對更廣泛的國際市場競爭。 |

| 2002年 | 臺灣正式加入 WTO | 農業政策須在國際貿易規範、市場競爭與農民權益之間取得平衡。 |

| 21世紀 | 發展精緻農業、農產品品牌、產銷履歷及農業加工 | 提高產品附加價值，強化食品安全與市場辨識度。 |

| 2010年代以來 | 智慧農業、設施農業、感測器與自動化技術逐步發展 | 透過資料與科技改善農場管理，減少資源浪費。 |

| 2020年代 | 氣候變遷調適、農業韌性、淨零排放與糧食安全受到更多關注 | 農業發展的目標從產量擴展至永續、韌性與風險管理。 |

臺灣戰後農業政策的主要轉變，包括土地改革、提高生產力、農業機械化、產業結構調整，以及近年重視農民所得、糧食安全與永續發展。[國立自然科學博物館](https://www.nmns.edu.tw/ch/learn/museum-education/theme/Theme-000218/?utm\_source=chatgpt.com)

## 九、21世紀：智慧農業與永續農業

| 時間 | 重要發展 | 歷史意義 |

|---|---|---|

| 2000年代 | GPS、地理資訊系統與精準農業技術逐步發展 | 讓農民更精細地管理田區、肥料、水分與作物生長狀況。 |

| 2000年代 | 基因體學與分子育種快速進步 | 加快作物性狀研究與育種工作的發展。 |

| 2010年代 | 無人機、衛星影像與田間感測器逐漸應用於農業 | 協助監測作物長勢、病蟲害及灌溉需求。 |

| 2010年代 | 智慧溫室、環境控制與自動化灌溉持續發展 | 改善設施農業的環境管理與資源利用效率。 |

| 2010年代 | 垂直農場與室內栽培受到關注 | 在部分城市環境中探索節省土地、控制生長條件的生產模式。 |

| 2020年代 | 人工智慧逐漸應用於病蟲害辨識、產量預測、農場管理與機器人控制 | 提升農業決策的即時性與自動化程度。 |

| 2020年代 | 基因編輯、氣候韌性育種與耐旱作物研究持續發展 | 探索面對高溫、乾旱、病蟲害與極端天氣的解決方案。 |

| 2020年代 | 再生農業、土壤保育、節水灌溉及減少食物浪費受到重視 | 將土壤健康、生態保護與長期生產力納入農業管理。 |

| 現在及未來 | 發展資料驅動、低碳、智慧化與循環型農業 | 追求糧食供應、環境保護與農民收益之間的平衡。 |

### 現代農業的六項主要趨勢

| 趨勢 | 核心概念 | 代表技術或方法 |

|---|---|---|

| 精準農業 | 依照田區差異調整投入 | GPS、衛星影像、土壤感測器 |

| 智慧農業 | 使用資料與自動化管理農場 | AI、物聯網、農業機器人 |

| 生物技術 | 透過遺傳與分子研究改善作物性狀 | 分子育種、基因編輯 |

| 永續農業 | 維持長期生產力並減少環境損害 | 輪作、覆蓋作物、土壤保育 |

| 氣候智慧農業 | 降低氣候風險並提高適應能力 | 耐熱耐旱品種、節水灌溉 |

| 循環農業 | 減少廢棄物並重新利用資源 | 農業剩餘物堆肥、養分循環、能源回收 |

需要注意的是，智慧農業不一定代表所有工作都由機器取代；許多技術的核心仍是協助農民作出更精確的判斷，並提高有限土地、水資源與勞動力的使用效率。

## 十、農業發展的五次重大轉型

若要掌握整部農業史，可以把它概括成五次重大轉型。

| 轉型階段 | 核心變化 | 代表技術 | 對人類社會的影響 |

|---|---|---|---|

| 第一次：農業起源 | 從狩獵採集走向栽培與畜牧 | 作物馴化、動物馴化、儲糧 | 定居村落、人口成長、早期文明 |

| 第二次：傳統農業成熟 | 從簡單耕作走向精耕細作 | 灌溉、犁耕、施肥、輪作 | 提高土地利用率，支撐城市與國家 |

| 第三次：農業革命與機械化 | 從以人畜力為主走向機械與科學農業 | 播種機、收割機、拖拉機、人工肥料 | 提高勞動生產力，推動城市化與工業化 |

| 第四次：綠色革命 | 從傳統品種走向高產作物與現代投入 | 高產品種、化肥、農藥、灌溉 | 提高部分地區的糧食產量，同時帶來環境挑戰 |

| 第五次：智慧與永續農業 | 從大量投入走向資料化、精準化與韌性管理 | AI、感測器、無人機、基因編輯 | 兼顧糧食安全、資源效率與環境永續 |

這些轉型並不是前一階段完全消失、後一階段立即取代，而是不同農業模式長期並存，各地依照自然條件、經濟能力與社會需求採取不同發展路徑。[OUP Academic](https://academic.oup.com/edited-volume/56212/chapter/443858147?utm\_source=chatgpt.com)
