音樂家生平・莫札特

莫札特生平大事記

沃夫岡・阿瑪迪斯・莫札特（Wolfgang Amadeus Mozart，1756－1791）

莫札特是西方古典音樂史上最具代表性的作曲家之一，也是古典主義音樂的核心人物。 他以驚人的音樂天賦、優美而精確的旋律、精巧的音樂結構，以及對歌劇人物心理的深刻描寫聞名。

莫札特出生於奧地利薩爾斯堡，從小便展現出卓越的音樂才能。年幼時，他與姊姊在父親帶領下巡迴歐洲各地，為王室與貴族演奏。成年後，他離開薩爾斯堡，定居維也納，以自由作曲家、鋼琴演奏家及音樂教師的身分發展事業。

雖然莫札特只活了35年，卻創作了大量交響曲、協奏曲、歌劇、室內樂及宗教音樂，留下《費加洛婚禮》、《唐・喬望尼》、《魔笛》、《第四十號交響曲》與《安魂曲》等不朽作品。

他的音樂兼具優雅、平衡、戲劇性與情感深度，充分展現了18世紀啟蒙時代的藝術理想。Mozarteum Salzburg

二、莫札特生平分階段詳述

第一階段：神童誕生與童年巡演（1756－1766）

關鍵字：音樂世家、神童、歐洲巡演

1. 1756年：出生於薩爾斯堡

莫札特出生於當時神聖羅馬帝國境內的薩爾斯堡大主教領地。

父親利奧波德・莫札特是一名宮廷音樂家、小提琴家與音樂教育家，母親安娜・瑪麗亞則負責家庭生活。

莫札特是家中七名子女中最小的一個，只有姊姊瑪麗亞・安娜長大成人。

父親出版的小提琴教學著作在歐洲頗具影響力，也為莫札特提供了良好的音樂教育環境。

2. 1761年：五歲開始創作

莫札特在五歲左右已開始創作音樂，早期作品包括短小的鍵盤曲。

這些作品由父親記錄下來，顯示莫札特很早便能理解音樂的旋律、節奏與基本結構。

他的天賦不只表現在演奏技巧，也表現在快速理解與組織音樂材料的能力。

3. 1762年：首次前往慕尼黑與維也納

莫札特年幼時便與姊姊一起在宮廷演出，受到王室與貴族關注。

父親很快意識到，孩子的音樂才能不僅可以培養，也能成為家庭的重要收入來源。

因此，他安排兩名孩子進行巡演，讓他們在不同宮廷與城市展現才華。

4. 1763－1766年：西歐巡演

這次長途旅行持續約三年半，行經德意志地區、法國、英國、荷蘭與瑞士等地。

莫札特在巴黎與倫敦接觸當時重要的音樂家，也聽到各種不同的器樂與歌劇作品。

尤其在倫敦期間，他認識了約翰・克里斯蒂安・巴赫。這位作曲家是巴赫之子，也是古典主義音樂發展的重要人物。

歷史意義： 這些旅行使莫札特不只接受家庭教育，也能直接接觸歐洲各地的音樂傳統，為他日後融合不同風格奠定基礎。 Mozarteum Salzburg

第二階段：義大利之旅與早期歌劇創作（1769－1773）

關鍵字：義大利歌劇、作曲技巧、國際聲譽

1. 1769年：展開義大利之旅

莫札特與父親前往義大利，這是他學習義大利歌劇傳統的重要階段。

義大利當時是歐洲歌劇的核心地區，歌唱技巧、詠嘆調與舞台戲劇的發展尤其成熟。

莫札特透過實際觀摩、學習與創作，迅速掌握義大利歌劇的形式與特色。

2. 1770年：《本都王米特里達特》

莫札特為米蘭創作歌劇《本都王米特里達特》（Mitridate, re di Ponto，K.87）。

這部作品於1770年首演並獲得成功，顯示他即使年僅14歲，也已能勝任大型歌劇的創作。

3. 1771年：《阿斯卡尼奧在阿爾巴》

莫札特創作《阿斯卡尼奧在阿爾巴》（Ascanio in Alba，K.111），作品在米蘭演出。

這部作品的成功使他獲得更多委託，也進一步累積歌劇創作經驗。

4. 1772年：《盧喬・西拉》

《盧喬・西拉》（Lucio Silla，K.135）於米蘭首演。

這部歌劇展現莫札特對義大利正歌劇的掌握，也顯示他在旋律、人物情緒及聲樂寫作方面日益成熟。

5. 1773年：返回薩爾斯堡

莫札特結束義大利旅行後，回到薩爾斯堡宮廷工作。

此後，他繼續創作交響曲、弦樂四重奏、協奏曲與宗教音樂。

然而，他逐漸感到薩爾斯堡的音樂環境缺乏足夠的歌劇演出機會，也限制了他的職業發展。

第三階段：薩爾斯堡時期與尋找出路（1773－1781）

關鍵字：宮廷音樂家、鋼琴協奏曲、職業自主

1. 1775年：小提琴協奏曲創作

莫札特在1775年創作了五首小提琴協奏曲中的主要作品。

這些協奏曲展現他對獨奏樂器與管弦樂團之間互動的掌握，也兼具優雅旋律與演奏技巧。

其中第五號小提琴協奏曲（K.219）尤其受到後世演奏家喜愛。

2. 1777年：前往曼海姆與巴黎

莫札特希望尋找新的職位，因此與母親前往曼海姆及巴黎。

曼海姆當時擁有著名的宮廷樂團，其演奏技巧與管弦樂效果對歐洲音樂發展具有重要影響。

然而，莫札特未能找到理想的工作，旅途中也經歷了感情與經濟方面的挫折。

3. 1778年：母親在巴黎去世

莫札特的母親安娜・瑪麗亞在巴黎病逝，享年57歲。

這對莫札特造成沉重打擊。

他最終返回薩爾斯堡，重新接受宮廷職務。

4. 1779年：擔任宮廷管風琴師

莫札特重新進入薩爾斯堡宮廷服務，繼續創作宗教音樂及器樂作品。

不過，他對宮廷制度的不滿日益加深，尤其希望能自由選擇創作題材、參與歌劇製作，並獲得更好的經濟待遇。

5. 1781年：與大主教決裂

莫札特因職業自主與待遇問題，與薩爾斯堡大主教科洛雷多發生嚴重衝突。

最後，他離開宮廷，選擇定居維也納。

這是莫札特一生的重要轉折：他不再只是受僱於宮廷的音樂家，而是嘗試以自由作曲家、鋼琴演奏家及教師的身分維持生計。 Salzburg.info

第四階段：維也納的黃金時期（1781－1786）

關鍵字：自由作曲家、鋼琴協奏曲、婚姻、歌劇創新

1. 1782年：《後宮誘逃》成功

莫札特創作德語歌唱劇《後宮誘逃》（Die Entführung aus dem Serail，K.384）。

這部作品在維也納首演後獲得成功，證明他能夠在德語歌劇領域取得重要成就。

作品融合戲劇情節、喜劇元素與高難度聲樂技巧，也展現莫札特對不同文化音樂風格的掌握。

2. 1782年：與康絲坦采結婚

莫札特與康絲坦采・韋伯結婚。

兩人共有六名子女，其中只有卡爾・托馬斯與弗朗茲・克薩維爾・沃夫岡活過童年。

康絲坦采在莫札特逝世後，積極推廣其音樂，並協助整理與保存作品。

3. 1784年：加入共濟會

莫札特加入維也納的共濟會組織。

當時部分共濟會社群重視理性、道德、教育與人類平等，與啟蒙時代的思想環境有所聯繫。

這些觀念也可在莫札特後期部分作品中找到呼應，但不宜將他的所有創作都直接解釋為共濟會思想的產物。

4. 1785年：弦樂四重奏與海頓

莫札特與海頓建立音樂上的交流。

他將六首弦樂四重奏題獻給海頓，這組作品後來被稱為「海頓四重奏」。

海頓曾高度評價莫札特的才能，而莫札特也深受海頓在弦樂四重奏形式上的創新影響。

5. 1786年：《費加洛婚禮》

莫札特與劇作家洛倫佐・達・彭特合作，創作歌劇《費加洛婚禮》（Le nozze di Figaro，K.492）。

作品透過僕人、貴族與家庭成員之間的誤會、計謀與情感衝突，描寫階級、權力、婚姻及人性。

它不僅是一部喜歌劇，也反映了18世紀社會對貴族特權與人際關係的重新思考。

藝術成就： 莫札特將旋律、戲劇節奏與人物心理結合，使歌劇中的音樂不只是美麗的歌曲，也能推動情節並展現人物的複雜性。 Mozarteum Salzburg

第五階段：歌劇巔峰與交響曲成熟（1787－1788）

關鍵字：唐・喬望尼、最後三首交響曲、創作成熟

1. 1787年：《唐・喬望尼》

莫札特與達・彭特再度合作，創作《唐・喬望尼》（Don Giovanni，K.527）。

作品融合喜劇、悲劇與道德衝突，主角唐・喬望尼既具有魅力，也不斷挑戰社會規範，最終面對自身行為的後果。

這部歌劇在人物塑造、管弦樂寫作與戲劇結構上均達到極高水準。

同年，莫札特的父親利奧波德去世。

2. 1788年：完成最後三首交響曲

莫札特在1788年完成三部重要交響曲：

  • 第39號交響曲，降E大調，K.543
  • 第40號交響曲，G小調，K.550
  • 第41號交響曲，C大調，K.551，後世稱《朱彼特》

這三部作品展現他在交響曲形式、旋律發展、管弦樂配置及情感表現方面的成熟。

其中，第40號交響曲以小調調性與持續流動的節奏，營造出強烈而細膩的情感張力。

第41號交響曲則以宏大的結構與精密的對位技巧聞名，尤其末樂章將多個主題結合，展現高度複雜的音樂設計。

不過，這三部交響曲的確切首演日期及當時演出情況，仍有部分史料上的不確定性。

第六階段：晚年困境與最後的傑作（1789－1791）

關鍵字：經濟壓力、魔笛、安魂曲、英年早逝

1. 1789年：尋求新的經濟機會

莫札特的經濟狀況逐漸惡化。

儘管他仍持續創作、演出與教學，但收入不穩定，加上家庭支出，使他經常需要向朋友借款。

他前往德意志地區旅行，試圖尋找新的工作與贊助者。

2. 1790年：《女人皆如此》

莫札特與達・彭特合作創作《女人皆如此》（Così fan tutte，K.588）。

這部歌劇探討愛情、忠誠、試探與人性的弱點，透過複雜的角色互動與精巧的音樂安排，呈現喜劇表面下的心理深度。

3. 1791年：《魔笛》

莫札特在生命最後一年創作《魔笛》（Die Zauberflöte，K.620）。

這部德語歌劇結合童話、喜劇、宗教象徵與啟蒙思想。

劇中的塔米諾與帕米娜經歷考驗，逐步走向智慧與成熟；帕帕基諾則帶來幽默與世俗生活的氣息。

作品不僅擁有廣受歡迎的旋律，也展現莫札特將不同音樂風格融合的能力。

4. 1791年：《狄托的仁慈》

莫札特創作歌劇《狄托的仁慈》（La clemenza di Tito，K.621），並於同年9月在布拉格首演。

這部作品為皇帝加冕慶典而創作，屬於義大利正歌劇傳統，展現莫札特在嚴肅歌劇領域的深厚功力。

5. 1791年：《安魂曲》

莫札特晚年接受委託創作《安魂曲》（Requiem，K.626），但在完成作品前便去世。

這部作品融合莊嚴的宗教氛圍、戲劇性的合唱與深沉的情感，成為音樂史上最著名的安魂曲之一。

莫札特逝世後，作品由他的學生弗朗茲・克薩維爾・蘇斯邁爾等人接續完成。

關於委託者的身分與創作經過，後來流傳出許多傳說；現代研究則依據書信、手稿與其他史料，逐步釐清其中的事實。

6. 1791年12月5日：逝世

莫札特於維也納逝世，享年35歲。

他去世時，《安魂曲》尚未完成。

儘管生命短暫，他仍留下大量重要作品，涵蓋交響曲、協奏曲、歌劇、室內樂、鋼琴曲及宗教音樂。

莫札特的早逝也使他成為音樂史上最受關注的人物之一，但其藝術成就不應只以生命長短衡量，而應從他在不同音樂類型中的創新與成熟程度理解。 Salzburg.info

四、莫札特的音樂風格與歷史地位

1. 古典主義音樂的代表

莫札特的作品具有古典主義音樂常見的特徵：

  • 旋律清晰、自然流暢。
  • 音樂結構平衡而有秩序。
  • 重視主題之間的對比與發展。
  • 善於運用和聲、節奏與配器塑造情感。

但他的音樂並非只有優雅與平衡，也經常呈現焦慮、悲傷、衝突與戲劇性。

2. 歌劇中的人物心理描寫

莫札特最重要的成就之一，是將音樂與戲劇緊密結合。

在《費加洛婚禮》中，不同角色可以在同一段重唱中同時表達不同的情緒與意圖；在《唐・喬望尼》中，音樂則能呈現主角的魅力、傲慢與恐懼。

這使歌劇中的人物不再只是唱出單一情緒，而能呈現更複雜的心理變化。

3. 鋼琴協奏曲的發展

莫札特創作了大量鋼琴協奏曲，並將獨奏鋼琴與管弦樂團的關係發展得更加豐富。

鋼琴不只是展示技巧的工具，也能與樂團對話、競爭、合作，甚至共同推動戲劇性發展。

他的鋼琴協奏曲對後來的貝多芬及整個古典主義協奏曲傳統影響深遠。

4. 交響曲與室內樂的成熟

莫札特在交響曲與弦樂四重奏中，展現出對音樂結構的高度掌握。

他能將簡潔的旋律材料發展成複雜而完整的樂章，也善於透過不同樂器的音色，營造細膩的情感變化。

5. 對後世音樂家的影響

莫札特對後世作曲家產生了深遠影響：

  • 海頓： 與莫札特相互尊重，並在弦樂四重奏與交響曲傳統中形成重要交流。
  • 貝多芬： 深受莫札特的鋼琴協奏曲、歌劇與交響曲影響。
  • 舒伯特： 延續古典主義旋律與形式傳統，並發展更鮮明的浪漫主義抒情風格。
  • 後世歌劇作曲家： 從莫札特的角色塑造與重唱技巧中獲得重要啟發。

巴赫去世時，莫札特尚未出生；莫札特出生時，海頓已經24歲；莫札特去世時，貝多芬則只有21歲。

因此，莫札特處於巴洛克傳統逐漸轉向古典主義的歷史背景中，而貝多芬則在繼承莫札特與海頓的基礎上，進一步拓展音樂形式與情感表現。

六、總結：如何理解莫札特的一生？

莫札特的一生可以整理為六個階段：

神童誕生 → 歐洲巡演 → 義大利歌劇訓練 → 薩爾斯堡宮廷生涯 → 維也納自由作曲家時期 → 晚年歌劇與宗教音樂傑作。

他的一生雖然短暫，卻跨越了多種音樂類型，從童年鍵盤小品到大型歌劇、交響曲與宗教作品，都展現出驚人的創作能力。

理解莫札特，不能只把他看作一位天才神童，也不能只關注他的早逝與經濟困境。

莫札特真正的歷史地位，在於他將旋律的自然流暢、古典形式的平衡、歌劇人物的心理描寫，以及音樂的戲劇性融合成高度成熟的藝術語言。

這也正是他的作品在兩百多年後，仍然持續受到演奏家、研究者與一般聽眾喜愛的原因。
